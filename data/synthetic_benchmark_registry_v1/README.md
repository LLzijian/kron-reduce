# Synthetic benchmark registry v1

This checksum-locked registry is the algorithm-correctness evidence for the
M0-ESC modal and stability selectors. It is not IEEE39 performance evidence.

The three deterministic systems separate three questions:

- `swing4_b2_modal`: three shared electromechanical modes under mutually
  selective disturbances. It tests whether a shared physical equation can
  recover poles that are not uniformly visible in individual trajectories.
- `swing4_reciprocal_port_r1`: the same network plus one reciprocal passive
  storage port. It tests dynamic-state discovery and supply cancellation.
- `swing2_known_separatrix`: a damped two-machine pendulum with exact energy
  barrier 2. It tests region and margin certificates.

The equations are implemented in
`src/kron_reduce/synthetic/benchmarks.py`. `registry.json` freezes the input
parameters and quotient-space ground truth generated by that implementation.
The checksum file is authoritative for the registry artifacts.

Synthetic results may pass or fail implementation gates, but may never replace
held-out IEEE39 evidence or justify statements about the physical 39-bus
topology.
