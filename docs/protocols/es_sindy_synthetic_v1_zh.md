# ES-SINDy 共享恢复力形状辨识

本轮检验十机约化方程能否从 100 ms 可见历史起报，回收两个能量形状系数并准确预测未见激励。只做一次拟合，零系数方程提供起点参照。

## 方程与工况

复用固定耦合、逐机功角阻尼和互易常端口。势能在基波上加入 \(\beta_2\Psi_2+\beta_3\Psi_3\)，其中 \(\Psi_m=\cos(r_e)\Phi_m-m\cos(mr_e)\Phi_1\)，两项在参考点的曲率均为零。独立 NumPy 真值使用 \(\beta_2=0.10,\beta_3=-0.05\)，在 1.25 和 0.625 ms 步长生成同一组干净轨迹。使用预登记完整名单 train 24、val 12、test 12，按配对激励分割。用 train 计算可见状态尺度。真值记忆只用于生成和评分。

## 辨识与评分

每事件使用第 0 至第 100 ms 的 11 个可见点估计记忆，半径 1，无零中心先验。机械偏差功率零阶保持。以零系数方程的因果起报记忆传播观测路径，用 50 ms 动量积分窗口和两列有界最小二乘热启动。随后用完整 train 的 1 s 自由预测做 12 次 Adam 更新，学习率 0.005，系数范围为 \([-0.25,0.25]\)。更新 0、4、8、12 做完整 val 的 3 s 检查，取最低平方误差，平分取较早更新。每次前向都使用当前方程重新初始化。冻结后用 5 ms 和 2.5 ms 两档步长，在全部三个名单评分 3 s、8 s 轨迹和冻结判据的失步结果。

两个系数各自相对误差上限为 20%。50 ms 积分设计矩阵的最小与最大奇异值之比至少为 0.001。val 事件平均归一化 RMSE 的 3 s、8 s 上限分别为 0.01、0.02，冻结模型的 3 s 归一化平方误差至少减半，且零系数参照的平方误差超过 \(10^{-8}\)。完整 val 要求失步判断匹配，触发时间偏差至多 40 ms。三组必须完成覆盖和双步长核验。非零输入能量收支误差和惯性中心漂移上限均为 \(10^{-10}\)。

执行入口为 `python -m kron_reduce.workflows.machine_local_topology --stage es_sindy`。单次授权只使用独立生成的合成数据。既有空间重分配与库外失配的判定继续由各自协议管理。本轮证据适用于固定骨架下的两项形状辨识。
