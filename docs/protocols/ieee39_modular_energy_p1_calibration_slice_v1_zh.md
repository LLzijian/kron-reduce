# P1 实现片段登记：受限读取与公平损失校准

日期：2026-08-31。前驱源码快照：`adc0204`。分支：`codex/loop-p1-a03`。
这是 A03 候选获取后、模型单元门前的实现登记，不是新的科学运行或 acceptance。
不修改冻结的 A03 获取协议，不读取 IEEE39 原始轨迹，不推进状态机。

## 本轮固定选择

- 五组重新拟合采用 fit-only：尺度和参数只从 fit 估计；selection 只用于选参；internal audit
  仅在冻结后评价。不得把旧 fit+selection 检查点当成新 fit-only 起点。
- 本轮只实现受限 ZOH 读取、损失与组 2/3 的共同校准内核；闭包、整块删除重拟合、模态统计、
  正式五组执行器及科学验收仍是后续必需项。已有模型的校准不证明该模型此前只用 fit 训练。
- 视界固定 1/5/10 s、采样 0.01 s、1001 点、RK4 最大步长 0.01 s、seed 324。
- 角度损失采用边角差，速度采用 COI 速度。两种尺度沿用已有定义：全部 fit 目标的总体标准差，
  下限 1e-8；同一对照共用同一尺度。此处不声称尺度估计本身也有来源平衡。
- 每组使用相同全部 fit 事件、相同模块、同一起点和相同优化变量；每个物理块一个正缩放，
  范围 0.25—4；默认最多 16 次求解器函数评估，ftol/xtol/gtol 均为 1e-8。
  零参数仍为零；本轮检验损失原因，不宣称已完成全部系数搜索或发现新模块。
- 两组共同使用全部事件、三个视界。原损失在事件和视界间等权，角度/速度按坐标数分配；
  平衡损失在来源、线路、事件、视界、输出间逐层等权。每个单元内部按实际元素数归一。
  因共同修正了旧少量事件校准方式，新比较不是旧脚本逐步重放。
- 任何预测失败、非有限输出或覆盖缺失均拒绝该次校准并保留起点；不能丢弃事件、缩短视界
  或填写零误差。求解器失败也不能因为损失下降而接受。
- 正缩放作用于记忆端口的 Gram 算子，端口因子乘平方根；不改变连接的互易性。
  这不是对全部物理门的替代验收。

## 数据访问的实现约束

角色来自已冻结的候选角色清单，校验 SHA256、F1、角色互斥、完整 ID 集合和线路分组。
先验证整批请求，再打开 HDF5；禁止未知 ID、其他折、external/safety/test 或缺失事件子集。
仅读取固定 1001 点的 t/delta/omega、Pm[0]、平衡 delta0/Pm 和登记的惯量先验。
不构造 CanonicalStore 的完整事件对象；不访问 outcome、event_time、未来 Pm、Pe、电压或 extended。
单元测试采用新建合成 HDF5，并记录实际 dataset 切片请求。

## 必须通过的测试

1. 未授权请求在任何原始文件读取之前失败；已冻结清单改动、重号、跨角色线路及子集请求失败。
2. 所有登记事件—视界—输出单元均出现；来源样本重复不能增加该来源总权重。
3. 角度坐标重复不能压低速度的平衡权重；不完整或非有限预测不能被丢弃。
4. 相同核心模型的两条真实 RK4 校准路径共用数据、尺度、变量和预算，且不修改起点。
5. 端口缩放的互易结构保持；失败恢复起点；每单元梯度向量之和与完整残差 Jacobian 算出的
   总梯度一致，并额外对照总目标的有限差分。

本轮测试结果只支持实现正确性；不能写成 IEEE39 性能改善、完整模型单元门通过或科学接受。
