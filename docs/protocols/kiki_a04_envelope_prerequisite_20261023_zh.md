# A04：激励范围前置检查与合成机制合同

日期：2026-10-23。本协议在新合成结果产生前固定。合成真值检查适用既有synthetic correctness豁免，首次真实入口按当时的AGENTS范围规则拒绝。随后用户已明确采纳文末开发评价条文，生效范围见[授权登记](kiki_a04_development_authorization_20261023_zh.md)。本协议不开放任何source val/test轨迹。

**研究目的。** 验证100 ms历史表示是否保留已知系统的隐初值信息，以及算法在没有这些信息时能否给出正确结论。另检查固定表示接入现有正弦被动模型后，数值积分、物理恒等式和保存重放是否成立。这里不评价kiki精度，不比较训练算法的最终收益。

**固定真值。** 十节点质量为`linspace(1,2,10)`，完整45边刚度为`linspace(0.05,0.12,45)`。令Q为现有`coi_basis(ones(10))`，阻尼为`0.3 Q Qᵀ`，互易端口为`0.8 Q[:,:2]`，隐状态反对称矩阵为`[[0,-0.7],[0.7,0]]`，隐耗散为`diag(0.2,0.4)`。不可观测反例只将互易端口置零。所有量由解析公式确定，不拟合真实数据。现有checksum锁定合成注册表须先通过校验；上述十节点解析夹具作为本协议的补充，单独绑定生成代码哈希，不修改原注册数据。

**精确观测映射。** 采用上述模型的线性恢复力版本；可见初态和功率固定为零，平衡角为零。以状态方程的矩阵A及`exp(A t)`构造11个10 ms时刻从两维隐初值到20个可见通道的映射。B保留第0/5/10点，C保留11点，D采用A04固定三基摘要。可见通道尺度固定为1 rad与1 rad/s；噪声比较限定在各表示的这个欧氏范数下，不等同于真实传感器的完整误差模型。

每个映射报告秩、奇异值、最坏噪声放大`1/σ_min`；满列秩时，用已知方程的伪逆重建seed324生成的32个标准正态隐初值，并验证最坏奇异向量噪声方向的放大恒等式。重建最大绝对误差须≤1e-10。两个系统共享相同初值，三个表示也共享，不能重抽样挑结果。

零端口系统要求三个映射均为秩0并返回`REFUSE_HIDDEN_STATE_IDENTIFICATION`。这说明隐藏坐标没有获得观测支持，应删除相应记忆模块；不把它误说成已经证明可见未来不可预测。已知动力学下的秩2，也不等于同时辨认未知动力学与隐藏初值，更不证明kiki中的初值唯一。

**非线性数值机制。** 改用同参数的正弦恢复力，seed324依次生成平衡角、初始角度、转速和零和功率；幅度分别0.1、0.2、0.1、0.02。真实隐初值固定为`[0.3,-0.2]`，用5 ms RK4生成记录起点后3.1 s路径。取11点历史，预测起点0.1 s。对A/B/C/D分别构造已知动力学与固定随机线性编码器；编码器标准差0.01，所有参数固定，不进行梯度更新。

每种表示在同一个事件上检查：3 s真实时间范围10/5 ms归一化最大差≤1e-5；历史和未来全部点供能恒等式误差≤1e-8、惯量加权COI和绝对值≤1e-10；未来8 s两完整路径有限、AND失步判据相同、触发差≤20 ms、按A03冻结尺度的联合差≤1e-3；保存后重新加载的5 ms预测逐值相同。数值机制使用预先声明的20通道单位尺度，不冒充kiki的train尺度。A移除记忆端口和隐状态后检查；B/C/D使用各自真实特征维数。

**预算和停止。** 2个解析系统×3种表示，32个已知隐初值；4种非线性机制检查；优化更新为0。没有结构胜者选择，没有“最优seed”，不消耗A04真实12次拟合预算。任一检查失败保存工件并返回失败；不改阈值后重算同run。结果包括解析映射、初值、重建、数值检查、四个明确标注“未训练机制”的检查点以及代码/协议哈希。

**真实范围认证的现有缺口。** 当前`ExcitationEnvelope`保存边界与证据ID，`ExcitationEnvelopeRouter`执行域外拒绝；两者不负责证明边界内模型有足够准确性。历史材料中的离线范围也没有可直接移用的100 ms因果检测器或当前模型证据。因此本轮不能通过实例化一个边界对象完成认证。直接用train极值建立经验盒只保证已见数值落在盒内，不能保证盒内组合、未知隐初值或未来轨迹受到支持。

无需完整Level 6才能讨论输入适用范围，但必须先明确其认证含义与证据：固定输入特征、范围构造规则、模型及数据绑定、评价总体、误差/拒绝规则，以及谁验证这份证据。当前尚无这一登记。如果声称严格覆盖未知真实系统，还需要可验证的模型失配界或隐藏初值集合界；现有100 ms样本和能量恒等式不能单独提供这些量。

**打破评价与范围认证循环的条文。** 首次真实入口记录了AGENTS中的先后关系缺口：内部train/val允许开发，但没有定义首次认证前如何取得评价证据。Astra提出以下条文，用户于2026-10-23明确采纳；对应授权ID为`kiki_a04_development_20261023`，已写入AGENTS及机器可读政策：
