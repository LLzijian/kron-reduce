# 逐机隐状态完整 TASK3 首轮协议

2026-11-13。用户授权按完整数据集给出结果后继续研究。全量名单为 train 346、val 107、test 76，精确 ID 及来源绑定见本轮机器可读计划中的 `sources`。首次评价直接覆盖完整名单。

## 模型与训练

采用 A06 seed324 第240步模型的质量、正弦势能系数和阻尼作为固定可见骨架。L10 含十个隐藏状态，互易端口为 (C=P\operatorname{diag}(g))，只学习十个正耦合幅值与十个记忆时间。初始幅值为 \(\|C_{A06}\|_F/\|P\|_F\)，时间为 0.06 至 1.6 s 的十点几何序列。每次预测使用三次完整 Gauss–Newton 历史初始化，随后闭环传播100 ms，重置实测可见末点后自由预测。

固定40次 Adam 更新，学习率0.01、betas=(0.9,0.999)、eps=1e-8、梯度范数裁剪10。每次更新按来源限定ID排序，以64例一批累积完整346例的等权梯度。CPU float64，单线程，确定性运算。训练沿用1 s/3 s等权事件目标，各时域按实际可用点数归一化，步长0.005 s。历史与目标尺度分别由完整 train 的事件均方均值平方根给出，下限1e-5。输入仅含11点q/v、Pm[10]偏差和静态平衡信息。

拟合遇到非有限值、不可辨识历史或线性求解失败时终止更新，丢弃当前未完成的累积梯度，冻结上一个完整更新的参数。终点由固定更新数或数值失败规则决定。随后依然完成全部 train、val、test 评价。

## 冻结与评价

fit 阶段只解码 train/val缓存成员。模型参数和训练尺度保存并绑定SHA-256后，评价全部train及val。另行登记test阶段，绑定同一冻结清单及源码，拟合次数为0。test只报告。

全模型预测8 s，步长0.0025与0.00125 s，各角色按固定16例一批计算。批计算抛出数值异常时，按预留预算逐个隔离该批成员，每个成员每档步长最多一次。隔离调用使用相同模型、输入、历史求解器与步长。指标未达标不触发额外调用。

评分直接调用哈希绑定的TASK3 Campaign 2评价函数，报告1/2/5/8 s事件平均、pooled、CVaR10、最差归一化RMSE，以及物理RMSE、真实可用区间和未覆盖数。比较尺度为0.47675314588683515 rad与1.0033667249602924 rad/s。模型输出相对运动，共同频率输出约定为0，该通道误差单独保留。

真实标签采用冻结TASK3标签。预测依照TASK3的五点失步和末1秒安定规则。失稳为正类，完整报告TP/TN/FP/FN、准确率、可判定准确率、覆盖率和未决、数值失败数，并给出可判定样本上的召回、漏判和误报率。存在未决或失败时总体准确率为空，零分母为空。按每个样本保存预测轨迹和初始化储能、历史残差，供下一步定位初始化与动力学误差。

## 预算与交付

训练上限为1次拟合、40次更新、240次反向传播、1200次批轨迹、652800次Torch RHS、57600次切线RHS，QR/SVD/三角求解/投影乘法各41520次。分解计数按事件，RHS按批调用。短样本使实际步数降低。

train+val评价的最坏预算包含29个正常批和453个逐例隔离调用，双步长合计4820次轨迹、19434240次Torch RHS、694080次切线RHS，QR/SVD/三角求解/投影乘法各5436次。test对应81个批/逐例调用，合计810次轨迹、3265920次Torch RHS、116640次切线RHS，各分解/求解/投影乘法912次。正常批成功后不执行隔离。

每阶段只执行一次，保留不可变结果目录、实际操作账本、来源访问账本、冻结模型、完整评价与失败。模型晋升通过独立审查决定。本轮定位为首次真实L10学习与全名单比较，完整算法设计及后续判断见[研究方案](../research/kiki_machine_local_full_plan_20261113_zh.md)。
