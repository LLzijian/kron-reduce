# 被动记忆饱和的完整 TASK3 评估

冻结原 T0M1 更新 12、逐机功角阻尼、记忆增益和极点。角度增大时，记忆输入和反馈共用幅值 \(h_i=(1+\gamma s_i)^{-1}\)。只训练 \(\gamma\)，起点 0.2，范围 \([0,2]\) rad⁻²。复用原 100 ms 的 11 帧历史、先验 \(10^{-6}\)、记忆半径和起报机械偏差功率。 [合成验证](memory_saturation_synthetic_v1_zh.md)

单次拟合只用完整 train 346，共 12 次完整更新，批量 64、Adam 学习率 0.03、梯度裁剪 1。目标沿用 1 s 和 3 s 等权可见轨迹损失及真实可用时长。更新 0、4、8、12 在完整 val 107 双步长评分。\(\gamma=0\) 锚点从同方程的已核验 val 回执读取。

在正系数检查点中，优先选择完整可判定、无数值失败、稳定误报不增加、六项轨迹分数不超过 0.5、稳定样本 8 s 事件平均归一化 RMSE 不超过锚点 105% 的方程。符合条件时依次比较失稳检出数（高优先）、六项轨迹分数（低优先）和更新次数（早优先）。无合格正系数时，用覆盖缺口、误报、检出数、轨迹分数和更新次数排序后冻结一个正系数候选。合格候选还需比锚点多检出至少一个 val 失稳事件，才算改善失稳检出。

候选冻结后以 2.5 和 1.25 ms 完成 train 346、val 107、test 76 的全部轨迹与稳定性评分，保留失败及未决。另核查 train 的实际可用窗口内失步复现。test 使用既有固定比较名单，仅报告。执行入口为 `python -m kron_reduce.workflows.kiki_machine_local_topology --memory-saturation --stage fit`，冻结后使用 `--stage test`。 [TASK3 评分协议](kiki_official_train_test_v1_zh.md)
