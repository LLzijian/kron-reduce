## 1. 真值与人群

真值复用 `fixture("local", backbone="sine")`：十台机器，`m_i=1+0.1i`，完整图45条边刚度均为0.12，`D=0.08 BBᵀ`，`C=P diag(0.35+0.025i)`，`τ=geomspace(0.05,2,10)` s，隐藏旋转项为零。`P=I−m1ᵀ/Σm`、`Q=Pᵀ`；输入功率与静态平衡角均为零。

事件 j=0…63，`φ_j=2π(j+0.5)/64`，`k_j=floor(j/2) mod 10`。列向量初态为 `q_h=Q[0.03 sin(i+φ_j)]`、`z_h=0.05 cos(i+φ_j)`、`v_h=Q[0.02 cos(i+φ_j)+a_j e_(k_j)]`，其中偶数 j 的 `a_j=0`，奇数 j 的 `a_j=16` rad/s。train 为0…31，val为32…47，test为48…63。每个角色完整使用32/16/16个事件，不替换、不先缩小试算。

独立 NumPy 投影 RK4 生成0…8.1 s、间隔0.01 s的811帧，最大子步0.00125/0.000625 s，后者为参考；逐输出间隔使用原 `ceil(interval/max_step−1e−12)` 规则。全部64个事件的两档真值先生成并保存。历史尺度取参考train第0…10帧的逐通道RMS，目标尺度取第11…310帧，两者下限1e−5。

按相同八秒规则从真值派生标签，角色须实际覆盖失步与窗口内安定两类，历史100 ms内不得已触发。两档真值类别和触发采样点必须一致，可见最大归一化差≤1e−6。真值门失败后保留全部已有证据，停止新增候选预测，不改相位或数值档位。真值、标签、尺度及其哈希在候选评价前冻结。

## 2. 四组固定预测

预测对象为同一个局部L10方程族，所有参数冻结，encoder绕过。组名与操作范围前缀固定如下：

| 组名 | 可见刚度 | 预测起点隐藏状态 |
|---|---|---|
| matched_gn | 真值刚度 | 本模型三次因果GN历史求解的闭环末态 |
| matched_oracle | 真值刚度 | 参考真值在100 ms的隐藏状态 |
| mismatch_gn | 每条边真值刚度×1.10 | 失配模型自己的三次因果GN历史求解闭环末态 |
| mismatch_oracle | 每条边真值刚度×1.10 | 参考真值在100 ms的隐藏状态 |

刚度失配只把每条边0.12改为0.132，质量、阻尼、g、τ、输入与平衡点不变。四组预测起点的q/v均严格使用观测第十一帧。两个GN组从零隐藏初态开始，执行原三次同阶段RK4切线、薄QR与三角解，再重算实际历史；不增加迭代、正则、伪逆或line search。隐藏秩十、条件数≤1e8，状态与隐藏增量有限且幅度≤1e12。oracle组直接由共同的真实q/v/z起点开始未来，不额外求解历史。真实隐藏状态只用于这个合成诊断对照。

各组固定按train、val、test顺序评价，未来8 s/801点，两档子步0.0025/0.00125 s；两个GN档位各自初始化，oracle两档初态完全相同。每角色按固定事件顺序最多16例一批。若某档批量预测抛数值异常，仅对该批每事件按原档位隔离一次；其他档位独立继续。若正常返回但误差或分类门失败，不追加调用。一个角色或对照失败仍评价其余可执行角色和对照。

## 3. 评分和判读

全部事件都有完整、同长目标。报告各角色1/2/3/5/8 s的合并、q/v归一化RMSE、物理RMSE、最大误差和逐事件结果；主要比较量为事件等权的三秒合并归一化MSE。GN组另保存初始z与预测起点z的真值误差、估计/真实隐藏储能、最终历史残差、三次迭代初态和增量。

失步：未包裹角范围大于π且最大质量COI相对速度大于0.02 pu，同时连续五个0.01 s点；未失步且末100点角范围均小于π、速度均小于0.005 pu才记窗口内安定，其余未决。拼接11帧历史及不重复起点的未来。每组每角色给出TP/TN/FP/FN、完整名单准确率、可判定准确率、可判定失稳召回/漏判/稳定误报、未决/失败及覆盖。任一未决或失败使完整准确率为null，零分母为null。

候选数值门：全路径有限、质量COI误差≤1e−10，两档可见最大归一化差≤1e−5，类别一致，失步触发时刻差≤0.02 s。matched_oracle每角色三秒合并NRMSE≤0.001；matched_gn再要求每个事件的初始z和起点z的RMSE≤1e−4、按历史尺度归一化的历史最大残差≤1e−7。这里把原计划中的隐藏恢复门明确为逐事件要求，避免角色平均掩盖单例恢复失败；在执行前统一冻结。两匹配对照每角色分类与真值全部一致；失配对照无“必须恶化”的目标门。

对每事件及每角色固定输出三秒MSE差：`matched_gn−matched_oracle`、`mismatch_oracle−matched_oracle`、`mismatch_gn−mismatch_oracle`。第三项允许负值，表示该错误动力学下的初态补偿改善预测，不代表估计隐藏状态更真实。任何缺失对照令对应配对差为null并报告覆盖，不补零。结合隐藏误差和储能作机制判断，不将三项当作真实系统误差的可加分解。
