# 被动记忆饱和的最小合成验证

保留固定耦合、逐机功角阻尼和原记忆极点。逐机端口幅值乘以 \(h_i=(1+\gamma s_i)^{-1}\)，其中 \(s_i\) 为该机相邻边功角偏差的平方均值。驱动和反馈共用该端口。只学习全网共享的 \(\gamma\)。 [模型设计](../research/topology_memory_energy_rom_zh.md)

复用 S2 的干净十机已知真值及完整激励名单 train 24、val 12、test 12。独立 NumPy 真值取 \(\gamma=0.6\)，使用 1.25 和 0.625 ms 步长。每事件以 100 ms 的 11 帧历史估计记忆，半径 1，先验 \(10^{-6}\)。固定 \(\gamma=0\) 给出一项完整 val 3 s 参照。候选从 0.2 起步，通过完整 train 的 1 s 自由预测更新 12 次，Adam 学习率 0.03、梯度裁剪 1、系数范围 \([0,2]\)。在更新 0、4、8、12 以完整 val 的 3 s 平方误差选检查点。冻结后按 5 和 2.5 ms 两档步长评估完整三组。

验收要求系数相对误差至多 25%、train/val 记忆核相对误差至多 10%、val 3 s 平方误差至少降低 2%。val 逐事件的 3 s 和 8 s 归一化 RMSE 上限为 0.02 和 0.05，稳定性匹配，失步触发时间偏差至多 40 ms。完整三组要求可判定、惯性中心漂移不超过 \(10^{-10}\)、两档预测归一化差不超过 \(10^{-5}\)。非零输入储能收支残差上限为 \(10^{-10}\)，独立真值两档步长误差上限为 \(10^{-6}\)。本轮验收适用于固定骨架的饱和记忆未来预测。[既有 S2 证据](../reports/topology_memory_rom_synthetic_20261116_zh.md)

入口为 `python -m kron_reduce.workflows.machine_local_topology --stage memory_saturation`。
