# M1 因果 GN 先验与半径解耦消融

用上一轮冻结的 T0M1 加逐机功角阻尼方程，量化先验衰减和放宽记忆半径各自对首摆速度和稳定轨迹的影响。共享系数和预处理沿用 M1 第 0 步。使用冻结的来源限定名单 `train=346` 和 `val=107`。拟合、梯度、共享参数更新和 `test` 轨迹读取的上限均为零。一次完整执行，先通过合成回归，再登记阶段批准。[第 0 步回执](../reports/10_postfault_structure/unified_first_swing_fit_20261119_evidence.json) · [自适应 GN 回执](../reports/10_postfault_structure/unified_first_swing_probes_v2_20261119_evidence.json)

## 对照与参数网格

每个事件使用故障清除后的前 100 ms（11 帧）功角和转速、参考平衡点、惯量、图先验及起报点机械功率。用零记忆状态做一次历史前向，第 2–11 帧经冻结尺度归一化后计算 RMS 残差 \(r_0\)。保持五次 GN、起报点可见状态重置和机械功率零阶保持。沿用 \(\lambda_0=10^{-6}\) 和原半径 \(R\)。原硬球的先验施加于 \(z/R\)。软球取 \(z=a/\sqrt{1+\|a/(mR)\|^2}\)，先验施加于 \(a/R\)。因此固定先验的硬球到软球差异包含半径、映射和先验坐标的联合影响。同为软球的固定先验各行可以直接比较半径。

| 组别 | 先验 | 半径 | 来源 |
| --- | --- | --- | --- |
| 原固定 GN | \(\lambda_0\) | 硬球 \(R\) | 复用 M1 v1 完整双步长结果 |
| 原自适应 GN | \(\lambda_0/[1+(r_0/r_{\rm ref})^2]\) | 软球 \(2R\) | 复用 v2 完整双步长结果 |
| 仅衰减先验 | 同 v2 衰减式 | 硬球 \(R\) | 本轮复算 |
| 固定先验与软球 | \(\lambda_0\) | 分别取 \(1.4R,1.6R,1.8R,2R\) | 本轮复算，\(2R\) 补齐四组正交对照 |
| 高阈值联合方案 | 见下式 | 超过阈值采用软球 \(1.6R\) | 分别取 P85、P90，本轮复算 |

二次衰减式沿用 v2 的 `train` 中位数参考 \(r_{\rm ref}\)，两档步长分别计算历史残差。高阈值方案用 2.5 ms 历史残差和 311 个 `train` 稳定样本的线性插值分位数 \(Q\)，两个步长共用该门控。\(r_0\le Q\) 时精确沿用原硬球 \(R\) 和固定先验，\(r_0>Q\) 时采用软球 \(1.6R\)，先验为

\[
\lambda_h(r_0)=\frac{\lambda_0}{1+\left[\max(0,r_0/Q-1)\right]^2}.
\]

分位数仅用 `train` 计算，在读取 `val` 前连同七个新方案、评分和预算写入冻结记录。样本所属标签只用于计算 `train` 参考分位数和评分。每个事件的门控量从自身 11 帧历史重新计算。

## 通过标准

七个新方案均对完整 `train` 和 `val` 作起报后 8 秒自由预测。RK4 步长为 2.5 ms 和 1.25 ms。采用冻结 TASK3 2.5 ms 轨迹评分，1.25 ms 用于数值和分类一致性检验。弱动量见证与相对转速峰值分别在两个步长上计算。对两个旧对照使用相同原始窗和相同评分口径。

| 指标 | 标准 |
| --- | --- |
| 数值资格与覆盖 | 完整 `train` 与 `val` 数值合格，无缺失，覆盖 95 个 `val` 稳定样本的 8 秒记录、12 个 `val` 失稳峰值和 33 个 `train` 见证 |
| `val` 失稳检出 | 确认检出 12/12，或确认检出 11/12 且起报后前 500 ms 峰值欠估中位数相对固定 GN 在两档步长都至少下降 20% |
| `train` 分离速度见证 | 33 个固定见证的带符号残差中位数距零在两档步长都至少下降 20%，绝对残差中位数均不升高 |
| `val` 稳定轨迹 | 95 个事件的 8 秒归一化 RMSE 事件平均值不超过 0.24，稳定误报不超过 1 个 |

峰值为真值可用网格上的最大质心相对转速绝对值，欠估为实测减预测的峰值差。门槛使用逐例峰值差的正部中位数，另保存带符号和绝对中位数。未决与数值失败分别记录。用 `val` 检出数、误报数、未决数、稳定 8 秒误差、双步长较大的峰值欠估和见证中位数距零列出没有被其他方案全面超过的方案。逐例列出旧自适应 GN 新增的稳定误报和未决，以及旧模型漏判后获检出的 `val` 失稳样本，同时查验初始和起报时刻记忆储能。此次网格固定，报告适用于已用的 `train/val`。

## 执行预算

完整名单共 453 个事件。每个新方案做两档预测，合计 6,342 条。批量取 64 个事件，失败批次内按事件与方案隔离一次。另作两次主步长零记忆历史计算。缓存上限为一次静态、一次 `train` 和一次 `val` 读取。逐例预测和访问日志、阈值、见证、归档和 SHA256 回执保存在该次运行的独立目录。[执行配置](../../configs/experiments/unified_first_swing_gn_decomposition_v3.toml)
