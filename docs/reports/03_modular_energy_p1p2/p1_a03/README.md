<a id="doc-fe53e62f8cb8-问题与原则"></a>

#### 问题与原则

A02 在真实候选获取时，因旧结构结果含 `margin: NaN` 而无法写入严格 JSON。
旧文件是不可修改的证据，字段未定义不能被改为零、当作稳定裕度或藏入成功统计。
迁移的任务只是保存与索引旧证据，不是重新解释旧实验。

因此把两个不同职责分开：原始科学结果按字节复制；单模型声明和引用关系写进新的
严格 JSON 文件。旧原始文件可以保留历史格式，新的说明文件不能使用 NaN/Infinity。


<a id="doc-fe53e62f8cb8-拟定工件"></a>

#### 拟定工件

1. `legacy_structure_selection_result.json`：从旧运行原样复制，复制前后 SHA256 必须一致。
2. `candidate_structure_selection_explicit.json`：仅包含单模型数量、无路由声明、旧文件路径与
   SHA256、迁移方式和结论限制；不展开旧指标，不复制或重算旧稳定标签。
3. `legacy_format_audit.json`：记录旧文件是否含未定义数值、对应字段路径及处置方式
   `preserved_in_legacy_payload_not_claimable`。不得输出非有限 JSON 数值，也不得将其替换成
   有效数字或把缺值等同于“认证稳定”。
4. `artifact_hashes.json`：覆盖整个新运行的所有普通文件；原始文件与说明文件都必须登记。

说明文件使用 `kron_reduce.legacy_structure_envelope.v1`，格式审计使用
`kron_reduce.legacy_json_format_audit.v1`。未定义值用 JSON pointer 和字符串种类索引；
字符串内容恰好是“NaN”不视为未定义数值。重复 JSON 键含义不唯一，必须拒绝。
新说明不能新增科学指标或删除已发现的未定义值记录；核验时从冻结原文件重新生成预期说明并比对。

旧 `validation_summary` 和 `lineage` 是补录单模型、无路由声明的依据。如果它们冲突、字段
缺失或旧结构已有相反声明，应拒绝获取；不能强制覆盖成期望值。

<a id="doc-117492a48447-3-完整平衡目标函数"></a>

#### 3. 完整平衡目标函数

预登记单元 c =（来源、故障线路、事件、视界、输出）。输出分为角度与速度，视界为
1、5、10 s。每个单元的残差数组形状和采样时间固定；积分失败不能删除单元。

逐层等权给出单元权重：

`w_c = 1 / (来源数 × 该来源线路数 × 该线路事件数 × 该事件视界数 × 该视界输出数)`。

求解器残差为 `r_c = sqrt(w_c / N_c) × (预测 − 观测) / s_output`。
其中 N_c 是该单元的标量残差个数；s_output 仅由登记的拟合数据估计并冻结。
目标函数 `L = sum_c ||r_c||²`，避免较长时间窗或较多角度坐标自然获得更多权重。
误差坐标、角度是否采用边差、尺度下限必须在首次科学运行前写入唯一合同，不能看结果选。

实现时同时保存最终单元清单与权重，而不只保存几个来源权重。
原损失组和平衡组共享相同残差单元、物理模型和全部事件；差异仅为登记的权重。
10 s rollout 可为较短视界提供前缀，不能每个视界重新寻找更有利初值。

梯度按参数组保存每个单元的向量。独立计算的总梯度应等于各单元梯度之和；
平方范数份额用于识别支配来源、视界和输出，不能代替向量闭合检查。
80% 支配警报用于诊断，不改变既定轨迹验收阈值。


<a id="doc-117492a48447-4-数据边界必须体现在调用结构上"></a>

#### 4. 数据边界必须体现在调用结构上

读取顺序：只读角色清单 → 核验 fold/ID/角色集合 → 为被许可角色请求轨迹 → 创建模型输入。
任何不允许的 ID 必须在请求原始数组之前报错，不先读整批再筛选。
来源和故障线路只进入目标函数权重与统计，不进入 rollout 的动力学状态或分支。

把三类内容分开传递：

- 模型输入：清除状态、静态先验、登记的因果外部输入。
- 拟合目标：允许角色的角度、速度；闭包拟合若使用历史 Pm，只能作为训练目标并单独登记。
- 审计侧信息：来源、线路、角色；稳定标签不进入本轮拟合或选择。

observed Pm 的组 4 由独立条件上界入口处理。不能让主入口携带未来通道，再依赖布尔标记承诺不用。
fit 目标中的 Pm 与部署时未来 Pm 是不同访问行为，访问日志必须区分，不得一概填写 false。


<a id="doc-117492a48447-5-因果机械功率闭包先验证能量连接"></a>

#### 5. 因果机械功率闭包：先验证能量连接

以下是待合成验证的设计，不是已接受方法。

在去掉整体转动的速度坐标 v 中，令机械功率增量对应的力为 u。使用记忆状态 z：

`u = Bᵀ z`，`dz/dt = −D z − B v`，`D = Dᵀ ≥ 0`。

若摆动模型从该端口获得的功率为 `vᵀu`，给闭包储能 `H_z = zᵀz / 2`，则二者之和的
新增能量变化为 `vᵀBᵀz + zᵀ(−Dz−Bv) = −zᵀDz ≤ 0`。
这给出互接的设计依据；只检查 D 或另一个状态矩阵稳定不够。

十机 COI 坐标还必须验证力与速度为共轭变量。例如质量矩阵 M 下选取
`Qᵀ M Q = I`、`Qᵀ M 1 = 0`，令 `omega = Q v`，机械功率增量取
`delta_Pm = M Q Bᵀ z`，则 `omegaᵀ delta_Pm = vᵀ Bᵀ z` 且总增量为零。
实际实现必须与当前模型的质量、投影、功率单位及清除状态约定逐项对齐，不能直接套公式。

闭包秩、D/B 参数化、初始化、拟合目标及预算需在实验前冻结；没有训练可辨识性就不保留该状态。
若使用清除 Pm 的 ZOH 为基础输入，z 可表示其后的因果增量；不能通过真实未来 Pm 初始化 z。
核心和闭包的全部状态应在同一 RK4 步中耦合推进，不得忽略核心记忆状态或只用事后功率替换。

先用可解析合成系统验证供能恒等式、COI、维数/单位、步长收敛和零耦合退化，之后再评价 IEEE39。
合成正确性不替代 IEEE39 速度改善证据，不产生 Level 6 名称。

#### 6. 模块和模态路径

每个模块先做不重拟合的置零预测，再做删除整块并重新拟合剩余参数的预测。
两条路径分别记录，使用同一事件、视界与数值误差估计。删除重拟合不能只改模块名字。
共享极点从最终同一套方程得到；不同激励只决定哪些极点可见，不切换模型。
零端口、不可见状态和少于三条独立线路的视图必须被适当地剔除或标为未确定。

P1 已登记阻尼误差是绝对误差 0.05；总纲的最终模态门是 5% 的误差约束。
二者不能混称：P1 诊断通过不自动形成最终论文频率/阻尼主张，后续门需明确统计定义并单独通过。

<a id="doc-9cfcd996fb55-本轮固定选择"></a>

#### 本轮固定选择

- 五组重新拟合采用 fit-only：尺度和参数只从 fit 估计；selection 只用于选参；internal audit
  仅在冻结后评价。不得把旧 fit+selection 检查点当成新 fit-only 起点。
- 本轮只实现受限 ZOH 读取、损失与组 2/3 的共同校准内核；闭包、整块删除重拟合、模态统计、
  正式五组执行器及科学验收仍是后续必需项。已有模型的校准不证明该模型此前只用 fit 训练。
- 视界固定 1/5/10 s、采样 0.01 s、1001 点、RK4 最大步长 0.01 s、seed 324。
- 角度损失采用边角差，速度采用 COI 速度。两种尺度沿用已有定义：全部 fit 目标的总体标准差，
  下限 1e-8；同一对照共用同一尺度。此处不声称尺度估计本身也有来源平衡。
- 每组使用相同全部 fit 事件、相同模块、同一起点和相同优化变量；每个物理块一个正缩放，
  范围 0.25—4；默认最多 16 次求解器函数评估，ftol/xtol/gtol 均为 1e-8。
  零参数仍为零；本轮检验损失原因，不宣称已完成全部系数搜索或发现新模块。
- 两组共同使用全部事件、三个视界。原损失在事件和视界间等权，角度/速度按坐标数分配；
  平衡损失在来源、线路、事件、视界、输出间逐层等权。每个单元内部按实际元素数归一。
  因共同修正了旧少量事件校准方式，新比较不是旧脚本逐步重放。
- 任何预测失败、非有限输出或覆盖缺失均拒绝该次校准并保留起点；不能丢弃事件、缩短视界
  或填写零误差。求解器失败也不能因为损失下降而接受。
- 正缩放作用于记忆端口的 Gram 算子，端口因子乘平方根；不改变连接的互易性。
  这不是对全部物理门的替代验收。

### P1 实现登记：模块反事实与线路配对统计

<a id="doc-33ba3ac0963a-1-唯一对照及顺序"></a>

`CandidateBlockInstance`，不是单个系数。依次登记每个模块的单独干预及全部可选模块的

- 置零：复制参照，仅将该模块全部系数、双向端口耦合置零，保留其他参数和初始化规则。
  零秩端口不产生虚假隐状态。结构描述保留，以区分“关掉”与“删除”。
- 删除重拟合：从结构中删除整个实例，重新新建空参数模型，用完整 fit 拟合全部剩余系数，
  selection 只选择同一冻结 ridge 网格。再用与第 3 组相同的平衡损失、预算和物理组缩放校准。
  不从参照复制剩余数值系数，不用 internal audit 做拟合、尺度或超参数选择。

没有可选模块时仍直接执行空集合联合对照；只有一个模块时，单独和联合干预仍分别留证。

<a id="doc-33ba3ac0963a-2-必须从方程计算的物理量"></a>

#### 2. 必须从方程计算的物理量

在完整参照模型自身的预测轨迹上计算每个被干预模块的储能 U、从核心流入模块的功率 P
和耗散 D，保留 `dU/dt=P-D` 的独立差分核验。具体为：

- 非线性势能：原模型额外势能项；P 为边速度与额外恢复力的内积，D=0。
- 边耗散：U=0；P=D 为边速度与额外耗散力的内积。
- 节点暂态：U=tau*h²/2，P=omega·sqrt(gain)*h，D=h²。
- 衰减记忆：U=tau*z²/2，P=边速度·B*z，D=z²。
- 振荡记忆：U=(p²+w²*q²)/2，P=边速度·B*p，D=2*zeta*w*p²。

联合量由上述方程直接相加；同时保留净端口功率绝对值和各端口绝对值之和，避免相互抵消
被隐去。记录参数范数时，记忆模块使用 B Bᵀ 的范数，避免同一端口换一组等价基就改变结论。

物理量先保留原单位。归一尺度固定为 `E_ref=sum(M)*s_omega²/2`，
功率尺度为 `E_ref/1s`；s_omega 只能来自已冻结的 fit 尺度，不看审计结果调节。
供能恒等式误差同时保存原单位及归一值，不把归一后的误差冒充原门槛的数值。

纯耗散模块的 U 必须如实为零。现有“储能、端口、预测三个效应均非零”的独立支持判据
对纯耗散模块不适用；本片段只标明这一协议限制，绝不用累积耗散替代储能，或自动改门槛。
完整可辨识性与 profile 审计未接通前，任何非零效应都不获得独立支持裁定。


<a id="doc-33ba3ac0963a-3-预测与数值误差"></a>

#### 3. 预测与数值误差

每个事件只从同一清除状态作一次 10 s rollout，1/5 s 使用其前缀。

预测变化用冻结 fit 的边角尺度和速度尺度分别归一，再取两者均方的等权平方根。
不以数据标签、来源、线路、未来输入切换模型。

参照另用 0.005、0.0025 s 上限积分，保存与 0.01 s 的差异和收敛比；近舍入误差时比值记为
不可用而不是强填 16。数值误差不反过来调优模型。任何失败都保留三视界记录，不能删事件。


<a id="doc-33ba3ac0963a-4-配对线路统计"></a>

#### 4. 配对线路统计

每个来源、视界、输出都保留完整事件配对。先平均同一线路内的事件 RMSE，再平均线路；
总体再对来源等权。退化定义为“候选与参照均值之差 / 参照均值”，不是逐事件比例的均值。
保存配对差、两侧最差 10% 事件及其 ID，不能只报告总体平均。

固定 seed 324、2000 次成对线路 bootstrap，95% 百分位区间，不移动区间去包住点估计。
来源视图按本来源线路重采样；总体按线路出现的来源集合分层，在每层内成对重采样线路，
保留同一物理线路跨来源的相关性和各来源覆盖。一个来源至少三条线路、且至少三条线路
可在其分层中重采样，才输出该视图的区间；不足时点值只作描述，区间为未确定。
不同视图区间不是同时置信区间，不作额外显著性主张。

参照误差为零、任一重采样分母为零或非有限时，相对退化记为不可用并给出原因，

<a id="doc-e1a24206522f-2-闭包方程和限定范围"></a>

#### 2. 闭包方程和限定范围

令 M 为固定质量对角阵，Q 为固定节点顺序下确定性构造的基，满足
`Qᵀ M Q=I`、`Qᵀ M 1=0`。v 为对应速度坐标。
本轮选择可审计的一阶对角闭包族：`du_j/dt = -alpha*u_j - kappa_j*v_j`，
`kappa_j >= 0`，`u_j(0)=0`，共同衰减率候选固定为 `alpha = 0.2, 1.0, 5.0 /s`。
这是一项有边界的 P1 闭包诊断，不代表对所有闭包族的搜索，也不代表最终 P3 结构已经确定。

用状态 `u_j=sqrt(kappa_j)*z_j`，令 `G=M Q diag(sqrt(kappa))`，则
`delta_Pm=G z`、`dz/dt=-alpha*z-Gᵀ*omega`。
新增储能为 `zᵀz/2`，与核心互接后的新增能量变化为 `-alpha*zᵀz`。
能量式以固定清除 Pm 为基础，不随真实未来 Pm 改写势能。
零 kappa 坐标不产生隐状态；全零闭包如实退化为 ZOH，不能声称具有预测贡献。

对每个 alpha，使用 fit 的观测 Pm **作为训练目标**。令
`f(t)=integral_0^t exp(-alpha*(t-s))*v(s) ds`，由观测速度的分段线性插值精确递推 f，
再解来源—线路—事件等权的 `u≈-kappa*f` 非负最小二乘。
分母不超过 `1e-14` 的坐标记为未激励并置零，不作为已识别参数。
alpha 只由 selection 上完整因果闭环的平衡角度/速度损失选择，不读取 selection 的未来 Pm 来拟合。

test、F2--F5、未来 `Pm`、`Pe`、电压、标签、事件时长、有效掩码和故障元数据都不得进入

<a id="doc-741a69a8fe31-2-非负效应的线路区间"></a>

#### 2. 非负效应的线路区间

每个单模块置零和全部模块联合置零分别计算以下三个非负量：

1. 直接预测效应：参照与置零轨迹在冻结角度、速度尺度下的等权合成变化；
2. 储能效应：参照轨迹上该模块平均储能除以冻结 `E_ref`；
3. 端口效应：参照轨迹上该模块端口功率绝对值均值除以冻结 `P_ref`。

每个来源、1/5/10 s 视界先平均同一故障线路内事件，再对线路等权。总体再对来源等权，
但总体只作描述，不作为“某个激励视图支持模块”的替代。bootstrap 固定 2000 次、seed 324；
来源视图重采样本来源线路，总体按线路覆盖来源集合分层并复用同一物理线路的抽样计数。
少于 3 条线路或少于 3 条可重采样线路时，只保存点估计并记为 `UNDETERMINED`。

区间直接保存 2.5% 与 97.5% 分位数，不移动端点去包含点估计。点估计不在百分位区间内
并不等于数据错误；只要求点和两个端点有限、效应非负、下端不大于上端。现有
`EffectCI`/`DeletionDegradation` 的表示层需取消“点必须位于区间内”的额外限制，
但分类阈值和严格不等号保持不变。

若任一事件失败，则对应来源/视界保留全部事件与失败 ID，效应区间不可用，不从剩余事件
制造区间。非有限值、布尔伪装数字、重复单元或元数据不一致均拒绝；不加 epsilon。


<a id="doc-741a69a8fe31-3-与数值误差同单位的容差"></a>

#### 3. 与数值误差同单位的容差

每个来源/视界的预测数值误差取参照模型 `0.01` 与 `0.005 s` 最大步长之差在事件上的
95% 分位数；发生积分失败或非有限值则该视图不可裁定。固定
`tau_y = max(1e-3, 10 * numerical_q95)`。

物理误差取同一来源/视界全部参照事件和被审计模块的最大归一供能恒等式误差；固定
`tau_phys = max(1e-4, 100 * supply_identity_error)`。原单位 `1e-8` 物理门仍单独检查，
不能用归一量冒充原门槛。模块三个效应的区间下端都严格超过各自容差，才算已建立非零效应。


<a id="doc-741a69a8fe31-4-条件可辨识性矩阵"></a>

#### 4. 条件可辨识性矩阵

用最终结构在完整 fit 轨迹上重建与拟合完全相同的来源—线路—事件—窗口等权弱形式矩阵
`A`，不加入 ridge 行。列按自身均方根缩放；列尺度为零或非有限即拒绝。参数块以完整
模块实例划分，不能把一个端口的单个系数当作模块。

对模块列 `M`，其余当前参数列为干扰块 `N`。先用 SVD 形成 `N` 的数值列空间，再计算
`R = (I - P_N) M`。参考奇异值是完整活动矩阵的最大奇异值 `s_ref`；模块条件最小奇异值
为 `s_min(R)`：

- `sigma_ratio = min(s_min(R)/s_ref, s_min(A)/s_ref)`；
- `condition = max(s_ref/s_min(R), s_ref/s_min(A))`。

这样单参数模块即使与其他参数几乎共线，也不会因“一个奇异值的条件数恒为 1”而假通过。
SVD 数值秩容差只用于识别机器精度下的零方向，不能替代冻结的 `1e-6` 与 `1e6` 科学门。
若模块任一声明参数列在冻结弱解中被筛为零，完整实例不得获得参数可辨识结论。


<a id="doc-741a69a8fe31-5-正参数对数尺度剖面"></a>

#### 5. 正参数对数尺度剖面

秩通过仍不能代替实际损失剖面。使用完整 fit 弱系统和保存的 selected ridge，从空参数重新
求一次完整非负弱解；ridge 只作原拟合正则，不能计入观测秩。以该弱解为剖面中心，分别把
整个模块参数块固定为 `0.5` 倍和 `2.0` 倍，每次重新非负拟合全部其余参数。

比较目标为与原求解器一致的完整目标：加权弱残差平方和加同一 ridge 下的归一参数平方和。
剖面增量取两侧相对增量的较小值。基准目标严格为零、任一求解失败、剖面目标低于基准且
超过舍入容差或产生非有限值时，结论为未确定；不使用 epsilon 制造比例。

模块参数门保持冻结：`sigma_ratio >= 1e-6`、`condition <= 1e6`，且两侧中较小的剖面损失
增量必须严格大于 2%。等于 2% 不通过。剖面只说明弱辨识阶段的局部参数约束；它不替代
最终闭环置零效应、删除重拟合或 internal audit 轨迹证据。


<a id="doc-741a69a8fe31-6-支持视图与删除判定"></a>

#### 6. 支持视图与删除判定

候选支持视图固定为每个实际来源乘以 1/5/10 s；总体汇总不作为独立激励视图。对某个
来源/视界，直接预测、储能和端口效应都建立非零区间，参数秩和剖面都通过，并且同一
来源/视界的角度或速度删除重拟合退化区间下端严格大于 2%，才可记为该视图独立支持。

若非零与可辨识性通过，而所有登记的来源×视界×输出删除区间上端都不超过 2%，模块可记为
可替代。边界交叉、区间不可用或只有总体汇总通过均为未解决。单模块结论不能推出全部模块
联合退化为 B2；联合置零和联合删除重拟合必须直接按同一规则计算。

### IEEE39 模块化能量 P1：共享方程极点与局部可观测性冻结协议

版本：`ieee39_modular_energy_p1_shared_pole_observability_slice_v1`。本协议属于
P1 A03 的模型单元门证据片段，只回答“冻结模型的哪些方程极点能在已登记激励中
被局部观测到”。它不执行新的 IEEE39 拟合，不改变工作流状态，也不产生模型晋级
或论文级频率结论。


<a id="doc-0ebb6d70bb0e-1-第一性原理与本轮假设"></a>

#### 1. 第一性原理与本轮假设

振荡频率若要成为模型结论，必须是一个明确动态方程在平衡点附近的极点。轨迹
DMD 只描述有限窗响应中出现了什么，既不能创造模型极点，也不能把受迫、非线性
响应自动解释成系统本征频率。因此本轮严格分成两条不反向连通的路径：

1. 从冻结的第三臂因果模型及其平衡静态量计算一次共享方程谱；
2. 在模型和共享谱完全冻结后，按已登记激励视图读取 internal-audit 速度轨迹，
   只判断每个共享极点在该视图中是否可见。

本轮适用一个额外、可证伪的假设：所有 internal-audit 事件的 `mass`、`incidence`、
`equilibrium_delta` 和 `Pm_equilibrium` 经 float64 规范化后必须逐字节相同。当前冻结
角色的只读静态审计满足这一条件。若任一量不同，本轮返回 `INVALID_STATIC_FAMILY`；
不得利用轨迹 DMD 将不同运行点的极点事后聚类。运行点变化必须新开“方程极点分支
延拓”协议。


<a id="doc-0ebb6d70bb0e-2-冻结输入访问边界与父工件"></a>

#### 2. 冻结输入、访问边界与父工件

- 模型唯一来源是已校验五臂父工件的 `core3.npz`，即
  `current_zoh_balanced_loss`；先校验五臂工件清单、父 manifest、第三臂 checkpoint
  哈希和角色 manifest 哈希。
- 只允许读取完整 F1 `internal_audit` 角色；test、F2--F5、external validation、
  post-freeze safety 角色均保持锁定。
- 模型输入仍只有登记的平衡静态量和因果 `Pm_clear` ZOH。来源名、故障线路、事件
  名、未来 `Pm`、`Pe`、电压、稳定标签、有效长度和事件时间不得进入模型或方程
  极点计算。
- `source_dataset` 和 `fault_line` 只能在共享谱冻结后用于局部观测分组和线路级
  bootstrap；它们不改变模型、极点、DMD 参数或匹配门槛。
- 不读取 v8 checkpoint 作为模型输入。v8 的普通 DMD 和 observed-`Pm` DMDc 仅作为
  历史负证据：它们没有形成共享模态晋级，不能被改写成新模型的极点来源。
- 本轮不拟合、不重拟合、不选超参数、不估计损失尺度，也不改变任何父工件。


<a id="doc-0ebb6d70bb0e-3-共享方程极点"></a>

#### 3. 共享方程极点

先对四个平衡静态数组做形状、有限性和逐字节一致性检查，并记录共同静态签名。
只有检查通过，才从按事件 ID 排序后的第一个静态副本调用
`PrunableEnergyModel.modal_spectrum`。极点计算固定为：

- 频率范围 `0.05--5 Hz`；
- 平衡残差无穷范数不超过 `1e-7`；
- 储能 Hessian 正定；
- 能量归一化速度可见度不低于 `1e-3`；
- 输入--输出留数秩大于零；
- 只保留正虚部、诊断完整的 `equation_reportable_modes`。

所有内部极点和拒绝原因都保存，但只有上述方程可报告极点可进入局部观测审计。
共享极点 ID 由第三臂 checkpoint 哈希、共同静态签名、排序后极点序号及其复特征值
共同确定。轨迹结果不得增加、删除、合并或移动共享极点。


<a id="doc-0ebb6d70bb0e-4-轨迹局部观测算法"></a>

#### 4. 轨迹局部观测算法


<a id="doc-0ebb6d70bb0e-41-预登记视图与统计单位"></a>

##### 4.1 预登记视图与统计单位

激励视图固定为角色 manifest 中已有的 `source_dataset`，不得按结果拆分或合并。
独立统计单位为 `(source_dataset, fault_line)`。同一线路的多个清除时间是重复事件，
不能增加独立线路数。


<a id="doc-0ebb6d70bb0e-42-有限窗与坐标"></a>

##### 4.2 有限窗与坐标

每个事件使用完整登记的 `0--10 s`、`dt=0.01 s` 速度轨迹。先转换为
`sqrt(mass) * omega` 的质量加权 COI 坐标，再逐通道减去该有限窗均值。不得使用
未来 `Pm`、标签或其他目标通道辅助模态提取。

对共享极点的质量加权复速度振型，取其实部和虚部张成的实子空间并正交化。有限窗
能量占比定义为速度轨迹投影到该子空间后的平方能量与总平方能量之比；总能量为零
时占比记为零，不得用归一化制造可见性。事件门槛为能量占比不低于 `0.01`。


<a id="doc-0ebb6d70bb0e-43-多秩-dmd-与一对一匹配"></a>

##### 4.3 多秩 DMD 与一对一匹配

普通 exact DMD 仅作为经验响应描述器。每个事件固定计算 rank `4、6、8` 三个版本，
频率范围同为 `0.05--5 Hz`；不根据结果改变秩、时间窗或滤波。每个秩内，全部共享
极点与全部经验模态用 Hungarian 一对一匹配，代价为

`频率相对误差 / 0.05 + 阻尼绝对误差 / 0.05 + (1 - MAC) / 0.20`。

匹配后再应用硬门：频率相对误差不超过 `0.05`，阻尼绝对误差不超过 `0.05`，
复 MAC 不低于 `0.80`。一个经验模态在同一秩中不能支持两个方程极点。某个极点在
至少两个登记秩上通过，才算该事件的经验匹配通过；没有经验模态是诚实的“不支持”，
不是数值补零。

事件支持必须同时满足：共享方程极点有效、平衡/储能/留数秩/速度可见度门通过、
有限窗能量门通过，以及三秩中至少两秩匹配通过。逐事件保存全部候选和匹配，不能
只保存通过者。


<a id="doc-0ebb6d70bb0e-44-线路与-bootstrap"></a>

##### 4.4 线路与 bootstrap

一条线路的支持率等于该线路支持事件数除以完整登记事件数；线路支持门固定为
`>= 0.50`，沿用 v8 已登记的事件比例语义，但使用本轮更严格的方程极点来源和匹配
门。任何失败或缺失事件都保留在分母中。

每个视图固定执行 2000 次、seed 324、以独立故障线路为单位的有放回 bootstrap。
每次计算重采样线路中的支持线路比例，并记录：

- 原始线路支持率；
- bootstrap 2.5%/97.5% 分位区间；
- `bootstrap_support_probability`：重采样支持率不低于 `0.80` 的抽样比例。

视图只有在独立线路数不少于 3 且
`bootstrap_support_probability >= 0.80` 时才通过。少于 3 条线路必须先返回
`UNDETERMINED`，即使原始支持率为 100%。合法 bootstrap 未通过则为
`UNSUPPORTED`；协议、父工件、静态或数据合同破坏则为 `INVALID`。

一个共享极点只需在至少一个预登记视图中得到 `SUPPORTED`，即可记为本轮
`LOCALLY_OBSERVED`。若至少一个视图样本充分但全部不支持，则为 `NOT_OBSERVED`；
若所有视图都因线路不足而未定，则为 `UNDETERMINED`。该状态仍只是 P1 单元证据，
不等于五折核心模态或论文级频率主张。


<a id="doc-0ebb6d70bb0e-5-合成已知真值门与对抗测试"></a>

#### 5. 合成已知真值门与对抗测试

在接触新的 IEEE39 模态结果前，算法必须先通过已知线性振荡系统：

- 恢复登记的频率、阻尼和复振型，并使被充分激励的真值极点通过；
- 同一模型的不同激励可分别支持不同极点，最终仍是同一共享极点集合；
- 未激励极点、同频但错误振型、单线路 100% 支持均不得通过；
- 一个经验模态不得同时支持两个方程极点；
- 零能量、零端口、微小可见度、非平衡点、非正定储能和 DMD 数值失败不得被
  归一化或删样本后伪装成支持；
- 打乱事件顺序不得改变结论，复制同一线路事件不得增加独立支持，删除失败事件
  必须被合同拒绝。

合成门只能证明审计算法按设计工作，不能替代 IEEE39 模态证据。

### P1-A03：受限读取与公平损失校准实现

<a id="doc-34aca30d07c0-已实现"></a>

#### 已实现

1. **受限读取。** 请求必须包含完整、已登记的 F1 角色；未知 ID、混入其他角色、漏事件或
   请求锁定角色，会在打开 HDF5 前失败。只读取固定观测窗的角度、速度、清除时刻 Pm
   和平衡先验，不沿用会读入未来 Pm、标签和事件信息的旧完整事件接口。
2. **完整平衡目标。** 所有 fit 事件均进入 1/5/10 s 的角度与速度误差；按来源、线路、事件、

   挤压速度权重。尺度仅来自 fit，selection 和 internal audit 不能进入该校准入口。
3. **真实模型对照校准。** 两种损失使用相同模型起点、事件、尺度、物理参数组和求解预算，
   只改变权重。记忆端口按保持互易连接的方式缩放。原始模型不被修改。
4. **明确回退。** 预测失败、覆盖不全、非有限尺度、误差平方和溢出、超出参数边界或求解器
   失败均拒绝候选。即使误差下降，求解失败仍不能接受；失败时保留原参数、尺度和诊断记录。
5. **可检查的梯度。** 保存各误差单元对实际优化变量的梯度，与完整残差算出的总梯度及
   总目标有限差分对照，不能用绝对值之和代替向量相加。

<a id="doc-9db51f941cd9-本轮解决了什么"></a>

#### 本轮解决了什么

新审计把过去容易混淆的两件事彻底分开：

1. 频率只能来自冻结模型在共同平衡点上的方程极点；
2. 轨迹 DMD 只回答某次激励是否在有限窗内看到了该极点。

IEEE39 当前 internal-audit 角色的平衡静态量只读核对为同一族，因此本协议允许计算
一个共享谱。执行器仍会逐字节复核质量、结构、平衡角和机械功率平衡点；任一事件
不同就返回 `INVALID_STATIC_FAMILY`，不会用轨迹结果把不同运行点的极点拼在一起。

局部观测采用固定 rank 4、6、8 三个 exact DMD，对全部共享极点和经验模态先做一对一
全局匹配，再应用频率、阻尼和振型门。一个经验模态不能重复支持两个方程极点。
事件结果按故障线路汇总，固定执行 2000 次、seed 324 的线路 bootstrap；少于三条
独立线路时，即使表面支持率为 100%，结论仍为 `UNDETERMINED`。


<a id="doc-9db51f941cd9-合成真值与对抗结果"></a>

#### 合成真值与对抗结果

已知线性振荡系统证明：同一共享模型的两个极点可以分别由两个激励视图支持，不需要
来源路由或多模型；频率相同但振型错误、未激励的零能量极点、单线路重复事件和 DMD
失败都不能制造通过。

工件验收不是只核对哈希。验收器会从逐事件三秩匹配重新计算事件、线路、bootstrap
随机数流、置信区间和视图状态。增删改文件会失败；即使攻击者修改摘要后重新计算
整棵工件树哈希，只要事件数、线路支持或 bootstrap 不一致，仍会被拒绝。

这些结果只证明算法和证据链按设计工作，不能替代 IEEE39 性能证据。


<a id="doc-9db51f941cd9-与-v8-的一致性"></a>

#### 与 v8 的一致性

历史 v8 终态是 `MODAL_ENVELOPE_MAP_CREATED`：没有跨角色共识模态，observed-`Pm`
DMDc 也没有形成可晋级模态。新实现保留该负结论，并进一步收紧解释边界：v8 的
普通 DMD 与 DMDc 只能作为历史经验响应证据，不继承其 checkpoint，不把它们改写成
共享系统极点。


<a id="doc-9db51f941cd9-当前不能写入论文的结论"></a>

#### 当前不能写入论文的结论

- 不能声称 IEEE39 已识别出某个振荡频率或阻尼。
- 不能声称当前十机候选通过模态门或完整模型单元门。
- 不能将单视图、单线路或合成结果替代五折 IEEE39 证据。
- 不能使用 `stability-certified equivalent` 名称。

目前唯一可用的正面表述是：共享方程极点与激励局部可观测性的审计算法已在已知
合成系统上通过，并具备不可变、可重算的执行工件合同。
