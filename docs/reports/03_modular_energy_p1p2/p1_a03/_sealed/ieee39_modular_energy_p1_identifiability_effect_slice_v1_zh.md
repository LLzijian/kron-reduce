# P1-A03 实现登记：模块效应区间与条件可辨识性

日期：2026-09-01。起点 `04cfce9`，分支 `codex/loop-p1-a03`。
本登记只补齐模型单元门所需的软件路径；不改变 A01/A02 的数值门槛，不执行新的 IEEE39
科学运行，不推进 A03 状态机。

## 1. 输入、参照与禁止事项

唯一参照仍为已保存五组包的第 3 组：统一十机结构、`Pm_clear` ZOH、来源平衡损失。
效应审计只能读取已封存的反事实评价包；可辨识性只能读取完整 fit 角色和五组包中已冻结的
ridge、弱积分窗口及结构。selection 只允许通过已保存的 ridge 选择结果产生影响，不能再次读取；
internal audit 不能进入秩、尺度、剖面或门槛计算。

test、F2--F5、未来 `Pm`、`Pe`、电压、标签、事件时长、有效掩码和故障元数据都不得进入
模型或可辨识性矩阵。来源与故障线路只用于事后分层统计，不成为模型输入或参数路由。
所有输入目录和文件先核验完整清单与 SHA256；输出必须新建、失败保留、成功后封存。

当前 A03 候选只允许审计保存结构中的 `NODE_HIGH_ORDER`、`EDGE_MEMORY` 和
`RESONANT_MEMORY` 实例。这三类都有明确储能。若实际保存结构出现纯边耗散，旧三效应规则
固定返回协议不适用并停止支持裁定；不能在本 attempt 内把耗散改称储能或临时更换门槛。

## 2. 非负效应的线路区间

每个单模块置零和全部模块联合置零分别计算以下三个非负量：

1. 直接预测效应：参照与置零轨迹在冻结角度、速度尺度下的等权合成变化；
2. 储能效应：参照轨迹上该模块平均储能除以冻结 `E_ref`；
3. 端口效应：参照轨迹上该模块端口功率绝对值均值除以冻结 `P_ref`。

每个来源、1/5/10 s 视界先平均同一故障线路内事件，再对线路等权。总体再对来源等权，
但总体只作描述，不作为“某个激励视图支持模块”的替代。bootstrap 固定 2000 次、seed 324；
来源视图重采样本来源线路，总体按线路覆盖来源集合分层并复用同一物理线路的抽样计数。
少于 3 条线路或少于 3 条可重采样线路时，只保存点估计并记为 `UNDETERMINED`。

区间直接保存 2.5% 与 97.5% 分位数，不移动端点去包含点估计。点估计不在百分位区间内
并不等于数据错误；只要求点和两个端点有限、效应非负、下端不大于上端。现有
`EffectCI`/`DeletionDegradation` 的表示层需取消“点必须位于区间内”的额外限制，
但分类阈值和严格不等号保持不变。

若任一事件失败，则对应来源/视界保留全部事件与失败 ID，效应区间不可用，不从剩余事件
制造区间。非有限值、布尔伪装数字、重复单元或元数据不一致均拒绝；不加 epsilon。

## 3. 与数值误差同单位的容差

每个来源/视界的预测数值误差取参照模型 `0.01` 与 `0.005 s` 最大步长之差在事件上的
95% 分位数；发生积分失败或非有限值则该视图不可裁定。固定
`tau_y = max(1e-3, 10 * numerical_q95)`。

物理误差取同一来源/视界全部参照事件和被审计模块的最大归一供能恒等式误差；固定
`tau_phys = max(1e-4, 100 * supply_identity_error)`。原单位 `1e-8` 物理门仍单独检查，
不能用归一量冒充原门槛。模块三个效应的区间下端都严格超过各自容差，才算已建立非零效应。

## 4. 条件可辨识性矩阵

用最终结构在完整 fit 轨迹上重建与拟合完全相同的来源—线路—事件—窗口等权弱形式矩阵
`A`，不加入 ridge 行。列按自身均方根缩放；列尺度为零或非有限即拒绝。参数块以完整
模块实例划分，不能把一个端口的单个系数当作模块。

对模块列 `M`，其余当前参数列为干扰块 `N`。先用 SVD 形成 `N` 的数值列空间，再计算
`R = (I - P_N) M`。参考奇异值是完整活动矩阵的最大奇异值 `s_ref`；模块条件最小奇异值
为 `s_min(R)`：

- `sigma_ratio = min(s_min(R)/s_ref, s_min(A)/s_ref)`；
- `condition = max(s_ref/s_min(R), s_ref/s_min(A))`。

这样单参数模块即使与其他参数几乎共线，也不会因“一个奇异值的条件数恒为 1”而假通过。
SVD 数值秩容差只用于识别机器精度下的零方向，不能替代冻结的 `1e-6` 与 `1e6` 科学门。
若模块任一声明参数列在冻结弱解中被筛为零，完整实例不得获得参数可辨识结论。

## 5. 正参数对数尺度剖面

秩通过仍不能代替实际损失剖面。使用完整 fit 弱系统和保存的 selected ridge，从空参数重新
求一次完整非负弱解；ridge 只作原拟合正则，不能计入观测秩。以该弱解为剖面中心，分别把
整个模块参数块固定为 `0.5` 倍和 `2.0` 倍，每次重新非负拟合全部其余参数。

比较目标为与原求解器一致的完整目标：加权弱残差平方和加同一 ridge 下的归一参数平方和。
剖面增量取两侧相对增量的较小值。基准目标严格为零、任一求解失败、剖面目标低于基准且
超过舍入容差或产生非有限值时，结论为未确定；不使用 epsilon 制造比例。

模块参数门保持冻结：`sigma_ratio >= 1e-6`、`condition <= 1e6`，且两侧中较小的剖面损失
增量必须严格大于 2%。等于 2% 不通过。剖面只说明弱辨识阶段的局部参数约束；它不替代
最终闭环置零效应、删除重拟合或 internal audit 轨迹证据。

## 6. 支持视图与删除判定

候选支持视图固定为每个实际来源乘以 1/5/10 s；总体汇总不作为独立激励视图。对某个
来源/视界，直接预测、储能和端口效应都建立非零区间，参数秩和剖面都通过，并且同一
来源/视界的角度或速度删除重拟合退化区间下端严格大于 2%，才可记为该视图独立支持。

若非零与可辨识性通过，而所有登记的来源×视界×输出删除区间上端都不超过 2%，模块可记为
可替代。边界交叉、区间不可用或只有总体汇总通过均为未解决。单模块结论不能推出全部模块
联合退化为 B2；联合置零和联合删除重拟合必须直接按同一规则计算。

实现必须先在已知非零、已知共线和弱激励合成系统上验证：线路等权区间、跨来源共享线路、
条件奇异值、半倍/双倍剖面、边界严格性和失败保留。随后只生成软件 QA，不读取新的 IEEE39
轨迹，不输出模块支持结论。
