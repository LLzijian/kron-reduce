## 1. 论文目标

本项目面向 IEEE39 故障后轨迹，识别一个统一的模块化动态等值模型。不同暂态可以为不同动力学模块提供证据；所有通过支持门的模块组成同一个方程和同一个部署模型。模型的目标输出是：

1. 在已认证激励包络内准确重现功角和转速暂态；
2. 在数据支持时报告可辨识的振荡频率；
3. 保持显式储能、耗散与端口结构；
4. 在不做在线暂态积分的情况下给出稳定区域和稳定裕度；
5. 对认证包络外输入拒绝外推并说明需要补充的数据。

论文以 IEEE39 工程证据为主。合成系统只用于验证模块恢复、模态恢复和稳定证书算法的正确性，不能替代 IEEE39 性能证据。

## 3. 单模型模块并集原则

一个输入轨迹语料只产生一个冻结模型：

```text
完整训练语料
  -> 数据级空间损失审计
  -> 每个激励视图产生候选模块与支持证据
  -> 候选模块取并集
  -> 全语料平衡拟合一个能量结构模型
  -> 按整块非劣性删除
  -> 冻结一个模型和一个认证包络
```

激励振幅、信息丰富度和数据来源可以用于候选生成、分层审计和包络说明，但不作为模型输入，也不建立部署路由。联合目标按数据来源、故障线路、事件和时间窗逐级等权。

十机模型以摆动骨架为根，可包含以下可删除模块：节点暂态储能、非线性势能、边耗散、衰减记忆、振荡记忆和因果机械功率闭包。旧七节点参数不迁移到十机模型；任何保留模块必须重新辨识并具有非零、可审计的动力学贡献。

## 4. 统一 Loop Engineering 合同

每个 P1–P8 子任务使用独立工作流和新 run ID：

```text
方案登记
  -> 候选或数据获取
  -> 实现与单元门
  -> 源码冻结
  -> 受控实验
  -> 残差诊断
  -> 对抗审查
  -> 科学验收
       ACCEPT -> 人工 merge_gate -> 简明报告
       REJECT/RETRY -> rollback_report -> 简明报告
```

验收工件必须同时记录：

- `process_status`: 实现和证据链是否有效；
- `scientific_verdict`: `ACCEPT`、`REJECT` 或 `RETRY`；
- `promotion_decision`: `PROMOTE` 或 `KEEP_BASELINE`；
- `rollback_target`: 未晋级时继续使用的提交或模型 run；
- `claim_boundary`: 本轮可进入论文的结论；
- `paper_usable_claims`: 可写入正文或补充材料的主张列表。

只有 `ACCEPT` 可路由到 `merge_gate`，且 merge gate 必须显式批准。失败 run、负结论和哈希工件保持不变；活动模型指针回到最近一次已接受基线。不得通过放宽门槛或追加未登记数据挽救同一轮实验。

## 6. P1 必答问题

1. 保留模块是否实际改变预测、储能或端口功率；若输出变化低于数值容差，则视为零效应模块。
2. 长视界速度误差来自动力学闭包、因果机械功率策略、目标权重还是参数不可辨识；必须以冻结反事实逐项区分。
3. 模态结论必须使用共享方程极点和激励局部可观测性；轨迹 DMD 只说明某激励是否观测到该极点。

P1 的成功是获得可信诊断，不是把当前模型改成 `ACCEPT`。

## 7. P4 联合验收门

### 7.1 轨迹

- 1、5、10 s 全部零积分失败，最大 COI 漂移不超过 `1e-10`。
- 相对最强已接受因果基线，每个数据来源和视界的故障线路 bootstrap 95% 退化上界不超过 2%。
- 10 s 总体误差至少改善 5%，配对 bootstrap 的改善区间方向明确。
- 10 s 角度和速度分开报告；速度 pooled R2 必须为正且不低于基线。
- 最差 10% CVaR 不得通过牺牲尾部换取平均值改善。

### 7.2 模块

- 每个模块在至少一个预登记激励视图中具有独立故障线路支持。
- 参数、储能贡献和删除效应高于数值/可辨识性容差。
- 删除模块时重新拟合其余参数；只有全部登记视图和视界均非劣时才删除。
- 模块支持差异只改变统一模型的结构并集，不产生训练或部署路由。

### 7.3 模态

- 合成系统先恢复已知频率、阻尼和振型。
- IEEE39 的频率主张来自共享模型极点；每个被声明模态在至少一个激励视图达到 80% 故障线路 bootstrap 支持。
- 可对照模态的频率和阻尼误差不超过 5%，MAC 不低于 0.8。
- 核心模态需在五折中至少四折复现；未通过者仅作为内部状态。

### 7.4 物理与数值

- 参数有限，耗散半正定，动态端口互易。
- 平衡点和后故障平衡点的储能 Hessian 严格正曲率。
- 数值供能恒等式误差不超过 `1e-8`。
- RK4 步长收敛比处于 8–32，且不存在非有限轨迹。

## 8. P5 Level 6 数据与证书门

`ieee39_postclear_canonical_v1` 永不修改。新建带独立目录、manifest 和 checksum 的稳定边界审计数据版本，目标为至少 80 个独立失稳“故障线路 × 运行点”组及相应稳定边界内样本。相邻清除时间属于同一相关组，不能重复计作独立样本。数据生成、数值真值判定和模型证书评价使用分离代码路径。

Level 6 同时要求：

- 没有虚假稳定证书，95% FSR 上界不超过 5%；
- 至少覆盖 50% 的数值稳定包络内样本，防止空证书；
- 合成认证区域不越出真实区域，区域对称差不超过 20%；
- 归一化稳定裕度 MAE 不超过 10%，裕度排序相关系数不低于 0.8；
- 所有物理和数值门通过。

任一项失败时，模型不得使用 `stability-certified equivalent` 名称，P7 投稿证据冻结不得前进。

## 10. 固定假设

- 论文面向 IEEE 电力系统读者，IEEE39 是主要性能证据。
- 每个完整输入语料只形成一个模型。
- Level 6 无积分稳定证书是核心贡献。
- 最终确认使用 F1–F5 和 seed 324；不追加多 seed 作为失败补救。
- 主表使用 `Pm_clear` 零阶保持；observed `Pm(t)` 只作为冻结模型的条件输入敏感性。只有另行登记的 matched-input 证据才能称其为上界。
- test 不参与拟合、归一化、校准、选择或门槛生成。
- 作者、单位、基金、许可和数据再分发权限由人工 publication gate 补齐。
