### IEEE39 模块化能量等值 P2-A01：公平基线与评价合同


<a id="doc-47baf6d49d73-1-本阶段只回答什么"></a>

#### 1. 本阶段只回答什么

P2 不选择论文主模型，也不证明新方法优于基线。它只冻结一套可以复现、公平且不泄漏的比较条件，并在同一条件下重新运行所有主表基线。历史结果只能说明方法曾经实现过，不能把不同坐标、不同输入策略或已读取 test 的数字复制进主表。

P2 的科学成功是“比较合同可信且所有结果可追溯”，不是“某个模型误差较小”。模型失败必须原样记录，不能用删样本、改尺度或改变视界补救。


<a id="doc-47baf6d49d73-2-从第一性原理得到的公平条件"></a>

#### 2. 从第一性原理得到的公平条件

要判断两种动力学是否更好，除模型方程外，其余影响误差的因素必须固定。故主表统一固定：事件集合、空间坐标、清除时刻、可用输入、输出时间、归一化、积分时钟、失败定义、配对统计和计算预算登记方式。


<a id="doc-47baf6d49d73-21-数据与角色"></a>

##### 2.1 数据与角色

- 数据版本固定为 `ieee39_postclear_canonical_v1`，折为 F1，seed 为 324。
- P2 只从 F1 的 canonical training IDs 建立 `fit / selection / internal_audit`；canonical validation、test 和 F2–F5 全部锁定。
- 先按 `source_dataset × fault_line` 分组，再以 `SHA256(dataset_revision | source | fault_line | 324)` 排序；排序前不得读取轨迹、标签或稳定结果。
- 每个来源独立分配线路。16 条 high-order 线路分为 10/3/3，7 条 near-critical 线路分为 3/1/3，依次对应 fit/selection/internal audit。这样每个来源的内部审计至少有三条独立线路。
- 只有能覆盖完整 10 s 输出网格的事件进入轨迹合同。长度仅用于预先登记的视界资格判断，不能进入模型、路由或损失权重。
- 超参数只用 fit 拟合、selection 选择。选择冻结后，所有方法都可按同一规则在 fit+selection 上最终重拟合一次；internal audit 只读一次。


<a id="doc-47baf6d49d73-22-坐标与输入"></a>

##### 2.2 坐标与输入

- 所有主表模型使用原始十机、质量加权 COI 坐标。不得把七节点误差与十机误差并排作为优劣证据。
- 主输入只有清除状态、`Pm_equilibrium`、`Pm_clear`、平衡点及登记的质量/图先验。
- 主表中 `Pm_clear` 在清除后零阶保持。来源、线路、事件 ID、时间、稳定标签、`Pe`、电压、valid length、mask 和未来摘要均不得进入模型。
- observed `Pm(t)` 只在模型和超参数冻结后进入独立的“条件输入敏感性”入口。它不进入主表、部署、选择或参数重拟合，也不称为性能上界。
- 来源标签可以用于分层抽样、等权损失和分层报告，但不得决定模型分支或参数。


<a id="doc-47baf6d49d73-23-时间与数值求解"></a>

##### 2.3 时间与数值求解

- 清除时刻严格为 `t=0`；输出网格为 0–10 s、步长 0.01 s。报告视界为 1、5、10 s，分别使用含清除点的前 101、501、1001 个样本。
- 所有连续时间模型使用同一质量加权 COI RK4，最大内部步长 0.01 s；不得为某一方法单独缩短步长后隐藏其代价。
- 主表的数据驱动方法也必须输出连续时间右端项。原生离散 LSTM、直接时间映射 PINN 等不同求解语义只能进入补充材料，不能进入同积分器主表。
- 非有限状态、积分器异常、时间未覆盖或 COI 漂移超过 `1e-10` 均记为失败。失败样本不记零误差、不删除，也不只在成功样本上宣称总体改善。


<a id="doc-47baf6d49d73-3-主表基线定义"></a>

#### 3. 主表基线定义

所有物理模型均从空参数开始在十机坐标重新拟合，不继承七节点参数。

| 登记名称 | 最小定义 | 角色 |
|---|---|---|
| `B2-10-ZOH` | 二阶摆动骨架，非负阻尼与对称耦合 | 因果物理锚点 |
| `EGDF-10-ZOH` | B2 加应力门控暂态节点储能与训练支持的阻尼下界 | 暂态节点基线 |
| `GMDPM-10-CAUSAL` | 暂态骨架加稳定图记忆，并以只读 `Pm_clear` 与预测速度的 Hurwitz 机械功率 ODE 闭包 | 旧物理主线的十机因果重建 |
| `SSDM-10-ZOH` | B2 加瞬时边耗散和稳定边记忆，不含来源路由 | 强条件模型的因果重建 |
| `LIN-ODE-10` | 在同一状态和静态输入上的稳定线性连续时间模型 | 简单数据驱动下界 |
| `SINDYc-ODE-10` | 预登记多项式/三角函数库、组稀疏选择、连续时间 RHS | 稀疏数据驱动基线 |
| `NODE-MLP-10` | 固定容量候选网格的连续时间神经网络 RHS | 非线性数据驱动基线 |

`M0-3EG-DF`、`M0-GMD-PM` 和 `SS-DM` 在历史文档中的名称不自动转移“已接受”含义；P2 的新名称只表示方程家族和输入合同。


<a id="doc-47baf6d49d73-4-拟合选择和计算预算"></a>

#### 4. 拟合、选择和计算预算

- 损失按“来源等权 → 线路等权 → 事件等权 → 时间窗等权”汇总，避免样本多的来源支配参数。
- 角度和速度使用 fit-only 尺度；尺度算法、数值下限和 SHA-256 随运行保存。任何方法不得单独归一化评价目标。
- 每个基线保存候选网格、实际优化步数、墙钟时间、参数数目、提前停止原因和失败尝试。公平性依靠公开且合理的预登记预算，不通过故意削弱对照实现。
- 结构/超参数以 selection 的零失败优先，再比较统一归一化损失；并列时选更小模型。规则冻结后才打开 internal audit。
- 最终模型只能由 fit+selection 产生一个参数集；来源或激励不能生成在线路由模型。


<a id="doc-47baf6d49d73-5-统一评价与统计"></a>

#### 5. 统一评价与统计

- 每个事件、每个视界分别计算角度 RMSE、速度 RMSE和共同尺度下的联合误差。
- pooled \(R^2\) 按“事件 × 节点”的时间序列分别去均值后累加 SST，不能用跨事件全局均值制造较高数值。
- 报告 mean、median、pooled RMSE、角度/速度 pooled \(R^2\)、失败率、最差 10% 均值及对应事件 ID。
- 配对不确定性以故障线路为抽样单位，按来源分层，5000 次 bootstrap，seed 324。线路内所有事件整体保留；不得把事件当成独立线路。
- 少于三条线路的单元返回 `UNDETERMINED`，不得用点估计代替置信结论。本合同通过重新分层保证两个来源的 internal audit 均有至少三条线路。
- observed-Pm 敏感性与 ZOH 主表使用同一冻结模型和同一事件，但单独成表，标题明确写“非部署输入敏感性”。


<a id="doc-47baf6d49d73-6-p2-验收门"></a>

#### 6. P2 验收门

P2 只有同时满足以下条件才能 `ACCEPT`：

1. 七个主表基线均有统一 `fit / predict / save / load / access-audit` 接口；
2. 角色 ID、来源/线路数、fit-only 尺度和时间网格均有不可变哈希；
3. test、canonical validation、F2–F5、标签和未来通道访问均为空；
4. 所有连续模型经过同一 RK4/COI/失败语义；
5. 所有表格由新 run 生成，历史 headline 未被复制；
6. 重复加载检查点的预测一致；随机模型在固定 seed、确定性设置和登记容差内复现；
7. 对抗审查主动攻击坐标偷换、observed-Pm 混入、来源路由、样本删除、全局 pooled \(R^2\)、事件级伪 bootstrap、失败记零和弱化强基线；
8. 过程失败则修复实现后新开 run；单个模型科学表现差则如实保留，不据此否决公平合同。

P2 验收不产生“最佳模型”主张。只有公平基线合同及其不可变复现通过后，主工作流才允许进入 P3。


<a id="doc-47baf6d49d73-7-当前库存结论与回退"></a>

#### 7. 当前库存结论与回退

- 十机因果 B2 有可复用实现，但必须在 P2 新角色与新统计口径下重跑。
- 历史 M0-3EG-DF 报告未绑定当前可验证 run；只保留方法背景。
- 历史 M0-GMD-PM 是七节点登记配置，当前未找到匹配的不可变结果；必须重建。
- 十机 SS-DM 的现有强结果使用 observed `Pm(t)`；只能作为历史条件结果，不能进入因果主表。
- 旧 SINDYc/PINN/LSTM 结果使用七节点、多折多 seed 且已读取 test；全部数字隔离。

若某基线无法在统一接口下公平实现，P2 停止并报告缺口，不删除该强基线后继续比较。回退目标始终为 P1 保留的十机 B2 参考，不晋级任何 P2 模型。
