# Kiki 数据上的 P2-A03 五方案重跑协议

日期：2026-10-22。任务：使用 kiki 数据重跑 A03，形成同一数据队列上的横向比较。本任务在 kron-reduce 中执行，只读 kiki 原始数据，不接管其正在进行的研究任务，不改写其文件、Git 状态或调度状态。

## 数据、划分和时间

数据源固定为 `kiki/private_data/ieee39_postfault` 与 `ieee39_expansion`。只允许原 train 的 227+142=369 个 ID，原 val/test 的轨迹保持关闭。读取 splits/index 元数据以检查划分，不把元数据当作特征。

先在每来源内对排序后的完整故障线路组用 NumPy seed 324 打乱，取 `max(3,ceil(0.25*n_lines))` 组作新 val，其余作新 train。来源分别有 14、9 个线路组，因此取 4、3 组；同一线路和同一故障母线不能跨新 train/val。母线 1/2 的 Line_1 整组分配。分组在轨迹质量、长度、模型分数之前确定，不按标签改分组。

历史固定为前 21 个真实采样点，预测从第 21 点即原始时钟 0.2 s 开始，未来最多 3 s。至少需要 22 个点；元数据预计 30 个事件不足，保留其 ID 和理由，不参与该任务预测。其余预计 339 个事件全部参与；未来不足 3 s 的事件使用真实可用区间，不补出真实目标。

原数据频率为绝对标幺值：先减 1、乘 `omega_s`，再转惯性中心坐标，单位 rad/s。角度转同一坐标后减静态平衡点。有效质量为 `inertia/omega_s`；两来源惯性和通道顺序必须一致。功率只读 `Pm[0]-Pm_equilibrium`，作平衡投影后保持常值。不得读取未来 Pm、Pe、电压或真实高阶状态。原始标记的记录延迟不作为输入；本任务以数据登记的 t=0 为时钟原点。

## 五方案与预算

保留 A03 的全部五组：无记忆正弦、正弦历史、线性历史、取消历史一致性损失的正弦历史、闭环目标为 1 s 的正弦历史。其余均为 1/3 s 多时长目标。隐状态数 0/2、3 帧线性编码器、seed 324、float64 CPU 单线程、每组 80 次 Adam 更新、学习率 0.01、编码器均方惩罚 1e-4、梯度范数 10，保持原值。

共享动量积分初始估计与尺度均从新 train 最多 3 s 的真实数据得到。单时长方案只改变后续闭环目标，不改变初始估计和尺度。变长分支在每条样本最后一个真实积分端点补一条积分约束并去重，确保不足 0.1 s 的真实未来也参与初始估计；默认完整时钟分支保持原算法。

对于事件 i 与时长 H，真实未来步数 `m_i,H=min(N_i-21,round(H/0.01))`。各事件在其真实 `m_i,H` 个点、20 个可见通道上计算归一化均方误差，再按来源→线路→事件等权，各时长等权。未来不足 1 s 时，两时长损失使用同一真实区间。历史损失与编码器惩罚按原协议加入。

变长批处理的空余存储只用于张量形状，缺失点损失权重严格为零，不是模型输入、不作为观测保存。积分只推进仍有目标的事件，已结束事件不继续生成无标签尾部。主模型预测接口不接收长度或掩码。

固定五次拟合，无加预算、重挑 seed 或按成绩续训。实现错误可在训练前通过测试修复；实际运行若出现错误保留失败 run，不覆盖，不为跨越科学门槛重跑。

## 评分、冻结与横向比较

每组都报告 train、val：

1. 截至 1/3 s 的真实可用区间：固定所有历史合格事件，按实际点数归一化，作为本轮选择指标。
2. 完整 1 s 子集和完整 3 s 子集的覆盖数；完整 3 s 的同一队列同时报告 1/3 s，便于与上一轮固定时长任务对照。
3. 物理单位角度/转速 RMSE、事件归一化 RMSE 均值与中位数、失败数、最长时长的来源分层线路配对区间。
4. 固定上一轮 train 尺度重算完整 3 s 队列分数，区别于本轮自身 train 尺度。跨数据集样本分布不同，不把其分数差写成模型改善。

按本轮 val 可用区间多时长归一化 RMSE、参数数、名称依次选择。候选全部保存并冻结，不做 train+val 重拟合。沿用探索检查：非零记忆、归一化 RMSE≤0.35、相对同方程置零与无记忆各改善至少 10%，以及全部候选供能恒等式≤1e-8、0.01/0.005 s 步长状态差≤1e-5。通过记 ACCEPT，否则 RETRY；均不替换基线。新选择指标的可用区间定义已改变，不能称为原完整时长验收通过。

冻结之后，在同一新 val 上增加原 A03 冻结正弦历史模型的无重训对照；用本轮 train 尺度评分并另报共同参考尺度。检查其唯一惯性通道排列、频率和单位，保存身份对齐证据。该对照是未适配的研究性迁移诊断，不是认证范围内的部署或泛化保证。原模型哈希与参数不能改变。

任何预测数值失败保留原队列，整体分数为空，不删除事件或记成零。完整时长子集不代表全部语料，必须与可用区间表并列。没有独立 test、稳定证书、节点聚合、P3 或正式部署结论。
