### A04：激励范围前置检查与合成机制合同

日期：2026-10-23。本协议在新合成结果产生前固定。合成真值检查适用既有synthetic correctness豁免，首次真实入口按当时的AGENTS范围规则拒绝。随后用户已明确采纳文末开发评价条文，生效范围见[授权登记](../a04_development/README.md#doc-b7d1691b98bd)。本协议不开放任何source val/test轨迹。

**研究目的。** 验证100 ms历史表示是否保留已知系统的隐初值信息，以及算法在没有这些信息时能否给出正确结论。另检查固定表示接入现有正弦被动模型后，数值积分、物理恒等式和保存重放是否成立。这里不评价kiki精度，不比较训练算法的最终收益。

**固定真值。** 十节点质量为`linspace(1,2,10)`，完整45边刚度为`linspace(0.05,0.12,45)`。令Q为现有`coi_basis(ones(10))`，阻尼为`0.3 Q Qᵀ`，互易端口为`0.8 Q[:,:2]`，隐状态反对称矩阵为`[[0,-0.7],[0.7,0]]`，隐耗散为`diag(0.2,0.4)`。不可观测反例只将互易端口置零。所有量由解析公式确定，不拟合真实数据。现有checksum锁定合成注册表须先通过校验；上述十节点解析夹具作为本协议的补充，单独绑定生成代码哈希，不修改原注册数据。

**精确观测映射。** 采用上述模型的线性恢复力版本；可见初态和功率固定为零，平衡角为零。以状态方程的矩阵A及`exp(A t)`构造11个10 ms时刻从两维隐初值到20个可见通道的映射。B保留第0/5/10点，C保留11点，D采用A04固定三基摘要。可见通道尺度固定为1 rad与1 rad/s；噪声比较限定在各表示的这个欧氏范数下，不等同于真实传感器的完整误差模型。

每个映射报告秩、奇异值、最坏噪声放大`1/σ_min`；满列秩时，用已知方程的伪逆重建seed324生成的32个标准正态隐初值，并验证最坏奇异向量噪声方向的放大恒等式。重建最大绝对误差须≤1e-10。两个系统共享相同初值，三个表示也共享，不能重抽样挑结果。

零端口系统要求三个映射均为秩0并返回`REFUSE_HIDDEN_STATE_IDENTIFICATION`。这说明隐藏坐标没有获得观测支持，应删除相应记忆模块；不把它误说成已经证明可见未来不可预测。已知动力学下的秩2，也不等于同时辨认未知动力学与隐藏初值，更不证明kiki中的初值唯一。

**非线性数值机制。** 改用同参数的正弦恢复力，seed324依次生成平衡角、初始角度、转速和零和功率；幅度分别0.1、0.2、0.1、0.02。真实隐初值固定为`[0.3,-0.2]`，用5 ms RK4生成记录起点后3.1 s路径。取11点历史，预测起点0.1 s。对A/B/C/D分别构造已知动力学与固定随机线性编码器；编码器标准差0.01，所有参数固定，不进行梯度更新。

每种表示在同一个事件上检查：3 s真实时间范围10/5 ms归一化最大差≤1e-5；历史和未来全部点供能恒等式误差≤1e-8、惯量加权COI和绝对值≤1e-10；未来8 s两完整路径有限、AND失步判据相同、触发差≤20 ms、按A03冻结尺度的联合差≤1e-3；保存后重新加载的5 ms预测逐值相同。数值机制使用预先声明的20通道单位尺度，不冒充kiki的train尺度。A移除记忆端口和隐状态后检查；B/C/D使用各自真实特征维数。

**预算和停止。** 2个解析系统×3种表示，32个已知隐初值；4种非线性机制检查；优化更新为0。没有结构胜者选择，没有“最优seed”，不消耗A04真实12次拟合预算。任一检查失败保存工件并返回失败；不改阈值后重算同run。结果包括解析映射、初值、重建、数值检查、四个明确标注“未训练机制”的检查点以及代码/协议哈希。

**真实范围认证的现有缺口。** 当前`ExcitationEnvelope`保存边界与证据ID，`ExcitationEnvelopeRouter`执行域外拒绝；两者不负责证明边界内模型有足够准确性。历史材料中的离线范围也没有可直接移用的100 ms因果检测器或当前模型证据。因此本轮不能通过实例化一个边界对象完成认证。直接用train极值建立经验盒只保证已见数值落在盒内，不能保证盒内组合、未知隐初值或未来轨迹受到支持。

无需完整Level 6才能讨论输入适用范围，但必须先明确其认证含义与证据：固定输入特征、范围构造规则、模型及数据绑定、评价总体、误差/拒绝规则，以及谁验证这份证据。当前尚无这一登记。如果声称严格覆盖未知真实系统，还需要可验证的模型失配界或隐藏初值集合界；现有100 ms样本和能量恒等式不能单独提供这些量。

**打破评价与范围认证循环的条文。** 首次真实入口记录了AGENTS中的先后关系缺口：内部train/val允许开发，但没有定义首次认证前如何取得评价证据。Astra提出以下条文，用户于2026-10-23明确采纳；对应授权ID为`kiki_a04_development_20261023`，已写入AGENTS及机器可读政策：

> 原始source train内，预先登记模型、因果输入合同、分组train/val、固定预算、所有失败保留规则及评价范围构造程序后，可以运行一次仅用于建立或否定适用范围的开发评价。该评价必须标为尚未认证的开发证据，不得向部署接口返回预测，不得把范围外样本删除后报告全队列风险，不得晋升模型。适用范围与拒绝规则须在独立登记的证据上获得确认后，才允许在其范围内发布预测。source val/test继续保持原有访问门禁。

这项用户批准的例外限定到原source train中的冻结A04开发评价，不改变部署接口的认证范围要求。先前0次真实拟合与预测的阻断结果继续保留；新的评价使用新不可变run，不把先前阻断解释成零漏判或已完成实验。

### A04工程与合成机制集成结果

日期：2026-10-23。核心算法设计及防线判断按用户要求调度Astra、Ultra推理；读取器边界测试交Luna，统筹代理完成集成、独立复跑、正式运行及证据核验。这里记录调度请求，不声称另有独立运行时身份认证。

**本轮完成了100 ms读取、固定历史摘要、选择与数值检查工具，并取得可复现的合成机制收益。** 正式合成实验通过；真实A04在范围检查处停止，未消耗12次训练预算。工程工具经审查可以集成，真实模型保持`KEEP_BASELINE`，A03检查点和默认选择不变。

**已知系统上的机制结果。** 使用预登记的十节点、两隐状态、已知线性方程和已知可见初态，以矩阵指数精确构造100 ms历史观测映射。三种表示共享32个隐初值；全部恢复两维隐状态，最大重建误差不超过1.78e-15。

| 表示 | 观测信息 | 最小奇异值 | 最坏噪声放大 |
|---|---|---:|---:|
| B | 第0/5/10点三帧状态 | 0.0721329167 | 13.8632963 |
| C | 全部11点状态 | 0.1270846410 | 7.86877149 |
| D | 全部11点的三项固定正交基摘要 | 0.1270846401 | 7.86877155 |

在本合同声明的表示噪声欧氏范数下，D相对B的最坏放大降低43.24%，与C的相对差约7.26e-9。这支持继续研究固定摘要：它在此平滑已知系统中保留了接近完整历史的隐初值辨认信息，同时保持与三帧编码相同的输入维数。这个结果由已知方程的观测映射获得，没有训练新的编码器，不能写成kiki轨迹误差降低43.24%。

零端口反例中，三种观测映射均为秩0，正确拒绝辨认隐藏坐标。由于该反例的隐藏坐标也不影响可见未来，结论是该记忆模块没有观测支持，不是可见未来必然不可预测。

**物理与数值检查。** 四种表示接入已知正弦动力学和明确标注“未训练”的固定随机编码器，检查供能恒等式、惯性中心坐标、3 s与8 s的10/5 ms双步长及保存重放。所有登记检查通过：3 s最大归一化差为5.68e-11，8 s最大联合差为2.36e-11，四个检查点重新加载后预测逐值一致。参数数量另在合成拟合单元检查中核对为A/B/C/D=54/238/558/238；正式合成实验本身优化更新为0。

**真实数据的前置条件。** A04注册了100 ms、`Pm[10]`常值输入、固定四候选和三个seed，但还没有绑定这一合同及模型的认证激励范围。现行AGENTS明确要求范围外评价拒绝。因此正式入口保存了12项未执行计划、范围拒绝、分组绑定、访问审计和失败记录；真实拟合0次、优化更新0次、预测0次，FSR/FUR为空，工作流仍在`scaffold`。没有打开source train/val/test轨迹，source val/test访问限制保留。runner的数据完整性检查会读取文件字节及结构元数据，不等于读取事件轨迹数组。

**一次工程错误及修复。** 首次合成计算的数值检查已通过，但使用了全局工作流尚未登记的`MECHANISM_VERIFIED`科学状态，状态写入因此失败。修复只将科学状态改为现有`ACCEPT/REJECT`，机制状态存入独立字段；数值方法、数据、seed和阈值均未改。新增完整runner回归后，以新run重放。观测结果、解析映射、数值检查及四个机制检查点与首次计算逐字节一致。首次失败目录没有覆盖或修改。

**工程集成与模型晋升分开执行。** Astra复审确认，这些工具的实际价值由因果读取测试、旧路径兼容、合成机制和拒绝/数值检查分别支持，可以在全仓测试、CI及证据核验通过后合并main。固定摘要的科学模型晋升需要真实同合同收益；这次不替换A03，不登记合成检查点为真实候选，也不使开发评价豁免条文生效。

验证记录：全仓测试565项通过，耗时946.97 s；该次执行在状态字段兼容修复前启动，修复后的核心、旧模型和读取器另行独立复跑37项，全部通过。相关改动的静态检查、项目审计及正式成功run的严格工件核验通过。没有把失败run报告为正常验收通过。
