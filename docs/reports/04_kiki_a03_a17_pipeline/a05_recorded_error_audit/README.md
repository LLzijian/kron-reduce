### A04既有记录的只读误差审计

本审计只重新汇总已封存的A04 JSON结果，不调用模型、不重新积分、不读取原始轨迹、不训练，不改变A04选择和`KEEP_BASELINE`裁定。它适用AGENTS允许的既有工件只读审计，不重新激活已消耗的开发评价授权。

源run为`paper_kiki_a04_short_history-short_history_learning-20261023T021629566301Z-7bab0f36-e7569872`，源工件清单SHA256固定为`f26f7db6016764591300508c2fa216d8ab323bc91dd7d3b622a194d5bc4d3c3c`。先严格校验源run全部文件集合和哈希，再只解析清单内的JSON；输出使用新目录和独立哈希清单。

对每个候选、seed、train/val分别计算，不把seed合并为新增故障样本。来源数为S，来源s内线路数为L_s，该来源线路内事件数为N_s,l，则原权重为`w_i=1/(S L_s N_s,l)`。每事件主归一化均方误差为`m_i=(m_i,1s+m_i,3s)/2`，其中每个时长只计算真实可用记录。总体主归一化RMSE为`sqrt(sum_i w_i m_i)`，必须与既有结果匹配到1e-12。

按标签、来源、线路与最长真实可用时长分组，组贡献为`C_g=sum_i_in_g w_i m_i`，分组时保留原总体分母，全部组贡献之和必须回到总体均方误差。平方误差贡献比例为`C_g/sum_i w_i m_i`；条件归一化RMSE另列为`sqrt(C_g/sum_i_in_g w_i)`。候选对A的差使用同事件配对的`sum w_i(m_candidate-m_A)`。各组中位数不可再相加以代替总体中位数。

角度和转速的物理均方误差各按原权重汇总，单位分别为rad²与rad²/s²，开平方后为各自物理RMSE；主时长合并使用1 s/3 s均方误差等权。两种物理误差不可直接相加或当作归一化通道贡献。既有JSON没有20个通道各自的归一化残差，不能由两个物理RMSE还原精确的角度/转速归一化贡献比例。

任何缺失、非有限、失败评分、未知标签、队列或时长错配必须拒绝，不能删除后汇总或填零。标签只用于冻结后的报告切片，不进入模型。保留全部24组model/role汇总，以及已有训练日志；日志是所记录更新前的损失，不冒充最终检查点误差或收敛证明。

本审计回答误差集中在哪里、哪些分组代价互相抵消。它不证明物理参数变化、初始化或机械功率误差造成这些现象；因果机制需要另行登记的对照实验。新真实训练、预测及科学模型比较仍需独立授权。

### 下一轮算法设计依据：保留记忆收益，检验物理骨架的共同调整

**最有信息的下一步，是把物理骨架与记忆模块的训练拆成一个明确对照。** 既有结果显示：记忆模块降低了失稳样本的轨迹误差，同时增加了稳定样本的误差。应先检验这种代价与物理骨架共同更新的关系，再决定训练顺序和正则化。

本轮已完成只读审计、方法文献核查及Astra Ultra核心设计。新审计run为`a04-recorded-error-audit-20261023-v1`，代码冻结提交`f98420e53dcfa19205157684779525c2eb2e8c18`；[证据清单](_sealed/kiki_a05_recorded_error_audit_20261023_evidence.json)绑定全部源记录和新审计工件。24组model/train/val及各1 s/3 s指标均按原权重复现到1e-12。优化更新、新预测、原始轨迹读取和source val/test新增读取均为0。A04选择、数值失败记录与`KEEP_BASELINE`裁定保持原样。


<a id="doc-974b6dca3020-1-误差分解回答了什么"></a>

#### 1. 误差分解回答了什么

统计对象是A04同一100 ms任务的内部val：88个事件，含74个稳定样本和14个失稳样本。原权重依次在来源、来源内线路、线路内事件等权。稳定组权重质量为0.835581，失稳组为0.164419；不能用人数比例替换权重，也不能把三个seed当作新增独立故障。

令每事件的主归一化均方误差为真实可用1 s/3 s均方误差的等权平均。组贡献`C_g=sum(w_i*m_i)`使用原总体分母；各组贡献之和等于主归一化RMSE的平方。以下是单个seed的完整比较，表中数值全部为归一化平方误差贡献，不是RMSE或误差比例。

| val模型 | 稳定组贡献 | 失稳组贡献 | 总体均方误差 |
|---|---:|---:|---:|
| A seed324 | 0.175308 | 0.129640 | 0.304948 |
| C seed324 | 0.276640 | 0.065002 | 0.341643 |
| C相对A的变化 | +0.101333 | −0.064637 | +0.036695 |

全部9个记忆模型均呈现稳定组贡献增加、失稳组贡献降低。7个检查点总体均方误差增加；B seed326和D seed326分别减少0.011723、0.001803，但这两个检查点均漏判14/14个合格失稳样本。于是，较低的平均轨迹误差、失稳样本真实可用时段的拟合、未来8 s失步判定，是三个不能相互替代的结果。

线路配对分解也呈现一致的方向：9个记忆模型相对A，在Line_8、Line_37的总体误差贡献均增加，在Line_24、Line_7均降低。全部线路仍保留在总体中；这说明应检查跨线路的收益与代价，不能删除某些线路后报告整体改进。现有val只有7条线路，该切片属于开发诊断。

角度和转速的物理RMSE在审计中分别保留。已有JSON没有20个通道各自的残差，无法精确还原角度、转速对归一化总误差的各自贡献，不能由两个带不同物理单位的RMSE推算百分比。完整统计定义见[只读审计协议](#doc-e94764b4c5a6)。


<a id="doc-974b6dca3020-2-为什么先研究训练过程"></a>

#### 2. 为什么先研究训练过程

原A04同时更新可见骨架、记忆方程和编码器。Astra只读检查已存参数后确认，记忆模型的刚度和可见阻尼均偏离A；因此不能把现有差异全部归因于历史表示。当前两维端口也未显示明显的整体秩塌缩，直接增维缺少针对性。

优化日志显示末段训练损失仍下降，但没有中间检查点的val评价，不能推断延长训练一定改善泛化。历史一致性附加损失为0也是预登记选择；A03已经比较过权重1和0，不能把它当作遗漏而直接恢复。

方法检索核对了[历史编码与多步仿真辨识](https://proceedings.mlr.press/v144/beintema21a.html)、[连续时间子空间编码及其可辨认性条件](https://arxiv.org/html/2204.09405v2)、[初始化研究](https://arxiv.org/abs/2304.02119)，并参考作者维护的[jax-sysid实现](https://github.com/bemporad/jax-sysid)对初始化、正则化和优化设置的分离。这些方法支持把训练变量单独研究，没有提供kiki改进或稳定性认证的证据。[来源与适用边界清单](../a05/_sealed/kiki_a05_method_sources_20261023.json)记录了核验范围。


<a id="doc-974b6dca3020-3-已形成的算法与训练方案"></a>

#### 3. 已形成的算法与训练方案

[Astra核心设计稿](../a05/README.md#doc-846d590fcb8a)给出完整方程、参数起点、预算和判断规则；[不可执行的方案登记](../../../../configs/proposals/kiki_a05_freeze_vs_joint.json)明确标记待专用授权。

保留十节点、正弦势能、两维记忆、三时刻编码器和互易端口。正值刚度、半正定耗散、反对称隐状态耦合及COI约束继续由参数化保证；未来仍自由积分。两组共享已存A seed324的物理骨架、相同的train尺度；每个seed的记忆初值逐数组相同。

| 配对组 | 每次训练 | 唯一改变的因素 | 用途 |
|---|---|---|---|
| 固定骨架组F | 只更新记忆与编码器，80步 | 物理骨架保持共同起点 | 机制诊断 |
| 共同更新组J | 物理骨架、记忆、编码器共同更新，80步 | 允许物理骨架调整 | 配对对照 |

seed固定324、325、326，共6次新拟合、480次新更新，Adam学习率0.01，最后一步检查点，不加seed或延长时长。历史A的80次训练为两组共同继承的成本，单独披露。为保持干预清楚，两组均先计算同一完整参数梯度并应用范数上限10，再在F屏蔽物理骨架更新；不能训练完再替换骨架。

判断重点是：固定骨架能否一致减少稳定轨迹代价，同时保留失稳轨迹收益；物理、数值与冻结后漏判/误报条件仍分别检查。固定组成功也只支持该数据、起点和预算下的训练干预，不能直接晋升为最终模型。若证据支持，后续再单独研究“先训练记忆、再共同微调”，最终模型仍须共同拟合。

本轮交付是已有证据的误差归因与下一轮设计。A05新真实训练需要按项目规则独立登记授权，A04的一次性授权继续为`consumed`；source val/test与独立确认门禁保持原状态。

验证：59项针对性及相关回归测试通过，代码检查与项目审计通过；源A04与新审计工件均严格校验。JSON审计不读取模型或预测数组；报告另外列出的参数变化，由既有检查点参数只读复核并绑定SHA，不进行模型实例化或新预测。旧模型和旧结果文件保持原样。
