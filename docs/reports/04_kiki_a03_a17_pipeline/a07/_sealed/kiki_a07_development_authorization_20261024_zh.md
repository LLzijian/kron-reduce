## 共同起点与固定预算

两组分别从 A06 step-240 的同 seed 完整模型参数和保存的 Adam 状态恢复；每个 seed 的模型与 optimizer state 路径和 SHA256均绑定在 TOML 配置中。恢复后两组起点逐 seed 完全相同。Adam 总步数从240开始，每组每 seed继续240次，最终计480；每个seed只有末步240检查点，共6次拟合、最多1440次新增更新。不得增加中间检查点、seed、更新、重试或自动续训。

数据、模型结构、输入合同、每事件损失定义、train尺度、批量方式和其他优化设置保持一致。M组继续使用加权平均事件均方误差，加原编码器惩罚。T组使用固定温度的倾斜目标

`tau * log(sum_i w_i * exp(m_i / tau)) + 原编码器惩罚`。

三个seed的tau依次为0.7844805082870585、0.7768666645735861、0.7861097423844166，分别取同seed A06 train最大事件均方误差。该值只由train确定，不使用val或标签调整。M/T的终点评价独立报告是否达到零，不按分类结果挑组。
