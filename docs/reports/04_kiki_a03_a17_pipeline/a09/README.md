<a id="doc-e5d1410c0027-3-时钟坐标和拼接"></a>

#### 3. 时钟、坐标和拼接

令原记录点数为 L_i，冻结的真实可用未来点数为

\[
N_i=\min(L_i-11,300),\qquad T_i=0.01N_i.
\]

历史使用原索引 0:11，即记录时间 0,…,0.10 s；未来目标使用索引 10:11+N_i，含预测起点，共 N_i+1 点。未来评分只用索引 1,…,N_i，对应 0.01,…,T_i，不含重复起点。最长未来为 3 s，不计算缺失的后段，也不补成 8 s。

严格复用原转换，\(m=\mathrm{inertia}/\omega_s\)、\(\omega_s=2\pi60\)：

\[
q=P_m\delta_{raw}-P_m\delta_{eq},\quad
v=P_m[(\omega_{raw}-1)\omega_s],\quad
u=Q_m(Pm[10]-Pm_{eq}),
\]

\[
P_mx=x-\mathbf1\frac{m^Tx}{\sum m},\qquad
Q_mp=p-m\frac{\mathbf1^Tp}{\sum m}.
\]

q 为 rad，v 为 rad/s。角差计算时加回已给定平衡角；COI 转速转成 pu 时除以 omega_s，不能重复换算或额外给 inertia 乘 2。质量、静态先验、源 feature_scale/target_scale 均核验后原样复用，不重拟合或重标定。

每个预测组合只调用一次 `initialize()`，获得历史积分路径及其末端 z，再调用一次 `closure.rollout()`。未来 q/v 重置为最后真实观测，只继承 z；不要随后再调用 `predict()` 重复历史积分。

规则使用两条长度为 11+N_i 的序列：

- 真值：实测 history + target[1:]。
- 预测：同一实测 history + prediction[1:]。

初始化器生成的历史 q/v 只用于数值/物理检查，不用于替代规则中的实测历史。历史积分末端可见状态与未来重置状态不是连续动力学路径，不能跨该边界差分、计算连续能量变化或据此推断力的突变。

#### 4. 两种步长、唯一预测范围和精确预算

每个 seed、每个合格事件分别使用 float64 RK4、max_step=0.01 与 0.005 s；两者输出都在原 0.01 s 网格。所有参数保持冻结。0.01 s 用于对照已存 A06 评分，0.005 s 作为预定主要诊断路径，两者均完整保留，不按结果挑步长。

已存 JSON 给出 \(\sum_iN_i=72,147\)，258 例每条历史有 10 个输出间隔。因此：

| 项目 | 固定预算上限 |
|---|---:|
| 新拟合／优化更新 | 0／0 |
| 事件×seed×步长预测路径 | 258×3×2 = 1,548 |
| 历史＋未来 rollout 调用 | 3,096 |
| 每 seed、0.01 s RK4 更新 | 74,727 |
| 每 seed、0.005 s RK4 更新 | 149,454 |
| 全部积分 RK4 更新 | 672,543 |
| 积分 RHS 求值 | 2,690,172 |
| 保存输出状态的能量恒等式 RHS 检查 | 451,458 |
| 两类 RHS 求值合计 | 3,141,630 |

能量检查计数为 \(3\times2\sum_i[11+(N_i+1)]=451,458\)，历史与未来起点各自检查，因为可见状态经过重置。这是额外代数 RHS 计算，不是额外预测；不能漏记在计算量中。无需为了重放再生成第三条路径，保存数组/hash 检查与所有后续代数统计复用本轮输出。

预算前置条件：载入后按原积分器 `ceil(interval/max_step−1e−12)` 核算所有时钟。每例 history 的两个步长分别必须恰为 10/20 个子步，future 分别 N_i/2N_i；provider 对原时间的容差不能代替这项检查。若不满足，预检停止，不静默改时钟或增加预算。每个失败消耗自己的预测槽位，记录失败前实际更新/RHS；不重试、不另选 seed，不延伸到不存在的真实点。


<a id="doc-e5d1410c0027-5-有限真实窗口上的原规则与连续余量"></a>

#### 5. 有限真实窗口上的原规则与连续余量

本次不调用要求 801 点的原 `los_classification()`，而用一个合成测试覆盖的有限窗口实现，逐项保持它的角差、速度、严格大于和连续五点语义，不作插值。

对拼接序列索引 k（记录时间 0.01k s，预测相对时间 0.01k−0.10 s），定义

\[
a_k=\operatorname{ptp}(q_k+q_\star),\quad
s_k=\|P_mv_k\|_\infty/\omega_s,\quad
c_k=\min(a_k/\pi-1,s_k/0.02-1),
\]

\[
r_j=\min_{\ell=0,\ldots,4}c_{j+\ell},\qquad
\rho=\max_j r_j.
\]

正余量等价于这一可用窗口中存在严格的五点触发。为避免把预测前已有事实算成模型能力，同时输出三项：历史窗口（五点末索引≤10）、含未来点窗口（末索引≥11，可跨预测起点）、全部窗口的 rho、是否触发和第一个触发末索引。全部窗口是原完整拼接规则；机制判断主要看含未来点窗口，并把历史已触发事件另列，不丢弃。

规则触发时间是首个正 r_j 的末点时间，即 (j+4)×0.01 s；预测相对时间再减 0.10 s。严格 rho>0、rho=0 和 rho<0 均原样记录。另列 abs(rho)≤1e−12 的算术边界标记，它不改变原布尔阈值。

`observed_rule_hit` 只表示**真实可用轨迹触发这一规则**，不是失稳标签。rho≤0 只表示本窗口内未找到这五点证据，不能写成稳定；记录缺失后段也不能判为稳定。报告预测是否保留观测规则、是否在没有观测触发的本窗口产生触发，不使用 FN/FP/FSR 名称。


<a id="doc-e5d1410c0027-6-可验证的误差界与时间形状"></a>

#### 6. 可验证的误差界与时间形状

对每个步长，在同一真实可用拼接窗口计算

\[
\delta_q=\max_k\|\widehat q_k-q_k\|_\infty,\qquad
\delta_v=\max_k\|P_m(\widehat v_k-v_k)\|_\infty,
\]

\[
E_{\rm vector}=\max\{2\delta_q/\pi,\delta_v/(0.02\omega_s)\},
\quad
E_{\rm atom}=\max_k\max\{|\widehat a_k-a_k|/\pi,
|\widehat s_k-s_k|/0.02\}.
\]

直接由 min/max 的 Lipschitz 性：

\[
|\rho(\widehat y)-\rho(y)|\le E_{\rm atom}\le E_{\rm vector}.
\]

这与 [Fainekos、Pappas 的原始时序性质余量框架](https://www.georgejpappas.org/wp-content/uploads/2024/04/RV06.pdf) 一致；具体阈值、五点窗口及上述常数由本项目固定规则直接推导，不移植该论文对其他模型的保证。

分别对全部、含未来点窗口相关点及下述固定五点窗口验证。容差为 \(10^{-12}\max(1,|\rho_{true}|,|\rho_{pred}|,E_{vector})\)；若违反该代数界，属于实现/对齐错误，不能继续作机制解释。

当 rho_true>0 且 E_atom<rho_true 时，该窗口的正符号有现有数组误差界保护。若符号改变，必有 E_atom≥rho_true；这只是必要的误差幅度解释，不是造成动力学错误的因果证明。E_atom≥rho_true 也不意味着一定漏掉规则。该界是已知数组间的确定性比较，不是对未见真实系统、测量噪声或未来轨迹的认证界。

对每个事件，只由真值确定一个含未来点的代表五点窗口：取 r_j 最大者，完全相等时取最早者；真值 rho≤0 时仍可记录，但不作为正触发证据。输出预测在同一五点窗口的余量、最大误差、角度/速度哪个条件限制余量；区分“保留此窗口”与“在另一个时刻触发”。不按预测失败改变代表窗口。

逐时刻归一化平方误差沿用源 target_scale：\(e_{ik}^2=\|S^{-1}(\widehat y-y)\|^2/20\)。输出完整 e² 序列、首秒/其后均值、最大 e² 及出现时刻、原事件目标 m_i、普通全可用点均值。max/mean 比值的零分母标为未定义，不造 0。MSE、RMSE、物理最大角误差及 pu 最大速度误差分列。

原目标时间系数为

\[
c_{ik}^{loss}=\tfrac1{2n_{1i}}\mathbf1_{k\le n_{1i}}
+\tfrac1{2n_{3i}}\mathbf1_{k\le n_{3i}},
\qquad m_i=\sum_k c_{ik}^{loss}e_{ik}^2.
\]

代表窗口里实际属于未来的点集合为 W_i，定义 \(p_i=\sum_{k\in W_i}c_{ik}^{loss}\)、\(C_i=\sum_{k\in W_i}c_{ik}^{loss}e_{ik}^2\)。C_i−p_i m_i>0 表示该窗口的误差密度高于原事件平均；不修改任何权重。所有这些统计使用全部事件，不能把窗口挑选转成训练特征或失稳标签。

0.01 s 路径须将每例原 1/3 s MSE、归一化角度/速度贡献及原层级汇总重建至 1e−12。若不一致，保留来源/接口不一致并停止相关总体验收，不能重新训练或更换源。按固定 n3≤100、100<n3<300、n3=300 三桶汇总；贡献始终使用原总体分母，桶内条件均值另列。seed 分行，不把 774 条模型—事件记录视为独立事件样本。

<a id="doc-e5d1410c0027-8-何种结果足以提出下一项独立候选"></a>

#### 8. 何种结果足以提出下一项独立候选

这是一轮审计，不产生模型选择或晋升。完成条件是来源、读取边界、固定预算与全部计划槽位对齐，且代数重建可核验；科学输出须区分数值检查通过与未通过的事件。下一训练提案不能利用未通过数值或对齐检查的证据。

允许提出“时间内轨迹误差聚合”独立对照的最低描述性条件预先固定为：

1. 全部计划工作完整，三源评分重建和权限检查通过，没有用删除事件换取总体结论；全部路径的上述物理/数值要求通过。
2. 至少两个不同 train 事件、来自至少两个不同的物理 fault_line，均没有历史已触发，真值含未来窗口 rho>1e−12；三个 seed 的两种步长均未保留其正触发。来源同时报告；同一物理线路出现在两个来源不算作两条不同线路。
3. 对这些事件，粗细结果和误差界一致；每个 seed 的预定 0.005 s 路径在真值代表窗口上均满足 C_i−p_i m_i>1e−12，即出现重复的时间局部误差浓集。列出全部符合和不符合事件，不能只报告两个例子。

这三个条件只允许**提出**一个统一用于所有事件/真实时刻的新轨迹目标对照，不证明新目标有效，更不是根据名单加权。两个事件和两个线路组是避免单例定制的最低设计门槛，不是统计显著性标准。下一轮仍须在执行前确定唯一公式、起点、对照、预算及验收，不能由本轮正余量名单生成标签目标。

若观察到规则保持失败但没有误差浓集，只记录模型形状不匹配；本次不足以支持时间聚合候选。若全部真实触发都被保留，或 train 内没有严格的相关触发证据，本审计不能解释此前 val 漏判；不据此自动加结构。若主要是预测在真实缺失之后的性质，需独立的数据/输入支持问题，而不是拟合虚构后段。

**本次审计无论得到什么 rho 结果，都不足以批准非线性相位记忆。** 后者还需一项预先定义的 train 残余力/幅度方向审计，证明问题不主要在现有端口空间之外、幅度相关新方向不与常系数旋转退化重合，并经过已知真值合成检验。潜态坐标、K/D 错差与导数敏感性须分开；没有独立证据就不进入该候选。

若发现数值不一致，后续只能先提出固定参数的独立数值问题，不放宽本轮阈值。任何新问题都需独立 registered authorization 与 immutable run，A06/A08 原预算不重开。本草案不承诺零漏判，也不把有限观测的一般理论限制写成当前数据不可辨识已被证明。
