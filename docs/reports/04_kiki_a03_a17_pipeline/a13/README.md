<a id="doc-4c1365b73ff6-1-固定方程与估计对象"></a>

#### 1. 固定方程与估计对象

令 \(M=\operatorname{diag}(m)\)，\(Q=I-\mathbf1m^T/(\mathbf1^Tm)\)，\(P=Q^T\)。状态用 Q，力用 P。严格保留现有方程：

\[
\dot q=v,\quad M\dot v=P[p-F(q)-Dv-Cz],\quad
\dot z=C^Tv+Az,\quad A=J-R,
\]
\[
F(q)=B\operatorname{diag}(k)\{\sin[B^T(q+q_{eq})]-\sin(B^Tq_{eq})\}.
\]

估计量是合法历史**起点**的 \(z_h\)，不是起报末态。输入 p 使用原合同的 `history.constant_power`；真实计划中它来自 Pm[10]，在模型历史内按原规则保持常值。这是原模型的已声明输入近似，不能称为整段历史中实际测到的机械功率。

历史移至 \(t_0=0\)，\(h_j=t_{j+1}-t_j\)，\(T=t_J\)。q 与 v 分别采用分段线性插值，不在中间插入任何真实观测。定义

\[
\Phi(t)=e^{At},\quad w'=Aw+C^Tv_{obs},\quad w(0)=0,
\]
\[
g_j=\int_{I_j}P[p-F(q_{obs})-Dv_{obs}]dt-M(v_{j+1}-v_j),
\quad b_j=g_j-PC\int_{I_j}w(t)dt,
\quad L_j=PC\Phi(t_j)\int_0^{h_j}e^{Au}du.
\]

连续且模型正确时 \(b=Lz_h\)。实际离散计算只是对所声明插值成立的条件方程，不自动得到未知连续真轨迹的方程。


<a id="doc-4c1365b73ff6-11-固定增广指数不使用-a-的逆"></a>

##### 1.1 固定增广指数，不使用 A 的逆

每个真实区间计算一次 \(4r\times4r\) 指数：

\[
\exp\!\left[h\begin{pmatrix}
A&I&0&0\\0&0&I&0\\0&0&0&I\\0&0&0&0
\end{pmatrix}\right]_{\text{第一块行}}=[\Phi_h,F_1,F_2,F_3].
\]

其中 \(F_1=\int_0^he^{Au}du\)，\(F_2=\int_0^h(h-u)e^{Au}du\)，\(F_3=\frac12\int_0^h(h-u)^2e^{Au}du\)。令 \(u_j=C^Tv_j\)、\(d_j=C^T(v_{j+1}-v_j)/h_j\)，则

\[
w_{j+1}=\Phi_hw_j+F_1u_j+F_2d_j,\qquad
\int_{I_j}w=F_1w_j+F_2u_j+F_3d_j.
\]

\(\Phi(t_j)\) 从单位阵按实际 h 顺序相乘。该计算对所声明的线性 v 插值精确到浮点误差，A 奇异也可用；不采用 `inv(A)`、差商小参数分支或伪逆代替矩阵积分。


<a id="doc-4c1365b73ff6-12-正弦力求积与唯一主解"></a>

##### 1.2 正弦力求积与唯一主解

阻尼积分使用 \(h_jD(v_j+v_{j+1})/2\)，功率积分使用 \(h_jp\)。正弦力分别用固定 Gauss–Legendre 2 点与 4 点公式积分；**4 点为唯一主解，2 点只检查求积差**。两者使用相同的 L、w 与端点动量，不由结果选择阶数。节点和权重采用标准闭式常数，映射到各实际区间；没有自适应求积或追加节点。

归一化使用固定模型的速度尺度 \(s_v\)，合成统一 \(s_q=s_v=\mathbf1\)。令
\[
S=\operatorname{diag}(1/(m_i s_{v,i})),\qquad
c_j=\sqrt{h_j/T}/h_j,
\quad \widetilde L_j=c_jSL_j,\quad\widetilde b_j=c_jSb_j.
\]
这是加权的归一化平均加速度残差，不是独立噪声的协方差白化。相邻区间共享端点，不能按区间数量构造独立样本置信区间。

对 \(\widetilde L\) 做一次薄 SVD，再分别求两个右端的无 ridge 最小二乘。固定数值秩阈值为
\[
\epsilon_{rank}=64\epsilon_{64}\max(nJ,r)
\max\{\sigma_1(\widetilde L),\|SPC\|_2\}.
\]
自然尺度 \(\|SPC\|_2\) 防止本应为零的周期积分被舍入噪声误判满秩；弱 C 会同时缩小两项，不能用这项数值约定掩盖弱信号。\(PC=0\) 时 rank=0。C 的物理投影 SVD 使用阈值 \(64\epsilon_{64}\max(n,r)\|PC\|_2\)；可见作用矩阵 \(O=[PC;0.01PCA]\) 使用 \(64\epsilon_{64}\max(2n,r)\|O\|_2\)，全零时 rank=0。报告全部奇异值、阈值、rank、\(\sigma_{min}\)、条件数和 \(1/\sigma_{min}\)，不只报告 condition number。

rank<r 时可以保存最小范数代表用于合成代数检查，必须标记 unresolved；未来真实审计不把该向量发给候选历史传播器，不回退为 encoder 后冒称候选成功。没有奇异值阈值搜索、正则搜索或后验裁剪隐藏状态。

本方案 r=2，\(\|SPC\|_2\) 固定用 2×2 Gram 矩阵的最大特征值闭式表达计算：若 Gram 元素为 a,b,b,d，则取 \(\sqrt{(a+d+\sqrt{(a-d)^2+4b^2})/2}\)。该标量运算单列，不暗中调用另一轮 SVD；未缩放 C 的谱范数可直接用已有 C 分解。禁止把非均匀 S 后的范数误写成原 C 的最大奇异值。


<a id="doc-4c1365b73ff6-2-五组必须分开的量"></a>

#### 2. 五组必须分开的量

1. **隐藏力空间残差**：\(r_{force,j}=(I-PC(PC)^\dagger)g_j\)。投影在物理力的欧氏空间计算，再另报 S 归一化值；不能先缩放后混称同一个物理投影。它不依赖初态估计方法。
2. **动态一致性残差**：\(r_{dyn}=b-L\widehat z_h\)。每段在 range(PC) 内，不代表同一个初态能解释全部时段。候选降低该 LS 目标是构造结果，不能据此证明独立预测收益。
3. **运动学残差**：\(r_{kin,j}=q_{j+1}-q_j-h_j(v_j+v_{j+1})/2\)。分别报 rad 及按 s_q 缩放的量；不把 q/v 插值不一致全归因于 z。
4. **条件性与误差敏感度**：固定 L、满列秩时 \(\|\Delta z\|\le\|\Delta\widetilde b\|/\sigma_{min}\)。矩阵有误差时还含 \(\|\Delta\widetilde L\|\|z\|\)；真实骨架误差和观测误差未知，不能把仅有的求积差代入后称真实初态误差界。分母为零的相对残差记 None，不设为 0。
5. **隐藏储能与传播一致性**：报 \(\|z_h\|^2/2\)、观测驱动末态 \(z_T^{obs}=\Phi(T)z_h+w(T)\)、闭环末态 \(z_T^{cl}\) 和二者差。模型隐藏能量不是已知真实 220 状态的内部能量；现有正弦势能也没有因此获得全局正定证书。

如拟做未来比较，主流程只替换历史起点估计：原 encoder 与积分候选都按原闭环 RHS 传播历史，再把 q/v 重置为末次真实观测，保留各自 z。\(z_T^{obs}\) 只作诊断。直接用观测驱动末态起报会改变整个初始化流程，不能偷偷并入同一个单因素比较。

#### 4. 十五项固定正确性检验

**S01：线性连续 oracle 与已有 observer。** 用上述线性模型。连续积分 oracle 解须恢复 z0，误差≤1e−10；原 `PassiveLatentClosure.estimate_latent` 用 11 个精确可见样本恢复的历史末态须与完整指数真值一致≤1e−10。生产型分段线性估计在 11/21/41 点分别计算，两次加密的初态误差各满足 \(e_{fine}\le0.4e_{coarse}+10^{-10}\)，41 点误差≤1e−4。**不要求离散积分估计与精确离散 observer 逐位相等**：它们使用的连续插值假设不同。

**S02：非均匀质量 P/Q 负对照。** 正确实现复用 S01 的 11 点历史；测试专用错误实现把力投影换 Q。对 f=(1,0,0,0)，须复现 \(\mathbf1^TPf=0\)、\(\mathbf1^TQf=0.6\)（误差≤1e−14），并使错误实现的力/COI 检查明确失败。生产接口不提供可切换的错误投影选项。

**S03：正弦求积的解析参照。** 单区间 h=0.1，\(q(t)=q_0+tQ(3,-2,1,-1)^T\)，v 为对应常向量。每条边积分由 \(h\sin(a+\beta h/2)\operatorname{sinc}(\beta h/(2\pi))-h\sin(a_{eq})\) 精确给出；这里 sinc 使用 NumPy 的 \(\sin(\pi x)/(\pi x)\) 约定。Gauss4 物理力积分最大绝对差≤1e−12，且误差≤0.01×Gauss2 误差+1e−14；应直接证明使用正弦而非 Kq。此路径用于求积单元测试，不称为某个无额外输入 ODE 的真轨迹。

**S04：正确正弦闭合。** 使用前述两条真值和三种观察网格。分开报告真值积分误差、同一插值的 Gauss2/4 差、观察加密后的初态误差。后者使用 S01 相同的收敛及最终 1e−4 条件。不能把 Gauss4 很准等同于 11 点插值已经准确。

**S05：秩亏但永远不影响可见未来。** 改为 \(C=[0.8u_1,0]\)、\(A=\operatorname{diag}(-0.4,-0.7)\)，其余为线性模型。初态取 (0.7,−0.4) 与 (0.7,1.6)。完整指数可见路径差≤1e−12，初始隐藏能量差=1.2；L rank=1，\(\mathcal U=\ker\left[\begin{smallmatrix}PC\\0.01PCA\end{smallmatrix}\right]=\operatorname{span}(e_2)\)。允许报告可见等价，必须拒绝完整 z 和总隐藏能量唯一的主张。

**S06：秩亏且采样后的未来作用有关。** 固定 n=2、m=(1,1)、K=D=R=0、p=0、q_eq=0、\(u=(1,-1)/\sqrt2\)、h=0.01、\(\omega=2\pi/h\)、\(\alpha=\sqrt3\omega\)、\(C=[\alpha u,0]\)、\(A=\left(\begin{smallmatrix}0&-\omega\\\omega&0\end{smallmatrix}\right)\)。令 \(\Omega=2\omega\)，q0=v0=0、z0=(a,0)，a 分别为 1、2。精确解为
\[
q(t)=u\,\alpha a(\cos\Omega t-1)/\Omega^2,\quad
v(t)=-u\,\alpha a\sin\Omega t/\Omega,
\quad z(t)=(a\cos\Omega t,\omega a\sin\Omega t/\Omega).
\]
11 个 h 间隔可见样本均为零（解析计算残差≤1e−11）；取这些数学精确的零样本供估计器，L 必须按固定阈值判 rank=0，而 \(\mathcal U=\{0\}\)。在 T+h/8，两条路径速度差范数=\(\sqrt3/2\)>0.8。该被动反例确实同时给出相同离散 q/v 与不同采样间/之后可见作用；它不是仅凭 \(\ker L\) 推测两条闭环轨迹。无需 RK4 解析高频系统。

**S07：弱端口满秩。** 保留 A，把 C 改为 1e−8 C。用精确构造 \(\widetilde b=\widetilde Lz\)，分别在强/弱端口令 z=0；添加范数 1e−8、沿最小左奇异向量的已知右端扰动。两种 L 均须 rank=2，条件数相对差≤1e−10，奇异值按 1e−8 缩放；估计误差须为 \(10^{-8}/\sigma_{min}\)（相对误差≤1e−9），对应能量为其平方的一半。弱端口的误差放大比须为 1e8，允许相对误差≤1e−8。不得用小残差或相同条件数将它标为稳健恢复。

**S08：错误骨架产生力空间外残差。** 在 S01 连续 oracle 上只把估计 K 改为 \(K+0.3u_3u_3^T\)。每区间 g 的变化须等于 \(-0.3u_3u_3^T\int qdt\)（≤1e−12），force-space 残差相应变化；其总范数须>1e−5。该新增骨架项仍平衡且半正定，物理结构正确不能免除历史失配。

**S09：错误常值输入在端口外。** S01 oracle 估计输入改为 \(p+0.2u_3\)，g 变化精确为 \(0.2h_ju_3\)，force-space 残差变化须同值≤1e−12。此负例明确不是 encoder 可以解释的方向。

**S10：错误输入可被初态完全吸收。** 使用线性基础模型但 A=0，令 a=(0.25,−0.5)，估计输入误设为 p+Ca。连续 oracle 的目标变化为 La；恢复值必须为 z0+a，动态残差≤1e−10，而初态偏差范数>0.5。A 奇异不得触发求逆失败。它证明常值输入错误也能给出零残差；不能把零残差称为正确骨架/输入的证据。

**S11：力空间内但动态不一致。** 用 S01 的 L 构造区间扰动 \(g_j^{(0)}=h_j(-1)^jCe_1\)，按同一 W 缩放，再减去其在 range(\(\widetilde L\)) 的投影，归一到范数 0.01 后加到 \(\widetilde Lz_0\)。每个反缩放区间仍位于 range(C)，force-space 残差≤1e−12；dynamic 残差范数必须为 0.01（≤1e−12），初态保持 z0≤1e−10。不能把两个残差合成一个“通过”。

**S12：已知端点噪声。** S01 的 11 点 q 增加 \(10^{-5}(-1)^jQe_1/\|Qe_1\|\)，v 增加 \(10^{-4}(-1)^jQe_3/\|Qe_3\|\)。不平滑、不重新投影为另一条轨迹。重算全部积分项，记录实际 \(\Delta\widetilde b\)，检验 \(\|\Delta z\|\le\|\Delta\widetilde b\|/\sigma_{min}+10^{-10}\)。同时核验线性 LS 预测的 \(\Delta z=\widetilde L^\dagger\Delta\widetilde b\)，误差≤1e−10，并报告能量变化。噪声不是独立端点样本的置信模型。

**S13：运动学不一致。** S01 q 增加 \(10^{-3}(j\bmod2)Qe_1/\|Qe_1\|\)，v 不变。r_kin 变化必须等于相邻 q 扰动之差≤1e−12。估计器不得为降低这一量而改写真实 q/v，或将其标为新隐藏力证据。

**S14：因果输入和三点支持。** 对 S01 的 11 点输入调用两次，第二次只改变外部测试容器的未来 q/v、未来功率、标签、事件 ID、长度；这些属性一旦读取立即报错。合法数组完全相同，输出逐数组相同。另用前三个真实点执行一次 T=0.02 的估计，记录 rank/sigma/误差，不要求它必定失败或与 100ms 一样准确。该三点合成记录不进入任何真实 20ms 证据。

**S15：共同闭环历史和可见 reset。** 用 S04 的 11 点历史；对照初态固定 z_enc=0，候选为唯一 Gauss4 解。每组分别按原闭环方程、最大步长 .005/.0025 传播到 T，不向中间时刻注入实测 v。两种步长各组状态最大差≤1e−8。未来初始化结构只组装 \([q_{obs}(T),v_{obs}(T),z_T^{cl}]\)，不运行未来：q/v 必须 array_equal，z 必须等于对应闭环末态，不得替换为 z_T^obs。另保存两种末态的差；不假定线性条件解最小化非线性闭环历史误差。

所有已调用 RHS 的合成路径均做能量/COI 检查：能量恒等式相对误差≤1e−10（分母 max(1,|导数|,|供给−耗散|)），质量加权 COI 绝对残差≤1e−10。正弦路径按 41 个输出点检查；S15 按 11 点检查，不跨可见 reset 差分。合成失败完整保留；修复实现后可新建 correctness run，但不得改参数或阈值以使旧失败通过。

#### 8. 未来审计判定，不自动开启未来比较

**有效性 V**：来源/成员范围/原权重/预算全部通过；774 槽全部有结果且 rank=2；两个求积初态及观测驱动末态之差均≤\(10^{-6}(1+\|z^{(4)}\|)\)；全部候选历史 .005/.0025 可见状态 target_scale 归一化最大差≤1e−5，隐藏状态差≤\(10^{-5}(1+\max_t\|z^{(.0025)}(t)\|)\)；所有历史能量恒等式误差≤1e−8、质量加权 COI≤1e−10，且无不可恢复失败。这些是数值/计算有效性条件，不是未知真实初态认证。

**独立历史证据 I**：按原事件权重，分别在两个步长、三个 seed 统计非初始 10 点 q/v 历史归一化 MSE；单事件值为 \(\ell_i=(10\cdot2n)^{-1}\sum_{j=1}^{10}\|([q^{cl}_j,v^{cl}_j]-[q^{obs}_j,v^{obs}_j])/s\|_2^2\)，每通道分别除 10n。Gauss4 候选相对缓存 encoder 的总体 MSE 每个 seed 严格下降，角度与速度两通道 MSE 各不增；原权重最差 10% 的分数质量 CVaR 不增。CVaR 按单事件 MSE 从大到小排，取累计原权重 0.1，边界事件只取所需部分质量，最后除 0.1；不得按标签挑尾部。两个方法全部 258 条使用同一总体分母，不剔除失败事件后称改善。I 是闭环历史重建证据，不能用构造上必然不增的 LS 残差替代。

**解释边界**：完整保存 force/dynamic/kinematic 三类残差的物理值、归一化值、最大值及原权重汇总；保存所有奇异值、单位扰动放大量、两个初态/末态和隐藏能量比。没有已知真实噪声与骨架误差上界时，不签发初态恢复证书，不将能量大但有限自动称可信。仅 V∧I 可支持“值得提出一项固定预算、uncertified 的未来初始化比较”；该提出还须由科学审查看残差分解和能量，不会自动运行，也不预先授权任何未来 val。

若 V 失败，先解决数值、输入或条件性问题，不能调整 ridge 后继续本轮。若 V 通过而 I 不成立，则拒绝当前积分初值方法的闭环历史收益假设；不能继续只增加历史权重或隐藏维数来回避结论。若力空间外残差占主要部分，不把问题归给 encoder；若动态残差明显而力空间残差小，固定 A/C 或输入近似仍需检查。小残差、I 通过和低隐藏能量也不能证明真实物理正确，S10 就是固定反例。

#### 结论

对固定 pH 骨架，以动量平衡的积分形式估计历史起点隐藏状态，可避免对观测速度显式数值微分。冻结方案的 15 个合成病例和物理检查全部通过，计算量与预先登记预算一致。结果支持在给定模型和观测条件下开展受控的后续 train-only 初始化机制审计；它不证明真实系统的隐藏状态已恢复，也不证明失稳漏判率改善。


<a id="doc-1daa27c713ae-关键结果"></a>

#### 关键结果

线性和正弦合成真值的网格加密初态误差近似每次缩小为四分之一：线性例从 2.7480×10⁻⁴ 降至 1.7175×10⁻⁵，正弦例从 1.4280×10⁻⁴ 降至 8.9248×10⁻⁶。正弦力积分的二点求积误差为 3.3351×10⁻⁶，四点为 4.5508×10⁻¹³。全部六条积分路径的能量恒等式最大相对残差为 3.33×10⁻¹⁶，COI 最大残差为 1.11×10⁻¹⁶。

固定反例界定了结果的解释范围：弱端口即使满秩且条件数不变，绝对奇异值变小仍可把同一右端扰动引起的初态变化放大 10⁸；错误输入可被隐藏初态吸收，使最小二乘残差为零但估计初态偏离真值；还有一个高频被动例具有相同离散可见采样而未来速度不同。因此，残差低、矩阵满秩或离散采样拟合一致都不能单独作为物理隐藏状态恢复证据。

#### 算法及证据各自回答什么

模型写作

\[
\dot q=v,\quad M\dot v=P[p-F(q)-Dv-Cz],\quad
\dot z=C^Tv+A_z z,
\]

其中 \(Q=I-\mathbf1m^T/(\mathbf1^Tm)\)、\(P=Q^T\)、\(A_z=J-R\)。对每个真实历史区间，构造

\[
g_j=\int_{t_j}^{t_{j+1}}P[p-F(q)-Dv]dt-M(v_{j+1}-v_j),
\quad b_j=g_j-PC\int_{t_j}^{t_{j+1}}w(t)dt,
\]

\[
w'=A_z w+C^Tv_{obs},\quad w(0)=0,\qquad
L_j=PC\int_{t_j}^{t_{j+1}}e^{A_zt}dt,
\quad \hat z_0=\arg\min_z\|\widetilde Lz-\widetilde b\|^2.
\]

矩阵积分来自增广块矩阵指数，不使用 \(A_z^{-1}\)，因此零衰减/奇异 \(A_z\) 不造成公式失效。主计算固定四点 Gauss 求积；二点求积只检验数值差，不按结果选择。没有 ridge、阈值搜索、额外模型参数或联合训练。

### 初态估计与短历史可辨识：原始文献核验

检索按 `nature-academic-search` 的 multi-source-search 流程完成，限于论文原文、作者预印本和官方出版社页面。问题范围按 [固定模型积分初态方案](#doc-4c1365b73ff6)：用有限 q/v 历史估计固定 pH 结构模型的隐藏起点状态。以下文献提供方法背景或理论边界，不替代该方案自己的合成真值检验和固定预算审计。


<a id="doc-cb5efe0373e3-1-积分估计可避免显式数值微分但结论依赖模型和可辨识条件"></a>

#### 1. 积分估计可避免显式数值微分，但结论依赖模型和可辨识条件

**Itai Dattner、Chris A. J. Klaassen，2015。** “Optimal Rate of Direct Estimators in Systems of Ordinary Differential Equations Linear in Functions of the Parameters.” *Electronic Journal of Statistics* 9(2): 1939–1973. DOI: [10.1214/15-EJS1053](https://doi.org/10.1214/15-EJS1053)；作者预印本 [arXiv:1305.4126](https://arxiv.org/abs/1305.4126)。

核实内容：作者针对对未知参数线性的 ODE，提出积分形式的直接估计，避免估计状态导数；论文给出其模型类别中的参数可辨识条件及相应渐近率。原文还把初值 \(\xi\) 纳入估计式。这里可支持“积分残差方法能绕开显式数值微分，并可在特定假设下估计参数和初值”。

不能支持：它不证明本项目的隐藏变量 \(z_h\) 在部分可见、固定且可能失配的 pH 骨架下可恢复；更不证明降低本项目的积分最小二乘残差等于恢复真实物理隐藏状态。其假设、观测状态和估计对象与本方案不同。


<a id="doc-cb5efe0373e3-2-ph-模型识别中内部初态本身可以成为校准变量"></a>

#### 2. pH 模型识别中，内部初态本身可以成为校准变量

**Michael Günther、Birgit Jacob、Claudia Totzeck，2023 年 arXiv 预印本。** “Structure-preserving identification of port-Hamiltonian systems — a sensitivity-based approach.” [arXiv:2301.02019](https://arxiv.org/abs/2301.02019)。

核实内容：作者描述了从时域输入输出数据校准 pH 系统的梯度方法，并在迭代中保持矩阵的斜对称和半正定结构；摘要明确说，只有输入输出观测时，内部状态初值也需要校准，并以合成数据展示方法可行性。

不能支持：这是数值校准方法及合成可行性结果，不是“输出误差下降即隐藏状态真实恢复”的一般定理，也没有验证本项目基于积分动量平衡的固定模型 LS 初态估计。请把它用作问题类比，不作本方法有效性的证据。


<a id="doc-cb5efe0373e3-3-连续时间局部弱可观测性有明确前提"></a>

#### 3. 连续时间局部弱可观测性有明确前提

**Robert Hermann、Arthur J. Krener，1977。** “Nonlinear Controllability and Observability.” *IEEE Transactions on Automatic Control* 22(5): 728–740. DOI: [10.1109/TAC.1977.1101601](https://doi.org/10.1109/TAC.1977.1101601)；作者提供的论文原文：[PDF](https://www.math.ucdavis.edu/~krener/1-25/10.IEEETAC77.pdf)。

核实内容：论文建立光滑连续时间非线性控制系统的可控性、可观测性框架；本方案引用的定理针对给定系统上的局部弱可观测性条件。

不能支持：连续时间的可观测性秩条件本身不等价于有限个离散样本下的稳定恢复，也不量化噪声、模型误差或短窗口的条件数。对本任务应把连续秩分析、实际离散矩阵秩、奇异值敏感度和独立真值误差分别报告。


<a id="doc-cb5efe0373e3-4-连续可观测不自动保留到离散采样"></a>

#### 4. 连续可观测不自动保留到离散采样

**S. Ammar、J.-C. Vivalda，2004。** “On the preservation of observability under sampling.” *Systems & Control Letters* 52(1): 7–15. DOI: [10.1016/j.sysconle.2003.08.008](https://doi.org/10.1016/j.sysconle.2003.08.008)；[官方出版社页面](https://www.sciencedirect.com/science/article/abs/pii/S0167691103002925)。

核实内容：论文直接研究采样下可观测性的保持问题。出版社页面的引言指出，数字控制场景只在固定离散时刻观察连续系统；其结论针对采样间隔及系统条件，研究何时可保持可观测性。

不能支持：不能将其概括成“采样必然破坏可观测性”；同样也不能把连续可观测性或某个离散矩阵满秩，推广成当前短历史必然足以稳定恢复隐藏状态。具体定理条件须与本项目的观测映射、采样时钟和窗口匹配。


<a id="doc-cb5efe0373e3-5-连续系统可辨识仍可能遭遇系统混叠"></a>

#### 5. 连续系统可辨识仍可能遭遇系统混叠

**Zhexuan Zeng、Zuogong Yue、Alexandre Mauroy、Jorge Goncalves、Ye Yuan，2024（arXiv 预印本 2022）。** “A Sampling Theorem for Exact Identification of Continuous-time Nonlinear Dynamical Systems.” *IEEE Transactions on Automatic Control* 69(12): 8402–8417. DOI: [10.1109/TAC.2024.3409639](https://doi.org/10.1109/TAC.2024.3409639)；作者预印本：[arXiv:2204.14021](https://arxiv.org/abs/2204.14021)。

核实内容：作者研究从离散采样精确识别连续非线性动力系统的条件，给出 Koopman 框架下的采样周期/系统混叠判据；摘要明确指出，即使模型本身可辨识，低采样频率仍会使连续时间系统识别受挑战，并可能产生相同离散观测对应不同连续动力学的系统混叠。

不能支持：论文的系统类、频谱条件和识别目标须逐项核对；它不直接证明本项目特定隐藏状态不可辨，也不提供一个通用采样率阈值供当前历史使用。它支持的是谨慎边界：离散样本秩或拟合良好不能单独排除采样混叠。
