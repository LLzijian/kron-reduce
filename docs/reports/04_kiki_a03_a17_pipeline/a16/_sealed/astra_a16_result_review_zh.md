## 4. 假设 LS 位移界究竟说明什么

令 B 为冻结的加权历史矩阵，a=Bᵀd̃、G=BᵀB。各槽的行列式下界为正，a 的范数下界大于 0，因此同一个有限数据问题的假设唯一 LS 解在右端改变后会有非零位移。A16 仅给出

\[
\|a\|_{\mathrm{lo}}/\operatorname{tr}(G)_{\mathrm{hi}}
\le \|\Delta z\|_2
\le \|a\|_{\mathrm{hi}}\operatorname{tr}(G)_{\mathrm{hi}}/\det(G)_{\mathrm{lo}},
\]

没有求 Δz、没有构造新 z₀，也没有得到新的闭环 z_T。Gram 条件充分界支持有限问题的可辨性，不等同于实际系统的隐藏状态可辨识。
