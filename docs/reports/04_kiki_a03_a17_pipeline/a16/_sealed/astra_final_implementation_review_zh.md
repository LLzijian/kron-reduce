## 1. 科学问题与因果边界

实现固定使用 A14 的三个 A06 step240 模型所保存的矩阵和残差、同一 258 条 train 历史及三个 seed，共 774 槽。258 条分析人口沿用原权重；全部 268 个原分配对象另外保留在覆盖记录中。三个 seed 不作为三份独立数据。输入范围是记录点 0–10，即记录开始后的 100 ms，不能改称严格故障清除后的 100 ms。

比较对象是冻结的 Pm10 常值与同一已观测历史内 11 点 Pm 的分段线性插值。程序计算固定方程右端的冲量修正，不重新估计状态，不改变既有初始化，不使用未来 Pm、q/v、标签、事件时间、internal val 或 source val/test。该结果可以说明固定历史方程对这一输入修正的响应，不能据此解释 A15 的未来退化、认定恢复了真实隐藏状态或宣称漏判已降到 0。

原字段保留 `Pm=GENROU.tm` 的登记语义，不乘转速；质量为 `Mraw/omega_s`，不额外乘 2；力采用 `P=Q^T` 的映射。根属性、生成器顺序、来源质量和旧 Pm10 锚点均核对。时间按原减法顺序对齐到 A14 保存的 time/h；三个 seed 的 P 和同事件 h 必须逐位相同，才共享一次冲量。点值的求和采用本项声明的固定标量顺序，旧锚点仍保留原值，并另外报告逐位相同与否及绝对差；1e-12 身份容差不构成物理误差界。

## 2. 区间代数和解释

独立复核确认 `G=B^T B`、`a=B^T d` 以及两类固定残差变化的符号、缩放和映射顺序正确。空间残差先施加保存的 `force_residual_projector`，再施加 cS；它与时间堆叠矩阵 B 的列空间检验保持区分。

当行列式下界 d_- 与迹上界 t_+ 为正时，`lambda_max <= t_+`、`lambda_min >= d_-/t_+`，由此得到 `a_-/t_+ <= ||Delta z|| <= a_+ t_+/d_-`。程序只计算这些范数界，未计算新 Delta z 或新状态。`condition_upper` 是 B 的二范数条件数上界。所有区间以保存的有限二进制输入为起点，固定顺序累加并向外扩展；四角乘除、跨零平方和非负平方根处理均保守。

非正行列式下界表示 `numerically_unresolved`，不能解释为秩亏；a 范数下界为零表示未检出，不能解释为输入无影响。实际实现把敏感性界溢出归为 `numerical_failure`、`complete=False`，比设计草案中的 `numerically_unresolved` 更保守。本审核明确接受该分类：原槽与原权重保留，不增加分解、求解或补算。新增区间不覆盖观测误差、源积分误差、观测点之间的插值误差或物理模型失配。

## 4. 失败留痕与持久关闭

来源身份、输入合同、读取边界、预算或日志失败停止整轮。有限代数失败保存已完成诊断和计数，保留该槽及其原权重，再处理其他预定槽。缺失槽存在时，全人口指标置空，同时保存原权重下的部分贡献和缺失权重，不按成功槽重新归一。

最终实现已经修复本审核发现的非有限返回序列化问题：真实溢出的原始 `inf` 在结果中保留明确表示，在日志与闭合范围清单中写为 `value=null` 并保留 `representation` 和原因；attempted/returned 整数不变。实际溢出因此能够作为局部失败持久关闭，而不会因 JSON 拒绝 `inf` 意外变成整轮日志错误。

新的读取与科学范围对象在任何未处理异常后永久停止接受调用。预留、NPZ/JSON 保存或闭合日志的同步失败，均不允许继续下一个载荷或科学调用。结果和计数保存完成后才发布闭合记录；中断范围按已预留上限记为未知且已消费。局部科学失败的原始 Pm/t 已由先行保存的来源输入记录保留。
