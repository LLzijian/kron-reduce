# A16 有界历史机械功率核对授权

依据用户持续指令“继续改进算法和设计，一定要降到0，持续工作，得到最终结果后向我汇报”，登记一次 A16。核心科学方案与边界判断由 Astra Ultra 审核。A04–A15 的授权和已消费预算保持关闭。

只使用 A14 同一 258 条 train 事件、三个冻结模型所保存的矩阵与残差，以及同一历史内 11 个 Pm 和时间记录点。全 268 个原分配事件和 774 个诊断槽均保留在覆盖记录中。不改变输入资格、人口、权重、初始化或已发布模型。

固定问题为：Pm10 常值近似遗漏的分段线性历史输入冲量，是否对固定初态方程有可检出的作用，其范数影响界有多大。没有新状态求解、模型构造、拟合、未来预测或未来归因。标签、internal val、source val/test 关闭。

读取与计算额度逐项遵守两个冻结的 A16 proposals 文件；不得临时扩大成员、时长、分解或候选集合。两个 HDF 和 778 个 NPZ 运行前后各一次完整字节校验；数组描述先于选定 payload。有限数值核的合成检查和最终实施审核全部冻结，且源提交推送到私有仓库并通过检查后，才可原子消费专用共享预算开始一次真实执行。失败槽仍消费其额度，不重试、不恢复，不从原权重删除。

每个 source/impulse/slot/aggregate 调用开始前持久预留完整原语上限，核内逐类 attempted/returned 和硬额度检查，保存结果和计数后持久关闭。来源、读取边界、额度或日志错误停止整轮；局部数值异常保存已完成内容并继续剩余预定槽。中断调用按预留上限消费。

本项不设置 ACCEPT，不授权训练、后续比较、模型晋升或交付预测。结果只能说明固定历史方程对这一输入修正的响应；不能据此宣称已解释 A15 未来退化或达成 0 漏判。后续科学问题另行登记和审核。
