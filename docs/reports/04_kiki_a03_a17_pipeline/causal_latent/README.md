<a id="doc-e7ac54ff3091-1-设计结论"></a>

#### 1. 设计结论

统一动态等值模型采用“保留状态 + 隐状态”的增广方程，并把隐状态初始化作为独立的可辨识问题。角度和转速的历史观测用于估计隐状态，随后模型闭环积分预测；预测区间不再注入真实轨迹。

保留十机空间分辨率并不等于保留完整高阶系统的动态状态；节点数与每个节点的动态阶数需要分别判断。

这一设计同时处理两种被舍弃状态的影响：过去运动积累的记忆，以及预测开始时已经存在的内部储能。后者不能由从零开始的记忆滤波器自动补足。


<a id="doc-e7ac54ff3091-2-为什么当前状态可能不足以决定未来"></a>

#### 2. 为什么当前状态可能不足以决定未来

设完整状态为 `(x,h)`，其中 `x=(δ,ω)`，满足

\[
\dot x=f(x,h,u),\qquad \dot h=g(x,h,u).
\]

如果存在相同的 `x,u` 和不同的 `h₁,h₂`，使 `f(x,h₁,u)≠f(x,h₂,u)`，则不存在能同时精确描述两条轨迹的确定性方程 `ẋ=F(x,u)`。这是信息不足，与网络容量或优化次数无关。

“舍弃状态后一定非马尔科夫”需要这个条件。若被舍弃状态不反馈到可见状态，或在所考虑集合内是可见状态的唯一函数，仍可能闭合；快速松弛时也可能得到有明确误差范围的近似闭合。当前 IEEE39 尚需通过 train 内的观测与残差证据判断这种近似是否足够。

线性分块系统可直接展示记忆与初值两项：

\[
\dot x=A_{xx}x+A_{xh}h+B_xu,\quad
\dot h=A_{hx}x+A_{hh}h+B_hu,
\]

\[
\dot x(t)=A_{xx}x(t)+B_xu(t)
 +A_{xh}e^{A_{hh}t}h(0)
 +\int_0^t A_{xh}e^{A_{hh}(t-s)}[A_{hx}x(s)+B_hu(s)]\,ds.
\]

积分项表示历史记忆；`A_xh exp(A_hh t) h(0)` 表示未观测初值的持续影响。只拟合积分项、把 `h(0)` 固定为零，隐含了额外的初值假设。Mori–Zwanzig 投影对一般系统给出相关的瞬时、记忆和未解析初值项；[Chorin、Hald 和 Kupferman（2000）](https://pnas.org/doi/full/10.1073/pnas.97.7.2968)提供这一理论依据。

<a id="doc-e7ac54ff3091-4-增广能量结构"></a>

#### 4. 增广能量结构

本次原型使用线性势能，以独立核查隐状态机制：

\[
\dot q=v,\quad M\dot v=-Kq-Dv-Cz+u,\quad
\dot z=C^Tv+(J-R)z,
\]

其中 `K,D,R` 对称半正定，`J=-Jᵀ`；`K,D,C` 的端口平衡保证质量加权 COI 约束。`q` 表示相对平衡点的角度。储能及其变化率为

\[
H=\tfrac12q^TKq+\tfrac12v^TMv+\tfrac12z^Tz,\qquad
\dot H=v^Tu-v^TDv-z^TRz.
\]

隐状态与机械状态之间的功率相互抵消，可保留衰减和振荡记忆。用辅助状态实现记忆核也有已有方法支撑，参见 [Lei、Baker 和 Li（2016）](https://arxiv.org/abs/1606.02596)。这为后续非线性势能和可删除记忆模块提供结构基础；原型的储能恒等式检验不等同于完整稳定区域认证。


<a id="doc-e7ac54ff3091-5-初值估计与预测时钟"></a>

#### 5. 初值估计与预测时钟

初始化器接收固定窗口内的角度、转速和登记的恒定输入，解观测方程估计窗口开始时的隐状态，再推进至预测起点。它不读取真实隐状态，也不对角度、转速做数值微分。当前原型假定方程参数已知，验证职责是可观测性和初始化正确性。

初始化检查包括观测矩阵秩、最小奇异值和条件数。秩不足、信号过弱或病态时拒绝给出唯一隐状态。对预测无影响的隐藏自由度可在后续最小实现中删除；对未来有影响而无法辨认的状态应保留不确定性。

真实数据任务按可用信息分开登记：

| 任务 | 可用观测 | 预测起点 | 可回答的问题 |
|---|---|---|---|
| 清除时刻预测 | 清除状态及登记先验 | 清除时刻 | 预测条件均值、范围或给出信息不足的拒绝 |
| 清除前历史预测 | 实际可获取的清除前角度、转速历史 | 清除时刻 | 历史能否辨认清除时刻隐状态 |
| 短窗观测后预测 | 清除至固定 `τ` 的角度、转速 | 清除后 `τ` | 延迟 `τ` 后的闭环预测精度 |

清除前后可能发生拓扑和输入切换，清除前历史不能直接套用后故障方程。当前 canonical 接口和字段说明面向清除后轨迹，尚未验证清除前观测可用；优先登记短窗观测任务。

若使用清除后 `τ` 秒的观测，在清除后 `T=1/5/10 s` 评价时，实际预测长度为 `T-τ`；另外可登记从 `τ` 开始的固定预测长度，但只能使用真实覆盖的时间范围。各模型在同一任务内使用相同窗口、同一起点和相同评分区间，观测窗口不计入未来预测误差。

历史窗口只读取原始时间戳不晚于预测起点的观测。对目标轨迹可用的双侧插值或平滑不能直接迁移到历史输入：不得使用 `τ` 之后的插值支点、中心差分或平滑样本来构造 `τ` 时刻的输入。真实数据接入时需增加这项边界攻击测试。


<a id="doc-e7ac54ff3091-6-合成试验的论证职责"></a>

#### 6. 合成试验的论证职责

试验登记为 `causal_latent_initialization_synthetic_v1`，只生成解析合成系统：

1. **信息不足反例**：相同十机角度、转速及全部允许静态输入，设置两组不同隐状态，检查未来分离，并给出确定性预测的逐通道 RMSE 下界。
2. **初始化对照**：在相同观测窗口和预测起点比较无记忆、隐状态零初始化、历史初始化，以及真实隐状态参照。参照只用于合成误差计算。
3. **可观测性攻击**：关闭一个隐状态端口，并验证估计器拒绝；单元测试另外覆盖端口过弱和病态情形。
4. **物理与数值验证**：随机状态检查储能恒等式；自由预测与矩阵指数真值比较；检查 COI 约束及重复加载一致性。
5. **噪声敏感性**：在登记噪声下重复初始化，单独报告误差，不用该结果选择模型。

本次合成窗口为清除后 0.2 s 的 21 个观测点，随后预测 1 s。这些数值由独立配置固定，不是 IEEE39 窗口选择结果。运行工件提供精确单位、起点和评分区间。

#### 7. 后续任务及完成条件

| 顺序 | 任务 | 完成条件 |
|---|---|---|
| 1 | 合成机制验证 | 反例、初值恢复、拒绝、储能与重放检查通过，并保存不可变结果 |
| 2 | 登记 IEEE39 历史输入协议 | 固定 train/val/test 用途、允许字段、窗口候选、起点、误差尺度和评分区间；原 P2 主表独立保存 |
| 3 | 学习隐状态方程与初始化器 | 参数和初始化器都由 train 学习，容量、窗口、正则化由 val 选择；保存一个模型和一个参数集 |
| 4 | 检查是否需要更多动态状态 | 用积分残差、不同长度窗口和可见状态邻域内的未来分散检查；不把观测噪声或不同输入混作记忆证据 |
| 5 | 统一模块选择 | 联合拟合势能、耗散、衰减及振荡隐状态；按整块删除重新拟合，报告闭环影响 |
| 6 | 冻结后评价 | 各方法使用相同历史、起点和样本；报告 1/5/10 s 对应的实际预测长度、失败及故障线路配对区间 |
| 7 | 隐状态不确定性与稳定裕度 | 对可行隐状态集合计算最保守储能裕度；无法约束隐藏能量时拒绝确定性清除状态证书 |

非线性学习阶段优先使用积分形式的闭环拟合，避免把导数噪声当成隐藏动力学。每条训练轨迹可以有离线隐状态估计作为优化辅助，但独立事件的预测初值必须来自同一个共享初始化器，不能从该事件未来轨迹反求后再用于预测。隐坐标通常存在旋转或缩放等不唯一性，物理解读依据可辨认的端口、极点和储能，而不强行对应某个原始设备变量。


<a id="doc-e7ac54ff3091-8-稳定证书随初值合同一起调整"></a>

#### 8. 稳定证书随初值合同一起调整

增广储能为 `H(x,z)`。当 `z` 无法从清除状态唯一确定时，`c-H(x,ẑ)` 只是所选初值下的裕度。要给出对允许隐藏初值均有效的判断，应评价

\[
\mathrm{margin}_{robust}=c-\sup_{z\in\mathcal Z_0}H(x_0,z).
\]

集合 `𝒵₀` 必须由登记先验或因果观测约束。若使用统计置信集合，须同时报告覆盖假设和概率含义；若得到不了有限有效界，返回信息不足。Level 6 的区域、裕度和失稳漏判检验继续按独立证据要求执行。

<a id="doc-6082ff1af140-结论"></a>

#### 结论

新增的增广动力学原型已验证：在方程已知、隐状态可观测的合成系统中，角度和转速的有限历史能够恢复预测起点的隐藏初值，并支持保持储能关系的闭环预测。初值估计应与记忆动力学共同进入后续统一模型。

代码检查同时确认，P2 的 EGDF、SSDM、GMDPM 已包含内部动态状态，但预测入口把这些状态设为零。因此，后续算法任务需要显式处理隐藏初值，而不能把“存在记忆模块”直接等同于“隐藏状态已经辨认”。

#### 相同清除输入可以对应不同未来

两组轨迹的十机清除角度、转速、输入及静态先验完全相同，隐状态初值分别取相反值。以清除时刻为起点、未来 1 s 为计算范围，角度轨迹分离 RMSE 为 `0.0269335953 rad`，转速轨迹分离 RMSE 为 `0.0572457618 rad/s`。

若这两个初值等概率出现，任何只使用相同清除输入、输出单条确定轨迹的预测器，在这两个样本上的角度 RMSE 下界为 `0.0134667977 rad`，转速 RMSE 下界为 `0.0286228809 rad/s`。这里的 RMSE 对两个样本、全部输出时刻和十个节点逐通道计算。这是该合成配对的下界，不是 IEEE39 的误差下界。

#### 相同历史窗口下的初始化对照

各方法获得相同的角度、转速观测：清除后 `0–0.2 s` 的 21 个点。预测从清除后 `0.2 s` 开始，持续 `1 s`，即评价区间为清除后 `0.2–1.2 s`，包含预测起点，共 101 个点。下表均针对同一个正隐状态样本；所有动态参数固定为合成真值。

| 方案 | 角度 RMSE（rad） | 转速 RMSE（rad/s） |
|---|---:|---:|
| 无记忆动力学 | 0.0111545229 | 0.0236449012 |
| 隐状态动力学，零初始化 | 0.0113682212 | 0.0241538038 |
| 隐状态动力学，历史初始化 | 3.81257×10⁻¹¹ | 9.18364×10⁻¹¹ |

在上述合成样本和相同时间范围中，向角度、转速观测分别加入投影前标准差 `10⁻⁵ rad`、`10⁻⁵ rad/s` 的噪声后，历史初始化方案的角度 RMSE 为 `1.06945×10⁻⁵ rad`，转速 RMSE 为 `1.28869×10⁻⁵ rad/s`。该结果为固定 seed 324 的噪声敏感性记录。

- 单元测试覆盖未来观测拒绝、弱观测、病态窗口、非零恒定输入、检查点保护与禁止 HDF 数据访问。

储能恒等式验证支撑该原型的结构正确性。IEEE39 的隐状态方程学习、轨迹精度和稳定区域仍由各自的登记试验提供证据。


<a id="doc-6082ff1af140-推进安排"></a>

#### 推进安排

1. 为 IEEE39 单独登记历史输入任务，固定 train/val/test 用途、观测窗口、预测起点、允许字段和实际评分时长；保持原 P2-A01 的清除状态基线可追溯。
2. 联合学习隐状态动力学与共享初始化器。参数由 train 学习，记忆维数、窗口和正则化由 val 选择；预测时只用允许历史估计初值。
3. 在相同信息和积分预算下完成无记忆、零初始化、历史初始化对照，再进行统一模块拟合与整块删除。
4. 将隐状态估计的不确定性传递给稳定裕度；对不能约束隐藏储能的输入返回信息不足。

P2 工作流当前停在 `contract_unit_gate`；真实 F1 `controlled_replay`、对抗审查与验收尚待完成。新增合成证据作为算法设计依据，独立保存于本次注册运行。
