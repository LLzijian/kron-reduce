### TASK3 200 ms 冻结参数评估

比较已冻结的 A03 正弦记忆、正弦无隐记忆、线性记忆模型在 TASK3 原评测样本上的表现。用户在明确 `val` 105 例、已曝光 `test` 75 例的范围后指示：“不再重训，直接使用冻结的参数进行评估”。保持原权重、编码器、尺度和模型名单；零拟合、零优化更新、零再选择。

- 只读 TASK3 已封存缓存。`val` 原分配 117、合格 105；`test` 原分配 86、合格 75（expansion 43、holdout 补充集 32）。未覆盖事件保留。验证缓存、评分器及检查点身份；不打开原 HDF5，不解码 `train` 轨迹。缓存整文件的哈希校验读取字节不等于解码数组。
- 观测为记录 0–200 ms 的 21 点功角和转速，输入为该起点的 `Pm[20]−Pm_equilibrium`。按 A03 原定义投影到惯性中心坐标。冻结历史初始化使用同一个常值作条件，不声称真实历史功率恒定。该输入不同于 A03 拟合时的 `Pm[0]`，结果属于固定参数迁移评估。
- 真正观测的历史和起点保持原样。未来使用原相对功角与相对转速输出；固定约定共同频率偏差为零，不补入观测共同频率的保持、拟合状态或任何未来信息。完整六项分数中的共同频率误差按这个明确约定计入，不能称为模型学到的共同频率预测。
- 复用 TASK3 已冻结的 1/2/5/8 s 轨迹、失稳样本可用数据、共同频率、8 s 失步和数值规则。每个模型每个划分先用 5/10 ms；若原综合分数未取得，再按 TASK3 原规则用 2.5 ms 与 5 ms 核对一次。历史隐状态初始化与未来预测使用同一个步长上限。失败与未决保留，不重试或换模型。
- 原 A03 接口在积分异常时不返回中途结果。该条未来路径记为不可用，不补算失败前的区间；这比 TASK3 保留失败前有效区间更保守。若发生异常，单列并保留，不将受影响指标称为完全等口径结果。
- 最多 540 个模型与样本组合、1620 条路径、3,099,600 次 RK4 更新、12,398,400 次右端计算。先冻结名单和规则，完成 `val` 后再读 `test`。执行只允许在登记的唯一 checkout，首次缓存读取前一次性消耗。通用运行器的 `TEST_EXPOSED` 保持不变；专用入口在方案和确切实现未获独立审查并登记前拒绝执行。

历史 TASK3 结果作同样本参照，保留原训练与数值状态。本轮比较的是冻结模型表现，不是相同训练条件下的算法优劣；已曝光 `test` 不构成独立确认，结果不用于模型晋升或部署。
