#### 2. 四个机制判断需要怎样表述

**固定端口限制成立，具体残差来源待分解。** 固定参数和观测历史时，隐藏力位于 `range(PC)`，任何初态估计都不能消除其物理正交补上的动量残差。端口维数增加或随状态变化是候选扩展，现有比例没有证明扩展后能够消除该残差。

**初始化器更换造成训练与使用方式不同，但储能增加不等于未来必然恶化。** 训练中的 `encoder_penalty` 惩罚 encoder 参数均方，并非逐样本隐藏能量硬约束。无正则最小二乘会吸收设计矩阵列空间内的误差；[A13 S10](../../04_kiki_a03_a17_pipeline/a13/README.md#doc-7ab8e2d54e4b)具体展示的是错误输入被初态吸收、残差仍为零。较高储能如何交换、耗散及影响未来，依赖完整状态与动力学。A15/A17 的 REJECT 保持原判，但不能据此把能量增长认定为唯一原因。

**共同能量屏障是条件定理。** 常值 COI 输入下，保持同一储能和互易耦合可得到 `dW/dt≤0`。要断言轨迹不能触发失稳，还需证明同一完整初态位于共同有效域内的紧致、正向不变子水平集连通分支，且该分支内所有状态都不触发所用判据。现有证据没有证明 `expansion_0118` 满足这些条件。共同充分区域也不等于整个实际吸引域。见[能量屏障补充](../../04_kiki_a03_a17_pipeline/a16/README.md#doc-8abac79dff34)。

**时间权重不支持“长样本天然压倒短样本”的结论。** 当前[训练实现](../../../../src/kron_reduce/models/nonlinear_latent.py)对完整 3 s 样本，前 100 个未来时刻每点权重为 `1/150`，后 200 点为 `1/600`，因此前 1 s 占时间权重的三分之二。对只有 N 个未来时刻的样本，每个时域分别除以 `min(时域点数,N)`，不是按缺少的数据扣除事件权重。外层按 source→line→event 分配权重，不能用类别样本数比例替代训练权重，更不能从权重质量推出梯度方向。现有证据未证明稳定样本推动了阻尼增大或刚度下降，也未证明 A11 的拒绝源于振荡尾部相位噪声。

原方案引用的约 83.6% 实为 A04 内部 val 的稳定样本权重质量，不是 train 的梯度份额。见 [A05 设计中的既有诊断](../../04_kiki_a03_a17_pipeline/a05/README.md#doc-846d590fcb8a)。


<a id="doc-d306b4c8a553-3-阶段一的数学对象与判断条件"></a>

#### 3. 阶段一的数学对象与判断条件


<a id="doc-d306b4c8a553-31-先区分参数已知与参数同时未知"></a>

##### 3.1 先区分参数已知与参数同时未知

主问题固定真值参数、输入、可见初态和 COI 坐标，估计历史起点隐藏状态 \(z_h\)。参数也需要识别是另一个问题，不能用已知参数下的成功代替回答。

令 \(M=\operatorname{diag}(m)\)，\(Q=I-\mathbf1m^\top/(\mathbf1^\top m)\)，\(P=Q^\top\)，\(A=J-R\)。保留现有方程

\[
\dot q=v,\quad M\dot v=P[p-F(q)-Dv-Cz],\qquad
\dot z=C^\top v+Az.
\]

理想连续、无噪声且参数输入正确时，若 \(PC\) 满列秩，可见动量导数已经唯一给出 \(z(t)\)。这里要求的是 \(PC\)，不是未经投影的 C。现实问题在于有限离散 q/v 观测不直接提供精确导数或区间内路径。

实际离散观测映射应另定义为

\[
\mathcal F_T(z_h)=\{q(t_j;z_h),v(t_j;z_h)\}_{j=0}^{J},
\]

其中使用完整闭环真值方程、固定可见初态和相同已知输入。线性真值可用完整系统指数描述，非线性真值须区分局部灵敏度与全局多解。去除坐标规范后，局部 Jacobian 满列秩支持局部可辨，不自动证明整个初态集合上的唯一或稳健恢复。[Boyd–Lall 的离散观测矩阵讲义](https://ee263.stanford.edu/lectures/observ.pdf)提供线性已知系统的标准定义。

完整隐藏初态恢复与可见未来预测分别判定。两个隐藏状态可以历史不可区分，却在全部关心的未来时刻产生同一可见轨迹；[A13 S05](../../04_kiki_a03_a17_pipeline/a13/README.md#doc-7ab8e2d54e4b)已有这样的证据。噪声条件下，还需在注册初态集合内检查观测差不超过噪声容许范围的状态对，其未来差是否超过声明容差。有限状态对检验不能代替连续集合上的全局证明。


<a id="doc-d306b4c8a553-32-积分矩阵只是一个有插值假设的估计方程"></a>

##### 3.2 积分矩阵只是一个有插值假设的估计方程

沿用[冻结积分定义](../../04_kiki_a03_a17_pipeline/a13/README.md#doc-4c1365b73ff6)的 \(S=\operatorname{diag}(1/(m_i s_{v,i}))\)、\(h_j=t_{j+1}-t_j\)、\(T=t_J-t_0\)，将历史起点平移为零。令

\[
L_j=PC\int_{t_j}^{t_{j+1}}e^{At}\,dt,\qquad
\widetilde L_j=\frac{SL_j}{\sqrt{Th_j}},\qquad F_o(t)=SPCe^{At}.
\]

对应的连续 Gram 矩阵为

\[
W_c(T)=\int_0^T F_o(t)^\top F_o(t)\,dt.
\]

按区间 Cauchy–Schwarz 不等式，

\[
\widetilde L^\top\widetilde L
=\sum_j\frac{1}{Th_j}
\left(\int_{I_j}F_o(t)\,dt\right)^\top
\left(\int_{I_j}F_o(t)\,dt\right)
\preceq \frac{W_c(T)}{T}.
\]

因此应比较 \(\widetilde L^\top\widetilde L\) 与 \(W_c/T\) 的谱，或对应平方根与奇异值，不能直接把不同量纲的 \(W_c\) 特征值和 \(\widetilde L\) 奇异值相比。现有时间平均归一化不保证窗口越长，最小奇异值就越大。这个连续 Gram 描述隐藏齐次响应的力输出，不是含噪 q/v 离散观测本身的完整信息矩阵。


<a id="doc-d306b4c8a553-33-一个解析反例说明为什么两种满秩仍不够"></a>

##### 3.3 一个解析反例说明为什么两种满秩仍不够

取 \(M=I\)，\(n\ge3\)，\(1\le r\le n-1\)，\(N^\top N=I_r\)、\(\mathbf1^\top N=0\)，\(C=\omega N\)，\(U=D=J=R=0\)，\(p=0\)，\(q(0)=v(0)=0\)，且 \(\omega h=2\pi\)。完整闭环的解析解为

\[
z(t)=\cos(\omega t)z_h,\quad
v(t)=-N\sin(\omega t)z_h,\quad
q(t)=\frac{N}{\omega}[\cos(\omega t)-1]z_h.
\]

任意 \(z_h\) 在所有 \(t_j=jh\) 上给出相同的零 q/v。可是 \(PC=C\) 满列秩，积分算法使用 \(A=0\) 得到 \(L_j=hC\)，同样满列秩。把这些零观测线性插值后，右端为零，算法返回零初态。可见，插值方程唯一解仍可与真实离散观测的不可辨识同时发生。

这是 Astra Ultra 复核的解析边界反例，没有执行数值试验。零势能、零耗散不能替代某个严格正定有界参数族的检验。它也没有证明 kiki 存在同类混叠。若未来仍只在同相位网格评分，差异会继续隐藏，协议必须声明关心的未来时间集合及失稳规则的离散时钟。


<a id="doc-d306b4c8a553-34-误差必须按来源拆开"></a>

##### 3.4 误差必须按来源拆开

在固定、满列秩的 \(\widetilde L\) 下，

\[
\widehat z_h-z_h=\widetilde L^\dagger\Delta\widetilde b,\qquad
\|\widehat z_h-z_h\|\le
\frac{\|\Delta\widetilde b\|}{\sigma_{\min}(\widetilde L)}.
\]

这只是在该方程正确时的敏感度关系。若算子也有偏差，另含 \(\Delta\widetilde L\,z_h\) 的影响。实际准备应分开观察

- 同一分段线性 q 上的 Gauss 求积误差。
- 分段线性 q/v 与连续真值路径之间的插值、运动学误差。
- 输入回放近似与骨架或参数失配。
- 观测噪声经共享端点差分、积分后的相关误差。
- 历史起点误差、闭环历史末态误差与未来传播敏感性。

两点与四点 Gauss 的差不能给出全部插值或真实初态误差界。S 是现有指标缩放，不是噪声协方差白化。噪声范围未知时，“奇异值充裕”没有可操作含义；需要相对于冻结状态尺度和噪声预算报告恢复误差。临近失稳边界，轨迹误差较小也不自动保持分类，需要单列真值判据余量与边界未决情况。

#### 4. 最小比较设计与事前冻结清单

100 ms 为主合同，固定 10 ms 间隔时有 11 点。20/50/200 ms 分别为 3/6/21 点，只作预先指定的长度诊断。使用同一预测起点的嵌套历史，比较相同未来时段，不按结果挑窗口。完整真值仅供参照与评分，估计器只收到声明的可见历史与输入。

| 对照内容 | 回答的问题与必要记录 |
| --- | --- |
| 已知真初态、参数与输入的完整闭环参照 | 先隔离真值生成和传播误差。真值积分器、两档精度和失败停止条件事前冻结，不以反复加密获得通过。 |
| 精确采样观测映射与分段线性积分估计 | 区分可观测信息与估计器近似。分别报告完整观测映射的局部灵敏度、积分谱、真值 \(z_h\) 恢复误差；保留已知混叠反例。 |
| 弱端口与已知观测噪声 | 同时报告绝对奇异值、噪声幅度、初态及未来误差。相同条件数不足以表示相同稳健性；包含弱可见方向。 |
| 物理端口外失配与加权算子列空间内失配 | 分开注入，不把 A14 的约 46% 汇总比例当作力扰动幅值或固定自然常数。先声明范数、方向、时间形状和幅度；已知扰动带来的能量或外部做功另列。 |
| 端口内但跨时间不满足隐藏方程的失配 | 区分每时刻力空间可表达与同一个隐藏初态可解释；刚度误差位于端口内，不代表其堆叠量属于积分算子的列空间。 |
| 常值输入的一致性对照 | 两种历史输入流程在常功率下应彼此一致；各自与真值之间的估计和传播误差另列，避免把估计误差与输入实现差混合。 |
| 有限的参数失配方向 | 固定参数偏差而不拟合，检查隐藏初态与参数误差混淆。参数联合识别保留为后续独立问题。 |

直接向积分右端注入向量属于代数诊断，不自动构成符合真值 ODE 的合成轨迹。动力学失配比较须另外声明真值方程，并与代数对照分开。

每项涉及预测的比较保留同一完整链条：估计 \(z_h\) → 从获准观测的历史首点 q/v 闭环积分 → 历史末点仅重置为获准观测的可见 q/v → 保留各自闭环 \(z_T\) → 同一未来常值输入下预测。噪声比较的首末点同样含声明的观测误差，干净 q/v 只供真值参照或独立登记的信息对照。观测驱动 \(z_T^{obs}\) 另列诊断，不能替代闭环 \(z_T^{cl}\)；真值 z 不进入候选估计器。

复用 [A13](../../04_kiki_a03_a17_pipeline/a13/README.md#doc-7ab8e2d54e4b) 已保存的收敛、弱端口、输入混淆与混叠证据作为设计依据。其已完成算例不重复执行。本轮拟议新增部分重点补足完整离散观测映射、噪声与同一未来链条；节点数、隐藏维度和参数范围必须明确注册，不将历史四节点结果冒称十节点结论。

执行前仍须冻结以下内容

1. 真值系统、节点数与维度、参数和初态集合、COI 规范、输入、有限窗口及采样表。隐藏频率之外还需覆盖端口强度、阻尼和完整闭环频率，不能只扫 \(\operatorname{Im}\lambda(A)\)。
2. 观测噪声模型、幅度、相关性及固定种子，失配方向与幅度，所有状态和误差尺度。参数不能按 A15/A17 现象反向调到出现预期失败。
3. 历史与未来 3 s/8 s 的角色、精度和评分时间集合，恢复误差、最差误差、未决和失败的判定门槛，失稳边界的余量要求。精确采样参照若需搜索或求解，必须给出有限上界与失败出口。
4. 真值、估计器、参照和评分的代码及哈希，矩阵指数、SVD、LS、力、RHS、路径和全部调用预算，保存数组与独立重放清单。预算包括负例和失败尝试。

<a id="doc-d306b4c8a553-51-能量约束初始化器"></a>

##### 5.1 能量约束初始化器

可保留为阶段一之后的候选，但先区分历史起点和预测起点的能量。如果限制 \(H_z(z_h)\)，并不自动限制闭环传播后的 \(H_z(z_T)\)。可见机械能变化也不能在缺少隐藏初始能量或不可观测方向上界时，唯一给出总隐藏能量上界；encoder 分布范围只是统计先验，不是物理证书。

给定正半径 \(\rho=\sqrt{2\bar H_z}\)，考虑

\[
\min_z \tfrac12\|\widetilde Lz-\widetilde b\|^2,\quad
\tfrac12\|z\|^2\le\bar H_z.
\]

满列秩时，KKT 条件给出

\[
z(\lambda)=V\operatorname{diag}\left(
\frac{\sigma_i}{\sigma_i^2+\lambda}\right)U^\top\widetilde b.
\]

无约束解在球内时取 \(\lambda=0\)；约束有效时由 \(\|z(\lambda)\|=\rho\) 确定非负乘子。边界半径为零直接规定 \(z=0\)，秩亏情形须另定未决处理。这是给定能量预算后的标量求解，不是由一个正交残差比例唯一解析推出 \(\lambda\)。椭球约束还需相应的度量变换，不能直接沿用球约束公式。[Golub–Hansen–O'Leary 原文，第 2 节](https://www.cs.umd.edu/users/oleary/reprints/j51.pdf)给出约束最小二乘与正则形式的关系。

在同一加权坐标中，若 \(\Delta\widetilde b=\widetilde L a\)，最小二乘初态可偏移 a，残差仍为零；若 \(\widetilde L^\top\Delta\widetilde b=0\)，它增加残差而不改变无约束初态解。物理 `range(PC)` 的正交补与加权堆叠 `range(Ltilde)` 的正交补还不是同一对象。因此，正交残差比例可以作为诊断量，不能单独识别需要多少收缩。

可微求解器进入训练属于新算法。届时需让训练与使用采用同一合法历史、同一闭环初始化流程，检验约束切换、秩变化及梯度，优先使用稳定线性求解而非直接对退化 SVD 向量反向传播。减少 encoder 参数不等于总计算成本下降，求解和反向传播须计入预算。不能改写或替换已消费 A14 的冻结求解器。

##### 5.2 状态依赖端口与势能

互易的 \(-PC(q)z\) 和 \(C(q)^\top Qv\) 可保持功率抵消。所提 \(C_0+P\operatorname{diag}(\sin(Qq))NA(\Theta)\) 在维度、平衡力基和坐标一致时可作为候选；状态变化不保证列空间实际旋转，也不保证端口外残差下降。尽管能量抵消的代数形式保留，状态依赖实现、平衡、梯度与数值精化仍需新检查。

二次谐波会改变势能面，但 \(k_2\ge0\) 不保证势垒降低、局部刚度正定或漏判改善。需导出匹配的势能、平衡与 Hessian，并验证使用区域；现有移位正弦势能本身不具全局非负保证。不能从通用发电机机理直接认定某个已曝光样本的真实错误来源。

联合势能 \(\sum_e k_e\Phi_e(q)+\tfrac12\|z-G\Psi(q)\|^2\) 需要在整个 pH 方程中使用新的 q/z 梯度。加上原动能得到 H，令 \(\xi=z-G\Psi(q)\)，则 \(\nabla_z H=\xi\)，\(\nabla_q H=\nabla U-[D\Psi(q)]^\top G^\top\xi\)，其中 \(D\Psi\) 是 \(\Psi\) 的 Jacobian。功率一致的一个形式为

\[
M\dot v=P[u-\nabla_q H-Dv-C(q)\nabla_z H],\qquad
\dot z=C(q)^\top Qv+(J-R)\nabla_z H,
\]

对应隐藏耗散为 \(\xi^\top R\xi\)。只替换可见恢复力、仍保留旧的 \(-Cz\)、\(C^\top v\)、\(-Rz\) 形式，不能沿用旧能量恒等式。平方项非负也不证明整个移位势能全局非负。

端口、势能和初始化器应分别比较。当前没有依据把三者作为一个已确认改进直接合并。

##### 3.1 线性真值与观测参照

对每个线性模型构造 22 维状态 x=(q,v,z) 的生成矩阵 G，以及末维恒为 1 的 23 维仿射矩阵 G_aff。可见动力学必须含项目规定的力投影 P。即使当前平衡力参数令 P 的部分作用代数消失，也不混用 P 与 Q。

每个不同 G_aff 只生成一次 exp(0.01G_aff)，随后按整十毫秒时钟递推。对 0.2 s 和 8.2 s 的转移，分别与直接矩阵指数比较；允许按 (模型身份,时长) 缓存直接指数。每条估计器历史及未来段的末态，也用对应直接端点转移核对，缓存复用必须在预算中明确。生成矩阵作用与公共 `closure.rhs` 在三个固定状态核对：零状态、(q_*,v_*,z_*)，以及 (Qe_3,Qe_4,(1,−1))。不得把矩阵指数/矩阵传播冒充 RK4 或漏记公共 RHS 调用。

历史 J 个非首点的完整采样算子为

\[
O_T={1\over\sqrt{20J}}
\operatorname{stack}_{j=1}^J\bigl[H e^{Gt_j}E_z\bigr],
\]

其中局部历史时钟 t_j=jh，H 提取 20 个可见通道，E_z 把两维隐藏初态放入完整状态。已知可见首点和常输入产生的基准路径使用 z_h=0；其可见输出记为 y_j^0。精确采样参照求解

\[
\widehat z_{exact}=\arg\min_z\left\|O_Tz-
{1\over\sqrt{20J}}\operatorname{stack}_{j=1}^J(y_j^{obs}-y_j^0)\right\|^2.
\]

含噪病例的 y_j^0 从**含噪可见首点**开始，因此首点噪声经动力学传播的影响保留。这里“精确”指模型采样映射，没有声称含噪反演精确。主线性族 O_T 是全局线性映射，满列秩可证明固定已知参数、固定可见首点下的全局唯一性；不推广到联合参数识别或正弦模型。

##### 3.2 固定积分估计

沿用 q/v 分别分段线性插值、w′=Aw+Cᵀv_obs、w(0)=0，定义

\[
g_j=\int_{I_j}P[p-F(q_{obs})-Dv_{obs}]dt-M(v_{j+1}-v_j),
\quad b_j=g_j-PC\int_{I_j}w(t)dt,
\]
\[
L_j=PC\int_{I_j}e^{At}dt,\quad
S=\operatorname{diag}(1/m_i),\quad
c_j={1\over\sqrt{Th_j}},\quad
\widetilde L_j=c_jSL_j,\quad\widetilde b_j=c_jSb_j.
\]

使用原定义的 8×8 增广矩阵指数计算隐藏卷积与积分，不求 A 的逆。q 上力积分固定 Gauss4 为主解、Gauss2 为求积诊断；两者共用同一 L、w 和端点动量。线性 F 的两阶求积应一致；正弦差值只反映同一插值上的求积差。每个右端用保存的同一薄 SVD 求无正则 LS；不搜索阈值、不裁剪状态、不回退 encoder。

报告物理欧氏投影 r_F,j=(I−Π_PC)g_j、动态残差 b−Lz、加权动态残差、运动学残差 q_(j+1)−q_j−h_j(v_j+v_(j+1))/2、两种末态 z_T^obs 与 z_T^cl。S 缩放后的投影量另列，不把它们称为同一个正交分解。

数值秩统一采用 τ_X=64 ε64 max(shape(X)) max(σ_max(X),a_X)。O_T 的 a_X=1；积分算子的 a_X=||SPC||_F；PC 的 a_X=0。记录全部奇异值、阈值、秩和绝对逆奇异值。秩不足保存未决，不把最小范数代表当作完整恢复成功；第 7 节需要的代数代表单独标记。

对 O_T 和积分算子分别做秩判断，不相互替代。另记录

\[
W_c(T)=\int_0^T e^{A^\top t}C^\top P^\top S^2PCe^{At}dt,
\qquad\widetilde L^\top\widetilde L\preceq W_c(T)/T.
\]

W_c 使用固定 4×4 块矩阵指数计算：若 E=exp(T[−Aᵀ,Q_c;0,A])、Q_c=CᵀPᵀS²PC，则 W_c=exp(AᵀT)E_12。exp(AT)复用隐藏转移。保存未对称原值及对称误差；对称平均只用于实对称谱诊断，不掩盖原值不一致。

<a id="doc-b0bb3c592ade-5-完整传播链和正弦数值条件"></a>

#### 5. 完整传播链和正弦数值条件

每个完整链方法固定执行：从获准观测历史首点 q/v 与该方法 z_h 出发，在历史内自由闭环传播；历史中间不注入观测；在 t=0 只重置为获准观测末点 q/v，保留各自 z_T^cl；随后在同一常输入 p 下自由预测到 8 s。含噪首末点都使用含噪值。保存 reset 前后完整状态和能量差，不能将该离散跳变计为连续动力学被动性失败。

true-z oracle 使用真实历史起点 z_h，但同样从该病例获准观测 q/v 出发并进行同一 reset；含噪时它不一定等于干净真值轨迹。评分分别相对干净真值，以及相对这个信息对照。z_T^obs 只作诊断，不能进入未来预测。

线性链全部用第 3.1 节的准确仿射传播，保存每 10 ms 输出和直接端点核对。正弦固定名义步长为 0.00125/0.000625 s，即每个 10 ms 区间固定 8/16 次 RK4 更新。调用公共 rollout 时，实际传入的 max_step 为 nominal_step×(1+10^−10)，只用于避免相邻十毫秒浮点时钟相减后被 ceil 错判为额外子步。每次调用前，用完整输出时钟断言公共规则 ceil(diff(clock)/dispatch_max_step−10^−12) 的结果逐区间恰为 8/16；不符立即停止。公共 RK4 的实际子步仍为 diff(clock)/8 或 /16，不按放宽值作为实际积分步长。逐路径保存名义步长、传入 max_step、子步数及实际子步最小/最大值；这次确定性浮点处理在运行前冻结，不由结果改变。两条正弦真值从 −0.2 到 8 s；细真值截取两组 100 ms 输入。每个病例的 integral 与 true-z oracle 各执行两档历史及未来段，不借用另一档的隐藏末态。

正弦全部方法可解时的精确积分预算为：两条真值 6,560+13,120 次更新；四个“病例×方法”各有 6,480+12,960 次更新；合计 **97,440 次 RK4 更新、389,760 次积分 RHS、18 个独立积分段**。真值段 2 个，加上 2 病例×2 方法×2 步长×历史/未来 16 段。若某积分方法按冻结数值秩规则为 unresolved，则保留该方法记录和分解，跳过其传播、不使用替代初态；令 a 为两个正弦病例中 resolved 的方法数，实际积分 RHS 必须精确等于 78,720+77,760a，段数必须等于 2+4a，并与逐路径时钟记录的四倍 RK4 更新总数一致。a=4 时达到上述完整预算；未用额度不转移。段间 reset 不算 RK4 更新。逐调用日志记录 path_role、method、名义步长及传入 max_step；历史和未来使用对应 phase。真值路径 role=truth，并以其前 20 个十毫秒区间（−0.2 至 0 s）计为 history_integration，其余计为 future_integration，不能把整条真值或候选未来误记为历史。

所有保存输出检查 finite 和 COI。每段路径在首点、索引 floor((N−1)/2) 的中点、末点调用公共 energy_identity，并计入 physical_rhs；全部方法可解时的 18 个正弦段有 54 次 physical_rhs，正弦上述两类 RHS 合计 389,814；有 unresolved 方法时该物理检查数为 3(2+4a)。额外模型生成矩阵核对、线性路径物理检查及 reset 的纯 energy 求值单列，不藏在此数字内。抽样能量恒等式不是 RK4 全路径能量误差证书或稳定域证书。


<a id="doc-b0bb3c592ade-6-误差指标与有限噪声可区分性"></a>

#### 6. 误差指标与有限噪声可区分性

每个完整链分别保存 z_h、z_T^cl 的欧氏误差，隐藏储能误差，3/8 s 可见归一化 RMS 和最大绝对误差；同时分列 q、v。RMS 的分母为该时域的非起点输出数×20，不把 3 s 指标再与 8 s 混合为可调权重。主要科学判定使用最大绝对可见误差；两种指标都保留。

固定经验容差：干净和刚度失配病例的隐藏起点误差阈值为 10^−3、3/8 s 可见最大误差阈值均为 10^−3；含噪病例两阈值均为 10^−2。true-z oracle 的未来误差也按相应病例记录。阈值是该合成尺度下的预定工程尺度，不是失稳概率、真实 kiki 误差证书或总体可恢复性的定义。数值误差门槛另列在第 9 节。

在线性主模型和 weak 的 100 ms 算子上各做一次固定有限状态对检查。用 z_h,true 为中心、半径 1 的隐藏状态球作**评价集合**，不把真值中心提供给估计器或用于裁剪。取 ε=10^−5、

\[
a=\min(0.5,\epsilon/\sigma_{min}(O_{0.1})),\qquad
z_\pm=z_{h,true}\pm aV_{min}.
\]

二者从相同干净可见首点、相同输入、同一真值参数出发，完整采样历史的归一化差应为 2aσ_min≤2ε。未来比较使用各自连续真值链，不强行重置为同一个可见末点；这是信息对的真值比较，不是候选初始化流程。线性状态对可直接由保存的完整转移作用计算，无需新参数搜索或优化。分别记录 3/8 s 可见 RMS/最大差。若最大差严格超过 2×10^−2，则存在同一噪声容许观测，而任何一个预测不可能同时对这两条真值达到 10^−2 最大误差，构成该噪声预算和工程容差下的未来信息不足反例。不超过只表示该固定状态对未构成此反例，不能证明整个球都稳健。

线性 O 满列秩另提供确定性界 ||Δz||≤||Δy||/σ_min，明确 Δy 是经过已知首点与输入扣除的归一化右端扰动；交替噪声要包含首点传播项。若使用该界报告整个已知线性族的状态误差上界，必须保留实际右端噪声范数，不能直接把原始 q/v 噪声幅度代入。正弦两病例只报告经验状态/未来误差，不声称全局可辨，也不运行非线性初态优化。


<a id="doc-b0bb3c592ade-7-两种不同的不可辨负例"></a>

#### 7. 两种不同的不可辨负例

**A_alias。** n=10、r=2、M=I、N 仍为上述平衡力基，C=ω[N_1,N_2]，ω=2π/0.01，K=D=J=R=0，p=0。历史起点 q=v=0，两个隐藏初态为 (0.6,−0.4) 与 (1.6,−0.4)。不用 RK4，直接用

\[
z(s)=\cos(\omega s)z_h,\quad v(s)=-[N_1,N_2]\sin(\omega s)z_h,
\quad q(s)={[N_1,N_2]\over\omega}[\cos(\omega s)-1]z_h,
\]

其中 s 从历史起点计。所有十毫秒节点的数学精确 q/v 均为零；估计器输入这些精确零，另保存浮点三角函数计算对零的偏差。完整节点观测映射解析上 O=0；若同时用完整矩阵指数构造数值 O，须与零一致至 10^−10，且按冻结阈值判为 rank=0。PC 满列秩、A=0、L_j=hC 满列秩；Gauss4 积分估计返回 z_h=0。节点未来的可见差保持零，不据此宣称全部连续未来相同。

追加且仅追加未来 τ={0.0025,2.9975,7.9975} s 的解析记录。每处两个真值的速度差二范数为 1，远大于预定 10^−2 未来容差，检出非同相位未来相关混叠。保存估计零状态的解析历史/reset/未来，与两个 oracle 分列。三角函数节点残差≤10^−10、各追加点速度差与 1 的差≤10^−10。验证解析导数、公共 RHS 和 COI 的一致性。此模型只作半正定边界反例，不声称属于主参数严格耗散族，也不声称真实 kiki 存在该混叠。

**U_hidden_null。** 使用 hidden_null 变体，在 t=−0.2 的同一 q_*,v_* 下分别取 z_*=(0.6,−0.4) 和 (0.6,0.6)。第二隐藏方向按 exp(−0.55t) 自由衰减而不作用于可见系统。两条真值的全部历史及 3/8 s 可见输出差≤10^−10，第二隐藏状态差非零；其 100 ms O 与积分算子均应为 rank=1。报告完整隐藏状态/储能不可唯一恢复、可见未来等价。允许保存最小范数代数代表，不将其发给普通 full-rank 候选流程冒称完整恢复。


<a id="doc-b0bb3c592ade-8-三种代数失配与常输入恒等式"></a>

#### 8. 三种代数失配与常输入恒等式

复用 L100_clean 的原时钟、L、\widetilde L、S、c 和真实历史起点 z_h。以下右端使用人为构造的 b_*=Lz_h，明确不声称它就是分段线性观测构造的 b。它们不产生真实或合成 ODE 观测，也不报告未来收益。

1. **D_force_orth：** 每区间 d_j=0.02h_jN_3。对 b_*+d 求解。物理正交补投影应恢复 d；其误差≤10^−10。记录加权估计偏移，**不要求其为零**，因为非均匀 S 不保留原物理正交性。另将同一加权扰动减去它在 range(\widetilde L) 中的投影，复用原 SVD 再解一个右端；该加权正交扰动须保持 z_h 不变至 10^−10。这一固定额外 LS 单独计入预算，用于分清两种度量。保存不同度量下的残差，任何比例都使用明确分母；不追求复现 A14 的 46%。
2. **D_column_confounded：** 固定 a=(0.25,−0.15)，令加权右端为 \widetilde L(z_h+a)。估计应为 z_h+a（误差≤10^−10），加权残差≤10^−10。它证明状态偏移可伴随零残差，不识别真实误差来源。
3. **D_port_temporal：** 先令 d_j^(0)=h_j(−1)^j C(1,0)ᵀ，j=0,…,9；按 c_jS 缩放堆叠后，减去其在 range(\widetilde L) 上的欧氏投影，得到 r。要求 ||r||>10^−12，再归一为 ||r||=0.01；若不成立记实现/设计未决并停止，不换方向。向 \widetilde Lz_h 加此 r。估计仍为 z_h（误差≤10^−10），加权动态残差范数为 0.01（绝对差≤10^−10）；反缩放后的每块物理端口外残差≤10^−10。
4. **I_constant_input：** 对主 100 ms 历史，用 h_jp 和 h_j(p+p)/2 分别构造输入冲量；复用完全相同的其余项。两右端、同一 SVD 下初态及观测驱动末态最大差≤10^−12。常值与线性插值的历史输入在各固定阶段时刻返回相同 p；候选传播映射因此相同。可以复用已保存闭环路径并以输入和右端恒等式为证据，不冒称额外跑过两次独立未来。两流程相同不要求积分估计等于真值；其真值误差沿用 L100_clean。

所有容差在见到本轮数值结果前冻结。除专门说明外使用 absolute error≤tol×max(1,相关比较量范数)。

| 检查 | 门槛和处理 |

| 所有输出 finite | 必须全部成立 |
| COI | abs(mᵀq)、abs(mᵀv)≤10^−10 max(1,norm(m)·norm(状态分量)) |

没有源标签、val/test 或真实失稳结果；不产生新 FNR/FSR，也不报告稳定性认证。已知线性族的正结果、正弦有限病例结果、解析负例各自保持范围。本轮完成后只作证据审查和下一问题裁定，不自动进入后续候选阶段。

#### 分轴科学结论

下表隐藏误差为历史起点的欧氏误差；未来误差为协议固定尺度下全部非起点 q/v 输出的最大绝对误差。干净和失配阈值为 `1e-3`，含噪阈值为 `1e-2`。

| 证据 | 隐藏状态轴 | 未来与信息轴 |
| --- | --- | --- |
| 主线性 100 ms、干净 | 精确采样 LS 误差 `1.11e-16`；积分 LS 为 `7.30e-6`，均达阈 | 完整采样算子秩为 2；积分 LS 的 3/8 s 最大误差均为 `1.19e-6` |
| 主正弦 100 ms | 干净、交替噪声的积分误差分别为 `6.71e-6`、`6.39e-6` | 对应 3/8 s 最大误差分别为 `1.07e-6`、`9.53e-5`；支持这两组观测的经验恢复，不产生全局非线性唯一性证明 |
| 弱 C、干净 | 精确采样 LS 为 `1.53e-12`；积分 LS 为 `3.61e-2`，后者未达隐藏阈值 | 积分 LS 的 3/8 s 最大误差均为 `9.55e-7`，达到未来阈值 |
| 弱 C、最弱方向噪声 | 两种估计隐藏误差约 `19.26`，未达阈 | 两者 3/8 s 最大误差约 `4.98e-4`，均达阈；大隐藏误差不等于该时域可见预测失败 |
| 刚度失配、干净 | 两种估计误差约 `0.063` | 两种估计和真实隐藏初态对照的未来均未达 `1e-3`；恢复真实初态本身不足以使这个错参模型达标 |
| alias / hidden_null | alias 的积分算子秩为 2，但真实节点采样映射为零；hidden_null 的两算子均为秩 1 | alias 在同相位未来节点等价，三个追加时刻的速度差范数均为 1；hidden_null 的全部保存可见路径完全相同 |

主线性 20/50/100/200 ms 的准确采样反演均恢复隐藏初态至 `1e-15` 内，说明 100 ms 不是该干净系统的最短必要窗口。主模型与弱 C 的采样条件数都约为 1.71，而最小奇异值由 `5.190e-3` 降至 `5.191e-7`；判断噪声放大必须保留绝对灵敏度和规定尺度。

主模型与弱 C 的有限噪声状态对，8 s 最大可见差分别为 `8.856e-4`、`2.583e-5`，没有越过协议的两倍容差 `2e-2`；这两个状态对未形成未来信息不足证据，也没有覆盖整个状态集合。alias 使用 `K=D=J=R=0` 的半正定边界参数，它反驳“积分算子满秩普遍保证采样可辨”，不属于主严格耗散参数族。


<a id="doc-f8482c63af94-误差机制与阶段一回答"></a>

#### 误差机制与阶段一回答

Gauss2/4 求解结果在主线性和正弦干净病例中的差约为 `1e-16`，但隐藏误差仍约为 `7e-6`；弱 C 的两阶差为 `1.27e-13`，隐藏误差为 `3.61e-2`。求积一致性不能代替真实恢复误差检查，也不能据此认定提高求积阶数会消除分段线性观测近似的偏差。正弦粗细步长的路径差通过预定数值门槛。

三项代数对照分别成立：物理正交扰动经质量缩放后使状态偏移 `3.128e-3`；加权正交扰动的偏移为 `3.724e-16`；列空间扰动使状态偏移 `0.291548` 而残差约 `2.82e-16`；逐时位于端口内的扰动仍可留下 `0.01` 的时间不一致残差。常输入的两种表示得到相同右端、估计与观测驱动末态。它们区分失配机制，不能识别 A15/A17 的真实根因。

因此，对“100 ms 是否够用”的回答必须绑定对象：本轮主线性已知模型具有离散隐藏初态唯一性和达阈恢复；正弦固定病例具有达阈经验结果；弱端口下状态精度与未来精度分离；一般常 C 系统不存在由积分满秩直接导出的统一保证。本轮不涉及真实 train/val/test，不产生失稳漏判率、稳定域认证或模型晋升。


<a id="doc-f8482c63af94-下一项最小独立候选"></a>

#### 下一项最小独立候选

若继续研究初始化，建议单独登记“一个固定能量上界的约束积分 LS”与无约束积分 LS 的有限对照，保持同一模型、观测、历史闭环和未来判据，不并入 C(q)、势能或训练目标变化。弱 C 含噪病例的估计初始隐藏储能约为 179.6，真值约为 0.240，但未来已达阈；下一项应回答能否控制储能而保持未来精度，不能预设未来收益。

能量上界须明确物理来源并在执行前冻结；若来自已知真值，应标为 oracle 条件。不能由正交残差比例单独确定正则强度，也不根据本轮未来误差搜索上界。新病例、比较、预算和精确实现需要独立注册及科学审核；本结果审查不授权下一轮执行。
