#### 隐藏恢复与其他基线

两个活跃病例的隐藏初态误差分别从 `2.940460`、`6.926800` 降至 `0.363236`、`0.961872`，预测起点误差降至 `0.350014`、`0.931733`；四个数仍超过含噪阈值 1e-2。CW_clean 的两个隐藏误差也超过干净阈值 1e-3。三个 CL 病例达到各自隐藏恢复阈值，但固定半径均未触发，不能把这些恢复结果归为主动约束的收益。

三个 CW 病例的零初态未来也达阈。在 CW_periodic、CW_ramp 中，零初态 E3/E8 分别为 `4.906639e-5`、`4.529275e-5`，都低于固定球对应值。CW_ramp 的零初态隐藏起点误差 `0.640312` 也低于固定球的 `0.961872`。因此，本轮接受的是事前指定的**相对无约束 LS** 确认，不能将其改称四方法中的统一最优。零初态在三个 CL 病例的未来误差约为 `0.135`，均未达阈，也不能据弱端口结果将零初态提升为统一替代方案。

true-z 信息对照在含噪病例中仍有非零可见误差，因为它同样使用获准的含噪可见首末点。真值方向、候选路径和未来评分均未用于选择半径或噪声。全部 24 条方法记录、两时域、两隐藏误差和两储能值见[完整结果报告](#doc-31b532a5f152)，该报告的主要科学主张已核对一致。

初始能量约束没有被重新施加到隐藏末态或未来；零初始能量对应的增长比保存为 null。真值初始能量 0.205 处于预定球内，两种确定性扰动没有总体概率含义。结论不扩展到球外真值、模型失配、非线性或真实系统。维持默认初始化器和 `KEEP_BASELINE`；本结果审核不授权追加比较或新阶段。
