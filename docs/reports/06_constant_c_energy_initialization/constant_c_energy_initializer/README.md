<a id="doc-9ca7305815de-1-候选与三个半径"></a>

#### 1. 候选与三个半径

读取阶段一已保存的**加权堆叠积分矩阵** L 与 Gauss4 右端 b；保留原质量缩放、时间归一化、薄 SVD `L=U diag(σ) Vᵀ` 和数值秩阈值。这里的 L 是阶段一的 `integral.matrix`，不是物理未缩放矩阵或完整采样算子。求解

\[
\min_z\;\tfrac12\|Lz-b\|_2^2,
\qquad \tfrac12\|z\|_2^2\le\bar H=\tfrac12\rho^2.
\]

| 候选 | 半径及含义 |
| --- | --- |
| `zero` | ρ=0，唯一可行初态为零；单独命名的消融基线 |
| `oracle_radius` | ρ=||z_h,true||₂；调用方读取真实隐藏初态，只向求解器提供这个标量；真值可行，不保证最佳状态恢复或最佳未来 |
| `fixed_radius` | ρ=1、H̄=0.5；本轮新声明的原点先验球，未经真实数据物理校准 |

阶段一的噪声评价球以真实 z 为中心，**不是本协议的原点球**；不能据此前者为后者提供先验依据。oracle 半径是信息对照，不与非 oracle 候选混作可部署能力。三种半径全部保留，不按结果择优、不搜索半径、不从残差比例推导半径。

约束作用于历史起点 z_h。它不限制历史闭环末态 z_T^cl 的储能，不保证隐藏储能沿轨迹单调下降，也不允许在历史、重置或未来再次裁剪 z。


<a id="doc-9ca7305815de-2-求解器定义与数值停止规则"></a>

#### 2. 求解器定义与数值停止规则

新独立模块为 `src/kron_reduce/evaluation/energy_constrained_initializer.py`，接口为 `solve_energy_ball(matrix, right, svd, radius, unconstrained=None)`。不修改或导入阶段一科学执行入口，不接入现有部署初始化器。下列顺序固定。

1. 验证输入形状、float64 有限值及非负有限半径；来源清单、SVD 尺寸、σ 非负降序、保存阈值与秩一致性由准备/未来读取守卫核对。允许用矩阵乘法核对 U/V 正交及 SVD 重建，不重新分解、重新选择数值秩或调用通用 LS。
2. **ρ=0 优先于秩分支：** 返回精确零向量，`status=zero_baseline`、`multiplier=null`、`multiplier_kind=zero_radius_limit`，根迭代数为零。`+∞` 只能作为极限说明，不能作为有限 KKT 乘子或非标准 JSON 数值。平方约束在零点的梯度为零，通常不存在满足有限乘子驻点式的 λ；因此该分支以唯一可行点验收，有限乘子 KKT 字段为 null 并注明原因。
3. **ρ>0 且保存数值秩<2：** `status=unresolved`、`multiplier_kind=rank_unresolved`，不提供传播初态。本轮按研究政策选择不解决该分支；不能把它解释成凸问题无解或必然多解。球内凸最小二乘总有最优解；活跃正乘子也能使亏秩问题的正则 Hessian 正定。
4. **满秩且无约束解在球内：** 使用稳定范数判断 `||z_unc||≤ρ`，λ=0，返回已保存 `integral.z4` 的逐元素相同副本；仍核对原问题驻点残差。未来比较必须传入这个原始无约束解。省略 `unconstrained` 的接口只供手工工程测试，由已有 SVD 应用 `V(g/σ)`，不得重新 LS。
5. **满秩且球外：** 令 `g=Uᵀb`、`a_i=σ_i g_i`、`d_i=σ_i²`、`h_i=a_i/ρ`。解唯一正根

\[
F(\lambda)=\operatorname{hypot}_i\!\left({h_i\over d_i+\lambda}\right)-1=0,
\qquad z(\lambda)=V\left({a_i\over d_i+\lambda}\right).
\]

精确算术的初始界为

\[
\lambda_{lo}=\max\{0,\max_i(|h_i|-d_i)\},\qquad
\lambda_{hi}=\|h\|_2-\min_i d_i.
\]

下界来自每个分量不超过半径，上界来自共同最小分母；它们只适用于上述满秩球外分支。使用稳定 `hypot`，不直接形成可能溢出的平方和。要求 d_i 有限且严格为正，a、h、分母及后续算术可表示；平方下溢、溢出或非有限值均受控失败，不默默换尺度、改半径或返回伪解。

两个界分别用 `nextafter` 向外舍入并实际计算符号，保持 `F(lo)≥0、F(hi)≤0`。若下界因舍入落错侧，固定退回零再检查；上界最多执行 8 次 `hi←nextafter(hi+max(hi,max(d)),+∞)` 修复。仍不能得到有限有效区间则停止。区间修复是预定数值保护，不是新的参数搜索。

每次根更新使用保护 Newton：设 `w_i=h_i/(d_i+λ)`、`n=hypot(w)`，则 `F'=-n Σ[(w_i/n)²/(d_i+λ)]`。导数不能给出有效 Newton 点或 Newton 点不在当前区间中间 80% 时改用二分；遇到非有限中间算术仍按前述规则受控失败。按符号更新区间，最多 64 次更新、每次求解最多 80 次标量 F 评估，含端点和修复评估。只从可行上端返回，要求 `0≤1-n_hi≤1e-12`；表示停滞、超限或不收敛均停止，不增迭代、不重试。保存初始/最终区间、修复与迭代次数、各次评估及分支；失败异常也须携带已产生的诊断，不能丢失迭代上下文。

返回后在**原始 L,b,z,λ** 上检查：相对可行性 `max(0,||z||/ρ−1)≤1e-12`；活跃约束的相对边界误差≤`1e-12`；λ 非负；驻点残差

\[
{\|L^T(Lz-b)+\lambda z\|_2\over
\|L\|_F(\|L\|_F\|z\|_2+\|b\|_2)+\lambda\|z\|_2}\le10^{-10}.
\]

分母为零时要求分子精确为零，单独记录；不用任意 epsilon 制造比值。活跃分支的归一化互补性 `|(||z||/ρ)²−1|≤3e-12`，非活跃分支因 λ=0 为零。保留拟合目标和原始残差，不能将约束引起的拟合目标增加算作数值失败。零半径分支不套用上述除以 ρ 的公式。

返回字段区分分支与几何关系：`constraint_active` 保留 zero/正乘子分支标记，`regularization_active` 只标记 λ>0 的正则分支，`constraint_binding` 表示按规定范数容差位于边界。无约束解恰在边界时可同时 λ=0、binding=true、regularization_active=false；零半径 binding=true，但没有有限正乘子。

工程测试使用手工给定薄 SVD：零半径且亏秩、正半径亏秩退出、球内精确复用、各向同性闭式活跃解、非等奇异值的 KKT/区间、零右端及不可表示算术的受控失败。允许设置极端谱的满秩工程负例，核对数学解唯一但固定迭代预算耗尽时有界退出、保存诊断且不返回伪解；该数值失败不同于 rank-policy 未决。本协议不承诺所有满秩矩阵均在 64 步内收敛。不得以阶段一病例跑求解器充当工程测试。

#### 5. 分轴证伪与完整保存

数值有效性独立判定：源身份和白名单一致、全部有限、求解器分支/KKT 通过、COI 和瞬时能量恒等式归一化误差≤`1e-10`、正弦粗细完整输出最大差≤`1e-8`、准确预算成立。任一失败停止全轮、保留全部已产生证据，不调门槛或重试。预定 rank 未决及科学指标未达阈不算数值失败，保留后继续其他已登记独立病例。

每候选保存：状态和来源复用标记；ρ/H̄/半径来源、真值是否在球内；z_h/z_T^cl 和各自误差；隐藏储能及相对真值/无约束差值；λ/分支/区间/迭代/KKT；积分残差和目标；完整历史、reset 前后状态及总能量跳变；3/8 s 的 q/v 分项、RMS 和最大误差，分别相对干净真值与同病例 true-z 对照。能量比的分母为零时记 null/undefined 并保留绝对差，不加 epsilon。

未来和隐藏恢复沿用阶段一工程阈值：干净/刚度失配 `1e-3`，含噪 `1e-2`。未来另外记录相对无约束误差增量：`Eρ(h)−Eunc(h)≤1e-8` 才称在数值容差内非劣；两者都达原阈不等于误差没有增加。3 s 与 8 s 分开，oracle 不参与非 oracle 结论选择。

预定反证边界：固定半径若使原本达阈的未来越过原阈，便反驳它在这批病例中保留未来达阈能力；若误差增加超过 `1e-8`，便反驳对应时域的数值非劣。约束满足只证明起点储能受控；真值被先验球排除时单独标记，不能把先验偏差改称求解器错误。正结果也按已报告病例保留隐藏恢复、储能与未来三轴，不要求零基线、oracle 和固定半径全部成功。

最终比较需要独立保存证据审计和科学结果审查。当前准备不涉及训练、端到端梯度、C(q)、势能、时间加权、真实 train/val/test、失稳漏判率或模型晋升。

#### 结论

固定半径 ρ=1 在 W100_weakdir 中将历史起点隐藏储能从 **179.568277 限制到 0.5**，预测起点隐藏储能从 **160.875538 降到 0.447938**。相对干净真值的 3 s 和 8 s 可见最大误差均从 **4.972350e-4 降到 5.519439e-5**，继续通过预设的 1e-2 阈值。隐藏初态误差从 19.258470 降至 1.422293，仍未达到 1e-2 的恢复阈值：本例支持限制能量膨胀并改善可见未来，不支持完整隐藏状态恢复。

固定半径只在上述一个满秩病例触发，其余七个满秩病例均逐点复用原路径。不能把这些不变结果解释成七次主动修正的收益。W100_clean 的 oracle 隐藏误差从 `0.0361224` 降至 `0.0287333`，仍未恢复；三个半径的未来均达阈。两个弱端口病例连零基线也能达到可见未来阈值，进一步说明低可见误差不能作为隐藏恢复的替代指标；零基线在其余七个病例均未达未来阈值。

**oracle 半径不保证最佳恢复或数值非劣。** L100_clean、S100_clean 的 oracle 仍通过绝对状态和未来阈值，但未来最大误差比无约束分别增加 `3.48859018e-7`、`3.45188072e-7`，超过事前非劣容差 `1e-8`；两例必须保留为非劣失败。含交替噪声的 L/S 病例在该指标下非劣，不据此推广到其他噪声或系统。

**失配机制的关键分支本轮未触发。** K100_mismatch 的无约束初始能量 `0.204977566` 已低于 oracle 真值能量 `0.243537295`，两个正半径均非活跃，状态与未来完全不变。本轮既没有证明正球约束能消除失配吸收，也没有检验主动收缩破坏这种补偿的效果。给真实隐藏初态的错模型对照，其 3/8 s 最大误差均为 `0.0130201213`，仍未达阈，并高于偏差 LS 解的对应值；这支持该病例中初态偏差与错模型可见误差存在补偿关系，不等于真实初态错误就是唯一原因。零半径的误差升至 `0.157604799`，只为完全去除隐藏初态的过度收缩负例，不能归为两个未触发正半径的损害。

**秩未决没有被改写成恢复成功。** U_hidden_null 的两个正半径按既定政策不传播。零基线同时删除可见耦合方向的初态，因此其未来失败与“另一个隐藏方向不可见”并不矛盾。亏秩退出是本轮研究规则，不是球约束凸问题必然无解或不唯一的数学结论。

约束仅施加于历史起点，未在预测起点或未来重新裁剪；重置能量跳变和连续能量恒等式分别保留。零初始储能比值为 null。所有半径与原阈值保持冻结，没有从结果选择更紧半径或追加比较。

#### 后续边界

本阶段回答是：在固定弱端口含噪病例中，可以控制隐藏初始能量并保持、改善该时域可见预测；该约束没有补足隐藏方向信息，也未修复本轮错参数模型。若继续验证，最小独立候选是保持现有求解器和固定 ρ=1，对事前冻结的新合成参数/噪声病例确认此现象；半径的物理来源与适用范围须单独说明。模型失配、C(q)、势能和训练目标变化各自需要独立假设与登记。本审核不授权新运行或部署，维持 `KEEP_BASELINE`。
