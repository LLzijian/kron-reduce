### clean 数据上的逐机隐状态学习：最小一轮

日期：2026-11-13。核心设计与科学审核：Astra Ultra。

本轮优先得到初步动力学学习结果：只使用 local 的 clean 合成数据，不额外注入噪声，延后统计先验和噪声估计。用可微的 100 ms 历史求解代替自由编码器，只训练十台机器的耦合幅度和时间常数。固定训练 240 步后，无论 RMSE 是否达标，都完成 train、val、test 评价并报告精度。


<a id="doc-140967fd9fc7-比较与解释"></a>

#### 比较与解释

同一新合成语料包含 64 个事件，按 32/16/16 固定角色，种子为 `2026111301`。只有一个 L10 拟合。三组模型分别为已知真值参数、独立配方的训练初始参数、训练终末参数；三者都使用相同的历史求解和预测接口。真值参数组检验初始化与数值链，初始/终末参数组显示动力学学习带来的变化。真值参数不提供给候选初始化或优化器。

L10 保留 `C=P diag(g)`、逐机一阶隐状态、正时间常数和互易能量耦合。质量、势能、阻尼与平衡点骨架固定；仅 `log_g` 和有界时间常数的原始参数共 20 个量可训练。编码器被冻结并绕过，不拟合先验或噪声，不增加结构家族。候选初值为 `g_i=0.4`、`τ=geomspace(0.06,1.6,10)`，沿用已有独立配方。

clean 首帧 q/v 作为初态可见部分，利用全部后续十帧仅求十维隐藏初态。历史矩阵随当前动力学更新，通过可微薄 QR 和三角求解获得隐状态，随后闭环推进历史，在预测起点保留既有的可见末点重置。无需引入 28 维联合初态或新的输出接口。


<a id="doc-140967fd9fc7-最小执行与报告"></a>

#### 最小执行与报告

准确数学、数值检查、预算与失败处理见[短协议](#doc-92c13bfaa7d5)。训练固定 Adam 240 步、学习率 0.01，只用 train 未来目标；不早停、不选最佳 checkpoint、不从 val/test 选择配置。预测输入仍为 100 ms/11 帧及合法功率。未来真实数据继续使用 TASK3 的 train 346、val 107、test 76 名单规则，本轮不读取真实数据。

三组模型的 train/val/test 均报告 1/3/8 s q、v 与合并 NRMSE、物理 RMSE、主 NRMSE、隐状态误差和参数误差。主指标沿用 1 s 与 3 s NMSE 的等权平均后开方。旧 clean 主/3 s NRMSE ≤0.001 继续作为结果标记，绝不作为跳过 val/test 的条件；8 s 为延长预测描述。无额外噪声的结果不覆盖旧 noisy 失败记录。

若终末模型未达标，仍保留全角色精度和训练曲线，据此区分固定真值链误差、动力学学习误差与泛化差。数值失败时记录失败位置，并对明确标记的最后有限诊断参数尝试全部角色；无法生成有效预测的角色明确记失败，不能用缺失值或零误差冒充精度。权限、预算、来源身份或程序错误仍停止不合法执行。

这是一轮初步 synthetic 学习证据，不因单次成功直接晋升基线。噪声统计和更复杂结构继续延后；本轮结果形成后再登记下一项最小工作。用户已授权自主推进与自动提交，本轮按新的准确范围执行，不复活旧范围。

### clean 逐机学习协议 v1

日期：2026-11-13。设计与科学审核：Astra Ultra。阶段：`machine_local_clean_learning_v1/learning`。本协议服务于[最小一轮计划](#doc-140967fd9fc7)，与旧 noisy 门禁分开登记。


<a id="doc-92c13bfaa7d5-1-数据模型和训练参数"></a>

#### 1. 数据、模型和训练参数

复用 `fixture("local")` 和解析 40 维真值生成器，种子 `2026111301`，64 个事件、每事件 811 帧，角色顺序为 train 32、val 16、test 16。不生成噪声。输入及角色在首次拟合前保存并哈希；尺度只从 train 计算，沿用目标 `j=11,…,310` 和历史 `j=0,…,10` 的通道 RMS、下限 `1e−5`。j 从历史起点计时；预测起点为 j=10，未来 3 s 终点为 j=310。

候选为 `DiagonalMemoryModel` 的 local、linear、十隐状态配置。固定质量、stiffness、damping、equilibrium；`C=P diag(exp(log_g))`，时间常数沿用现有有界映射到 `(0.02,5)`。只训练十个 `port_parameter` 与十个 `rate_parameter`。encoder 冻结、绕过且无正则损失；不从真值 g/τ 初始化。候选初值 g 全为 0.4，τ 为 `geomspace(0.06,1.6,10)`。


<a id="doc-92c13bfaa7d5-2-可微历史初始化"></a>

#### 2. 可微历史初始化

令当前动力学参数为 θ，历史观测 `y_e,j=(q_e,j,v_e,j)`。同一次批量传播包括各事件 `(q_e,0,v_e,0,z=0)` 的基准和十个零可见状态、零输入的隐藏基向量，得到 `b_θ,e,j` 与 `D_θ,j`。它们均来自模型实际的投影 RK4 离散映射。

用固定 train 历史尺度 s 构造

`A_θ=stack_{j=1..10}[diag(1/s) H D_θ,j]`，形状 200×10；

`r_θ,e=stack_{j=1..10}[diag(1/s)(y_e,j−H b_θ,e,j)]`。

求薄 QR `A_θ=Q_θR_θ`，再解上三角方程 `R_θ z_h,e=Q_θᵀr_θ,e`。不形成正规方程，不加入 ridge。Q、R、右端项、解、历史重构及未来传播全部保留梯度。

仅数值门使用脱离梯度的 R 奇异值：阈值为 `64 eps max(A.shape) σmax`，要求秩 10、`σmax/σmin≤1e8`。原矩阵行数使用 200，而不是以 R 的 10 行替代。谱只控制数值有效性，不作为损失，不改变求解结果。退化时返回明确失败，不自动伪逆、截断奇异值或改初态维数。

重建完整历史 `x_e,j=b_θ,e,j+D_θ,j z_h,e`，预测起点为 `(q_e,10,v_e,10,z_e,10)`。保留旧可见末点重置，未来无任何观测反馈。该接口只接收 j=0..10 的 q/v、合法常值功率和静态平衡点，不接收未来、真实 z 或事件标签。


<a id="doc-92c13bfaa7d5-3-一次拟合与准确梯度检查"></a>

#### 3. 一次拟合与准确梯度检查

使用 CPU float64，复用 `linear_fast`，它实现与逐子步投影 RK4 相同的四阶多项式映射。训练最大子步 0.005 s；所有训练事件等权，损失为未来 1 s 和 3 s 的通道归一化 MSE 等权平均，不包含预测起点。训练数据仅 train，未来监督对应 j=11..310。

固定 240 次 Adam 更新，学习率 0.01、betas=(0.9,0.999)、eps=1e−8，实际 20 参数的合并梯度范数裁剪为 10。无学习率搜索、额外预训练、early stopping 或 checkpoint 选择。保存初态、终末参数、每步 train 损失、梯度范数和耗时。

拟合前，用初始候选及 train 前两个事件检查完整 3 s 损失对两个参数块的方向梯度。方向由独立固定种子 `2026111302` 生成，各块归一化；同一次 autograd 获得两块解析梯度。分别用中心差分 eps=`1e−5,1e−6`，每个方向均要求 `abs(FD−analytic)≤1e−9+1e−5 abs(analytic)`。保存方向、正负损失和解析值，共一次解析前向与八次扰动前向，不更新模型。此检查验证历史求解到预测的完整梯度，不重做旧模型的全部 S0。


<a id="doc-92c13bfaa7d5-4-无条件完成全部角色评价"></a>

#### 4. 无条件完成全部角色评价

终末参数冻结后评价三组模型：真值 θ、训练初始 θ、训练终末 θ。对每组均尝试 train、val、test，主步长 0.0025 s、精化步长 0.00125 s，输出未来 800 帧。全部角色的预测均只输入其 100 ms 历史，不使用其未来来初始化或选择参数。精化预测只作数值一致性检查。

每个角色报告 1/3/8 s 的 q/v/合并 NRMSE、物理 RMSE、最大误差，主 NRMSE，隐藏起点与预测起点 RMSE、历史误差、COI 和步长差。g、τ 相对真值误差只作评价，不进入拟合。原 clean 主/3 s NRMSE ≤0.001、COI≤`1e−10`、按目标尺度归一化的精化预测最大差 ≤`1e−5` 分别记录。任何 RMSE 不达标都不跳过其余角色，不阻止报告 val/test。

真值参数组另记 `truth_control_pass`：各角色主/3 s NRMSE≤0.001，隐藏起点及预测起点 RMSE≤`1e−4`。它验证固定真值下的初始化与数值链；失败也继续全部评分，但不能把本轮称为正确链条上的成功学习。候选的隐状态误差只作描述。每模型、每角色另用预测起点的首个事件核验物理能量恒等式，误差门为 `1e−10`。

拟合若发生数值失败，不重试或追加更新：保存失败参数与最后已验证有限的参数、对应更新编号。该组标记拟合失败，再以明确标记的有限诊断 checkpoint 尝试全部角色；它不能冒充完成 240 步的终末模型。单角色无法求解或传播时写入失败原因，并继续其他角色和固定对照。若失败发生于权限、预算、哈希身份或程序逻辑，则停止不合法执行并记录尚未完成的角色。

梯度正确性失败不得继续拟合错误实现；写出失败证据并修正后另行登记。科学精度失败与实现正确性失败分开处理。


<a id="doc-92c13bfaa7d5-5-执行预算与证据"></a>

#### 5. 执行预算与证据

本轮拟合 1 次、优化更新最多 240 次，训练梯度最多 240 次，加方向检查梯度 1 次。QR、脱离梯度的 R 谱和三角求解每次历史初始化各一次。按九次梯度检查前向、240 次训练前向、三模型×三角色×两步长评分，共最多 267 次历史求解、534 次轨迹调用。独立真值生成使用 expm 3 次；无旧 NPZ 解码，无噪声生成、先验拟合或真实数据读取。

全局预设上限：`matrix_products` 400000、`rollouts` 600、`qr` 300、`svd` 300、`triangular_solves` 300、`gradients` 241、`optimizer_updates` 240、`fits` 1、`expm` 3、`numpy_rhs` 9。其他科学原语为零。完整成功路径的矩阵静态账为 252299：真值 812、梯度检查 `9×873=7857`、训练 `240×873=209520`、九个模型/角色评分 `9×3790=34110`；每次评分由两档预测 1890+1898 和两次 COI 乘法构成。另有 9 次能量 RHS，267 次 QR/SVD/三角求解，534 次轨迹调用。

逐范围矩阵上限为 truth 900、gradient 8000、fit 220000、九个 score 各 4000；机器计划同时登记其余原语的逐范围上限。计数沿用现有 helper 对显式传播矩阵/输出操作的口径，批量不乘事件数，不计库内部或反向传播算子；运行时间另存。预算只计已发出的分组额度，正常返回闭合，失败范围保留未知内部返回数并全额消费。数值异常必须穿过范围记录边界后再被上层处理，不能因继续其他角色而把失败范围记作正常返回。

保存角色/输入哈希、初始与终末参数、QR/谱/求解残差证据、完整梯度差分证据、训练曲线、三模型全部角色预测与指标、异常和原语账。随后只执行一次登记的保存数组算术审计，不重新传播或拟合。结果同时报告完成状态、技术状态和精度标记，不用单一 pass 隐去未达标结果。用户已授权本轮方向；实现与机器预算准确审核后执行一次，不复活旧授权。
