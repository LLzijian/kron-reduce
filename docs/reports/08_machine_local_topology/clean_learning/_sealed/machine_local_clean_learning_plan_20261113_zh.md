# clean 数据上的逐机隐状态学习：最小一轮

日期：2026-11-13。核心设计与科学审核：Astra Ultra。

本轮优先得到初步动力学学习结果：只使用 local 的 clean 合成数据，不额外注入噪声，延后统计先验和噪声估计。用可微的 100 ms 历史求解代替自由编码器，只训练十台机器的耦合幅度和时间常数。固定训练 240 步后，无论 RMSE 是否达标，都完成 train、val、test 评价并报告精度。

## 比较与解释

同一新合成语料包含 64 个事件，按 32/16/16 固定角色，种子为 `2026111301`。只有一个 L10 拟合。三组模型分别为已知真值参数、独立配方的训练初始参数、训练终末参数；三者都使用相同的历史求解和预测接口。真值参数组检验初始化与数值链，初始/终末参数组显示动力学学习带来的变化。真值参数不提供给候选初始化或优化器。

L10 保留 `C=P diag(g)`、逐机一阶隐状态、正时间常数和互易能量耦合。质量、势能、阻尼与平衡点骨架固定；仅 `log_g` 和有界时间常数的原始参数共 20 个量可训练。编码器被冻结并绕过，不拟合先验或噪声，不增加结构家族。候选初值为 `g_i=0.4`、`τ=geomspace(0.06,1.6,10)`，沿用已有独立配方。

clean 首帧 q/v 作为初态可见部分，利用全部后续十帧仅求十维隐藏初态。历史矩阵随当前动力学更新，通过可微薄 QR 和三角求解获得隐状态，随后闭环推进历史，在预测起点保留既有的可见末点重置。无需引入 28 维联合初态或新的输出接口。

## 最小执行与报告

准确数学、数值检查、预算与失败处理见[短协议](../protocols/machine_local_clean_learning_v1_zh.md)。训练固定 Adam 240 步、学习率 0.01，只用 train 未来目标；不早停、不选最佳 checkpoint、不从 val/test 选择配置。预测输入仍为 100 ms/11 帧及合法功率。未来真实数据继续使用 TASK3 的 train 346、val 107、test 76 名单规则，本轮不读取真实数据。

三组模型的 train/val/test 均报告 1/3/8 s q、v 与合并 NRMSE、物理 RMSE、主 NRMSE、隐状态误差和参数误差。主指标沿用 1 s 与 3 s NMSE 的等权平均后开方。旧 clean 主/3 s NRMSE ≤0.001 继续作为结果标记，绝不作为跳过 val/test 的条件；8 s 为延长预测描述。无额外噪声的结果不覆盖旧 noisy 失败记录。

若终末模型未达标，仍保留全角色精度和训练曲线，据此区分固定真值链误差、动力学学习误差与泛化差。数值失败时记录失败位置，并对明确标记的最后有限诊断参数尝试全部角色；无法生成有效预测的角色明确记失败，不能用缺失值或零误差冒充精度。权限、预算、来源身份或程序错误仍停止不合法执行。

这是一轮初步 synthetic 学习证据，不因单次成功直接晋升基线。噪声统计和更复杂结构继续延后；本轮结果形成后再登记下一项最小工作。用户已授权自主推进与自动提交，本轮按新的准确范围执行，不复活旧范围。
