### 已知真值下分辨初始化与动力学失配

日期：2026-11-13。科学设计：Astra Ultra。状态：`PREPARATION_ONLY`。本计划接续[完整 TASK3 结果审查](../task3_baseline/README.md#doc-619433be1ef6)中已完成的 train 保存诊断；新增计算须先完成协议、准确实现、测试与预算登记。本文件不开放真实数据读取或新的模型拟合。


<a id="doc-3dd0c70182ad-1-一个可区分的问题"></a>

#### 1. 一个可区分的问题

真实 train 的历史残差与未来误差没有呈现正向排序关系，保存储能又没有真实隐藏状态可供比较。下一步用已知真值把两个变化分开：保持同一动力学而替换预测起点隐藏状态，检验初始化差异；保持真值起点隐藏状态而改变可见刚度，检验动力学失配。刚度失配再配合因果初始化，可观察初态补偿与动力学误差的相互影响。

这是一轮零拟合、零附加噪声的固定判别，不扫描失配幅度，不增加 GN 次数，不据结果调整方法，也不使用真实 val/test 决定参数。


<a id="doc-3dd0c70182ad-2-真值系统和全部-64-个事件"></a>

#### 2. 真值系统和全部 64 个事件

复用已通过非线性 S0 的 `fixture("local", backbone="sine")` 方程，准确源码另行哈希绑定。令机器编号 `i=0,…,9`，质量 `m_i=1+0.1i`，完整图关联矩阵为 B，45 条边的刚度均为 0.12，阻尼为 `0.08 BBᵀ`。端口为 `C=P diag(g)`，其中 `P=I−m1ᵀ/Σm`、`g_i=0.35+0.025i`、`τ=geomspace(0.05,2,10)` s，隐藏旋转项为零；所有事件的恒定功率和平衡角为零。

新事件编号 `j=0,…,63`，`φ_j=2π(j+0.5)/64`，`k_j=floor(j/2) mod 10`。半格相位偏移使本轮初态区别于已完成 S0 的六个事件。以列向量记 `Q=Pᵀ`，固定

\[
q_h=Q[0.03\sin(i+\phi_j)],\quad z_h=0.05\cos(i+\phi_j),
\]

\[
v_h=Q[0.02\cos(i+\phi_j)+a_je_{k_j}],\qquad
a_j=\begin{cases}0,&j\text{为偶数},\\16,&j\text{为奇数}.\end{cases}
\]

train 为 j=0…31，val 为 j=32…47，test 为 j=48…63，数量为 32/16/16；每个角色包含等量的两种预定初态幅度。它们只是新冻结的合成角色，不与真实 TASK3 名单混用，也不宣称为跨系统独立确认。全部 64 个事件都进入四组评价，不先取两个事件试算，不按标签或误差换样。

使用独立 NumPy 投影 RK4 生成 0…8.1 s 的 811 帧真值，输出间隔 0.01 s，最大子步为 0.00125 与 0.000625 s，后一档作为参照。沿原公共实现的逐间隔 `ceil(interval/max_step−1e−12)` 子步规则，不改变浮点时钟。两档真值标签和触发点须一致，按 train 目标尺度归一化的可见最大差须≤`1e−6`；否则记录真值门失败，停止新预测，不调整样本或精化档位。

历史尺度由 32 个 train 参考轨迹的 j=0…10 帧逐通道 RMS 得到；目标尺度由同一 train 的 j=11…310 帧得到，下限均为 `1e−5`。真值、来源参数、角色、尺度和标签在任何候选预测前封存。真实标签与预测标签都由轨迹按同一冻结八秒规则派生；预设幅度不作为标签。每个角色须实际覆盖失步与窗口内安定两类，历史结束前不得已经失步；覆盖失败保留结果，不补样。


<a id="doc-3dd0c70182ad-3-四个冻结对照"></a>

#### 3. 四个冻结对照

匹配动力学取真值参数；失配动力学只把 45 条可见边刚度统一乘以 1.10，即每条 0.132，质量、阻尼、g、τ、功率和平衡角均不变。所有初态真值共享同一隐藏坐标和储能尺度。

| 对照 | 可见动力学 | 隐藏预测初态 | 论证职责 |
|---|---|---|---|
| matched-GN | 匹配 | 100 ms 因果三次 GN | 检验当前初始化器在该完整合成语料上的恢复 |
| matched-oracle | 匹配 | 真值 `z(0.1 s)` | 共同真值起点下的积分参照 |
| mismatch-GN | 刚度增加 10% | 该失配模型自己的三次 GN | 观察初始化对失配的补偿及后果 |
| mismatch-oracle | 刚度增加 10% | 真值 `z(0.1 s)` | 排除初态估计后观察动力学失配 |

两个 GN 对照严格使用现有三次同阶段切线、QR 和三角解，从零隐藏初态开始，完整重算历史，保留闭环隐藏末态。预测起点 q/v 均取真值观测的第十一帧；oracle 两组在同一可见重置后直接配入真值隐藏末态，从该共同完整起点预测八秒，不额外运行历史初始化。oracle 不读取未来隐藏状态，不生成任何可部署的额外输入权限。

四组都保持原投影与正弦方程，不更新参数。GN 秩十、条件数≤`1e8`、有限性及幅度上限沿已接受接口。预测档位为 0.0025/0.00125 s，两档 GN 各自求解历史；oracle 两档使用完全相同真值起点。每角色按事件顺序以最多 16 例一批，train 两批、val/test 各一批。某档批量数值异常时，对该批每例用相同档位隔离一次；其他档位独立继续。正常返回而门未通过不追加计算，任何失败保留，禁止重试、缩步或改初值。


<a id="doc-3dd0c70182ad-4-指标门槛和判读"></a>

#### 4. 指标、门槛和判读

所有事件都有相同完整八秒目标，消除上一轮真实记录中可用时长不同的混杂。四组按 train/val/test 分别报告 1/2/3/5/8 s 的可见归一化 RMSE、q/v 物理 RMSE、最大误差和逐事件结果；主要机制比较使用三个角色各自的**事件平均三秒归一化 MSE**，不混用 RMSE 的差与平方误差差。GN 另保存隐藏起点及预测起点误差、真实与估计储能、历史残差及三次增量。

轨迹稳定性采用原五点失步和最后一秒安定规则；四组同样报告 TP/TN/FP/FN、完整名单准确率、可判定准确率、失稳召回、漏判、稳定误报、未决和数值失败。存在未决或失败时完整准确率为 null，零分母为 null。两档分类须一致、失步时刻相差≤0.02 s，可见归一化最大差≤`1e−5`，所有输出有限，质量 COI 误差≤`1e−10`。这不是稳定性证书。

matched-oracle 必须达到三秒可见归一化 RMSE≤`0.001`；matched-GN 除此之外，隐藏起点及预测起点 RMSE≤`1e−4`，按历史尺度归一化的历史最大残差≤`1e−7`。这两组每个角色的稳定性判断须与真值全部一致。匹配对照失败意味着本轮不具备相应恢复依据；不拿失配对照解释去覆盖该失败。全部已开始、仍可执行的其他评价继续保存。

每个角色及每个事件固定列出以下三项有符号差值，不选择最好样本：

1. `matched-GN MSE − matched-oracle MSE`：匹配条件下的初态估计差距。
2. `mismatch-oracle MSE − matched-oracle MSE`：共同真值起点下可见刚度失配的影响。
3. `mismatch-GN MSE − mismatch-oracle MSE`：失配条件下，GN 初态相对真值初态改变了多少预测误差。

第三项可以为正，也可以为负；负值表示在这个错误动力学模型中补偿有益，不能因此认为估计隐藏状态更接近真值。联合隐藏状态误差、储能和未来误差判读，不把三项强行视为真实系统误差的可加分解。失配组不设必须恶化的通过线；它们承担判别职责，所有结果都可证伪原假设。

<a id="doc-d9ec457f8451-1-真值与人群"></a>

#### 1. 真值与人群

真值复用 `fixture("local", backbone="sine")`：十台机器，`m_i=1+0.1i`，完整图45条边刚度均为0.12，`D=0.08 BBᵀ`，`C=P diag(0.35+0.025i)`，`τ=geomspace(0.05,2,10)` s，隐藏旋转项为零。`P=I−m1ᵀ/Σm`、`Q=Pᵀ`；输入功率与静态平衡角均为零。

事件 j=0…63，`φ_j=2π(j+0.5)/64`，`k_j=floor(j/2) mod 10`。列向量初态为 `q_h=Q[0.03 sin(i+φ_j)]`、`z_h=0.05 cos(i+φ_j)`、`v_h=Q[0.02 cos(i+φ_j)+a_j e_(k_j)]`，其中偶数 j 的 `a_j=0`，奇数 j 的 `a_j=16` rad/s。train 为0…31，val为32…47，test为48…63。每个角色完整使用32/16/16个事件，不替换、不先缩小试算。

独立 NumPy 投影 RK4 生成0…8.1 s、间隔0.01 s的811帧，最大子步0.00125/0.000625 s，后者为参考；逐输出间隔使用原 `ceil(interval/max_step−1e−12)` 规则。全部64个事件的两档真值先生成并保存。历史尺度取参考train第0…10帧的逐通道RMS，目标尺度取第11…310帧，两者下限1e−5。

按相同八秒规则从真值派生标签，角色须实际覆盖失步与窗口内安定两类，历史100 ms内不得已触发。两档真值类别和触发采样点必须一致，可见最大归一化差≤1e−6。真值门失败后保留全部已有证据，停止新增候选预测，不改相位或数值档位。真值、标签、尺度及其哈希在候选评价前冻结。


<a id="doc-d9ec457f8451-2-四组固定预测"></a>

#### 2. 四组固定预测

预测对象为同一个局部L10方程族，所有参数冻结，encoder绕过。组名与操作范围前缀固定如下：

| 组名 | 可见刚度 | 预测起点隐藏状态 |
|---|---|---|
| matched_gn | 真值刚度 | 本模型三次因果GN历史求解的闭环末态 |
| matched_oracle | 真值刚度 | 参考真值在100 ms的隐藏状态 |
| mismatch_gn | 每条边真值刚度×1.10 | 失配模型自己的三次因果GN历史求解闭环末态 |
| mismatch_oracle | 每条边真值刚度×1.10 | 参考真值在100 ms的隐藏状态 |

刚度失配只把每条边0.12改为0.132，质量、阻尼、g、τ、输入与平衡点不变。四组预测起点的q/v均严格使用观测第十一帧。两个GN组从零隐藏初态开始，执行原三次同阶段RK4切线、薄QR与三角解，再重算实际历史；不增加迭代、正则、伪逆或line search。隐藏秩十、条件数≤1e8，状态与隐藏增量有限且幅度≤1e12。oracle组直接由共同的真实q/v/z起点开始未来，不额外求解历史。真实隐藏状态只用于这个合成诊断对照。

各组固定按train、val、test顺序评价，未来8 s/801点，两档子步0.0025/0.00125 s；两个GN档位各自初始化，oracle两档初态完全相同。每角色按固定事件顺序最多16例一批。若某档批量预测抛数值异常，仅对该批每事件按原档位隔离一次；其他档位独立继续。若正常返回但误差或分类门失败，不追加调用。一个角色或对照失败仍评价其余可执行角色和对照。


<a id="doc-d9ec457f8451-3-评分和判读"></a>

#### 3. 评分和判读

全部事件都有完整、同长目标。报告各角色1/2/3/5/8 s的合并、q/v归一化RMSE、物理RMSE、最大误差和逐事件结果；主要比较量为事件等权的三秒合并归一化MSE。GN组另保存初始z与预测起点z的真值误差、估计/真实隐藏储能、最终历史残差、三次迭代初态和增量。

失步：未包裹角范围大于π且最大质量COI相对速度大于0.02 pu，同时连续五个0.01 s点；未失步且末100点角范围均小于π、速度均小于0.005 pu才记窗口内安定，其余未决。拼接11帧历史及不重复起点的未来。每组每角色给出TP/TN/FP/FN、完整名单准确率、可判定准确率、可判定失稳召回/漏判/稳定误报、未决/失败及覆盖。任一未决或失败使完整准确率为null，零分母为null。

候选数值门：全路径有限、质量COI误差≤1e−10，两档可见最大归一化差≤1e−5，类别一致，失步触发时刻差≤0.02 s。matched_oracle每角色三秒合并NRMSE≤0.001；matched_gn再要求每个事件的初始z和起点z的RMSE≤1e−4、按历史尺度归一化的历史最大残差≤1e−7。这里把原计划中的隐藏恢复门明确为逐事件要求，避免角色平均掩盖单例恢复失败；在执行前统一冻结。两匹配对照每角色分类与真值全部一致；失配对照无“必须恶化”的目标门。

对每事件及每角色固定输出三秒MSE差：`matched_gn−matched_oracle`、`mismatch_oracle−matched_oracle`、`mismatch_gn−mismatch_oracle`。第三项允许负值，表示该错误动力学下的初态补偿改善预测，不代表估计隐藏状态更真实。任何缺失对照令对应配对差为null并报告覆盖，不补零。结合隐藏误差和储能作机制判断，不将三项当作真实系统误差的可加分解。

|---|---:|---:|---:|---:|---:|
| truth | 128 | 5,001,728 | 0 | 0 | 0 |
| 每个GN组train，含最坏隔离 | 340 | 0 | 1,370,880 | 48,960 | 384 |
| 每个GN组val或test，含最坏隔离 | 170 | 0 | 685,440 | 24,480 | 192 |
| 每个oracle组train，含最坏隔离 | 68 | 0 | 1,305,600 | 0 | 0 |
| 每个oracle组val或test，含最坏隔离 | 34 | 0 | 652,800 | 0 | 0 |
