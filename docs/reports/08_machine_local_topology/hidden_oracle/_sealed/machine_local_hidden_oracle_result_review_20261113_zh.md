这组对照把隐藏初始化和可见动力学误差区分开来：动力学匹配时，100 ms历史和固定三次GN能恢复隐藏状态；刚度统一偏高10%时，即使提供真实隐藏起点，预测仍有误差。GN会改变隐藏初态以解释错误动力学下的历史，其预测影响随时长和事件变化。

## 完整范围与主要结果

固定64个新事件，train32、val16、test16；四组均使用全部事件，零拟合、零附加噪声。四组都在100 ms使用同一观测可见起点。GN指固定三次因果历史求解；真实隐藏起点来自已知真值在100 ms的状态。后者只用于合成对照。下表是未来完整三秒和八秒窗口的合并q/v归一化误差，逐通道尺度由train固定。主要指标为逐事件归一化MSE的等权平均；pooled NRMSE为该均值的平方根，不是逐事件NRMSE的算术平均。

在这组受控方程中，可见刚度失配同时引起未来动力学偏差和隐藏状态估计偏差。失配GN的隐藏初始RMSE最大为0.306443，预测起点最大为0.210968；其历史归一化RMSE仍不超过6.85079e−5。因此，小历史残差不能单独证明隐藏状态恢复正确。

预测影响不能概括为所有时长都变差。八秒下，失配GN减去失配真实隐藏起点的事件平均归一化MSE分别为train −1.56005e−5、val −1.32365e−5、test +1.76425e−5。前两个角色表现为错误隐藏初态对错误动力学的部分补偿，test的均值方向相反。三秒与八秒都按预定口径保留，不根据方向选择结果。这些配对差是特定控制条件的比较，不是真实模型误差的可加分解。
