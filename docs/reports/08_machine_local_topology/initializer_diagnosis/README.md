### 逐机模型初始化诊断与后续修正计划

日期：2026-11-12。核心设计与科学审核：Astra Ultra。

用户已明确授权：根据 S1-base 结果，分开定位初始化泛化与动力学误差，修正后先通过合成验证，再按门禁自主推进和提交。本计划将第一步冻结为一次 local clean L10 诊断；结果决定下一项修正，不以完成诊断报告代替后续已授权工作。


<a id="doc-11c64e0120e6-1-已知问题与本次问题"></a>

#### 1. 已知问题与本次问题

[S1-base 审核](../synthetic_implementation/README.md#doc-33456fba3cb6)保留 `REJECT / KEEP_BASELINE / STOP_T0`：十二次固定拟合完成，物理和积分门通过，六个覆盖真值的配对均未达到预测门。local clean L10 的 train/test 3 s NRMSE 为 0.02718/0.21441，预测起点隐藏状态 RMSE 为 0.03944/0.24928。这些结果将初始化泛化列为优先疑点，尚未排除动力学误差和联合优化的贡献。

本次只改变“怎样求给定动力学下的 encoder”，不改变源数据、特征、正则、历史传播、预测起点重置或评分定义。分别固定真值动力学与本轮终点动力学，把 E 的条件问题准确求解一次；另以真值动力学和真实预测起点 z 作传播对照。准确合同见[初始化诊断协议](#doc-1f31dbc9b016)。


<a id="doc-11c64e0120e6-2-为什么这能区分问题"></a>

#### 2. 为什么这能区分问题

线性骨架下，固定动力学后，encoder 到完整因果预测的映射是仿射的。原 1 s/3 s 目标加 `1e-4 ||E||²/160` 为严格凸二次问题。其唯一最优解不依赖 Adam 的步数或初值，因而能检验有限联合优化留下的条件误差。

两次条件解使用同一 train 目标、相同特征尺度及正则。真值动力学条件解仍不能泛化时，优先检查初始化的样本覆盖、特征信息和正则偏差；真值条件解满足目标而终点动力学条件解仍明显偏离时，动力学修正也有直接依据。两者可以同时存在，不把差值解释成唯一因果分解。

train 特征谱与三帧/11 帧观测信息用于区分数据覆盖和采样信息。满秩不等于有限噪声下可可靠辨认，三帧观测满秩也不保证 32 个事件足以学习正确的状态映射。

<a id="doc-1f31dbc9b016-2-两个固定动力学与因果仿射映射"></a>

#### 2. 两个固定动力学与因果仿射映射

共同模型为原线性 L10，十机质量、势能与阻尼保持源值，`C=P diag(g)`、`J=0`、衰减 `diag(1/τ)`。两个条件分别固定：

- `truth_dynamics`：源真值的 C、τ；
- `fitted_dynamics`：源 `local_clean_L10` 第 240 步的 C、τ。

不训练 C、τ、质量或可见骨架。恢复源 checkpoint 一次；真值端口转为局部 g 时核对 `P diag(g)` 与源 C 一致。两条件均沿用源 encoder E₀ 作为目标比较的参考值，条件解不依赖 E₀ 初始化。

令标准化特征列向量为 `f_e`，`F∈R^(32×80)` 为 train 行堆叠，`z_h=E f_e`。历史自由传播 100 ms 后，仅将 q/v 重置为观测末点，隐藏末态连续，再预测。固定 θ 时，完整状态预测可写成

\[
x_{e,t}(E)=b_{e,t}^{\theta}+D_t^{\theta}E f_e.
\]

构造 b 时令历史起点 `z_h=0`，保留各事件真实观测起点 q/v、恒定功率及预测起点可见重置。构造 D 时用十个单位隐藏起点，初始 q/v、功率及平衡先验均为零；历史传播后把其 q/v 响应重置为零，再传播未来。D 因而包含完整历史链的隐藏响应，不得直接以预测起点单位 z 替代。

每个动力学、每档积分器可将 64 条基准状态与十个隐藏基向量组成同一批。训练采用原投影 RK4 子步 0.005 s、未来 300 点；评分和精化分别用 0.0025/0.00125 s、未来 800 点，输出间隔始终 0.01 s。复用已审核线性矩阵快路径，不使用矩阵指数作为预测积分器。


<a id="doc-1f31dbc9b016-3-与原训练完全一致的二次条件问题"></a>

#### 3. 与原训练完全一致的二次条件问题

取 D 的前 20 行为可见响应，`S=diag(target_scale)`，目标 `y_e,t`。预测起点不计损失；时间权重为

\[
w_t=\begin{cases}1/150,&t=1,\ldots,100,\\1/600,&t=101,\ldots,300.\end{cases}
\]

其和为一，对应 1 s 和 3 s 事件 MSE 等权。固定

\[
\lambda=10^{-4}/160=6.25\times10^{-7},\qquad
L(E)=\frac1{32\cdot20}\sum_{e,t}w_t
\|S^{-1}(b_{e,t}+D_tE f_e-y_{e,t})\|^2+\lambda\|E\|_F^2.
\]

历史损失仍为零。令 `r_e,t=y_e,t−b_e,t`，定义

\[
G_z=\frac1{20}\sum_t w_tD_t^\top S^{-2}D_t,\quad
G_F=F^\top F/32,\quad
B=\frac1{32\cdot20}\sum_{e,t}w_tD_t^\top S^{-2}r_{e,t}f_e^\top.
\]

唯一条件最优解满足 `G_z E G_F + λE=B`。按行展开 `vec_r(E)` 时，

\[
K=G_z\otimes G_F^\top+\lambda I_{800},\qquad
K\operatorname{vec}_r(E)=\operatorname{vec}_r(B).
\]

`G_F` 对称，可写作 `kron(G_z,G_F)`。不得重复除以 20 或 32，不把正则改成按十维 E 求均值。每个动力学求解一次 800×800 正定系统，共两次条件 encoder 拟合；不构造 192000×800 的完整设计阵、不执行 Adam、不追加正则路径。具体线性求解入口在代码哈希中冻结。

保存 Gz、GF、B、K、E、训练基准及响应、目标和各项损失。令 `r_K=K vec_r(E)−vec_r(B)`，因 `K≥λI`，条件目标距最优值的上界为 `||r_K||²/λ`；该量用于数值验收，不新增特征值分解。


<a id="doc-1f31dbc9b016-4-固定对照谱和指标"></a>

#### 4. 固定对照、谱和指标

两条件解均输出 train/val/test 的 1 s、3 s、8 s q/v 与合并 NRMSE、主指标、物理 q/v RMSE、隐藏状态误差/能量及 COI。主指标为 `sqrt((NMSE_1s+NMSE_3s)/2)`。原 fitted 模型的同角色指标和预测作为已保存参考，不重拟合。

`truth_state_oracle` 使用真值动力学和源真实预测起点 `(q,v,z)`，在 0.0025/0.00125 s 各预测一次 8 s。它检验状态已给定时的传播误差，不作为可部署预测器或主模型成绩。

谱诊断固定为两次 SVD：

1. 标准化 train 特征矩阵 F，保存全部奇异值和右奇异向量。数值秩阈值为 `64 eps64 max(shape(F)) σmax`。令 V_r 为选中右奇异向量的按行堆叠，计算 val 特征到 train 行空间的剩余能量比例 `c_val=||F_val−F_val V_rᵀV_r||²_F/||F_val||²_F`；分母为零时记录零特征情形，不隐式除零。
2. 从旧 `local_design` 中抽取第 0、5、10 帧的 60 行，以固定 q=0.2、v=0.1 行尺度规范化后做 SVD。11 帧的规范化谱复用旧 `local_scaled_singular`。两者均报告原谱和除以帧数平方根后的谱；前者保留观测总量，后者比较平均每帧的信息几何。行尺度不是噪声协方差白化。秩阈值按各自矩阵尺寸使用同一浮点规则。

`coverage_gap` 标记为 `c_val>1e-8`；`three_frame_rank_loss` 为三帧秩小于十而旧 11 帧秩为十；`three_frame_weakening` 为每帧规范化最小奇异值之比小于 0.1。这些标记描述覆盖或信息变化，不单独证明预测失败的唯一原因。不对 val/test 做额外谱分解。


<a id="doc-1f31dbc9b016-5-技术验收与预冻结分流"></a>

#### 5. 技术验收与预冻结分流

| 技术检查 | 阈值 |
| --- | --- |
| 输入/来源/角色/参数恢复 | 冻结哈希及结构一致；数值重构最大差 ≤1e-12 |
| 条件矩阵对称性 | `||K−Kᵀ||F / max(1,||K||F) ≤1e-12` |
| 条件解精度 | `||r_K||²/λ ≤1e-12`，全部有限 |
| 条件目标检查 | 用原训练定义重算，`L(E*)≤L(E₀)+1e-10` |
| 仿射/直接因果链 | 每个动力学在其条件解 E* 上直接预测 3 s，最大绝对差 ≤1e-10 |
| 真值状态传播 | 每角色 1/3/8 s 合并 NRMSE 均 ≤1e-5 |
| 积分精化 | 每候选、每角色 0–8 s 可见误差按目标尺度归一后最大值 ≤1e-5 |
| 有限性/COI | 无非有限数或状态绝对值超过1e12；质量 COI 绝对误差 ≤1e-10 |

任一技术门失败时，分类为 `DIAGNOSTIC_INVALID`，保存证据并先处理实现、数值或来源问题，不把失败解释成学习原因。全部技术门通过才得到 `DIAGNOSTIC_VALID`；这不要求条件 encoder 预测成功。

定义 `clean_target(role,candidate)` 为主 NRMSE 与 3 s NRMSE 同时 ≤0.001。定义 `improved(role,candidate)` 为主 NMSE 相对原 fitted 模型同角色降低至少 5%，即比值 ≤0.95；零参考误差只记录绝对差，不生成相对改善。动力学差标记定义为：fitted 条件解的 val 主 NMSE 大于 truth 条件解的 `1.25倍+1e-12`，且 val 3 s NMSE 同向更大。全部规则只用 train/val。

按以下顺序选择主要修正方向，同时保留所有非互斥标记：

1. 技术门失败：处理 `DIAGNOSTIC_INVALID`，不进入结果驱动修正。
2. truth 条件解未通过 val clean 目标：`INITIALIZER_LIMITATION_PRIORITY`。结合 train 目标、coverage 与三帧信息标记，准备初始化、样本覆盖或固定正则的最小修正。即使条件最优解 train 很好而 val 很差，也不声称单独证明某一种原因。
3. truth 条件解通过 val 目标，但 fitted 条件解未通过：`DYNAMICS_REPAIR_PRIORITY`。准备固定条件解的动力学修正，并保留 encoder 改善及动力学差标记。
4. 两条件均通过 val 目标：`CONDITIONAL_ENCODER_REPAIR_CANDIDATE`。准备将准确条件求解用于实际训练/初始化的候选实现；即使有小误差下的动力学差标记，也不据此强制增加已经满足目标后的修正。

5%/25% 是预定诊断决策线，不是显著性检验。条件解的 train/val 对比支持下一项修正的优先顺序，不提供唯一因果归因；当前 test 不改变上述分流。


<a id="doc-1f31dbc9b016-6-预算证据与继续工作"></a>

#### 6. 预算、证据与继续工作

本次只允许一次不可变运行。硬上限：旧 NPZ 解码 3 次、checkpoint 恢复 1 次、条件拟合/线性求解各 2 次、SVD 2 次、轨迹输出 18 次、显式矩阵乘法 30,000 次。迭代拟合、优化更新、autograd、NumPy/Torch RHS、expm 与真实数据读取均为零。线性求解库内部运算由两次求解的尺寸、残差、耗时及内存说明，不伪装为逐硬件算子计数。

18 次轨迹输出由两动力学各三档积分器的历史/未来共 12 次、真值状态对照 2 次、两次仿射一致性的直接因果链共 4 次组成。矩阵乘法按实际时间转移/输出时刻计，事件批量不再乘事件数；条件方程及重构中的显式矩阵操作也按准确实现的静态表登记。源码审核前绑定每个范围的确定调用表与全局上限，不在运行时追加预算。

两次条件拟合各一范围，其余输入、谱、传播对照和评分按静态计划划分。调用前登记额度，成功范围闭合返回；失败范围内部已发出额度的实际返回数量未知时明确记录，全部额度仍消费。权限、身份、日志或预算错误立即停止。任何求解/技术失败保留该范围；独立范围能否继续由机器计划预先固定，不能重试已失败求解。

保存全部输入绑定、两条件参数、特征与尺度、正规方程和解、原 E 目标、原始残差、仿射基准/响应、各档预测、谱方向、覆盖指标、所有门槛和分流标签、预算日志及运行环境。另登记一次对本轮新保存工件的算术复核；每文件最多解码一次，不重新调用模型、传播、分解、线性求解或 autograd。

诊断结果审核后继续用户已授权的修正工作，具体修正使用新的准确合同与范围。truth 条件解未达到目标意味着不能直接进入确认或 T0；不意味着整个任务在诊断报告处结束。修正后使用新冻结合成样本独立确认，通过后再登记与 TASK3 一致的 kiki 官方 train/test 阶段。本协议不读取真实数据、不修改旧阈值或晋升基线。

<a id="doc-d1ec1a06fe71-诊断设置与信息覆盖"></a>

#### 诊断设置与信息覆盖

- 两个条件模型均为线性 local L10：十个隐藏状态，质量、可见骨架与特征尺度冻结。真值动力学使用已知 `gᵢ = 0.350000 + 0.0250000i`（`i=0,…,9`）及 `τ = geomspace(0.0500000, 2.00000, 10)`；拟合动力学取自冻结的 `local_clean_L10` 第 240 步检查点。每个条件只求一次 train 条件最优 E，ridge 系数 `λ = 10⁻⁴/160 = 6.25000×10⁻⁷`，无优化器更新。
- 原联合模型为同一来源中的 `local_clean_L10` 联合拟合预测；来源人群为 64 条旧合成轨迹，train/val/test 分别为 32/16/16。真值动力学和拟合动力学条件解只用 32 条 train 轨迹求 E。
- 标准化 train 特征矩阵 F 为 32×80，秩为 `32/80`：32 行满行秩，但 80 维输入方向并未被 train 覆盖。数值秩阈值为 `2.00921×10⁻¹¹`。val 特征落在 train 行空间外的能量比例为 `0.000319204`；val 样本平均越出量为 `0.0172345`，test 为 `0.0143279`。因此 `coverage_gap=true`（预设阈值 `1.00000×10⁻⁸`）；该标记描述覆盖差异，不构成唯一因果证据。
- 三帧与十一帧观测设计的秩均为 `10/10`，`three_frame_rank_loss=false`；按帧数平方根归一化后的最小奇异值比为 `1.04341`，`three_frame_weakening=false`。这些谱量描述当前观测支持，不能单独确定初始化误差的成因。
