# 逐机模型初始化诊断与后续修正计划

日期：2026-11-12。核心设计与科学审核：Astra Ultra。

用户已明确授权：根据 S1-base 结果，分开定位初始化泛化与动力学误差，修正后先通过合成验证，再按门禁自主推进和提交。本计划将第一步冻结为一次 local clean L10 诊断；结果决定下一项修正，不以完成诊断报告代替后续已授权工作。

## 1. 已知问题与本次问题

[S1-base 审核](machine_local_s1_result_review_20261112_zh.md)保留 `REJECT / KEEP_BASELINE / STOP_T0`：十二次固定拟合完成，物理和积分门通过，六个覆盖真值的配对均未达到预测门。local clean L10 的 train/test 3 s NRMSE 为 0.02718/0.21441，预测起点隐藏状态 RMSE 为 0.03944/0.24928。这些结果将初始化泛化列为优先疑点，尚未排除动力学误差和联合优化的贡献。

本次只改变“怎样求给定动力学下的 encoder”，不改变源数据、特征、正则、历史传播、预测起点重置或评分定义。分别固定真值动力学与本轮终点动力学，把 E 的条件问题准确求解一次；另以真值动力学和真实预测起点 z 作传播对照。准确合同见[初始化诊断协议](../protocols/machine_local_initializer_diagnosis_v1_zh.md)。

## 2. 为什么这能区分问题

线性骨架下，固定动力学后，encoder 到完整因果预测的映射是仿射的。原 1 s/3 s 目标加 `1e-4 ||E||²/160` 为严格凸二次问题。其唯一最优解不依赖 Adam 的步数或初值，因而能检验有限联合优化留下的条件误差。

两次条件解使用同一 train 目标、相同特征尺度及正则。真值动力学条件解仍不能泛化时，优先检查初始化的样本覆盖、特征信息和正则偏差；真值条件解满足目标而终点动力学条件解仍明显偏离时，动力学修正也有直接依据。两者可以同时存在，不把差值解释成唯一因果分解。

train 特征谱与三帧/11 帧观测信息用于区分数据覆盖和采样信息。满秩不等于有限噪声下可可靠辨认，三帧观测满秩也不保证 32 个事件足以学习正确的状态映射。

## 3. 有限执行与预定推进

| 阶段 | 固定任务 | 后续 |
| --- | --- | --- |
| 诊断准备 | 两次条件 E 拟合、一次真实 z 对照、两个谱检查及有限保存复核 | 准确实现、输入与新预算审核后执行一次 |
| 诊断技术门 | 线性解残差、仿射/直接因果链一致、真值传播及积分精化 | 任一失败先处理证据或实现问题；不解释为学习原因 |
| 原因分流 | 使用 train/val 和预冻结规则；当前 test 只作回顾性描述 | 保留所有标记，选择下一项最小修正 |
| 修正实现 | 只修改诊断指出的初始化或动力学学习环节 | 新范围登记后验证；不追加旧运行的更新 |
| 独立合成确认 | 新冻结样本与 seed；保留 local/nonlocal、噪声和必要对照 | 通过后才登记真实数据阶段；失败继续保留证据并重新审核问题 |
| 真实数据阶段 | kiki 官方 train/test，任务设置与 TASK3 一致 | 在新合同中登记具体数据与预算后执行 |

两次 ridge 解是两次条件 encoder 拟合，迭代训练次数与 Adam 更新均为零。旧 S0/S1 授权保持已消费状态；读取三个旧合成工件由新的诊断范围授权，不复活旧运行。不得以准确求解替代登记或把它写成“没有拟合”。

若真值条件 encoder 的 val 仍未达到目标，下一步仍在本轮自主授权范围内：准备针对初始化的最小修正及独立登记。例如，使用固定完整历史观测算子构造随当前动力学变化的因果状态估计，替代无结构 dense E；任何新状态正则、数值截断、梯度路径和信息门槛须先冻结。这与直接把未来积分误差用于每条事件的隐藏状态拟合不同：预测时只能使用已观测历史。

若固定终点动力学的条件解显著落后于固定真值动力学，准备将条件 encoder 求解纳入动力学学习，检查只训练 g/τ 的可微条件优化或另一项明确修正。不能通过真实 z 输入、真值参数或 test 目标训练可部署模型。具体修正依据本次预冻结分流产生，并经准确实现审核；不同时搜索多个未登记方案。

## 4. 比较与确认纪律

本次 train/val/test 均为已经观察过的旧合成事件。E 只用 train 拟合，分流只使用 train/val；test 不选择解法、正则、步数或分支。5% 与 25% 是诊断决策线，不是统计显著性声明。对当前事件的改善只能作为诊断证据；修正方案确认使用新的冻结合成样本。

在修正准确实现冻结后登记新的生成种子、角色、噪声、候选、预算及阈值。保留原基础模型对照与相同因果观测预算，至少重新覆盖可表达真值的配对；具体数量由修正规模确定，不能把本次两次条件拟合或旧十二次拟合记作新确认。

用户对未来真实阶段的新指令优先于旧 internal train/val 方案：使用 kiki 官方 train/test，与 TASK3 的训练、预测时钟和评估设置一致。协调代理核对 TASK3 来源后登记确切数据、样本和任务合同；旧 internal 划分不再作为该新阶段的固定比较口径。归一化、参数学习及选择不使用官方 test；既有历史暴露如实记录，不据此再次施加用户已明确替换的禁读规则。本次合成诊断不读取任何真实数据。
