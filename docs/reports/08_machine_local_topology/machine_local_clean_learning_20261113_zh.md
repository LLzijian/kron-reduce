# Clean learning 单轮结果（2026-11-13）

本轮用可微因果历史初始化器学习合成 local 线性系统的逐机隐状态动力学。模型匹配已知可见骨架，encoder 固定为零，只学习十个端口增益 `g` 与十个时间常数 `τ`。使用无噪声历史；每个冻结模型均完成 train/val/test 评分，不因 RMSE 未达阈值而中止。该轮验证了已知可见骨架下的逐机参数学习，以及独立样本上的初态恢复和未来预测。
