# 非线性历史接口与稳定性判断：最小验证

日期：2026-11-13。核心设计与科学审核：Astra Ultra。

[上一轮](machine_local_clean_learning_result_review_20261113_zh.md)已验证匹配 local 线性系统中的可微初始化与 20 参数学习。本轮只补齐进入真实试验准备前必要的非线性接口检查，不训练参数，不额外注入噪声。

方法以真实正弦网络方程推进 100 ms 历史，通过与 RK4 同阶段积分的解析切线获得初始隐状态灵敏度，固定三次 Gauss–Newton 求隐藏初态。QR、增量和全部历史均可反传；最终重新闭环推进历史，保留观测末点可见状态重置。用 autograd JVP 核对切线，用两参数块的双步长方向差分核对完整预测梯度。

六个预定样本按 train/val/test 各分配两个，包含低能量与高初始速度对照；标签由真值轨迹确定。每个角色必须实际覆盖失步与窗口内收敛两类，并排除历史结束前已经触发的事件。覆盖不足即记录失败，不按结果补样本。

真值参数与固定 perturbed 参数都评价 train、val、test。每轮同时报告轨迹误差和稳定性判断：沿现有角差、COI 速度同时连续五点超限的失步规则，列出混淆矩阵、准确率、平衡准确率、失稳召回、未决与数值失败数量及覆盖率。全稳定样本不能支持双类别准确性结论，未决预测不硬归为稳定，窗口内收敛不称为稳定性证书。

准确初态、积分步长、梯度门、known 恢复门和一次执行预算见[协议](../protocols/machine_local_nonlinear_history_v1_zh.md)。各参数组和各角色独立评价，精度不达标仍完成其余可执行评价；无需新增 240 步训练。

本 S0 通过后可以准备另行登记的 TASK3 真实小规模试验，继续使用 train 346、val 107、test 76 名单及 100 ms 输入。它只验证本接口，不声称非线性学习已经收敛或真实预测已经有效。基线保持，T0 本阶段不开放；用户已授权继续推进，后续科学执行仍按新的准确范围登记。
