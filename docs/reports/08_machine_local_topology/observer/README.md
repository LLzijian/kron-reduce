### 用离散历史响应修正逐机模型初始化

日期：2026-11-12。核心设计与科学审核：Astra Ultra。

本次将 800 参数自由编码器替换为由当前动力学定义的历史状态求解器，先在固定动力学下验证。目标是检验：已有 100 ms 历史能否支持准确、可推广的隐状态初始化，并区分初始化修正后的剩余动力学误差。


<a id="doc-8d49bc82dfff-依据与修正"></a>

#### 依据与修正

[条件编码器诊断](../initializer_diagnosis/README.md#doc-6190ba875ea2)显示，真值动力学配合条件最优编码器的 train/val 3 s NRMSE 分别为 0.002837/0.161755，而真值隐状态对照约为 `1e-12`。三帧与十一帧的观测矩阵均为秩 10。因此，本次取消从有限事件学习自由映射的环节，直接利用模型对隐状态的历史响应。十一帧是已有合法观测，不增加历史长度，也不把旧结果改写为“三帧不可观测”。

固定模型 θ 时，以实际 RK4 离散传播构建历史可见响应 `Oθ`，从第 1–10 个历史时刻的观测残差求唯一最小二乘隐状态。满列秩且条件数不超过 `1e8` 才输出状态。随后完成同一 100 ms 历史闭环，保留预测起点隐状态，只重置该点的可见 q/v，再预测未来。状态求解仅使用当前事件历史及已知输入；不读取未来、不拟合 E、不引入新的函数家族。

新 local/nonlocal 种子分别为 `2026111211`、`2026111212`；每组 64 个事件，固定为 train 32、val 16、test 16。另设 τ 全部为 0.3 s 的等率负例，要求检测秩 9 并拒绝输出状态和未来。固定真值模型在这里是对照条件；本阶段通过只证明该状态求解方法在所测模型和噪声条件下有效，不等于学得模型已经通过独立确认。

精确公式、尺度、种子、误差门槛、来源文件和操作预算见 [执行协议](#doc-6f68c96c4128)。本次拟合、优化更新和梯度调用均为零；一次正式运行最多 25 次传播、13 次 SVD、6 次 expm、4 次旧 NPZ 解码和 30,000 次登记矩阵操作。

### 逐机模型离散历史初始化验证协议 v1

日期：2026-11-12。设计与科学审核：Astra Ultra。阶段：`machine_local_observer_v1/fixed`。研究依据见 [研究计划](#doc-8d49bc82dfff)。


<a id="doc-6f68c96c4128-1-范围与因果输入"></a>

#### 1. 范围与因果输入

本阶段修正初始化方法并验证固定动力学下的预测。每个事件提供 `t_h=-0.1 s` 至 `T=0` 的 11 帧 q/v，间隔 0.01 s，以及已知常值功率。历史起点和预测起点均保持原合成定义。预测不得读取未来目标、真值隐状态或其他事件的信息；真值隐状态仅参与保存后的指标计算。q/v 的质量 COI、固定 U/D、质量、平衡与原基础模型一致。

动力学是原十节点线性被动模型：`q'=v`、`Mv'=P(u−∇U−Dv−Cz)`、`z'=Cᵀv−diag(1/τ)z`。其中 `P=I−m1ᵀ/(1ᵀm)`，L10 为 `C=P diag(g)`，G10 为平衡基下的一般端口。隐状态无偏置、无新缩放，能量为 `‖z‖²/2`。本阶段所有模型参数固定；未调用的 E 不参与预测或评分。

求解器只适用于当前线性骨架。它用已有十一帧构造当前模型的观测响应，取消自由 E 映射。旧三帧响应已知满列秩，因此本协议不预设“增加帧数恢复了原先丢失的秩”。对含噪数据，历史第一帧 q/v 作为给定初态构建基准，而非同时估计的未知量；这一近似的影响由含噪病例实际检验。


<a id="doc-6f68c96c4128-2-离散历史状态求解"></a>

#### 2. 离散历史状态求解

对固定 θ 和积分子步 h，调用实际模型的投影 RK4 传播。一次批量传播包括 64 个事件的零隐状态基准，以及十个零可见状态、单位隐状态、零输入的响应。保存基准历史 `b_e,j∈R³⁰` 和响应 `D_j∈R³⁰×¹⁰`，`j=0,…,10`。线性传播满足

\[
x_{e,j}=b_{e,j}+D_j z_{e,h}.
\]

历史尺度 `s_hist∈R²⁰` 为该语料 clean train 32 个事件、11 帧可见状态的逐通道 RMS，下限 `1e-5`。clean/noisy 共用该尺度；它不是噪声协方差白化，也不使用未来目标尺度选择状态解。

令 `H` 选取前 20 个可见坐标，`S_h=diag(s_hist)`。第 0 帧的隐状态响应为零，将第 1–10 帧堆叠：

\[
O_\theta=\operatorname{stack}_{j=1}^{10}(S_h^{-1}HD_j)\in\mathbb R^{200\times10},\qquad
r_e=\operatorname{stack}_{j=1}^{10}[S_h^{-1}(y_{e,j}-Hb_{e,j})].
\]

每个病例、每档子步执行一次薄 SVD：`O=UΣVᵀ`。秩阈值为 `64 eps64 max(shape(O)) σmax`；必须秩为 10 且 `σmax/σmin≤1e8`，所有量有限，才输出唯一最小二乘解

\[
\hat z_{e,h}=V\Sigma^{-1}U^\top r_e.
\]

全部事件共用该次分解。没有 ridge、正则路径、训练或截断后补零。未通过秩或条件数门时记录未解析方向并拒绝输出隐状态、起点和未来；不得以伪逆数值代替识别通过。

用同一历史响应重构 `x̂_e,j=b_e,j+D_j ẑ_e,h`。在 `T=0` 保留该历史传播所得 `ẑ_e,T`，只把 q/v 重置为最后一帧观测，再预测 8 s。重置不使用真值隐状态，不在历史中反复重置可见状态。保存 SVD 三因子、设计矩阵、右端项、历史拟合残差、起点状态和未来轨迹，供一次保存算术审核使用。


<a id="doc-6f68c96c4128-3-数据模型与固定病例"></a>

#### 3. 数据、模型与固定病例

旧 `local_clean_L10` 对应原 64 事件和原角色，来自已完成诊断和 S1。旧拟合模型完整恢复一次；真值模型由冻结解析参数构造。

| 病例 ID | 输入 | 固定模型 | 精度用途 |
|---|---|---|---|
| `old_truth` | 旧 local clean | 真值 L10 | required clean |
| `old_fitted` | 旧 local clean | 原 S1 fitted L10 | 剩余动力学误差诊断 |
| `local_clean` | 新 local clean | 真值 L10 | required clean |
| `local_noise01` | 同一新 local，加 1% 历史噪声 | 真值 L10 | required noisy |
| `nonlocal_clean` | 新 nonlocal clean | 真值 G10 | required clean |
| `nonlocal_noise01` | 同一新 nonlocal，加 1% 历史噪声 | 真值 G10 | required noisy |

新 local 和 nonlocal 种子分别固定为 `2026111211`、`2026111212`。每组 64 个事件，顺序固定 train 0:32、val 32:48、test 48:64。`i=0,…,9`，`m_i=1+0.1i`、`g_i=0.35+0.025i`、`τ=geomspace(0.05,2,10)`；完全图 45 边刚度均 0.12，`D=0.08BBᵀ`。nonlocal 端口为 local 端口右乘原冻结的正交 DCT-II 矩阵，衰减顺序不变。

使用同一 NumPy `default_rng(seed)`，依序生成四个独立 `64×10` 标准正态数组。行向量初态为 `q_h=0.2 ξ_q P`、`v_h=0.1 ξ_v P`、`z_h=0.15 ξ_z`、`u=0.03 ξ_u Pᵀ`。真值用 40 维含常值输入的增广生成矩阵，由 `expm(0.01A)` 生成 811 帧；`0.1/8.1 s` 端点各直接 expm 检查，最大绝对差 ≤`1e-10`。这两组新事件独立于先前诊断样本，模型族和参数分布保持不变。

噪声由各 `seed+100` 的独立 `64×11×20` 标准正态数组生成，乘 `0.01 s_hist`，然后将 q/v 两块按质量 COI 投影。噪声仅加在观测历史上；目标和已知功率不加噪。保存 clean/noisy 配对输入、角色、尺度、真值模型与生成规则，评分前生成输入哈希清单。

等率负例单独构造 `τ_i=0.3 s`，其余 local 真值参数不变；零可见历史和输入只用于激发单位隐状态响应，尺度固定为全 1。一次 `0.0025 s` 历史传播和一次 SVD 必须得到数值秩 9、`resolved=false`，且不生成预测起点与未来。该负例不新增拟合。

<a id="doc-6f68c96c4128-5-指标与验收"></a>

#### 5. 指标与验收

每个正例分别使用 `0.0025/0.00125 s` 子步完成历史与 8 s 未来，输出间隔均为 0.01 s。采用已经通过 S0 的线性 RK4 矩阵路径，保持逐子步投影及可见末点重置。精化比较包含各自历史状态求解，覆盖整个因果预测器。

预测尺度为 clean train 32 事件、未来第 1–300 帧逐通道 RMS，下限 `1e-5`。分别报告每个 train/val/test 的 q、v、合并 1/3/8 s NRMSE、物理 RMSE、最大误差。主 NRMSE 定义为 `sqrt((NRMSE_1s²+NRMSE_3s²)/2)`，不同于单独 3 s NRMSE。隐状态历史起点/预测起点 RMSE 按该角色全部事件及十个固定坐标计算。

| 门槛 | 固定规则 |
|---|---|
| 来源 | 冻结文件身份、哈希、数组形状与补充方程核对通过 |
| 正例可求解性 | 六病例、两档子步均满列秩 10 且条件数 ≤`1e8` |
| 有限性 | 全部历史与 8 s 轨迹有限，状态绝对值 ≤`1e12` |
| COI | 两档历史与未来质量 COI 绝对误差均 ≤`1e-10` |
| 子步精化 | 两档 0–8 s 可见预测差按目标尺度归一后最大值 ≤`1e-5` |
| required clean 预测 | 三病例每个角色的主/3 s NRMSE 均 ≤0.001 |
| required clean 状态 | 三病例每个角色的历史起点/预测起点隐状态 RMSE 均 ≤`1e-4` |
| required noisy 预测 | 两病例每个角色的主/3 s NRMSE 均 ≤0.02 |
| 等率负例 | 秩 9，拒绝状态和未来输出 |

`old_fitted` 的预测和隐状态误差为诊断项，不要求达到 clean 精度门；其可求解性、有限性、COI 和精化仍为技术门。含噪隐状态误差及全部 8 s 精度为描述项，不事后增加或放宽门槛。历史残差反映噪声和动力学失配，不要求含噪或旧拟合病例达到零残差。本阶段无模型选择；所有预定病例和角色完整报告。

若所有门通过，输出 `REGISTER_OBSERVER_DYNAMICS_TRAINING`，允许准备并登记完整因果梯度检查及未知动力学训练的新范围。已知真值条件下的新种子通过，不能代替学得动力学的独立确认。若真值 clean 通过而含噪预测失败，下一修正聚焦初始化的噪声处理；若技术或 clean 门失败，先处理对应实现/求解边界。失败输出 `OBSERVER_REPAIR_REQUIRED` 并保留所有证据。两条路线均不直接开放 T0、不晋升基线、不自动追加当前预算。

## 报告与结果

<a id="doc-333ce3562b94-任务与结果"></a>

#### 任务与结果

[S2 协议](#doc-6f68c96c4128)评估固定动力学下的离散历史初始化器。每个合成事件提供 11 帧、100 ms 的 q/v 历史，初始化器使用当前模型的历史观测响应估计隐藏初态；之后从已观测末点重置 q/v 并预测 8 s。六组各含 train 32、val 16、test 16 个事件；新生成的 local 与 nonlocal 数据分别使用冻结种子 `2026111211` 和 `2026111212`。

旧真值动力学和两组新无噪声病例的三种角色均恢复到数值精度，主 NRMSE 约为 `1e-9` 或更低，隐藏初态及预测起点 RMSE 约为 `1e-8` 或更低。旧拟合动力学保留了可见预测误差；它是固定参数误差对照，不作为恢复门要求。两组 1% 历史噪声病例都未达到预设的 `0.02` 主/3 s NRMSE 门，后续工作聚焦观测噪声下的初始化。等率控制以秩 9 拒绝输出隐藏状态和未来，符合拒绝规则。

这项验证固定了真值或已有拟合动力学，没有训练动力学参数；已知参数下的无噪声恢复不代表学得模型的独立确认。`t0_allowed=false`，基线保持 `KEEP_BASELINE`。

<a id="doc-73d37091a634-下一项可证伪修正"></a>

#### 下一项可证伪修正

现有方法把第一帧含噪 q/v 当作精确初态。下一项修正只解除这一等式约束：在质量 COI 子空间内联合估计 18 个可见初态坐标和十个隐状态，使用相同 100 ms、十一帧加权历史损失，保留预测起点可见重置，不增加 ridge 或改变噪声权重。

这是待检验的机制，不是已确定的唯一根因。联合估计增加未知量，也可能放大弱方向噪声。历史拟合残差下降是解除约束后最小二乘的固有性质，不能单独作为成功证据；判据仍是预先冻结的未来误差和独立新种子确认。两组旧含噪样本只提供 train/val 配对机制比较，旧 test 不参与选择。
