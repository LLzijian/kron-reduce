# 用离散历史响应修正逐机模型初始化

日期：2026-11-12。核心设计与科学审核：Astra Ultra。

本次将 800 参数自由编码器替换为由当前动力学定义的历史状态求解器，先在固定动力学下验证。目标是检验：已有 100 ms 历史能否支持准确、可推广的隐状态初始化，并区分初始化修正后的剩余动力学误差。

## 依据与修正

[条件编码器诊断](machine_local_initializer_diagnosis_result_review_20261112_zh.md)显示，真值动力学配合条件最优编码器的 train/val 3 s NRMSE 分别为 0.002837/0.161755，而真值隐状态对照约为 `1e-12`。三帧与十一帧的观测矩阵均为秩 10。因此，本次取消从有限事件学习自由映射的环节，直接利用模型对隐状态的历史响应。十一帧是已有合法观测，不增加历史长度，也不把旧结果改写为“三帧不可观测”。

固定模型 θ 时，以实际 RK4 离散传播构建历史可见响应 `Oθ`，从第 1–10 个历史时刻的观测残差求唯一最小二乘隐状态。满列秩且条件数不超过 `1e8` 才输出状态。随后完成同一 100 ms 历史闭环，保留预测起点隐状态，只重置该点的可见 q/v，再预测未来。状态求解仅使用当前事件历史及已知输入；不读取未来、不拟合 E、不引入新的函数家族。

## 本次六个固定病例

| 病例 | 观测 | 固定动力学 | 作用 |
|---|---|---|---|
| `old_truth` | 原 local clean | 真值 L10 | 在相同事件上验证初始化修正 |
| `old_fitted` | 原 local clean | 原 S1 学得 L10 | 观察修正后剩余动力学误差 |
| `local_clean` | 新 local clean | 真值 L10 | 新种子下的局部状态恢复 |
| `local_noise01` | 同一新 local，历史加 1% 噪声 | 真值 L10 | 噪声敏感性 |
| `nonlocal_clean` | 新 nonlocal clean | 真值 G10 | 非局部端口下的状态恢复 |
| `nonlocal_noise01` | 同一新 nonlocal，历史加 1% 噪声 | 真值 G10 | 非局部端口的噪声敏感性 |

新 local/nonlocal 种子分别为 `2026111211`、`2026111212`；每组 64 个事件，固定为 train 32、val 16、test 16。另设 τ 全部为 0.3 s 的等率负例，要求检测秩 9 并拒绝输出状态和未来。固定真值模型在这里是对照条件；本阶段通过只证明该状态求解方法在所测模型和噪声条件下有效，不等于学得模型已经通过独立确认。

## 门禁与继续路线

精确公式、尺度、种子、误差门槛、来源文件和操作预算见 [执行协议](../protocols/machine_local_observer_v1_zh.md)。本次拟合、优化更新和梯度调用均为零；一次正式运行最多 25 次传播、13 次 SVD、6 次 expm、4 次旧 NPZ 解码和 30,000 次登记矩阵操作。

三个真值 clean 病例须通过主/3 s NRMSE ≤0.001，以及历史起点与预测起点隐状态 RMSE ≤`1e-4`。两个含噪真值病例须通过主/3 s NRMSE ≤0.02。所有正例通过数值门，等率负例正确拒绝。8 s 精度用于描述，有限性和步长精化仍覆盖整个 8 s。

通过后，下一项最小工作是登记可微历史求解器及动力学参数训练，先检查完整因果链梯度，再用新冻结合成事件确认。若 `old_fitted` 仍未达到预测目标，结果支持继续处理学得动力学；该病例不作为真值状态求解方法的精度门。若真值 clean 通过而噪声病例失败，下一修正限定于噪声下的初始化，并保留当前失败结果。任一技术门或真值 clean 门失败，先修正相应实现、离散传播或历史求解约束，不从有限失败推断数学不可辨识。
