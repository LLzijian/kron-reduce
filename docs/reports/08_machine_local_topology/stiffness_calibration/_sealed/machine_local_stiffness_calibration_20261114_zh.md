## 共享刚度和隐藏状态

从 100 ms、11 帧观测开始，每次使用当前刚度重做三步 Gauss–Newton 初始化。预测起点的可见状态取观测末帧，隐藏状态取历史传播末态。目标使用 5 ms 积分步长、未来三秒、20 个可见通道的事件等权归一化 MSE。
