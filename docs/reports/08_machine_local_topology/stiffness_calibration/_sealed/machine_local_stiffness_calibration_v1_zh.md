# 单一共享刚度系数校准协议 v1

日期：2026-11-13。科学设计：Astra Ultra。工作流 `machine_local_stiffness_calibration_v1`，唯一科学阶段 `calibration`。本协议将第一阶段问题固定为：在其余动力学正确、历史初始化每次重新求解的条件下，三秒可见轨迹能否支持恢复一个共享刚度系数。准确实现、操作预算与审核记录绑定后才执行；本文件不代替操作员批准，不开放真实数据读取。

## 1. 固定模型与因果链

真值为 `fixture("local", backbone="sine")`：十机，`m_i=1+0.1i`，完整图45条边，`k_e=0.12`，`D=0.08 BBᵀ`，`C=P diag(0.35+0.025i)`，`τ=geomspace(0.05,2,10)` s；`P=I−m1ᵀ/Σm`、`Q=Pᵀ`。功率、平衡角及隐藏旋转项均为零。

候选唯一待校准量为 `λ`，每条边统一使用 `k_e=0.132 exp(λ)`，记 `γ=exp(λ)`。范围固定为 `λ∈[log(0.5),log(2)]`；`λ=0` 表示10%刚度失配基准。质量、阻尼、g、τ、输入、平衡点、历史算法和所有尺度固定。物理正确值 `γ*=10/11` 只用于冻结后的评价，不进入优化器初始化、采样点、目标函数或终止规则。

每次目标调用都用当前有效刚度从零隐藏状态开始，对11帧、100 ms观测执行三次完整GN：同阶段投影RK4状态与切线、薄QR、三角解；然后用最终隐藏初值重算实际历史。预测起点使用观测末帧q/v，保留该模型历史传播得到的隐藏末态。每个目标值覆盖全部32个train事件；不缓存其他刚度下的隐藏状态，不增加迭代、正则、隐藏能量损失、逐事件参数或line search。

RHS、同阶段切线、储能表达和冻结导出的刚度必须来自同一组有效值。复用现有模型的刚度数组即可实现这一数值校准，不增加可训练张量或端到端梯度路径。工程检查覆盖非单位γ下RHS、切线和导出的一致性；旧模型默认行为不变。

## 2. 新的完整64例总体

事件 `j=0,…,63`，节点 `i=0,…,9`。固定

\[
\phi_j=2\pi(j+0.25)/64,\qquad k_j=\lfloor j/2\rfloor\bmod10,
\]
\[
q_h=Q[0.03\sin(i+\phi_j)],\quad
z_h=0.05\cos(i+\phi_j),\quad
v_h=Q[0.02\cos(i+\phi_j)+16\mathbf1_{j\ \mathrm{odd}}e_{k_j}].
\]

ID为 `stiffness_calibration_v1:000` 至 `stiffness_calibration_v1:063`；train为0…31、val为32…47、test为48…63。相位偏移区别于上一轮的`j+0.5`，不读取或复用上一轮轨迹。分组、相位、扰动机器和幅度均在生成前冻结，不按结果重抽或替换。

独立NumPy投影RK4生成0…8.1 s的811帧，输出间隔0.01 s，最大子步0.00125/0.000625 s；后者为参考，逐输出间隔沿用 `ceil(interval/max_step−1e−12)`。尺度只取参考train：历史尺度为0…10帧逐通道RMS，目标尺度为11…310帧逐通道RMS，统一下限`1e-5`。历史对应0…0.1 s；全部预测从0.1 s开始，评价时长均相对于此起点。

生成全部64例两档真值后，要求每个角色均实际包含稳定和失稳两类，100 ms历史内无LOS，两档类别和触发采样点完全一致，可见最大归一化差≤`1e-6`且全部有限。真值门失败时保存证据并停止新增目标与候选预测，不改变总体或步长。真值标签只由固定八秒轨迹规则产生，不用于拟合、归一化或选择。

## 3. 唯一目标与一次有界优化

目标使用5 ms最大子步、10 ms输出，未来0.01…3 s共300点，排除预测起点。令固定目标尺度为`S`，定义

\[
J_{5}(\lambda)=\frac1{32}\sum_{e\in train}\frac1{300\cdot20}
\sum_{t=1}^{300}\left\|S^{-1}(\widehat y_{e,t}(\lambda)-y_{e,t})\right\|_2^2.
\]

每个事件先算20通道、300点归一化MSE，再对32个事件等权平均。历史真值隐藏状态、未来隐藏状态、分类标签、val和test均不进入这个标量。历史尺度和目标尺度在拟合前固定。

唯一优化器为 `scipy.optimize.minimize_scalar(method="bounded", bounds=(log(.5),log(2)), options={"xatol":1e-8,"maxiter":80})`。有界Brent没有可指定的`x0`；`λ=0`是基准参数，不额外充当搜索起点。[SciPy官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.minimize_scalar.html)将其定义为有界局部最小化；九点诊断不把它改成全局搜索。

独立调用计数器在发出每次完整train目标前检查上限80，不依赖库对`maxiter`的解释。不得追加重新优化、缩小区间、其他初值、优化器或精度选择。按调用顺序保存λ、γ、逐事件损失、完整目标值、有限性和失败原因。数值失败的目标记为`null`，向优化器返回`+inf`作为不可用标记；不补零、不平均剩余事件、不重试该目标，不做逐事件拟合试算。权限、日志、身份或预算失败直接停止。

候选固定为Brent实际访问过的有限目标中最小值对应的λ；精确相等时取最早一次。保存优化器`success/status/message/nfev`和实际计数；非收敛结果保留其状态，不伪装为收敛。没有有限访问点则候选缺失，所有fitted事件明确记未覆盖。选择完成立即冻结参数、模型导出、尺度、合同和哈希，此后不再更新λ。

## 4. 冻结后的目标曲线与完整预测

冻结后另做九次完整train目标：`λ_j=log(.5)+j log(4)/8`，`j=0,…,8`，步长、因果链及三秒损失与拟合完全一致。按固定顺序保存完整结果，即使某点与优化访问点重合也独立计数；这些点不重新选择候选。再单独计算一次`γ*=10/11`的同口径5 ms train目标。两项共十次，不挪用80次优化预算。

随后固定评价三组：`mismatch`为γ=1，`known`为γ*，`fitted`为冻结γ。三组均运行同一三次GN链，不使用真实隐藏初态。每组完整评价train32、val16、test16，未来8 s，两档最大子步2.5/1.25 ms，每档各自重新初始化；输出间隔仍为10 ms。按固定顺序每批最多16例。

某档批量预测抛数值异常时，允许对该批按原顺序、原档位逐事件隔离一次；其他档位和角色继续。正常返回但数值门或分类门不通过时不追加模型调用。缺失fitted参数时输出完整名单的不可用记录，仍完成另外两组；任何RMSE或识别诊断不通过都不取消已冻结的其他角色评价。

保存三次GN更新前的真实非线性历史残差、最终重新传播的历史残差、隐藏初值及增量范数、奇异值与秩、最终历史和可见重置向量。前后残差统一使用历史第1…10帧及同一历史尺度。隐藏误差分别比较历史起点和预测起点，避免把历史拟合残差当作真实隐藏状态恢复。

## 5. 指标、数值门与三项独立判断

各组各角色报告1/2/3/5/8 s的逐事件及汇总：事件等权归一化MSE、其平方根、逐事件归一化RMSE均值、q/v各自归一化RMSE、带物理单位的RMSE和最大绝对误差。三秒事件等权归一化MSE为主要轨迹量；不同时间范围分别列出。

稳定性主指标固定八秒。使用相同11帧历史与未来轨迹派生真值和预测标签：未包裹角范围>`π`且最大质量COI相对速度>`0.02 pu`，连续五个10 ms点记失稳；未失稳且最后100点角范围均<`π`、速度均<`0.005 pu`才记稳定；其余未决。每组每角色报告TP/TN/FP/FN、完整名单准确率、可判定准确率、失稳召回、漏判率、稳定误报率、未决/未覆盖/数值失败及覆盖率。任何未决、未覆盖或数值失败令完整准确率为`null`，零分母为`null`。五个轨迹时长不改变该八秒标签窗口。

数值门沿用已审核规则：全路径有限且状态幅度≤`1e12`，隐藏观测秩10、条件数≤`1e8`；质量COI误差≤`1e-10`；两档可见轨迹最大归一化差≤`1e-5`，标签一致，LOS触发差≤两个输出点。`known`参照各角色三秒合并NRMSE≤`0.001`，每事件两处隐藏RMSE≤`1e-4`，历史最大归一化残差≤`1e-7`，八秒标签与真值一致。缺失或数值不合格的完整角色主要指标为`null`，仍保留逐事件可用结果和覆盖。

结果分别回答以下问题，不合并成一个未经证明的“全局可辨识”标记。

1. **参数分辨情况。** 报告γ的有符号误差、绝对误差、相对误差、λ误差及有效刚度。`|λhat−log(10/11)|≤10 xatol`只命名为“在优化容差内一致”，不作为物理参数恢复的唯一门。距离任一搜索边界≤`10 xatol`记边界结果。令`ε_J=64 eps64 max(1,全部有限5 ms目标值)`；九点中任何目标小于`J5(λhat)−ε_J`记优化曲线矛盾，不改候选。优化器收敛、内点、完整有限候选及无曲线矛盾分别记录。
2. **同一目标下的数值分辨情况。** 从已保存的train预测计算fitted和known的`J2.5`、`J1.25`，定义`δJ=max(ε_J, |J5−J2.5|, |J2.5−J1.25|)`，后两项覆盖这两组。比较`J5(γ*)−J5(γhat)`与`±δJ`，并列出九点中`|J5(λ_j)−J5(γhat)|≤δJ`的采样点。δJ描述这两个固定参数处的积分变化，不是整个区间误差上界、统计置信区间或连续参数区间；稀疏九点不能证明全局唯一性。缺失任何必要值时相关判断为`null`。
3. **隐藏恢复与预测。** 分开报告fitted的逐事件隐藏恢复门、历史残差门和三秒预测门；同时给出fitted−mismatch、known−mismatch的逐事件及角色平均MSE差，涵盖全部五个时长。完整配对才给完整角色平均；零基准不算相对改善。用同口径有符号差和数值精度解释方向，不设置5%或其他任意改善比例。八秒变化、隐藏偏差和三秒主目标可以不同向，应按各自意义报告。

`test`只报告冻结模型结果，不选择参数、阈值、模型、后续修正或扩展范围。技术失败、优化未收敛、曲线矛盾、隐藏未恢复、预测目标未达到分别保留。结果进入`REVIEW_SCALAR_CALIBRATION`；真值或实现数值门失败须先作对应技术审核。基线决策保持`KEEP_BASELINE`，不自动晋升、部署、读取真实数据或开启下一轮。
