<a id="doc-dc5120c0b605-逐机记忆的能量约束历史求解"></a>

### 逐机记忆的能量约束历史求解

原始 T0M1 先求无约束的 Gauss–Newton 更新，再将新的历史起点隐态沿径向缩回能量球。原方法在 train 的 284/346 例、val 的 98/107 例触及半径。历史对不同记忆方向的灵敏度不同时，径向投影通常偏离带约束的最小二乘最优解。触顶比例给出检验该机制的依据。[半径对照](../task3_radius/README.md#doc-699c87b431dc)

真实阻尼校准使 train 的 1 s／3 s 目标下降 18.85%，同时 train 检出的真失稳从 24/35 降至 9/35，val 从 8/12 降至 1/12。下一轮在原 T0M1 第 12 步方程上单独检验初始化求解。沿用 100 ms 测量、半径 6.61055385191009、先验权重 $10^{-6}$、train 尺度和末点可见状态重置。[阻尼试验](../task3_damping/README.md#doc-3a3b55f16410)


<a id="doc-dc5120c0b605-绝对隐态的约束最小二乘"></a>

#### 绝对隐态的约束最小二乘

第 $k$ 次历史传播产生缩放后的灵敏度 $J_k$ 和观测残差 $r_k=y-h(z_k)$。200 个残差等权，保留原二次先验。求解

\[
\min_{\lVert z\rVert_2\le R}\frac12\lVert A_k z-b_k\rVert_2^2,
\qquad A_k=\begin{bmatrix}J_k\\ \sqrt{200\lambda}I/R\end{bmatrix},
\qquad b_k=\begin{bmatrix}r_k+J_k z_k\\0\end{bmatrix}.
\]

约束作用于新的绝对隐态。用薄 SVD 分解 $A_k=U\Sigma V^\top$。球内使用无约束解。球外做 64 次二分，求得唯一正乘子 $\mu$，令 $z(\mu)=V\operatorname{diag}(\sigma_i/(\sigma_i^2+\mu))U^\top b_k$ 满足球面条件。初始区间上端取略向外舍入的 $\lVert A_k^\top b_k\rVert/R$，保留可行上端。在归一化奇异值下对 $\log(\mu+\sigma_{\min}^2)$ 二分，保持极小正乘子的分辨率。相对球面残差与归一化 KKT 残差上限为 $10^{-10}$，驻点残差使用原矩阵和右端计算。求解保留增广矩阵满列秩及条件数不超过 $10^8$ 的要求，另报只含观测的奇异谱和数值秩。

使用 CUDA float64，保留五次外层更新。沿旧点与子问题解的可行线段检查实际历史目标，至多减半八次。仅接受目标不增加的点。一次批量试探的数值异常由评分隔离到逐例，单个事件试探积分失败时继续减半，全部试算被拒绝时保留当前点并记录。合成代数检查单独比较精确子问题和径向投影的目标，合成轨迹对照再比较完整历史算法与真值起报。逐例保存历史起点和预测起点的隐态误差与储能。


<a id="doc-dc5120c0b605-验证与进入条件"></a>

#### 验证与进入条件

1. 在各向异性系统验证球内解与原解一致至 $10^{-10}$，球面解通过 KKT 并优于径向投影。另测秩不足与条件数超限，显式记录未决。
2. 在合成完整 train、val、test 上分别检查可行真值、球外真值和错系数。球内匹配病例要求相对隐态误差和 8 s 归一化 RMSE 至多 $10^{-3}$，以真值起报预测为诊断对照。球外真值检验半径的可达性。沿用延迟失步的错误阻尼方程及其真值起报状态，检验动力学本身能否恢复失步。使用两档步长并报告全部轨迹和稳定性结果。
3. 通过合成门后单独注册完整 TASK3 对照。train 要求数值资格完整，TP 至少 24、FP 至多 2、未决至多 8，原 35 个真失稳的匹配窗口复现超过 6 例。val 要求 107/107 可判定、至少判对 104 例、零误报、六项误差至多 0.50、95 例稳定的 8 s 事件平均归一化 RMSE 至多为原对照的 1.05 倍。历史目标与未来结果分别验收。冻结候选后完成 346/107/76 全部评分，test 仅用于报告。

精确子问题和单调回溯已接入固定拓扑逐机模型的候选路径。CPU 检查覆盖球内解、球面驻点、径向投影对照、秩亏和条件数限制，CUDA 检查覆盖极小正乘子及双事件历史传播。正式合成执行需冻结病例、预算、协议和独立审查，再根据门槛决定真实 TASK3 的访问范围。

## 执行协议

<a id="doc-de23b26f09ce-固定拓扑逐机记忆的约束历史求解对照"></a>

### 固定拓扑逐机记忆的约束历史求解对照

比较径向裁剪与精确能量球求解。预测使用同一个已知固定拓扑方程、100 ms 的十一点可见历史、历史起点半径 1、预测起点可见末点重置和固定功率。全程零参数拟合。准则和推导见[研究方案](#doc-dc5120c0b605)。


<a id="doc-de23b26f09ce-冻结名单与对照"></a>

#### 冻结名单与对照

- 保留 12 个原合成病例的功角、转速、功率和角色，固定拓扑。各例用同一原始隐态方向生成两份真值，范数分别为 0.5、1.5。独立 NumPy RK4 用 1.25 ms 和 0.625 ms 生成 8.1 s 状态。
- 加入已归档的 24 个延迟失步对照，沿用原名单、角色和零起始记忆。合计 train 24、val 12、test 12。真值双步长重判，保留全部病例。历史尺度和未来尺度分别取全 train 的前 11 帧及起报后前 300 帧的均方根，分量下限为 $10^{-5}$。
- 四组对照各跑完整名单。第一组在起报时使用真值隐态。第二组用原径向裁剪和 $10^{-6}$ 先验。第三组用精确球约束和相同先验。第四组用精确球约束及零先验，用于检验干净历史的可恢复性。
- 延迟失步的 24 例另有一组对照。起报隐态和其余方程系数用真值，只将可见阻尼乘以已归档合成阻尼拟合的起始倍率 1.323437744597295。对照记录真实首次触发窗内的预测失步余量和完整 8 s 分类，检验错误阻尼在真值起报时的影响。


<a id="doc-de23b26f09ce-评分与判定"></a>

#### 评分与判定

两档 CUDA float64 RK4 步长上限为 2.5 ms、1.25 ms。两档独立 NumPy 真值均保存，可见状态的最大归一化差须至多 $10^{-6}$。保存每组 train、val、test 的轨迹与稳定性、匹配窗口余量、历史起点与预测起点的隐态误差和能量。精确组记录历史目标、接受步长、KKT 残差及各估计迭代点的纯观测矩阵奇异谱。

验收门使用 train 与 val。真值和四组完整名单通过现有双步长数值资格。真值起报对照须与独立真值分类一致，8 s 归一化 RMSE 至多 $10^{-5}$。精确组的共同先验历史目标在每次接受更新后不增加，观测矩阵数值秩为 10。零先验下，可行病例的稳定性与真值匹配，8 s 归一化 RMSE 至多 $10^{-3}$。球内非零真值病例的历史起点和预测起点隐态误差，以真值历史起点范数 0.5 归一后均至多 $10^{-3}$。同先验精确组的可行病例须保持上述可见未来门槛。球外病例检验可达性，精确组应触及半径，最终含先验历史目标相对径向裁剪逐例差值至多 $10^{-10}$，且至少一例降低 $10^{-10}$。test 仅报告。


<a id="doc-de23b26f09ce-单次预算"></a>

#### 单次预算

一次执行，解码一个冻结合成真值 NPZ，真实数据读取和拟合次数为零。四个 48 例条件和一个 24 例条件使用双步长。每个步长允许一次全名单批次及数值失败时每个事件一次隔离。原历史算法每次最多五个切线历史、一次历史重算、一次未来积分。精确算法再允许每次更新最多九次历史试探。

| 操作 | 上限 |
|---|---:|
| NumPy 动力学右端 | 77760 |
| 传播调用 | 11026 |
| Torch 动力学右端 | 11026560 |
| Torch 切线右端 | 352800 |
| QR 和三角求解，各自上限 | 960 |
| SVD | 4800 |
| 矩阵乘法 | 10560 |
| 球约束二分更新，按有效事件计 | 122880 |

本阶段结束后独立核对保存证据。通过合成门槛后，为完整 TASK3 冻结比较单独登记授权。部署判定为 KEEP_BASELINE。

### 固定拓扑下的能量球历史求解

本轮在固定已知拓扑方程上比较径向裁剪与精确能量球约束历史求解。精确求解在无先验、真值隐态位于半径球内的合成病例上恢复了已知隐态；完整科学门未通过，保留 `KEEP_BASELINE`。

<a id="doc-038fc6f10b21-历史求解结果"></a>

#### 历史求解结果

带原先验的精确球约束通过数值秩门，train 和 val 的历史目标逐次不增加。9 个球外真值病例中有 5 例最终落在半径边界。27 个可行真值病例中有 4 例超过 8 s 轨迹误差门槛。无先验精确求解通过干净真值恢复门。9 个球内非零真值病例中，历史起点隐态误差最大为 $2.17\times10^{-9}$，预测起点隐态误差最大为 $1.84\times10^{-9}$。

工程门通过。原先验候选的可见未来和边界改进门均未通过，范围停留在合成。零先验结果支持在已知方程、干净历史和球内真值范围内恢复隐态。

运行 `machine_local_topology_ball_history_v1-ball_history-20261115T094142724906Z-01f6e4da-6510defd`，耗时 43.47 秒；Python 3.12.14、Torch 2.13.0+cu130、CUDA 13.0、NVIDIA GeForce RTX 4060 Ti。执行证据见[证据回执](_sealed/machine_local_topology_ball_history_20261115_evidence.json)，设计与门槛见[协议](#doc-de23b26f09ce)及[研究方案](#doc-dc5120c0b605)。
