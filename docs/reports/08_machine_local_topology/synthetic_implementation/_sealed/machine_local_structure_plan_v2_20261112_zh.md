## 2. 固定模型与训练链

保留十个机器的可见状态。令 \(P=I-m\mathbf1^\top/(\mathbf1^\top m)\)、\(Q=P^\top\)，满足 \(m^\top q=m^\top v=0\)。基础方程为

\[
\dot q=v,\qquad
M\dot v=P\{u-\nabla U_0(q)-D_0v-Cz\},\qquad
\dot z=C^\top v-\operatorname{diag}(1/\tau)z.
\]

G2/G10 分别使用二维、十维隐藏状态与自由平衡端口 \(C=NW\)；L10 使用 \(C=P\operatorname{diag}(g)\)、每机一个基础状态。\(N\) 是固定零和力空间的正交基，\(g>0\)、\(0.02<\tau<5\) s。三个模型均为 \(J=0\)，只训练端口、衰减率与 encoder；质量、势能、阻尼和给定平衡角冻结。L10 的基础槽位不被删除；小端口只能报告作用缺乏支持，不能据槽位数认定十个已辨认机制。

encoder 输出历史起点状态，候选模型自由传播 100 ms，在预测起点只重置实测 \(q,v\)，保留隐藏末态，再自由预测。未来梯度贯穿全部链条。输入保持原有三个历史帧、恒定功率和静态平衡先验共 80 维；模型不接收真实未来、来源、标签或事件身份。

所有新模型统一使用

\[
\mathcal L=\mathcal L_{1s/3s}+10^{-4}\|E\|_F^2/160.
\]

分母对应固定 \(r_{\rm ref}=2\)，不随模型阶数或未来模块删除改变。历史损失为零；Adam、固定终点、积分时钟和实际训练参数的裁剪规则由协议冻结。原 trainer 不随本次研究被修改。

固定隐藏储能 \(\frac12z^\top z\) 与互易端口给出供能恒等式。非零固定输入可以增加储能；稳定域与无积分稳定判断仍需同输入平衡、移位储能、曲率、可检测性和区域证据，不由本次基础实现直接取得。

## 4. 后续结构发现采用的已采纳修订

函数阶段继续使用能量匹配的归一化谐波与非负耗散。弱式只生成条件线性的提案；候选进入训练后必须重新运行自己的完整因果链。五档稀疏路径和每类一个提案保持有限搜索，端口、时间尺度和 encoder 的联合辨识不宣称为凸问题。

共同支撑准备、删除和最终拟合使用同一允许参数集合。准备模型先做联合精化，然后按冻结块顺序进行一遍删除；每次三个 seed 的两侧均重拟合，以共同规则统一更新支撑。接受时采用删除侧，拒绝时采用保留侧；保留侧失败则停止该阶段。最后回到未经过删除搜索额外训练的共同锚点做六次最终配对，不再自动启动删除循环。这样才与 \(45+6K\le81\) 的完整真实研究预算相符；该预算尚不是当前阶段的执行额度。

后续系数求解器、曲率正裕量、置零及可行性复核须固定。首选成本明确的终点曲率拒绝：支撑和非负参数化保持，终点不满足参考集合曲率则拒绝该拟合；若改为逐步投影，单独登记投影与优化器状态处理。

5%、2%、1% 保持为待登记真实阶段的开发决策线。固定预测的线路重采样不能包含未重跑的模型拟合与结构搜索不确定性；最终外推结论依赖独立数据。不同统计对象的区间、物理 RMSE 与归一化 MSE 分开报告。
