# 逐机耦合与记忆隐变量 S0 合成协议

在独立 NumPy 已知真值系统上验证四个组合 T0M0、T1M0、T0M1、T1M1。共享刚度、阻尼、端口与衰减时间固定。四组各生成相同的 12 个激励，固定 train 6、val 3、test 3。T0 的节点修正为零，T1 使用各事件的零和节点修正。M0 删除整个记忆块，M1 使用十个逐机状态、不同衰减率和互易端口。用固定种子 20261115 生成独立的节点修正与记忆初态。两类隐状态共同存在时，另用缺少任一项及缺少两项的方程做对照。

采用[研究方案](../research/machine_local_topology_memory_plan_20261115_zh.md)的移位势能与 COI 投影。事件内 (a) 固定。用 11 帧 100 ms 历史及平衡机械功率，从零联合估计记忆初态 (z_h) 和普通零和基上的耦合坐标。按观测尺度构造残差，将 RK4 同阶段解析切线堆叠成 Jacobian。每次完整 Gauss–Newton 更新后，将两个块分别投影到半径 1 和 0.6 的欧氏球，共五次更新。QR 求解采用既有相对秩与条件数检查。用闭环历史传播获得预测起点记忆状态，可见起点取末帧观测。预测继续使用同一个耦合修正值和起点机械功率。真值隐态对照直接从真实起报状态积分。

真值以 1.25/0.625 ms 两档独立 RK4 生成。用 CUDA float64 以 2.5/1.25 ms 预测至 8 秒，覆盖全部名单并保存失败。批次求解失败时逐例隔离一次。使用各真值组 train 计算历史、未来尺度，下限 0.0001。用 TASK3 五点规则派生真值与预测稳定性标签，记录未决、覆盖、混淆计数及准确率。分列 1、2、3、5、8 秒轨迹误差。缺少隐块的对照和完整 test 用于报告。

## 工程门

- 四组检查真值历史起点瞬时能量恒等式，按绝对功率项之和归一且分母至少为 1，误差上限 (10^{-10})。
- 真值两步长全路径最大归一化差不超过 (10^{-6})，类别一致且触发帧相差不超过 2。预测数值资格要求两步长的可见状态最大归一化差不超过 (10^{-5})，COI 残差不超过 (10^{-10})，类别与触发帧满足同一规则。
- 各组 train、val 的已知隐态对照 8 秒合并状态归一化 RMSE 不超过 (10^{-6})。因果预测要求 8 秒不超过 (10^{-3})、历史不超过 (10^{-7})，同时有效边刚度最大相对误差、历史起点与预测起点的记忆向量误差均不超过 (10^{-3})。
- 各组 train、val 真值起点的加权历史 Jacobian，耦合列乘 0.6、记忆列乘 1，除以 (sqrt{200}) 后最小奇异值至少 (10^{-6})，条件数不超过 (10^8)。保存完整和分块奇异谱。静止 T1M0 和等衰减率 T0M1 分别要求可见历史 Jacobian 秩为 0 和 9。

本轮工程门核验已知共享系数下的可见历史和预测。共享参数学习、结构选择、受控噪声和字典外真值由后续协议验证。科学结论维持 KEEP_BASELINE。

## 执行与预算

一次不可变执行。零真实数据、零检查点读取、零拟合。解释器为约束文件中的 Python 3.12 及 CUDA 13.0 版 Torch。操作上限包括 311040 次 NumPy RHS，1123 次 Torch 传播、5692484 次 Torch RHS、157600 次切线 RHS、4 次能量自动求导。QR、三角求解及相关乘法各 1200 次，SVD 1288 次。预测上限含数值失败时的逐例隔离。执行前核对登记的计划、实现及独立复核文件哈希。
