### TASK3 固定逐机模型的 train 动量诊断

固定已归档的 T0M1 第 12 步方程、原始半径 6.61055385191009 和起报功率零阶保持。使用完整 train 346 的实测功角、转速与允许的起报功率。名单包含 311 例稳定、35 例失稳。文件绑定来自原 TASK3 源清单。通过读取器只解码 train 的 346 个坐标和起报功率，打开静态和开发缓存各一次。val 和 test 的分组元数据沿用冻结名单，本次轨迹读取范围为 train。

采用合成门已验证的弱形式。逐例使用 100 ms 历史、含历史起点且延伸至最多 3 s 的全部实际可用观测。35 个失稳事件另记录从历史起点至真实首个五点触发的匹配时段。保持固定标签与全部未决病例。每个区间沿实测功角、转速插值，积分可见动量以及线性逐机记忆。报告初始记忆子空间的秩与条件数，与之正交的残差、达到原半径的约束残差，以及半径约束的附加代价。代数隐态用于解释下界，不能进入预测。

刚度、阻尼和二次谐波方向各用全 train 残差形成同一标量修正，再在稳定、失稳、首触发时段与故障分组分别核对剩余残差。记忆惯性用合成中固定的五点剖面 $\{2/3,0.8,1,1.25,1.5\}$，可见力和静态记忆增益固定。仅将已验证的刚度、阻尼方向及离散时标视为可立即进入候选准备的对照。方向拟合若能使全 train SSE 至少下降 10%，且稳定和失稳组均改善、可见系数仍为正，则具备后续候选资格。刚度、阻尼还须改善首触发时段。二次谐波为结构筛查，需要独立合成验证。诊断结果不授权权重修改。

一次运行，零闭环预测、零部署拟合。两个冻结检查点载入，最多 2111 次 SVD、727 次球约束诊断、550610 个区间。只使用原始时钟和实际可用长度。运行保存逐事件证据、预算、精确读取角色，独立核验后归档。实际候选另行冻结并在 train、val、test 上完整评分。

### TASK3 train 逐机记忆动量诊断

固定 T0M1 第 12 步方程和记忆半径 6.61055385191009，对完整 TASK3 train 346 例开展沿实测路径的动量残差诊断，其中稳定 311 例、失稳 35 例。研究回执判定诊断门通过，部署基线保持 `KEEP_BASELINE`；唯一进入后续候选准备的修正方向是阻尼因子 `0.3436767364716119`。读取审计只打开 static 与 development 档案各一次；轨迹和起报功率仅解码完整 train 名单，没有读取 val/test 轨迹。


<a id="doc-e34f7a9a3e3d-秩正交残差与能量球"></a>

#### 秩、正交残差与能量球

每个病例分别使用 100 ms 历史和起报后最多 3 s 的全部可用实测段。逐例用 SVD 消去自由初始记忆，报告剩余正交残差。下表的正交 SSE 份额为各组正交 SSE 总和除以右端 SSE 总和。

| 观测范围 | 样本组 | 满秩 / 总数（维数 10） | 正交 SSE 份额 |
|---|---|---:|---:|
| 100 ms 历史 | 全部 | 346/346 | 5.91% |
|  | 稳定 | 311/311 | 7.90% |
|  | 失稳 | 35/35 | 1.90% |
| 起报后最多 3 s | 全部 | 346/346 | 33.95% |
|  | 稳定 | 311/311 | 72.77% |
|  | 失稳 | 35/35 | 20.19% |

原半径球约束诊断共完成 346/346 例，未决与数值失败均为零。约束触顶计数如下：

| 观测范围 | 全部 | 稳定 | 失稳 |
|---|---:|---:|---:|

| 起报后最多 3 s | 188/346 | 154/311 | 34/35 |

| 修正方向 | 标量变化 | 全部 train 残差变化 | 稳定组 | 失稳组 | 判定 |

| 阻尼 D | −0.656323（倍率 0.3436767365） | −32.30% | −18.90% | −49.42% | 两组均下降，唯一支持方向 |

<a id="doc-e34f7a9a3e3d-解释范围"></a>

#### 解释范围

这是沿实测功角、转速路径的动量方程诊断，区间内按线性路径积分，起报功率按零阶保持。全路径代数消去得到的初始记忆是自由诊断隐态，包含 100 ms 之后的观测信息；它只用于衡量现有方程可解释的残差下界，不能作为因果历史初始化或输入预测器。此次没有修改权重、执行闭环预测或读取 val/test 轨迹。后续若研究固定阻尼倍率，须另行冻结完整 train/val/test 预测评估合同。
