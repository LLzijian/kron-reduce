## 1. 共同起点与唯一模型差别

共同来源固定为 `results/paper_kiki_a06_refinement-joint_refinement-20261024T025925447927Z-9aa5ee65-524be996/checkpoint-240-324/model.npz`，SHA-256 为 `a7f094d52da465b0fe8214e7e74fe408594dbe06efe78e659163a469351623b8`。这是前一轮已登记的 A06 seed324 第240步骨架；本轮不以旧逐机模型的训练终点为初值，也不根据本轮 val/test 选择起点。

从该文件一次读取质量、正弦势能边刚度、阻尼及来源端口；按前一轮 `make_model` 的确定性公式构建一个未训练逐机模型。保留十台机器及十个隐藏状态，令

\[
P=I-m\mathbf1^T/\sum_i m_i,\quad
C=P\operatorname{diag}(g),\quad
g_i=\|C_{A06}\|_F/\|P\|_F,\quad
\tau=\operatorname{geomspace}(0.06,1.6,10)\;\mathrm{s}.
\]

幅度须有限且为正；encoder 为零并绕过。两组复制同一初始状态，质量、阻尼、边刚度锚点、g、τ、输入与尺度均相同，初始共享参数均为 `λ=0`。保存初始状态及共同锚点摘要，逐数组验证相等；不以 NPZ 容器字节差异判断模型不同。

| 方案 | 实际训练参数 | 有效边刚度 |
|---|---|---|
| R20 | 十个局部端口幅度 g、十个时间常数 τ | `k_anchor`；λ 固定为零 |
| R21 | 同样二十项及一个共享 λ | `k_anchor * exp(λ)` |

局部幅度沿用指数正值参数化；τ 沿用现有平滑参数化及 `0.02<τ<5` s。R21 固定 `λ∈[log(0.5),log(2)]`，即 `0.5≤γ=exp(λ)≤2`，范围沿用已审核共享刚度校准协议。每次 Adam 更新后，先检查全部参数和优化器状态有限，再在 `no_grad` 中将 λ 投影到闭区间；不改 Adam 动量。记录投影前值、投影后值和是否命中边界。g/τ 的原始参数不增加投影。有限性失败先按第3节回滚，不能用投影修复无穷值或 NaN。两组各自只对实际训练参数做合并梯度裁剪。

共享正比例保持锚点势能的函数形式和已有曲率符号；不据此宣称扩大稳定区域或已获稳定性证书。当前合成校准得到的 γ 不进入真实模型初值或目标。

## 2. 可微实现及执行前检查

有效刚度统一由一个 `effective_stiffness` 入口生成。R21 的 λ 必须保持为 Torch 参数，指数和乘法保留计算图。RHS、同阶段切线、势能及其梯度、线性专用路径（若调用）和冻结导出读取同一有效刚度；不能通过 NumPy 转换或替换 buffer 实现训练。默认旧模型的有效刚度仍为原刚度。

训练复用 `nonlinear_history.predict_from_history`：每次调用从零隐藏初态开始，以11帧、100 ms q/v历史执行三次完整 Gauss–Newton；同阶段投影 RK4 同时推进状态和切线，经薄 QR 与三角解更新隐藏初值。随后用最终隐藏初值重算全部历史，在预测起点重置实测 q/v，保留该模型传播所得隐藏末态，再自由预测。三次迭代、设计矩阵、QR、三角解、最终历史和未来均保留对 λ、g、τ 的梯度；只有数值秩判断的 SVD 脱离梯度。冻结预测接口内的 `torch.no_grad()` 不用于训练。

人工小系统工程检查必须覆盖：λ=0 时 R20/R21 相同；非单位 γ 时 RHS、切线、势能导数与导出一致；完整历史至未来损失对 λ 及 g/τ 的方向导数与中心差分一致；有效刚度冻结重载预测一致；旧模型默认行为兼容。继续复用已有完整名单损失权重、微批累积、失败回滚和冻结边界测试。人工检查不读取真实来源或旧结果数组，不开展新增合成模型搜索。

## 3. 同一目标、共同训练节奏与 val 选择

精确名单使用[固定来源限定 ID](../../configs/proposals/kiki_task3_split_reference_v1.json)，不重新划分、不删样。输入遵循 `measured_history_100ms_zoh_v1`：0–100 ms 十一帧 q/v、`Pm[10]−Pm_equilibrium` 恒定功率及静态平衡信息。Pe、电压、标签、事件时间、有效长度、来源、故障元数据和未来摘要不进入模型。真实可用长度只控制目标与评分。

两组共享一次由完整 train 估计的历史和目标尺度。历史尺度对各事件11帧逐通道平方值先取时间均值，再对346事件等权取均值并开方；目标尺度按同样算法使用预测起点后最多300个真实可用点。统一下限 `1e-5`，保存尺度、ID和每事件点数。目标尺度与 TASK3 比较尺度分别保留。

令事件 e 的未来可用点数为 `n_e=min(300,len(x_e)−11)`，`n_e≥1`；预测起点不计入目标。S 为上述目标尺度，输出间隔为0.01 s。唯一训练目标为

\[
J_h(\theta)=\frac1{346}\sum_{e\in train}\frac12
\sum_{H\in\{100,300\}}\frac1{20\min(H,n_e)}
\sum_{t=1}^{\min(H,n_e)}\left\|S^{-1}(\widehat y_{e,t,h}(\theta)-y_{e,t})\right\|_2^2.
\]

这里 y 是20通道质量 COI 相对状态，h 为 RK4 最大子步；训练固定 `h=0.005 s`。此量为1 s/3 s事件等权归一化 MSE，不是归一化 RMSE或物理 RMSE。两个时窗各用实际可用点归一；缺少合法目标使完整目标不可用，不向其他事件重分权重。不加正则、历史损失、隐藏能量损失或分类损失。

两组分别使用 fresh Adam：`lr=0.01`、`betas=(0.9,0.999)`、`eps=1e-8`、`weight_decay=0`、`amsgrad=False`、`foreach=False`、`fused=False`、`maximize=False`。CPU float64、单线程、确定性。按来源限定 ID 排序，每次更新依次处理五批64例及末批26例；全部六批在同一参数上累积，每事件权重为1/346。六批全部成功后才对该组实际训练参数合并梯度裁剪至范数10，提交一次更新。两组各最多80次，共最多160次；各组优化器状态在检查之间连续保留，不重启 Adam。相同更新数不表示相同 FLOPs。

共同检查位置固定为第10、20、30、40、50、60、70、80次完整更新后，每次先让两个仍在训练的组到达该位置，再分别检查；不检查第0步。每组每次用全部107个 val 事件，按固定 ID 顺序分为64和43例两批，在 `torch.no_grad()` 中以5 ms步长重算三次 GN 及最多3秒预测。目标与训练相同，只将事件均值的分母改为107，尺度始终采用 train 固定尺度，真实目标点数仍逐事件截取。不对 val 反传，不用分类或 TASK3 评分选择参数。每次检查保存逐事件目标、完整均值、点数、参数及有效性。

两组各自选择所有已检查、完整107例均有限且满足历史数值规则的候选中，val 归一化 MSE 严格最小的一次；分数完全相等时取最早一次。一次检查的任一批数值失败时，仍完成另一批以记录覆盖，该次完整目标为 `null`，不参与选择，不用可用事件均值代替，不追加隔离或重试。两组最终选中步数可以不同；共同训练节奏使其获得相同的正常检查机会，报告同时列实际训练步数与选中步数。

共同提前停止采用独立于严格选优的耐心计数。每组第一次完整有效检查建立参照 A；以后仅当 `J_val < A−1e−4*max(abs(A),1e−12)` 时记为有意义改善，并将该组 A 更新为当前值。小于此阈值的多次小幅变化可累积至后来相对 A 达到阈值；它们仍按上段严格最小规则参与选优。某次共同检查中，只要任一活跃组首次建立参照、发生有意义改善，或任一活跃组的完整 val 目标无效，共同耐心计数归零；否则加一。连续三次共同检查均无有意义改善时同时停止，最早为第40步；未触发则到第80步停止。该阈值只控制训练长度，不是模型性能、晋升或科学通过门，不将触发停止称为已证明收敛。

每步 train 曲线用于核对学习过程、变化趋势和数值失败；val 曲线承担上述训练长度与参数选择。不得观察曲线后临时改变学习率、耐心、上限、检查间隔或追加训练。日志每行标明 train loss 属于更新前参数，并记录梯度范数；R21另记λ投影前后值与是否发生投影。每个 val 检查点保存该次更新后的完整模型参数。优化过程记录由固定 Adam 配置、逐步训练日志、检查点参数、共同耐心状态和最终选择记录组成；本轮不保存 Adam 动量张量，也不开放续训。

任一训练批、梯度、参数、优化器状态发生非有限值、历史秩不足、条件数超限或求解数值失败时，停止该组拟合，丢弃本次未完成更新并回滚到上一个完整更新状态。该组若已有合法 val 候选则最终仍选此前严格最佳者；若一个也没有，则使用失败前最新完整更新状态，明确标记“无合法 val 候选，使用最后完整更新”，首步失败时该状态为初始参数。到80步仍没有合法 val 候选也按同一替代规则处理，不把替代参数称为 val 最优。

训练失败组不再更新或重复监测，在随后共同停止判断中记“已停止，无新增改善”，不填补本次 val 分数；历史分数只标作历史。另一组沿原10步时间轴继续，并按共同耐心或80步上限停止。任一活跃组无效检查仍将共同计数归零；两组都已停止则立即结束。报告保留失败参数、失败原因、失去等量训练机会的事实及各自实际/选中步数，不取消另一组或完整正式评价，不改步长、批大小、学习率或重试。正常历史求解要求秩10、条件数不超过 `1e8`、全路径有限且状态幅度不超过 `1e12`。权限、来源身份或预算失败属于执行边界错误，停止相关科学调用并保留证据。

## 4. 双方共同冻结及分阶段读取

fit 阶段先读取 train、构建共同初值并计算共享尺度，将两组初始模型、来源合同、完整名单、固定选择规则及尺度封存为初始监测清单；校验双方初始模型和尺度后，才允许读取 val 用于本协议明确授权的监测与选择。该初始清单的训练和选择仍未关闭，不是最终冻结，不得授权 test。

双方训练及 val 选择结束后，保存双方选中参数、各自实际与选中更新数、优化过程记录、共同初值、共同尺度、输入与评分合同、名单和代码哈希，再关闭训练与选择。最终共同冻结清单必须绑定双方选中 checkpoint 及同一 preprocessing 文件。最终验证两组实际冻结物与共同尺度，不能只核对其中一方。

一个来源 reader 读取 train 一次、val 一次，供两组训练、选择及最终正式评价复用。val 监测每次覆盖完整107例；双方最终冻结后，首次正式八秒双步长评价均覆盖完整 train346、val107。test 采用另行登记的零拟合、零更新阶段，绑定最终共同冻结清单及全部相关源码并确认训练与选择已关闭后，读取76事件一次，供双方完整评价。两组全部 train/val/test 均须交付；RMSE、分类、提前停止或晋升门不决定是否继续其他角色或另一组。

真实数据来源及精确成员沿用已封存 TASK3 缓存，来源计划与新登记范围绑定 SHA。fit 允许 static 的 `mass,delta_star,pm_star,omega_s` 四个成员一次解码；development 文件按 train/val 各读取一次，分别解码346/107事件的 x、p0，共906成员。test 阶段 static 四成员一次，76个 test 文件各读取一次、各解码 x/p0，共152事件成员。禁止原 provider 回退、临时换源或重新读取同一角色。fit 读取一次 A06 checkpoint。双方冻结导出将有效刚度折入固定边刚度，保存含模型与历史初始化合同的独立 checkpoint；test 使用 `weights_only=True` 各读取一次这两个冻结物，无须再次读取 A06。共同清单的 checkpoint 字段可指向双方 checkpoint 路径及哈希的 JSON 索引；入口仍须在 reader 开放 val/test 前逐一核验两个实际文件及共同尺度。字节身份核查不等于数组解码，来源账本分别记录。

test 是已有历史暴露的固定比较基准，只用于报告，不用于参数、阈值、更新数、后续方案或晋升条件选择。val 本轮用于上述预先固定的训练长度及参数选择，其正式评价明确属于选择所用名单。默认基线保持 `KEEP_BASELINE`；独立确认、晋升和下一轮修改另行登记与审核。

## 5. 完整预测、指标和配对解释

每组从100 ms预测起点推进未来8秒，保存含起点的801帧；分别使用2.5/1.25 ms最大子步，每档重新完成三次 GN。每个角色按固定名单顺序每批最多16例，train/val/test 正常批次数为22/7/5。批次某档抛数值异常时，仅对该批每个事件按相同档位逐事件隔离一次，保留原失败，仍执行另一档。正常返回但指标或数值门未通过不触发追加调用；逐事件失败不递归重试。

轨迹主表调用绑定的 TASK3 评分，使用1/2/5/8 s完整时窗；失稳样本按真实可用时段另列。各时窗报告事件数、实际点数、事件平均、pooled、CVaR10、最差归一化 RMSE和带单位的 q/v RMSE。固定比较尺度为 `0.47675314588683515 rad`、`1.0033667249602924 rad/s`。共同频率输出为零偏差，其误差单独保留；不将该通道称为已学习结果。

最终选中模型的1 s/3 s训练口径目标从上述完整预测数组算术计算，采用共同 train 目标尺度及相对状态真实目标，分别标明 `J_2.5ms` 和 `J_1.25ms`。train/val/test 均给出按其完整名单等权计算的同口径值及逐事件值；val/test 的尺度仍固定于 train。它们使用训练的时窗、尺度和权重定义，积分步长不同，因此不能标作5 ms训练损失。第k条 train 日志是第k次更新前的 `J_5ms`，不称为第k步后模型的终点目标；第k步后的已存 val 检查才对应该候选的5 ms val 目标。本轮不为补充其他终点5 ms值追加模型调用。

预测稳定性使用 TASK3 固定八秒窗口及标签规则：历史与未来去除重复起点后拼接，未包裹角范围大于π、最大质量 COI 相对速度大于0.02 pu连续五点为失步；没有失步且最后一秒角范围小于π、速度小于0.005 pu才记窗口内安定，其余未决。真实标签保持 TASK3 原标签。沿用已绑定 TASK3 的两档数值资格规则：相对状态与共同频率 RMS 精化差各不超过0.001，使用该指标对应时窗；分类使用八秒，两档均失步则检查至较晚触发点。两档失步时间差不超过0.02 s，并要求失步、安定、未决三类相同。

各组各 split 报告分配数、数值失败、未覆盖、未决、可判定数、覆盖率、TP/TN/FP/FN、完整及可判定准确率、失稳召回、漏判率与稳定误报率。存在任一未决、未覆盖或数值失败时完整准确率为 `null`；可判定指标明确其分母，零分母为 `null`。缺失或无效指标保留 `null` 和失败原因，不补零。

所有配对差固定为 R21−R20：按来源限定 ID 对齐逐事件误差，分别报告每个 split、时窗与指标。只有双方全名单均具备有效量时才给完整名单平均配对差；否则完整量为 `null`，另给有明确覆盖数的完整配对事件平均，保留两边失败名单。不以一组失败事件过滤另一组主表。相对变化在 R20 分母为零时为 `null`。终点 MSE 同时给出两档配对差，及两组各自步长变化；差值与步长变化同量级时，只陈述所观察方向，不宣称已分辨出稳定改善。全名单轨迹、稳定性和边界命中分别判断，不以单一分类准确率代替动力学结论。

每组保存三次 GN 的历史残差、隐藏初值及更新范数、秩、最小奇异值和条件数，以及最终重算历史残差与两处隐藏储能。真实隐藏状态不可观测，这些量用于初始化诊断，不称为真实隐藏状态恢复。R21另报最终λ、γ、有效刚度及边界命中；R20报告γ=1。
