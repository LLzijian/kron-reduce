# R20/R21 共同起点配对准备

2026-11-14。状态：PREPARATION_ONLY，不登记真实数据读取或训练额度。

单一共享刚度合成验证完成：在其他动力学已知的条件下，train校准恢复了刚度、隐藏状态及完整轨迹；三组稳定性分类均已达到100%，本轮不构成分类精度提升证据。见[结果审核](machine_local_stiffness_calibration_result_review_20261114.json)。下一步准备检验：在相同真实模型起点和训练预算下，增加一个共享刚度系数是否改善轨迹。

| 方案 | 训练参数 | 有效边刚度 |
|---|---|---|
| R20 | 十个局部端口幅值g、十个时间常数τ | 固定共同起点刚度 |
| R21 | 相同20项，加一个共享λ | `k_anchor*exp(λ)` |

新协议在读取前绑定一个共同源模型文件及SHA。两组从同一份有效状态复制，质量、刚度、阻尼、g、τ、输入合同和初始化算法完全一致，R21初始λ=0；当前合成校准的γ不进入真实模型初值。不能把一组已有训练终点与另一组新增40步的结果当作等量训练比较。准确锚点选择由新协议冻结，不由test结果选择。

两组使用fresh Adam，学习率0.01、betas=(0.9,0.999)、eps=1e-8、weight_decay=0，各40次完整更新，合并梯度范数上限10，CPU float64、单线程。按同一来源限定ID顺序，每批最多64例累计全部train346，每事件权重均为1/346后才更新一次。两组共用只由train计算的历史和目标尺度。目标保留已审核真实协议的1s/3s事件等权归一化MSE及真实可用点数；当前合成三秒单目标不改变这一定义。各组只裁剪其实际训练参数，相同更新数不等于相同FLOPs。

R21需要新的可微刚度实现。λ必须保留为Torch参数，有效刚度由Torch指数生成，RHS、同阶段切线、势能表达和冻结导出共用同一有效值。当前无梯度实验的buffer替换方式不能用于训练。一个保持旧模型默认行为的`effective_stiffness`入口即可统一数值来源；λ的允许范围和出界处置在准确协议中另行冻结。

训练调用保留计算图的`nonlinear_history.predict_from_history`核心：从零隐藏初态开始，三次状态/切线RK4、QR与三角解，最终历史重算，实测q/v重置，隐藏末态连续，再预测未来。未来损失对λ、g、τ的梯度贯穿完整过程，包括λ对GN设计矩阵及隐藏初值的影响。只有数值秩判断的SVD脱离梯度。`FrozenMachineLocalForecaster.predict_batch`含`torch.no_grad()`，用于冻结评价，不作为训练入口。

人工小例工程检查覆盖共同λ=0起点一致性、非单位γ下RHS/切线/势能/导出一致性、完整因果链的λ和g/τ方向梯度与中心差分、冻结重载预测一致性及旧模型兼容性。新的科学检查、来源读取和保存证据审核均在新范围中登记，不复用本轮已消费额度。

两组完成40步或按相同数值失败规则冻结上一个完整更新状态后，统一关闭训练与选择。共同冻结清单记录参数、实际更新数、优化器记录、尺度、输入与评分合同及哈希。此后两组各自使用同一冻结模型评价全部train346、val107、test76，首次评价直接覆盖完整来源限定名单；任何RMSE或晋升门未通过都不取消其他角色或另一组的评价。

预测从100ms起点开始，未来8秒，2.5/1.25ms双步长，每角色按固定顺序最多16例一批，各档重新完成三次GN。数值失败批只在预登记预算内按相同步长逐事件隔离一次。test阶段同时绑定双方冻结清单，拟合次数为0；双方都给出完整test结果，不只评价val较好的一组。test继续作为已有历史暴露的固定比较基准，只报告，不调整参数、阈值、更新数、后续方案或晋升条件。

轨迹主表复用TASK3固定1/2/5/8秒、失稳样本实际可用时段和共同频率约定，报告事件平均、pooled、CVaR10、最差归一化RMSE及物理RMSE。另列训练口径1s/3s终点目标；所有比较明确尺度、时长、覆盖分母及数值资格。稳定性保留TASK3真实标签，预测使用固定八秒规则，各split报告TP/TN/FP/FN、完整与可判定准确率、失稳召回、漏判、稳定误报及未决/未覆盖/数值失败。存在未决、未覆盖或数值失败时完整准确率为null，零分母为null。

真实数据的GN残差、隐藏储能、更新范数、秩和条件数作为初始化诊断，不称为真实隐藏状态恢复。R21另报γ、有效刚度及边界状态。双方完整配对差和失败名单始终交付；基线决策保持KEEP_BASELINE，晋升另审。

准确执行计划须覆盖两次拟合、最多80次更新、所有批反传、RHS/切线/分解、来源访问、冻结与完整评价的调用预算。后续顺序为可微实现及共同起点审核、新登记的配对训练与完整评价、结果审核。谐波阳性/阴性合成对照另立阶段：分别使用真值含指定谐波与不含该项的人群，检查结构恢复及避免无依据结构；先验证平衡移位、势能导数、Hessian和声明区域内曲率，再评价识别和预测。两类对照不混入R20/R21，本轮通过不自动开启谐波搜索。
