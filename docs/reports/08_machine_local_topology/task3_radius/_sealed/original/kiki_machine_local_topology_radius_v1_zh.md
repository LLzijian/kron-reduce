# TASK3 冻结逐机记忆半径对照

比较 T0M1 第 12 步同一份权重下的两个历史起点记忆上限。原模型使用半径 (R_z) 和先验权重 (10^{-6})。候选 R2 使用 (2R_z) 和 (4\times10^{-6})。T0M1 的增广历史方程只有记忆先验，(\lambda/R_z^2) 相同，因此只改变每次 Gauss–Newton 的投影半径。两组共用历史尺度、训练评分尺度和相同物理系数。五次历史迭代、100 ms 输入、起报重置、机械功率零阶保持和评分程序沿用前一轮。冻结清单在读缓存前固定原权重、原预处理和候选的确定性倍数。[原模型报告](../reports/kiki_machine_local_topology_20261115_zh.md)

原半径对照绑定已经完成并复算的 346 个 train、107 个 val、76 个 test 评分。候选一次评价相同三个完整名单。train、val 依次消费同一开发读取器，test 使用独立读取器。原始轨迹每例读取一次。两个读取器各打开静态缓存一次，train 和 val 各打开开发缓存一次，test 打开 76 个已登记缓存，总计 80 次源缓存打开。只读取原模型保存的评分 JSON。运行零拟合、零更新、零重新选点。

两种步长分别为 2.5 和 1.25 ms，GPU float64，每批至多 32 例。一次批次数值失败后逐例隔离一次。预算包含最多 7658 次积分传播、22580160 次方程求值、1312800 次切线方程求值、10580 次同类事件级 QR/SVD/三角求解和对应乘法，以及两次检查点读取。正式运行由新建的单阶段工作流管理，仅执行一次。

开发验收在完整 val 上同时要求六项轨迹分数至多 0.50、稳定误报为零、未决至多 1 例、107 减 TP 和 TN 至多为 3，以及真实稳定样本的 8 秒事件平均归一化 RMSE 至多为对照的 1.05 倍。两个半径在 test 读取前已冻结，开发验收结果不改变 test 评价范围。完整 test 需判定 76/76 且至少判对 69 例才达到准确率目标。两组报告所有划分的稳定性计数、覆盖、轨迹指标和历史起点的记忆触顶率。部署决定为 `KEEP_BASELINE`。
