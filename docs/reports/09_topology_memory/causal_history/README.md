## 执行协议

<a id="doc-3a741c25d3df"></a>

<a id="doc-3a741c25d3df-固定已知参数下的因果历史先验对照"></a>

### 固定已知参数下的因果历史先验对照

本对照只检验历史估计中的先验权重是否影响拓扑—记忆状态的恢复。模型方程、参数、合成真值、历史输入、求解次数和评分流程全部固定；唯一比较项为原先验 `prior_weight=1e-6` 与 `prior_weight=0`。本结果属于既定合成真值队列上的对照，不构成独立数据确认。


<a id="doc-3a741c25d3df-执行前置条件与范围"></a>

#### 执行前置条件与范围

仅在主 S0–S4、40 候选运行完成并有已消耗的运行回执后执行本对照。沿用原冻结合成真值及其 S0–S3 参数，不重新生成样本、不重新选择结构。S4 不纳入本对照。

对 S0、S1、S2、S3 分别评估两个先验权重。每种系统都使用完整 train 24、val 12、test 12 名单。每个先验、每个划分、每种积分步长及每种历史条件均独立完成完整队列评分。test 只作冻结后的报告，不参与先验比较或通过判定。该对照不读取真实数据，部署决策固定为 `KEEP_BASELINE`。

主运行 S0 使用已知模型系数，参数更新数为 0。按原历史尺度和初态半径归一后，val 数据灵敏度矩阵的最小奇异值约为 \(1.714\times10^{-4}\)，最大奇异值约为 0.0127，先验增广项的对角元素为 0.014142。S0 在完整 val 的历史起始隐藏状态相对误差为 57.0%–66.2%。这组数量用于定义待检验的先验收缩机制。验收继续使用主运行的误差阈值。


<a id="doc-3a741c25d3df-因果历史估计"></a>

#### 因果历史估计

沿用原始 100 ms 历史和冻结模型已知参数。每个事件执行五次 Gauss–Newton 历史估计，记忆半径固定为 1，拓扑状态半径固定为 0.6。历史因果链只使用对应 100 ms 输入；起报后的真值不进入隐状态估计。除先验权重外，两个条件的初值、事件次序、求解规则及数值设置保持一致。

分别对干净历史和同一组已冻结轻度历史噪声重复估计。两种先验、全部样本和两档积分步长共用完全相同的噪声实现，保证成对比较。噪声的原冻结取值和种子随主运行产物读取，不在本对照中调整。


<a id="doc-3a741c25d3df-评分与记录"></a>

#### 评分与记录

每个估计结果从起报点自由预测 8 s，分别采用 2.5 ms 与 1.25 ms 积分步长。S0–S3 的 train、val、test 均完整评分。train 与 val 在两个先验、两种历史条件和两档步长下都必须达到完整数值覆盖；缺失、非有限和失败结果保留为失败，不以零或其他替代值补齐。test 同样记录覆盖及数值状态，但仅作报告。

每例保存历史损失、历史起始与起报点的记忆及拓扑状态估计、对应真值、归一化隐藏状态误差，以及两先验之间的成对差值。另保存按系统和划分汇总的状态误差、预测分数、覆盖和失败计数。条件数使用去掉先验行的历史灵敏度矩阵。真值参数与真实起报状态对照引用主运行的冻结结果。


<a id="doc-3a741c25d3df-通过判定"></a>

#### 通过判定

科学通过须同时满足：

- `prior_weight=0` 在 val 干净历史下的历史起始与起报点归一化隐藏状态误差最大值均不超过 0.2；
- 相对 `prior_weight=1e-6`，`prior_weight=0` 改善最大起始状态误差；
- 两种先验在原冻结标准下均通过 val 干净和带噪预测门；
- S0–S3 的 train 与 val 在两个先验、两种历史条件、两档积分步长下均有完整数值覆盖。

预测门沿用主运行的冻结定义和阈值。按原模型参数、噪声、样本名单和判定门报告未通过项及覆盖。


<a id="doc-3a741c25d3df-预算与产物"></a>

#### 预算与产物

本对照固定共享模型参数，拟合更新数为 0；只执行已规定的历史初值求解及冻结预测。NPZ 源文件读取额度为 4 次，合成真值读取范围限于 S0–S3 冻结产物。执行回执记录实际读取次数、五次历史求解、两先验配对关系、两种噪声条件、双步长完整评分、数据条件诊断和逐例结果。

保留每例隐藏状态估计与历史损失、train/val/test 评分、成对误差差值、数值覆盖、失败记录和独立复核所需的哈希。test 结果仅报告；不得据此选择先验、调整阈值或宣称独立确认。

## 报告与结果

<a id="doc-c9e56591a378"></a>

<a id="doc-c9e56591a378-固定真值下的-100-ms-隐状态恢复"></a>

### 固定真值下的 100 ms 隐状态恢复

固定方程和真值参数后，去掉历史求解中的零中心先验，使 S0–S3 在干净历史下均恢复出隐状态。完整 val 的最差误差从 66.2%–80.0% 降至 0.00055%–0.578%（历史起始），起报时最差误差均低于 0.676%。固定轻噪声下，去掉先验使四组 val 的最差隐状态误差和事件平均轨迹误差均变大。两种先验的可见预测都通过本次阈值。


<a id="doc-c9e56591a378-干净历史"></a>

#### 干净历史

每个系统各用同一冻结真值的 train 24、val 12、test 12 个事件，零参数更新。两个条件共用 11 个历史观测、五次 Gauss–Newton 更新、记忆半径 1 和拓扑半径 0.6，分别使用 `prior_weight=1e-6` 和 `0`。下表的隐状态误差为 \(\lVert\hat x-x\rVert_2/\max(\lVert x\rVert_2,0.1)\) 的 val 最大值，\(x\) 仅包含当前模型的隐状态。轨迹使用 2.5 ms 积分所得的 8 秒逐事件归一化 RMSE 等权均值。箭头从原先验指向零权重。

| 已知真值系统 | val 历史起始隐状态误差 | val 起报隐状态误差 | val 8 秒轨迹 | test 8 秒轨迹 |
| --- | ---: | ---: | ---: | ---: |
| S0，固定耦合与常端口 | 0.6624 → 6.55e−6 | 0.6607 → 1.13e−6 | 2.207e−3 → 5.003e−9 | 2.047e−3 → 5.031e−9 |
| S1，共同尺度与空间重分配 | 0.7496 → 5.78e−3 | 0.7059 → 6.75e−3 | 2.396e−3 → 2.191e−7 | 2.219e−3 → 2.157e−4 |
| S2，饱和记忆 | 0.7312 → 5.48e−6 | 0.6634 → 1.80e−6 | 4.879e−4 → 1.038e−10 | 4.986e−4 → 1.616e−10 |
| S3，动态拓扑与饱和记忆 | 0.8005 → 1.19e−4 | 0.7084 → 1.40e−4 | 7.678e−4 → 1.108e−8 | 8.074e−4 → 1.814e−8 |

固定系数、算子和输入的配对结果确认了先验对干净历史初态的收缩作用。主运行 S0 的数据灵敏度矩阵满秩，最小奇异值约为 \(1.714\times10^{-4}\)，先验增广对角为 0.014142。该局部线性化中最弱方向的数据增益约为 \(1.47\times10^{-4}\)。四个系统的恢复结论限于给定方程、已知系数与本次激励。


<a id="doc-c9e56591a378-固定轻噪声历史"></a>

#### 固定轻噪声历史

两个先验收到同一历史噪声，标准差为原 train 历史尺度的 \(10^{-3}\)，噪声按 COI 约束投影。8 秒预测与干净真值比较，评分口径同上。

| 已知真值系统 | val 历史起始隐状态误差最大值 | val 8 秒轨迹 | test 8 秒轨迹 |
| --- | ---: | ---: | ---: |
| S0 | 1.681 → 3.067 | 0.005331 → 0.005750 | 0.004710 → 0.007415 |
| S1 | 1.654 → 3.433 | 0.005195 → 0.009579 | 0.004803 → 0.010288 |
| S2 | 1.628 → 2.946 | 0.001516 → 0.001850 | 0.001460 → 0.001496 |
| S3 | 1.734 → 3.612 | 0.001714 → 0.005741 | 0.001767 → 0.005507 |

带噪且无先验时，四组 val 各有 12/12 例的历史起始记忆状态触及半径 1，S1 和 S3 的拓扑状态也各有 12/12 例触及半径 0.6。触及按距半径不超过 \(10^{-8}\) 判定。上表采用事件平均 RMSE。S0 带噪 val 的合并归一化 RMSE 从 0.00654 降至 0.00629，两种聚合量反映了不同的逐例误差分布。

四个系统、两种先验和两种历史条件的合成 train 均为 24/24 判对，val 与 test 均为 12/12 判对，覆盖率均为 100%。每个 val 和 test 划分均为 TP=6、TN=6、FP=0、FN=0，失稳召回为 100%，漏判率和误报率均为 0。val 与 test 的已命中失步时刻在 10 ms 评分网格上均与真值一致。两档步长、历史残差、逐机记忆与拓扑初态、成对误差与触发时间均保存在不可变运行结果中。

本对照通过工程和科学验收，结论适用于固定真值参数。去掉先验可作为干净合成机制对照。含噪轨迹和隐状态结果支持保留对弱灵敏度方向的约束。原 S0–S4 结构学习辨识仍缺少空间重分配恢复和 S4 库外失配拒绝证据，真实 TASK3 训练、联合精化和独立数据确认待这些条件满足。[执行协议](#doc-3a741c25d3df) · [运行回执](_sealed/topology_memory_rom_causal_20261116_evidence.json) · [主对照结果](../synthetic_rom/README.md#doc-00055d87ebb1)
