<a id="doc-0c59733d9557-耦合强度变化的合成对照"></a>

### 耦合强度变化的合成对照

本对照在已知方程和参数的合成系统上检验能否区分两种情况。耦合强度可以整体同步变化，也可以在各支路上分别变化。后者的对数倍率之和为零，因此倍率的几何平均保持不变。


<a id="doc-0c59733d9557-真值与候选"></a>

#### 真值与候选

五种干净合成真值覆盖固定耦合、仅整体变化、仅各支路分别变化、两种变化并存，以及固定耦合下含第五谐波的系统。第五谐波真值系数为 0.02，在四种候选中均缺省。四个候选分别采用固定耦合、仅整体变化、仅各支路分别变化和两种变化并存。整体变化的迁移率固定为 0.25，各支路分别变化的迁移率固定为 0.4。记忆保持常端口。本轮拟合次数为零。

每种真值各含完整 train 24、val 12、test 12，沿用原低／高激励分组构造，随机种子固定为 20261117。test 只用于冻结后的报告。

两种机制的初始支路对数倍率具有相同的均方根 0.08。整体状态取
\[
c=\pm\frac{L}{2}\operatorname{atanh}(0.08/L),\qquad L=\log(2)/2,
\]
符号按激励组交替。九维支路状态方向取自冻结种子；其范数由有界映射精确求解，使各支路对数倍率 RMS 与整体状态相同，约为 0.263。0.263 仅为说明值，执行时使用精确解。初始功角在三个机器上设置非均匀模式并叠加原随机扰动，再作 COI 中心化，功角范围限定在 0.45–0.65 rad。


<a id="doc-0c59733d9557-因果初值与诊断"></a>

#### 因果初值与诊断

参数与真值轨迹保持冻结，历史初值估计使用首 100 ms 因果输入、五次 Gauss–Newton、先验权重 0、记忆半径 1 和拓扑半径 0.6。沿用原低、高激励分组和构造规则。所有角色使用同一历史窗口和初值规则，不把起报后的信息用于历史估计。

短时诊断使用起报后首 200 ms 的逐机动量增量。每台机器的尺度取完整 train 真值动量增量的均方根，最小设为 \(10^{-4}\)。每个事件对 20 个时点和十台机器的归一化增量误差取均方根。候选必须在两档步长下使完整 val 的最大归一化 RMSE 不超过 \(10^{-4}\)，同时通过原 3 秒、8 秒轨迹与失步时序门。真值两档积分的最大归一化动量差须小于等于 \(10^{-5}\)。

另在 val 从真值起报状态运行每个候选 200 ms，省略被删除的坐标，缺少对应真值的新增坐标取零。该对照用来区分因果初值误差和方程误差。正确结构在该对照中也须通过短时误差门。两档积分分别核对历史起点和起报点的记忆、整体耦合及各支路耦合隐状态。相对误差以该组隐状态真值的范数归一化，记忆及各支路耦合的分母下限为 0.1，整体耦合为 0.01。每组隐状态的 val 最大相对误差须不超过 0.2。


<a id="doc-0c59733d9557-冻结评分与判定范围"></a>

#### 冻结评分与判定范围

所有五种真值、四种候选和三个划分分别完成 8 s 闭环轨迹及稳定性评分，使用两档 GPU 积分步长 2.5 ms、1.25 ms。完整 train、val、test 名单均独立评分。test 结果只报告，不参与选择。保存短时归一化误差与尺度、隐态误差、8 s 轨迹与稳定性结果，以及双步长差异、覆盖和数值失败。

通过两个预测门的候选按启用项少者优先，同样多时取 val 最大短时误差小者。所有候选的 val 数值覆盖须完整，train 和 val 真值须同时包含稳定和失稳样本。前四种真值须选中匹配候选。第五谐波真值须满足至少一个候选通过原长时预测门，且四个候选的两档积分均超过新短时误差阈值。这个判定考察固定系数下的方程失配检出，旧 S0–S4 判定仍以原回执为准。参数拟合和 TASK3 训练属于后续独立执行范围。

## 报告与结果

<a id="doc-eae8ebc9bb21"></a>

<a id="doc-eae8ebc9bb21-耦合强度变化的辨识与初值估计"></a>

### 耦合强度变化的辨识与初值估计

改用与支路耦合强度直接相关的坐标估计初值后，合成 val 正确选出了固定耦合、仅整体变化、仅各支路分别变化和两者并存四种结构。两种变化并存时，200 ms 动量误差已达标，支路耦合隐状态的最大相对误差仍为 38.2%，超出 20% 的验收线。这一项使修正对照未通过完整科学验收。


<a id="doc-eae8ebc9bb21-初值求解和方程误差"></a>

#### 初值求解和方程误差

本轮把全部支路乘同一个倍率称为耦合强度整体变化，把不同支路使用不同倍率称为各支路耦合强度分别变化。两种变化在历史起点的对数倍率均方根均为 0.08。每种真值含 24 组配对激励，完整 train 24、val 12、test 12。首轮比较五种真值与四个候选。修正轮重算五种真值下含支路变化的两个候选，固定耦合和仅整体变化的候选引用首轮经过哈希核验的评分。两轮均采用干净的 100 ms 历史、已知方程系数和五次 Gauss–Newton 更新，拟合次数为零。

使用真实起报状态时，正确结构在仅支路变化、两种变化并存两组 val 的最大归一化动量误差分别为 \(1.84\times10^{-11}\) 和 \(2.44\times10^{-11}\)。表中比较两种因果初值方法。动量误差是起报后首 200 ms 的逐机动量增量归一化 RMSE，在 val 全部 12 例和两档积分步长中取最大值。隐状态误差也取两档步长、历史起点及起报点的 val 最大值。

| 合成真值 | 原方法动量误差 | 修正后动量误差 | 原方法支路耦合隐状态误差 | 修正后隐状态误差 |
| --- | ---: | ---: | ---: | ---: |
| 仅各支路耦合强度分别变化 | 4.15e−4 | 4.92e−5 | 22.9% | 0.905% |
| 整体和各支路均变化 | 4.02e−3 | 4.49e−5 | 232.5% | 38.2% |

修正方法按支路耦合对数倍率对应的坐标计算更新，再转换回原隐状态并施加联合半径约束。首轮在仅整体变化真值中，允许两种变化的对照有一例 val 的双步长轨迹差为 \(1.72\times10^{-5}\)，超出 \(10^{-5}\) 数值门。修正后同一例降至 \(1.19\times10^{-7}\)。

两种变化并存时，val 中支路隐状态误差最大的一例 `transfer-26`，100 ms 历史的归一化 RMSE 约为 \(2.01\times10^{-7}\)，历史起点的联合耦合隐状态范数约为 0.251，低于半径 0.6。该例的历史轨迹已拟合得很接近，支路隐状态仍有明显偏差。现有结果无法区分五次更新的收敛程度和该事件在 100 ms 内的可辨识程度。38.2% 是支路耦合隐状态的相对误差。


<a id="doc-eae8ebc9bb21-完整预测与稳定性"></a>

#### 完整预测与稳定性

下表给出修正轮中正确结构的 8 秒逐事件归一化 RMSE 等权均值，采用 2.5 ms 积分。第五谐波一行给出固定耦合作为参考的分数。

| 合成真值 | train 8 秒 | val 8 秒 | test 8 秒 | val 正确数 | test 正确数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 固定耦合 | 3.88e−9 | 4.44e−9 | 5.86e−9 | 12/12 | 12/12 |
| 仅整体变化 | 3.35e−9 | 4.40e−9 | 4.93e−9 | 12/12 | 12/12 |
| 仅各支路分别变化 | 8.11e−6 | 5.16e−6 | 9.82e−6 | 12/12 | 12/12 |
| 两种变化并存 | 2.82e−6 | 6.56e−6 | 2.96e−5 | 12/12 | 12/12 |
| 含第五谐波，固定耦合候选 | 8.24e−4 | 7.85e−4 | 8.37e−4 | 12/12 | 12/12 |

每行的 val 和 test 均各有 TP=6、TN=6、FP=0、FN=0，覆盖率及失稳召回率均为 100%，漏判率和误报率均为 0。已命中的失步时刻在 10 ms 评分网格上与真值一致。含第五谐波的真值中，至少一个候选通过了原长时预测门。四种候选在两档积分的 val 200 ms 误差均超出 \(10^{-4}\)，其中固定耦合候选约为 \(8.79\times10^{-4}\)。短时指标能在该合成案例中检出方程缺项。

两轮均通过工程检查，完整科学验收均未通过。两种变化并存时的隐状态恢复、含噪历史和未知系数的结构学习还有待验证，因此本轮真实 TASK3 训练和评估未启动。完整候选结果、逐例评分和预算见运行回执。[首轮回执](_sealed/topology_memory_rom_coupling_strength_v1_20261117_evidence.json) · [初值修正回执](../branch_initialization/_sealed/topology_memory_rom_branch_init_v1_20261117_evidence.json)
