## 失稳分离方向

35 个失稳样本中有 33 个在本轮真实可用窗口内具备完整的起报后五点见证，均找到了同故障组的稳定参照。到见证终点的时间中位数为起报后 0.34 s。两组各用失稳样本的同一机器对和时间窗。以下为各项对这一对机器相对速度增量的贡献中位数，单位为 rad/s。

| 贡献项 | 失稳 33 例 | 匹配的稳定参照 |
|---|---:|---:|
| 机械输入 | −3.808 | −2.997 |
| 恢复力 | +8.293 | −2.412 |
| 可见阻尼 | −2.751 | +0.092 |
| 初始记忆 | +0.431 | +0.470 |
| 速度受驱记忆 | −0.542 | −0.036 |
| 方程残差 | +2.551 | −0.154 |

31/33 个失稳窗口存在正向的分离速度残差。沿这些观测路径，恢复力的中位贡献推动分离，受驱记忆和可见阻尼的中位贡献抑制分离。发生失稳的 35 例在起报后前 500 ms 的可用区间上，初始记忆做功中位数为 +0.622，受驱记忆为 −0.644，两项逐事件相加后再取中位数为 −0.0462，均用方程一致单位。两类记忆的作用方向不同，合计净做功接近零时仍须查看两项各自的贡献。仅 2 个见证样本在记录内观测到所定义的首个外摆回落。
