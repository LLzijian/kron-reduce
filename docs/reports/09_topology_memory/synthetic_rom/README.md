### Topology–Memory Energy-Constrained ROM

本设计是后续显式多机约化方程的统一母结构。拓扑状态调节保守的网络耦合，记忆状态负责带耗散的历史反馈。恢复力、记忆端口和拓扑松弛共享储能与功率账目。结构发现以冻结候选库、整组删除和重拟合确定保留项。目标是在同一条 100 ms 因果计算链下解释稳定和失稳两类运动。


<a id="doc-4d23250443a3-研究假说"></a>

#### 研究假说

在四条已报告的漏判轨迹中，预测的八秒相对转速峰值均低于 TASK3 的 0.02 pu 门槛。三条给出的最大角范围超过 \(\pi\)，0019 的峰值为 3.071 rad。TASK3 失步检验要求角范围和相对速度在同一窗口同时满足条件。运行功率和网络参数共同决定多机系统的平衡与分界。

固定端口、衰减很慢时，\(z(t)\approx z(0)+C^\top[q(t)-q(0)]\)，反馈含正半定的恢复项 \(CC^\top[q(t)-q(0)]\)。这给出了大功角下记忆拉回力可能过强的可检验机制。用户报告的 37 号型高历史残差与 38 号型较低历史残差提供两条诊断线索，分别对应方程对历史的解释能力和起报后的速度增长。四条既有 test 仅提供研究背景。候选支持、角尺度、时间窗与门限由预先登记的合成及 train 证据确定。[现有完整 TASK3 评分](../../08_machine_local_topology/task3_spatial_relaxation/README.md#doc-0ea75e26ad8a)


<a id="doc-4d23250443a3-方程与储能"></a>

#### 方程与储能

令 \(M=\operatorname{diag}(m)\)，力投影 \(P=I-m\mathbf1^\top/(\mathbf1^\top m)\)。在 \(m^\top q=m^\top v=0\) 时，\(P^\top v=v\)。以 \(\chi=(c,\xi)\in\mathbb R^{10}\) 表示一类拓扑状态，用 \(a=c\mathbf1+N\xi\) 表达其逐机分量。\(N\in\mathbb R^{10\times9}\) 是固定 Helmert 零和基。第二类隐状态 \(z\in\mathbb R^{10}\) 为逐机记忆。以 \(\chi\) 为计算坐标：

\[
\begin{aligned}
\dot q&=v, & M\dot v&=P[p-\nabla_q U-D(q,v,\chi)v]-C(q)z,\\
\dot z&=C(q)^\top v-Rz, & \dot\chi&=-G_\chi\nabla_\chi H,\\
H&=\tfrac12 v^\top Mv+U(q,\chi)+\tfrac12 z^\top z
     +\tfrac12\kappa_c c^2+\tfrac12\kappa_\xi\|\xi\|^2.
\end{aligned}
\]

取 \(G_\chi=\operatorname{diag}(\mu_c,\mu_\xi I_9)\)、\(R=\operatorname{diag}(1/\tau_i)\)、\(C(q)=P\operatorname{diag}(g_i h_i(q))\)，并约束 \(D,R,G_\chi\succeq0\)。\(C\) 已投影，机械和记忆两侧使用同一端口。若将方程改写到 \(a=T\chi\)，迁移率须变为 \(T G_\chi T^\top\)。

\[
\dot H=v^\top p-v^\top Dv-z^\top Rz-(\nabla_\chi H)^\top G_\chi\nabla_\chi H.
\]

这条等式给出机械输入和三类耗散。状态依赖端口的两侧功率逐点抵消，解析状态与参数切线仍须包含 \(\partial C/\partial q\)。带常输入时的平衡、倾斜储能下界、COI 上的局部曲率以及有效区域单独核验。拓扑隐态刻画有效耦合，物理电势只可作为外部已知真值对照。[端口哈密顿体系](https://doi.org/10.1561/2600000002)

<a id="doc-4d23250443a3-拓扑及恢复力"></a>

##### 拓扑及恢复力

用 \(A_g\) 表示关联矩阵。令 \(S=|A_g|^\top N\)。完全十机图满足 \(\mathbf1_E^\top S=0\)。任何后续图支持若不满足此式，先去掉 \(S\) 的边均值。固定 \(L_c=L_s=\log 2/2\)，令 \(r_S=\max_e\|S_e\|_2\)：

\[
\ell_e=L_c\tanh(2c/L_c)+S_e\frac{\xi}{\sqrt{1+(r_S/L_s)^2\|\xi\|_2^2}},\qquad
k_e=k_e^0\exp(\ell_e).
\]

边对数倍率的均值精确等于共同项，空间项严格零和。边倍率在 \([0.5,2]\) 内。两个分量各自限幅，避免逐边合并限幅导致均值与空间变化混合。所有相关消融共用同一分量限额。空间零和保持倍率的几何平均，刚度总和与模态刚度需要另行记录。基础刚度通过相对固定参考值的几何平均约束规范整体尺度，事件拓扑初态另有受限且以零为中心的先验。拓扑松弛使用这个实际映射的导数，\(\nabla_\chi U= (D_\chi\ell)^\top(k\odot\phi)\)。共同尺度下降和支路重分配各自接受科学检验。

对 \(d_e=(A_g^\top q)_e\)、参考角 \(r_e\) 取\(\phi_e=\Phi_1+\beta_{e,2}\Phi_2+\beta_{e,3}\Phi_3\)，其中

\[
\Phi_m(d_e;r_e)=\frac{\cos(mr_e)-\cos(m(r_e+d_e))}{m}-d_e\sin(mr_e),
\quad U=\sum_e k_e\phi_e.
\]

\(\partial_d\Phi_m=\sin(m(r_e+d))-\sin(mr_e)\)。偏差零点处恢复力为零。二、三阶项支持带符号系数，系数接受平衡点 COI Hessian 与工作区域储能审查。三阶项只在已登记证据支持时开放。


<a id="doc-4d23250443a3-记忆与耗散"></a>

##### 记忆与耗散

\[
s_i(q)=\frac{\sum_{e\ni i}\omega_{ie}(A_g^\top q)_e^2}{\sum_{e\ni i}\omega_{ie}},
\qquad h_i(q)=\frac{1}{1+\gamma_s s_i(q)},\quad \gamma_s=\delta_s^{-2}\ge0.
\]

每个有效节点的非负入边权和为正。\(\gamma_s=0\) 是常端口嵌套对照。\(\delta_s\) 由合成和 train 候选比较确定。对有该方向激励的一维单调位移，无衰减驱动的积分呈 \(\arctan\) 饱和。十机路径上的 \(h_i(q)\,dq_i\) 一般具有路径依赖，应核验受迫衰减界、端口做功与记忆积累。端口减弱同时减少驱动和反馈，积累的隐藏能量仍由 \(z^\top Rz\) 耗散。

首版保留十个一阶实极点，最多开放一个额外的共享记忆尺度。耗散库包含线性阻尼、已验算的逐机功角阻尼、非负支路调制和少量非负速度调制。已有逐机阻尼 \(D_0^{1/2}[I-\rho\operatorname{diag}(s_i/(1+s_i))]D_0^{1/2}\) 在 \(0\le\rho<1\) 下为半正定，保留作共同参考。新耗散项用非负权及 PSD 因子参数化。模型的隐态由拓扑与记忆两类组成。


<a id="doc-4d23250443a3-训练与结构发现"></a>

#### 训练与结构发现

每条事件的 \((\chi_h,z_h)=\mathcal I_{\theta,\mathcal S}(\mathcal H_{100\rm ms})\) 由同一因果算子估计。活跃拓扑坐标可取非零有限初值。每次前向用当前参数自由传播历史，起报时重置实测可见末点并传递两个隐藏状态。train 与部署共用初始化、输入和方程。val、test 对每个评估检查点固定共享参数，逐事件仅估计隐藏初值。记录投影前后的灵敏度、奇异值、边倍率和可见未来误差；可恢复性不足时按协议保留未决。

训练先校准共有骨架，再依次开放拓扑、饱和记忆及候选恢复力和耗散项。每次开放重新运行因果估计。候选组包括共同尺度、空间重分配、记忆端口饱和、各阶谐波与各耗散块。组稀疏项在统一尺度下作用于整个物理块，驱动与反馈同时保留或删除。每次删除在 train 上用相同预算重拟合并重新初始化，比较预注册 val 的轨迹、失稳时序、数值覆盖及物理核查，最后联合精化。具体阈值、组罚权与候选预算在运行前登记。[候选库稀疏辨识](https://doi.org/10.1073/pnas.1517384113)

最终目标允许在预冻结的 1、3、5、8 s 轨迹损失之外加入 \(M\Delta v\) 短窗估计误差及参数、初态能量正则。按样本实际可用时长计算各时域。速度增量来自同一条真值轨迹，开放该项前须在 train 上比较其与轨迹梯度的余弦、相对大小和局部改进方向。固定任何短窗、权重和检查点规则后再拟合。


<a id="doc-4d23250443a3-实施顺序与判定"></a>

#### 实施顺序与判定

1. **阶段 A，冻结模型的完整 train 物理诊断。** 沿实测路径分开保存动量冲量、机械做功、初始记忆释放与速度受驱记忆、起报跳变及首摆分离方向的收支。在 train 内对照稳定匹配样本及高低历史残差，比较结构假说的证据。[阶段 A 协议](../task3_momentum_work/README.md#doc-ccb939b6dee0)
2. **阶段 B，统一方程实现与合成辨识。** 先检查互易端口、非零输入能量收支、解析 Jacobian、双步长、零支持退化及冻结重载。S0 固定耦合与常端口，S1 动态拓扑，S2 饱和记忆，S3 两者并存，S4 用登记在库外的机制检验误选率。对照覆盖非零拓扑初态、慢记忆、无噪声和预冻结噪声、未见激励。分别验收训练后的可辨等价参数、记忆核、初态和未来等价性、匹配窗口失步时序以及阴性块删除。
3. **阶段 C，真实闭环竞争。** M0 用冻结的固定耦合、常记忆端口与逐机功角阻尼。M1 单独比较共同尺度和零和空间支持。M2 仅开放饱和记忆。M1、M2 各自通过预注册门后开放 M3。结构比较复用同名单、预算、初值规则、目标尺度和检查点规则。每轮冻结后完整评分 train 346、val 107、test 76。test 为已曝光的固定比较基准。
4. **冻结与确认。** 输出选中方程、参数和删除证据，分别报告稳定轨迹精度、五点失步判断、真值可用窗口内复现率和触发时间误差。保留未决和数值失败。独立数据另行登记，用于验证泛化与认证边界。

本文件固定母结构与候选库。各阶段的合成工况、真实名单、预算、训练停止与科学阈值由各自的不可变执行协议约束。

## 执行协议

<a id="doc-c1ced0cae5df"></a>

<a id="doc-c1ced0cae5df-阶段-b--拓扑记忆母结构合成辨识协议"></a>

### 阶段 B · 拓扑—记忆母结构合成辨识协议

本协议用已知真值检验拓扑状态与饱和记忆能否从同一条因果历史链中辨识。合成真值由独立 NumPy 积分器生成；模型只在 train 上更新，用 val 选择检查点，test 只作冻结后的报告。完整设计见[统一母结构](#doc-4d23250443a3)。


<a id="doc-c1ced0cae5df-真值系统与样本"></a>

#### 真值系统与样本

统一使用十机完整图、固定功率、固定机械参数、逐机记忆和慢记忆极点。逐机功角阻尼固定为 ρ=2/3、空间混合为 1。记忆端口饱和系数 γ_s 非负，γ_s=0 对应常端口。五种已知真值为：

| 系统 | 真值机制 |
|---|---|
| S0 | 固定拓扑、常记忆端口 |
| S1 | 动态拓扑 |
| S2 | 饱和记忆端口 |
| S3 | 动态拓扑与饱和记忆并存 |
| S4 | 拓扑关闭、端口不饱和，加入库外第五谐波恢复项 |

S4 的第五谐波系数固定为 0.02，只用于生成真值。每种真值包含 train 24、val 12、test 12 个事件，分别来自 12、6、6 组激励。每组共用初态、功率和隐状态，分别施加低速与高速扰动。同组事件归入同一划分。高速扰动随组编号增大，val 和 test 检查更强激励下的预测。每例保存完整 811 帧轨迹。随机种子、激励参数、慢记忆极点和各机制的其余数值由执行方案冻结。

候选库包含拓扑共同尺度、拓扑空间重分配和记忆端口饱和三个结构块的八种精确支持：空支持、每个单块支持、每对组合支持及三块并存。五种真值与八种支持形成 40 个候选起点。所有候选使用相同的初始化、事件次序及优化规则；每个候选仅用对应 train 更新。


<a id="doc-c1ced0cae5df-因果历史训练与选择"></a>

#### 因果历史、训练与选择

每次训练先以首 100 ms 的可用历史估计隐状态，随后从实测可见末点起报，按固定输入自由预测。训练损失只计 train 事件起报后的 1 s 轨迹误差；未来真值和标签不进入历史初始化。每次更新用一次包含全部 24 个 train 事件的向量化批次计算完整梯度，最多更新 12 次。完整批次通过执行前的显存工程检查后方可运行；任何批次变更须先修订并重新签署执行方案。

在更新 0、4、8、12 时，分别对完整 val 计算 3 s 轨迹分数并保存检查点。模型选择和并列处理规则、参数化、优化器设置、目标归一化、先验及精确支持定义由签署方案冻结。val 不参与梯度更新；test 不参与训练或检查点选择。


<a id="doc-c1ced0cae5df-冻结评分"></a>

#### 冻结评分

冻结选定检查点后，分别对完整 train、val、test 进行 8 s 闭环评分。使用 2.5 ms 和 1.25 ms 两档积分步长；对干净历史与预先固定的轻度历史噪声分别评分。噪声只作用于 100 ms 因果历史输入，预测均与干净真值轨迹比较。噪声幅度、种子、评分时间窗、误差尺度、误差聚合方式和数值失败定义由签署方案冻结。

每个划分各自用完整批次预测，批次的数值失败只影响该划分的覆盖。所有划分都报告轨迹误差、覆盖率、数值失败和未决样本。train 用于拟合，val 用于选择检查点和结构，test 提供冻结比较结果。test 名单与激励不参与任何选择。


<a id="doc-c1ced0cae5df-验收职责"></a>

#### 验收职责

工程检查覆盖非零输入下的能量收支、互易记忆端口、解析梯度、两档积分步长、零支持退化、冻结与重载一致性，以及所有划分的有效覆盖。阶段 A 的初始与受驱记忆做功拆分单独归档。具体容差和失败处置由执行方案冻结。

科学检查分别评估可辨等价参数、记忆核、初态和未来轨迹，比较匹配支持与删块支持在 val 上的表现，并核对失步判断与时序。结构支持以预登记的 train/val 标准判定。S4 的候选库不含第五谐波；其留出样本结果用于检查库外机制是否被误选为库内结构。S4 的真值系数保持冻结，不能依据候选结果调整。

验收指标、阈值、等价参数定义、稳定性判定、候选删除规则、模型选择并列规则及每项运行预算均须在执行前写入签署方案。保留未通过项、数值失败、未覆盖例和完整队列，按原冻结规则判定。


<a id="doc-c1ced0cae5df-执行与产物"></a>

#### 执行与产物

本协议限定合成已知真值检查，不读取真实数据，不加载 TASK3 轨迹，不改变部署基线。单次执行使用新 run ID，运行前绑定代码、输入清单、执行方案与预算；运行时记录 Python 3.12 环境、配置哈希和实际算子计数。

保存真值与激励清单、40 个候选起点及其冻结模型、train 更新记录、val 检查点曲线、双步长和两种历史条件下的逐例评分、能量与梯度核查、支持选择结果、失败及覆盖记录、运行回执和独立审核。通过本阶段后，真实闭环竞争仍须另行登记和批准。

#### 机制与初态

- S2 的饱和系数由 0.20 学到 0.464，真值为 0.60。沿合成 train 和 val 路径计算的记忆核相对误差为 1.55%。在这个真值系统上，选择能辨认出饱和记忆。val 最差历史起始隐状态相对误差为 72.1%。
- S1 和 S3 的 val 选中模型均把空间重分配删去。S1 中共同尺度单项和全真值支持的 val 3 秒平方误差分别为 \(5.406\times10^{-6}\) 和 \(5.552\times10^{-6}\)，S3 两者分别为 \(8.896\times10^{-7}\) 和 \(8.989\times10^{-7}\)。这一训练与激励组合下，轨迹精度未提供选中空间机制所需的证据。
- S4 的第五谐波未进入候选库。val 选中固定耦合和常端口，未误选新增机制。由于至少一个冻结候选达到既定的轨迹和失步时序标准，库外失配拒绝门未通过。
- S0 不更新共享参数。val 的数据灵敏度矩阵在 12 例中均为 10/10 秩，最小奇异值约为 \(1.714\times10^{-4}\)。原先验的增广对角元素为 0.014142，约为最小奇异值的 82.5 倍。固定已知系数后切换先验，可以检验初态收缩及其对噪声的影响。
