## 执行协议

<a id="doc-ccb939b6dee0-阶段-a--task3-train-的动量与做功诊断"></a>

### 阶段 A · TASK3 train 的动量与做功诊断

本阶段检验冻结基准中哪些物理项解释不了实测的速度增长。使用完整 TASK3 train 346，含稳定 311、失稳 35。基准为冻结 T0M1 第 12 步加逐机功角阻尼 \(\rho=2/3\)、空间混合 1，等同于逐机速率配对对照中选中的共同起点。沿观测路径做诊断，拟合次数、自由预测步数及 val/test 数据访问均为零。[统一母设计](../synthetic_rom/README.md#doc-4d23250443a3)


<a id="doc-ccb939b6dee0-因果起报和观测路径"></a>

#### 因果起报和观测路径

使用 `measured_history_100ms_zoh_v1`。CUDA float64 用 2.5 ms、1.25 ms 各算一次 11 帧因果历史，五次径向 Gauss–Newton 沿用冻结尺度和半径，先验权重 \(10^{-6}\)。保存两类起始记忆 \(z_h\) 和起报 \(z_T\)。记录历史的归一化 RMSE、估计初态范数、可见重置的 \(\Delta q,\Delta v,M\Delta v,\Delta K,\Delta U,\Delta H\)。起报重置量独立记账。

历史为首 11 帧。未来段从第 11 帧起算，最长 3 s，总计最多 311 帧。真实可用区间按原长度保留。逐区间对观测 \(q,v\) 分别线性插值，输入保持第 11 帧登记的机械偏差 \(p_0\)。历史段记忆从因果 \(z_h\) 开始，未来段从闭环历史末端的 \(z_T\) 开始。每段使用 \(z=z_{\mathrm{free}}+z_{\mathrm{driven}}\)，前者是该段起点状态的衰减传播，后者是零初值对该段实测速度的响应。初态与受驱冲量及做功分开保存。


<a id="doc-ccb939b6dee0-两套物理账目"></a>

#### 两套物理账目

在每个采样区间保存五个逐机向量 \(I_j=\int f_jdt\)，分别对应 \(Pp_0\)、\(-P\nabla U\)、\(-PD(q)v\)、\(-Cz_{\mathrm{free}}\)、\(-Cz_{\mathrm{driven}}\)。逐机实测平均加速度为 \(\Delta v/\Delta t\)，动量残差为 \(M\Delta v-\sum I_j\)。单独计算每项逐机做功 \(\int v_i f_{j,i}dt\)、逐机 \(\Delta K_i\) 与做功残差。对记忆保存端点能量及 \(\int z^\top Rz\,dt\)，核对总记忆做功 \(W_M=-\Delta H_z-\int z^\top Rz\,dt\)。同步记录 \(\Delta q-\int v\,dt\) 及 \(W_U+\Delta U\)，解释实测插值引入的差别。

同一 1.25 ms 因果初态分别用四点、八点 Gauss 求积。用八点重新计算 2.5 ms 初态的作用，以隔离初始化敏感性。各项的数值误差采用分量尺度 \(\max(1,|x_{\mathrm{ref}}|)\)。最大求积差、隐藏记忆功率不闭合、动量及做功加残差的账目核对上限均为 \(10^{-7}\)。真实动量与做功残差用于诊断，不按零值作通过条件。合成构造数据先检查符号、衰减与驱动分解、记忆能量恒等式和求积一致性。


<a id="doc-ccb939b6dee0-首摆和匹配规则"></a>

#### 首摆和匹配规则

每例报告完整观测未来段及起报后 500 ms 内实际可用区间的带符号累计项。按冻结五点规则找从起报点开始的第一个完整失步见证。取该窗首帧绝对功角最大和最小的两台机器，同值取较低索引。沿固定方向 \(d=e_i-e_j\) 报告各冲量对相对速度增量的贡献 \(d^\top M^{-1}I_j\)。无五点见证则保留缺失标记。对有方向的样本，首个外摆由观测网格上第一个 \(d^\top v>0\) 到其后首个 \(d^\top v\le0\) 界定。若记录内未观察到回落，保存外摆未结束标记。该统计用于区分首个外摆与五点见证。

稳定匹配从合格的 train 稳定病例中，以相同故障组和起报质量加权速度范数最接近为规则，并列按源限定 ID 排序，允许同一稳定病例作为多例参照。找不到同组病例时留空。起报前历史残差按完整 train 中位数分成高低两组。这两项只用于汇报统计。带符号净冲量、做功、绝对累计量与抵消程度共同判断作用方向。沿实测路径的收支支持候选假说，因果预测效果由后续闭环消融检验。


<a id="doc-ccb939b6dee0-预算与输出"></a>

#### 预算与输出

单次执行打开冻结 static 与 train 缓存各一次。计算上限为两档各一次因果历史估计，加一次批失败时的逐病例隔离。前后两个观测段合计最多 107260 个区间，执行 4／8／8 点三次计算，最多 321780 个区间调用与 2145200 个求积节点。每例最多三次储能调用。具体运行时、数值算子上限、哈希和名单见登记。输出每例汇总、两档因果历史解、区间数组、访问与算子台账，以及缺失与未决说明。阶段 B 的验收和科学可辨识性单独登记。

## 报告与结果

<a id="doc-7bb602349804"></a>

<a id="doc-7bb602349804-task3-train-动量与做功诊断"></a>

### TASK3 train 动量与做功诊断

冻结的 T0M1 加逐机功角阻尼完成完整 train 346 例的路径诊断。两档 100 ms 因果初始化全部有效。沿实测轨迹核对的最大求积差为 \(1.43\times10^{-14}\)，记忆做功闭合误差为 \(1.40\times10^{-14}\)。两项实测方程残差仍保留在账目中供机制分析。[执行协议](#doc-ccb939b6dee0)


<a id="doc-7bb602349804-起报前后的证据"></a>

#### 起报前后的证据

| 完整 train 分组 | 样本 | 100 ms 历史归一化 RMSE 中位数 | 起报速度重置范数中位数（rad/s） |
|---|---:|---:|---:|
| 稳定 | 311 | 0.05954 | 0.4311 |
| 失稳 | 35 | 0.20308 | 1.7424 |
| 历史残差低于或等于 train 中位数 | 173 | 0.02918 | 0.1549 |
| 历史残差高于 train 中位数 | 173 | 0.13801 | 0.9389 |

以 \(10^{-8}\) 的范数差判定贴近约束上界，346 例中有 283 例的历史起点记忆估计贴近冻结半径。高历史残差组在重置时需要更大的速度修正。这些数据支持在合成对照中检验联合拓扑初态与记忆初态的恢复能力。起报重置的动量与能量变化独立保存。


<a id="doc-7bb602349804-失稳分离方向"></a>

#### 失稳分离方向

35 个失稳样本中有 33 个在本轮真实可用窗口内具备完整的起报后五点见证，均找到了同故障组的稳定参照。到见证终点的时间中位数为起报后 0.34 s。两组各用失稳样本的同一机器对和时间窗。以下为各项对这一对机器相对速度增量的贡献中位数，单位为 rad/s。

| 贡献项 | 失稳 33 例 | 匹配的稳定参照 |
|---|---:|---:|
| 机械输入 | −3.808 | −2.997 |
| 恢复力 | +8.293 | −2.412 |
| 可见阻尼 | −2.751 | +0.092 |
| 初始记忆 | +0.431 | +0.470 |
| 速度受驱记忆 | −0.542 | −0.036 |
| 方程残差 | +2.551 | −0.154 |

31/33 个失稳窗口存在正向的分离速度残差。沿这些观测路径，恢复力的中位贡献推动分离，受驱记忆和可见阻尼的中位贡献抑制分离。发生失稳的 35 例在起报后前 500 ms 的可用区间上，初始记忆做功中位数为 +0.622，受驱记忆为 −0.644，两项逐事件相加后再取中位数为 −0.0462，均用方程一致单位。两类记忆的作用方向不同，合计净做功接近零时仍须查看两项各自的贡献。仅 2 个见证样本在记录内观测到所定义的首个外摆回落。

这些统计支持把历史初态解释和受驱记忆结构作为独立合成因子。实测路径上的账目留下了系统性的向外速度缺口，候选对自由闭环的作用由后续消融检查。本轮只读取两项登记的 train 范围缓存，拟合与自由未来预测均为零。[量化回执](_sealed/kiki_topology_memory_balance_20261116_evidence.json) · [独立结果审查](_sealed/kiki_topology_memory_balance_v1_result_review_20261116.json)
