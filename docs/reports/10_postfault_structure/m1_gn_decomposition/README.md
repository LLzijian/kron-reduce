### M1 因果 GN 先验与半径解耦消融

用上一轮冻结的 T0M1 加逐机功角阻尼方程，量化先验衰减和放宽记忆半径各自对首摆速度和稳定轨迹的影响。共享系数和预处理沿用 M1 第 0 步。使用冻结的来源限定名单 `train=346` 和 `val=107`。拟合、梯度、共享参数更新和 `test` 轨迹读取的上限均为零。一次完整执行，先通过合成回归，再登记阶段批准。[第 0 步回执](../m1_first_swing/_sealed/unified_first_swing_fit_20261119_evidence.json) · [自适应 GN 回执](../m1_probes/_sealed/unified_first_swing_probes_v2_20261119_evidence.json)


<a id="doc-a92915e1f13f-对照与参数网格"></a>

#### 对照与参数网格

每个事件使用故障清除后的前 100 ms（11 帧）功角和转速、参考平衡点、惯量、图先验及起报点机械功率。用零记忆状态做一次历史前向，第 2–11 帧经冻结尺度归一化后计算 RMS 残差 \(r_0\)。保持五次 GN、起报点可见状态重置和机械功率零阶保持。沿用 \(\lambda_0=10^{-6}\) 和原半径 \(R\)。原硬球的先验施加于 \(z/R\)。软球取 \(z=a/\sqrt{1+\|a/(mR)\|^2}\)，先验施加于 \(a/R\)。因此固定先验的硬球到软球差异包含半径、映射和先验坐标的联合影响。同为软球的固定先验各行可以直接比较半径。

| 组别 | 先验 | 半径 | 来源 |
| --- | --- | --- | --- |
| 原固定 GN | \(\lambda_0\) | 硬球 \(R\) | 复用 M1 v1 完整双步长结果 |
| 原自适应 GN | \(\lambda_0/[1+(r_0/r_{\rm ref})^2]\) | 软球 \(2R\) | 复用 v2 完整双步长结果 |
| 仅衰减先验 | 同 v2 衰减式 | 硬球 \(R\) | 本轮复算 |
| 固定先验与软球 | \(\lambda_0\) | 分别取 \(1.4R,1.6R,1.8R,2R\) | 本轮复算，\(2R\) 补齐四组正交对照 |
| 高阈值联合方案 | 见下式 | 超过阈值采用软球 \(1.6R\) | 分别取 P85、P90，本轮复算 |

二次衰减式沿用 v2 的 `train` 中位数参考 \(r_{\rm ref}\)，两档步长分别计算历史残差。高阈值方案用 2.5 ms 历史残差和 311 个 `train` 稳定样本的线性插值分位数 \(Q\)，两个步长共用该门控。\(r_0\le Q\) 时精确沿用原硬球 \(R\) 和固定先验，\(r_0>Q\) 时采用软球 \(1.6R\)，先验为

\[
\lambda_h(r_0)=\frac{\lambda_0}{1+\left[\max(0,r_0/Q-1)\right]^2}.
\]

分位数仅用 `train` 计算，在读取 `val` 前连同七个新方案、评分和预算写入冻结记录。样本所属标签只用于计算 `train` 参考分位数和评分。每个事件的门控量从自身 11 帧历史重新计算。


<a id="doc-a92915e1f13f-通过标准"></a>

#### 通过标准

七个新方案均对完整 `train` 和 `val` 作起报后 8 秒自由预测。RK4 步长为 2.5 ms 和 1.25 ms。采用冻结 TASK3 2.5 ms 轨迹评分，1.25 ms 用于数值和分类一致性检验。弱动量见证与相对转速峰值分别在两个步长上计算。对两个旧对照使用相同原始窗和相同评分口径。

| 指标 | 标准 |
| --- | --- |
| 数值资格与覆盖 | 完整 `train` 与 `val` 数值合格，无缺失，覆盖 95 个 `val` 稳定样本的 8 秒记录、12 个 `val` 失稳峰值和 33 个 `train` 见证 |
| `val` 失稳检出 | 确认检出 12/12，或确认检出 11/12 且起报后前 500 ms 峰值欠估中位数相对固定 GN 在两档步长都至少下降 20% |
| `train` 分离速度见证 | 33 个固定见证的带符号残差中位数距零在两档步长都至少下降 20%，绝对残差中位数均不升高 |
| `val` 稳定轨迹 | 95 个事件的 8 秒归一化 RMSE 事件平均值不超过 0.24，稳定误报不超过 1 个 |

峰值为真值可用网格上的最大质心相对转速绝对值，欠估为实测减预测的峰值差。门槛使用逐例峰值差的正部中位数，另保存带符号和绝对中位数。未决与数值失败分别记录。用 `val` 检出数、误报数、未决数、稳定 8 秒误差、双步长较大的峰值欠估和见证中位数距零列出没有被其他方案全面超过的方案。逐例列出旧自适应 GN 新增的稳定误报和未决，以及旧模型漏判后获检出的 `val` 失稳样本，同时查验初始和起报时刻记忆储能。此次网格固定，报告适用于已用的 `train/val`。


<a id="doc-a92915e1f13f-执行预算"></a>

#### 执行预算

完整名单共 453 个事件。每个新方案做两档预测，合计 6,342 条。批量取 64 个事件，失败批次内按事件与方案隔离一次。另作两次主步长零记忆历史计算。缓存上限为一次静态、一次 `train` 和一次 `val` 读取。逐例预测和访问日志、阈值、见证、归档和 SHA256 回执保存在该次运行的独立目录。[执行配置](../../../../configs/experiments/unified_first_swing_gn_decomposition_v3.toml)

### M1 因果 GN 解耦消融结果

固定先验搭配 \(1.8R\) 或 \(2R\) 的软半径，在完整 `val` 上均检出 **12/12** 个失稳样本，误报 1 个、未决 0 个。七个新方案均未通过联合验收。达到 12/12 的两组稳定 8 秒归一化 RMSE 超过 0.24，33 个 `train` 见证的残差降幅未达 20%。本轮保留原固定 GN 基线。[协议](#doc-a92915e1f13f) · [执行回执](_sealed/unified_first_swing_gn_decomposition_v3_20261119_evidence.json)

<a id="doc-ee04bd7e4647-先验和半径各改变了什么"></a>

#### 先验和半径各改变了什么

- **硬半径下，单独衰减先验维持了全部 453 例的原分类。** `val` 稳定误差只变动 −0.00007，`train` 见证和 `val` 峰值欠估分别增加 0.00808 和 0.01057 rad/s。在同为软 (2R\) 的对照中，衰减先验使两项速度残差分别下降 0.29112 和 0.21316 rad/s，同时使 `val` 稳定误差由 0.26284 增到 0.31095，误报由 1 个增到 2 个，未决由 0 个增到 1 个。这些是冻结模型的配对差异。硬球到软球同时改变半径、坐标映射及先验所作用的坐标。
- **固定先验软 (1.8R\) 和 (2R\) 已达到检出与误报门，见证分别改善 16.50% 和 16.12%。** (1.8R\) 的稳定 NRMSE 在新检出 12/12 的组内最低，距门槛仍差 0.02017。(2R\) 的 `val` 首摆欠估更小，为 1.01328 rad/s。两档步长均得到同样的验收结论。
- **P85 与 P90 减少了对低残差历史的改动，未通过连续指标。** 两个阈值分别为 0.220826 和 0.250502。`val` 后验历史 NRMSE 中位数分别为 0.06364 和 0.06818（旧自适应 GN 为 0.02146）。两组均重新检出 `expansion_0189`，原来检出的 `pilot_0366` 转为未决。峰值欠估下降 17.91% 和 17.55%，见证残差中位数分别升高 1.39% 和 2.50%。
- `train` 中 `pilot_0280` 与 `pilot_0300` 在保持硬 (R\) 的单独衰减方案中均仍漏判。固定先验软 (2R\) 已能检出 `pilot_0280`，固定先验软 (1.4R\) 已能检出 `pilot_0300`。本轮两次恢复发生在不同半径配置下。


<a id="doc-ee04bd7e4647-四个-val-事件的因果初始化"></a>

#### 四个 `val` 事件的因果初始化

下表为 2.5 ms 主步长的 **历史起始 / 起报时刻**记忆储能 \(\|z\|^2/2\)。方案分别为原固定 GN、旧软 (2R\) 自适应 GN，以及本轮固定先验软 (1.8R\)。后三列的括号给出相对冻结真值的分类结果。

| 来源限定事件 | \(r_0\) | 原固定 GN | 旧自适应 GN | 固定先验软 (1.8R\) |
| --- | ---: | --- | --- | --- |
| `ieee39_expansion/expansion_0189` | 0.27225 | 21.85 / 18.19（漏判） | 72.56 / 55.95（检出） | 54.51 / 39.70（检出） |
| `ieee39_postfault/pilot_0150` | 0.26346 | 21.85 / 7.85（稳定） | 42.07 / 15.55（误报） | 39.74 / 13.09（误报） |
| `ieee39_postfault/pilot_0232` | 0.38796 | 21.85 / 18.39（稳定） | 86.91 / 49.02（未决） | 68.01 / 53.57（稳定） |
| `ieee39_postfault/pilot_0237` | 0.25916 | 21.85 / 18.69（稳定） | 30.57 / 15.69（误报） | 62.74 / 52.91（稳定） |

固定先验软 (1.4R\) 已在起始储能 38.71 时检出 `expansion_0189`。三个稳定事件中，`pilot_0232`、`pilot_0237` 在所有新方案下均正确判为稳定，`pilot_0150` 在所有使用软半径的方案中仍误报。以 (1.8R\) 为例，`pilot_0150` 的稳定 8 秒 NRMSE 从 0.50758 升至 2.84761，这一项的配对差额按 95 例等权计为均值增加 0.02463。四例 (r_0\) 都高于 P90。`pilot_0232` 与 `pilot_0237` 在起报储能大于旧自适应 GN 的 (1.8R\) 方案下恢复稳定，因而这批配对结果也显示需保留逐例隐态与响应信息。

按六项登记指标比较，P85 联合方案优于固定先验软 \(1.6R\)。其余八组在本轮范围内均未被另一组全面超过。完整评分、两档新预测、见证与峰值及访问账本保存在 `unified_first_swing_gn_decomposition_v3-probe-20261119T074514989765Z-5637f04a-73c62955`。本结论适用于本次冻结模型和已使用的 `train/val` 名单。[校验回执](_sealed/unified_first_swing_gn_decomposition_v3_20261119_evidence.json)
