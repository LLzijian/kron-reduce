# M1 固定先验软半径下的梯度平衡拟合

检验冻结方程与因果初态联合微调后，能否在 `val` 保持 12/12 失稳检出，并进一步缩小 `train` 首摆分离速度残差。固定先验软 \(2R\) 在零更新时检出 `train` 的 29/35 和 `val` 的 12/12，`val` 前 500 ms 峰值欠估中位数为 1.01328 rad/s。原固定先验硬 \(R\) 为配对对照。两组从同一冻结方程出发，共享损失、梯度系数、参数范围和更新预算。[零更新对照](../reports/unified_first_swing_gn_decomposition_v3_20261119_zh.md)

## 因果起报和可训练参数

使用被冻结的 `train=346`、`val=107`、`test=76` 来源限定名单和真值标签。故障清除后 100 ms 起报，因果初始化使用 11 帧质心相对功角及转速、参考平衡点、惯量与图先验。以起报点机械功率偏差零阶保持，选中模型作确定性 8 秒自由预测。逐事件按当前共享系数重新做五步 GN，预测时在 100 ms 重置可见状态并传递记忆。两组初态都使用固定先验 \(\lambda_0=10^{-6}\)。对照在物理记忆上投影至硬球 \(R\) 并惩罚 \(z/R\)。软 \(2R\) 组使用 \(z=a/\sqrt{1+\|a/(2R)\|^2}\)，在 \(a/R\) 上施加相同系数的先验。比较对象是两种完整初始化配置。

两组同时开放 23 个系数，包括 10 个局部记忆增益、10 个时间常数参数、刚度倍率、基础阻尼倍率及逐机功角阻尼的共同幅度 \(\rho\)。用 \(\rho=0.95\operatorname{sigmoid}(b)\) 保持物理范围，初值为 \(2/3\)。两组优化均通过历史切线、GN 迭代和自由预测求导。保持固定边刚度结构及原记忆端口。逐机耗散权重保持非负，故障后带输入的储能不等式沿用 \(\dot H\le v^\top p\)。

## 训练目标和预算

- **轨迹损失。** 1 秒、3 秒按该窗内真实可用帧计算，两个窗等权，事件等权。沿用冻结 `train` 尺度。稳定事件在每个归一化残差上用二倍 Huber，转折点为 1；失稳事件用平方误差。二倍 Huber 在小残差区与平方误差一致，区外为线性。
- **首摆损失。** 复用 200 ms 弱动量及前 500 ms 单边转速项，合成 \(L_{\rm fs}=L_{\rm mom}+0.5L_{\rm asym}\)。35 个真实失稳事件的首摆事件权重为 8，311 个稳定事件为 1。权重只进入首摆项，按完整 `train` 事件数聚合。两窗的动力积分从因果起报记忆做起，沿线性插值的实测路径推进，使用已有的可用窗判据。
- **起点定标。** 在软 \(2R\) 组的第 0 步，在完整 `train` 累加 \(L_{\rm traj}\) 和 \(L_{\rm fs}\) 的梯度。一次性冻结 \(\alpha_{\rm fs}=1.1\|\nabla L_{\rm traj}\|/\|\nabla L_{\rm fs}\|\)，两组共用。保存两个梯度向量、原始范数、缩放后范数及 `log_damping_factor` 的单项和合成偏导，训练方向由合成损失决定。梯度为零或非有限时，两组只保留第 0 步评分。
- **稳健更新。** 全量 Adam 每组最多 18 次，梯度按固定顺序从 128、128、90 三批累加。训练用 5 ms RK4，学习率 0.002、梯度裁剪 1。锚点惩罚为优化坐标到第 0 步的平方距离，系数 1.0。刚度与基础阻尼倍率各限于 \([0.5,2]\)，记忆增益下限 0.01。起报记忆储能超过 \((2R)^2/2\) 后加系数 0.1 的相对超限平方惩罚。到达上限或遇到数值失败时结束该组，失败更新回退到最近有效参数并保留记录。

## 检查点选择和验收

第 0、3、6、9、12、15、18 步检查完整 `val`，并在每组每次检查计算相同的 33 个 `train` 见证。轨迹与分类按冻结 TASK3 方法，用 2.5 ms 主步长和 1.25 ms 精化步长。`val` 的 12 个失稳样本同时保存两档可用网格上的前 500 ms 峰值速度正欠估，作为连续选点指标。`train` 的见证保留带符号与绝对分离速度残差。

| 验收项 | 门槛 |
| --- | --- |
| 数值资格 | 双步长 `val` 数值合格 107/107，覆盖稳定事件 8 秒 NRMSE 95/95、失稳峰值 12/12、`train` 见证 33/33 |
| `val` 失稳与误报 | 检出 12/12、未决 0 个、稳定误报至多 2 个，目标至多 1 个 |
| `val` 稳定轨迹 | 全体 95 个真实稳定事件的 8 秒 NRMSE 中位数至多 0.21，判定为稳定的真实稳定事件（TN）8 秒均值至多 0.24 |
| `train` 见证 | 相比冻结硬球第 0 步，两档带符号残差中位数距零均下降至少 20%，主步长上限约 2.04082 rad/s |

选择顺序为联合过门、数值和见证完整且 `val` 过门、完整但未过门、存在缺失或数值失败。同档依次比较 `val` 数值失败与未覆盖总数、检出数（高者优先）、未决、误报、双步长较大的 500 ms 峰值正欠估中位数、双步长较大的见证中位数距零、全体稳定中位数、TN 均值、全体稳定均值，低者优先。并列保持较早步。联合科学验收同时要求两组完成登记的 18 步、软 \(2R\) 组选中步大于零，且选中点通过联合门。全体稳定均值、TN 分母、逐例错误、数值覆盖和所有分类计数一并报告。TN 均值的样本分母由各模型的分类结果确定。

## 冻结与独立执行范围

先通过合成检查。在登记的拟合阶段执行一次，两组最多 36 次共享参数更新、14 次完整 `val` 检查，保存逐步 `train` 损失、两组 `val` 曲线、选择步数和两组冻结快照。拟合阶段源缓存上限为一次静态及两次开发缓存，覆盖完整 `train/val`。冻结后复评两组完整 `train/val`，并依据完整名单评估标准登记一次单独的固定 `test` 阶段。该阶段绑定两组选中快照、预处理、名单和冻结评分的 SHA-256，源缓存上限为一次静态和 76 个事件，读取后对两组做双步长评分。固定 `test` 早已有历史曝光，用于冻结比较报告。拟合及后续报告各次执行使用独立结果目录与一次性授权记录。[冻结名单标准](kiki_official_train_test_v1_zh.md) · [执行配置](../../configs/experiments/unified_first_swing_v4_fit.toml)
