# 量测噪声与坏数据压力测试

本轮是冻结模型的量测噪声与坏数据压力测试（Measurement Noise & Outlier Stress Test）。冻结 V4 和 ES-ROM（M3b_G2）使用 100 ms 功角、转速观测及起报机械功率偏差，自由推演 8 s。鲁棒移动窗估计联合恢复十机惯量中心相对状态和记忆初值，使用拟合后的物理状态起报。

**科学判定为 `REJECT`。** 鲁棒估计在完整 `val` 保持无噪表现，并改善厚尾噪声下的轨迹误差和起报总储能判别。两种坏数据脉冲的综合损失未达到登记门槛。条件微调用满 15 次全量更新后，冻结门仍关闭。两组留出名单的实验访问次数均为 0。

## 完整 val 对照

`val` 包含 95 个稳定事件和 12 个失稳事件。六个模型、10 档噪声、规定重复及另外两组鲁棒候选共计 39,376 个模型、事件和工况组合，每组完成两种步长推演，数值不合格为 0。三种原冻结对照在两种步长各有 107/107 条无噪预测逐位重放一致。

无噪时，三组鲁棒候选均通过因果门回到原估计器。它们在两步长都确认 12/12 个失稳事件、误报 2/95 个稳定事件，稳定样本 8 s NRMSE 事件均值与 ES-ROM 原版相同。2.5 ms 下该均值为 0.43838。已知真值合成前置检查核验惯量中心投影、28 维切线、初态恢复、首末帧脉冲和带噪自由推演能量恒等式。

零重训候选 B 使用 0.0003 rad 的窗内运动学一致性阈值、Huber 截断值 1.5 和自适应先验系数 0.1。下表为 2.5 ms 步长、每档 5 次重复的综合损失相对降低幅度。两种步长的门禁判定一致。

| 必验工况 | 相对 ES-ROM 原版 | 相对因果平滑加原 GN | 改善门槛 |
|---|---:|---:|---|
| 动态高斯 | +0.89% | +1.30% | 未达标 |
| 固定尺度 30 dB | +5.57% | +6.85% | 达标 |
| Laplace | +4.95% | +2.80% | 达标 |
| Student t₃ | +15.12% | +13.41% | 达标 |
| 随机坏数据脉冲 | −0.29% | +1.13% | 未达标 |
| 首末帧坏数据脉冲 | −11.09% | −10.17% | 未达标 |

## 厚尾和端点脉冲

Student t₃ 工况下，候选 B 将稳定事件 8 s NRMSE 从 0.545 降至 0.224，将失稳事件可用区间 NRMSE 从 0.762 降至 0.657。五次重复的失稳确认召回率由 96.67% 提高至 100%，稳定误报率由 2.11% 降至 0.42%。这些数值使用 2.5 ms 步长和固定的 TASK3 归一化尺度。

端点脉冲下，原版和候选 B 都确认 60/60 个失稳事件重复观测，稳定误报从 9/475 降至 8/475。候选 B 的稳定 8 s NRMSE 从 0.458 降至 0.399，失稳可用区间 NRMSE 从 0.686 降至 0.680。前 500 ms 最大惯量中心相对转速的正欠估均值从 1.003 增至 1.308 rad/s，构成这一工况综合损失增加的主因。逐例配对后，首帧脉冲的 41 个失稳事件重复观测，平均欠估增加 0.344 rad/s。末帧脉冲的 19 个失稳事件重复观测，平均欠估增加 0.219 rad/s。

端点脉冲下，候选 B 的失步割集精确匹配率从 0.850 提高至 0.917，Jaccard 从 0.888 提高至 0.922。机械能 AUROC 从 0.933 变为 0.932，记忆储能 AUROC 从 0.526 提高至 0.823，总储能 AUROC 同步从 0.628 提高至 0.872。这些判别指标以各模型实际起报状态计算。

## 条件微调与冻结门

每次更新使用完整 `train=346` 的带噪起报估计，训练损失为与干净起报状态的归一化均方误差。使用有限差分和 Adam 更新先验系数与 Huber 截断值，保留 75 维冻结方程参数。每三次更新用相同的 46 个配对噪声批次评价完整 `val=107`，两种步长均通过数值核验。比较模型复用同一轮零重训评价。
