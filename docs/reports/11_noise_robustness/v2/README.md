# ES-ROM V2 量测噪声与坏数据压力测试

**合成前置门判定为 `REJECT`。** RTX 4060 Ti 双步长结果显示，八组 V2 候选均降低了原 GN 在首帧和末帧脉冲下的误差。相较 V1 候选 B，八组候选的两类峰值误差和 8 s NRMSE 均偏高，合成门通过数为 0/8。研究止于合成阶段。

## 双步长合成结果

试验对同一已知真值轨迹和同一组高斯背景注入 40 组脉冲，覆盖十台机组、两个窗口端点和两种相反的功角与转速脉冲符号。下表的端点指标为各 20 组受扰机组在起报后 500 ms 内的绝对速度峰值误差均值。8 s NRMSE 使用起报后的 800 帧，以固定角度和速度尺度归一化，汇总全部 40 组的平方误差后开方。2.5 ms 与 1.25 ms 步长的结果在表中精度一致。

候选 E 的三项误差在八组 V2 中最低。相对 V1 候选 B，首帧峰值误差增加 95.6%，末帧增加 286.5%，8 s NRMSE 增加 69.3%。即使以和 V1 持平为界，八组候选也全部存在差距。普通先验 G、H 和对应的逆信噪比先验 C、D 得到相同判定。

合成轨迹由同一组物理方程生成。这组结果量化了脉冲下逐通道净化与末帧融合的总体效果，结论适用于这组已知真值试验。全部 40 组的全机组峰值误差、逐点最大误差和逐例 NRMSE 随双步长原始结果留档。 [逐例得分](../../../../results/noise_robustness_esrom_v2-synthetic-20261126T234531027512Z-ce6188c1-e02e01d9/pulse_diagnostics.json) · [封存汇总](_sealed/synthetic_summary.json)

## 实施与证据边界

V2 使用 11 帧因果输入，串联逐通道 Huber 与 Tukey 净化、逆信噪比记忆先验、28 维阻尼联合求解和末帧融合。真实数据试验登记沿用冻结的 V4 与 ES-ROM 权重、物理方程、耗散结构和确定性噪声引擎。合成数据使用已知真值参数。

在两个步长下，28 维切线通过中心有限差分核验，无噪可见初态恢复误差小于 10⁻¹⁰。带噪 8 s 推演的惯量中心约束及能量恒等式核验界限为 10⁻¹²，均通过。
