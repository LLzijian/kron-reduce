## 双轨合成结果

轨道 A 复用 V2 的已知真值、稳态高斯背景和 40 个端点脉冲。轨道 B 在相同初态、输入和扰动下，用刚度和阻尼各提高 8% 的真值模型生成整段轨迹。所有预测器使用与 A 相同的方程。首末帧峰值误差分别对 20 个案例取均值，计算受扰机组起报后 500 ms 的绝对速度峰值差。8 s NRMSE 汇总 40 个案例起报后 800 帧的标准化平方误差。

候选 F 在八组中取得最低的双轨 8 s NRMSE。相对 V1 B，首、末帧峰值误差在 A 下降 8.83% 和 6.10%，在 B 下降 8.92% 和 6.14%。与同一轨道 A 上 V2 的候选 E 相比，V3 F 的 8 s NRMSE 下降 40.6%。所有 V3 候选的 8 s NRMSE 均高于 V1 B。

在 F 的 800 个逐例通道估计中，经验失配方差为正的通道在 A 有 69 个，在 B 有 70 个，两轨均涉及 30/40 例。B 中融合确实被激活，A 中的正方差也记录在案。每一轨、每一步长、每组 V3 候选的 80 个受扰功角与转速元素权重均精确为零。

## 实施和数据访问

V3 保留 100 ms 因果输入、冻结动力学和原无噪分流。可见先验为 0.0001。LM 前三轮使用数据尺度，后四轮加入逐通道经验失配方差。末帧融合增益由同一方差和因果噪声估计给出。两步长的单元测试分别通过 28 维切线有限差分、低于 10⁻¹⁰ 的无噪可见初态误差，以及低于 10⁻¹² 的带噪自由推演能量残差和惯量中心约束。 [V3 初始化器](../../../../src/kron_reduce/models/noise_robustness_mhe_v3.py)

工作流在合成阶段关闭。 `train=346`、`val=107`、`test=76` 与 `blind_v2=94` 的轨迹读取计数均为零。条件更新数为零。模型冻结、一次性留出评估、跨仓库 138 项哈希核对和真实名单对比图均未触发。跨仓库比对入口的 138 项匹配、缺项和单项改动检查使用合成清单，真实对侧文件读取计数为零。
