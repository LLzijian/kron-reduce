# ES-ROM V4 经验贝叶斯池化与量测噪声压力测试

本轮是冻结模型的量测噪声与坏数据压力测试（Measurement Noise & Outlier Stress Test）。候选 A 以零重训通过 `val=107`，六个必验工况的综合损失较两个对照平均降低 15.66%，最小降幅 11.24%。冻结后一次性完成 `test=76` 与 `blind_v2=94`。盲测中九个带噪档的总储能 AUROC 差值区间均高于零。

[V4 执行协议](protocol.md) · [标准、文献与十档噪声定义](../protocol.md) · [V3 双轨档案](../v3/README.md)

## 100 ms 初始化与合成核验

每例的功角和转速分别以组内较低中位数的 0.7 倍约束通道噪声尺度。池化后的尺度用于联合估计的失配方差和末帧融合，记忆先验继续使用因果逆信噪比。八组候选共用 Tukey 降权、28 维联合初始化器和冻结的 75 维动力学方程。G 与 H 关闭融合，直接使用估计轨迹的物理末帧。100 ms 内只有 11 帧功角和转速及起报机械功率偏差。噪声只叠加到这些量测，起报后机械功率保持常值并自由推演 8 s。评分真值沿用冻结 TASK3 与 M5。

轨迹归一化使用固定尺度 0.476753 rad 和 1.003367 rad/s。失步要求功角跨度超过 π，且最大惯量中心相对转速超过 0.02 pu，持续 5 帧。稳定要求从未失步且最后 100 帧功角跨度均小于 π，最大相对转速均小于 0.005 pu。失稳轨迹误差使用真值可用区间。

40 例零失配端点脉冲在两步长各执行一遍，各候选的 80 个受扰通道元素的 Tukey 权重均精确归零。800 条推演均为有限值。C、E、F、H 同时满足两项相对门槛。下表使用 2.5 ms 步长，1.25 ms 的门槛判断一致。峰值误差为受扰机组在起报后 500 ms 内的绝对速度峰值误差，首、末帧各 20 例，单位为 rad/s。8 s NRMSE 汇总 40 例。

## `val=107` 选型

登记协议规定前置门由至少一组候选通过，随后八组均进入完整 `val` 并按通过门槛后的平均综合损失改善排序。A 在合成门的末帧误差和 8 s NRMSE 超过 V1 B 的 1.02 倍上界，在真实 `val` 排名第一。A 使用 `alpha=0.03`、`c_var=4.0`、`kappa_term=1.0`、Huber 截断值 1.5 和逆信噪比先验。真实评测完成 78,752 条候选预测，并以同噪声哈希复用五个对照的 49,220 条 V1 归档预测。`val` 的十档各组双步长数值不合格计数均为零。

A 的无噪档在两步长均确认 12/12 个失稳事件、稳定误报 2/95。稳定 8 s NRMSE 为 0.438376，与原 ES-ROM 相同。六个必验档均通过 1% 的双对照门槛，24 个比较的算术平均降幅为 15.66%。下表给出各步长、各对照的综合损失降幅。

## 冻结后的一次性留出结果

冻结配置在 `test=76` 与 `blind_v2=94` 各评五种对照和池化 MHE，共 93,840 条预测。`test` 的 20,976 组、`blind_v2` 的 25,944 组双步长配对全部合格，各模型的数值失败和未覆盖计数均为 0。A 在两个步长的未决计数一致，每步长 `test` 为 50/3,496，`blind_v2` 为 42/4,324。原 ES-ROM 对应 76/3,496 和 22/4,324。含未决的重复保留可判定准确率和覆盖率，全名单准确率记为 `null`。

冻结 A 的无噪结果与原 ES-ROM 一致。`test` 的 TP/TN/FP/FN 为 5/67/0/2，另有 2 条未决，可判定准确率为 72/74。`blind_v2` 为 29/62/0/3，无未决，全名单准确率为 91/94。

2.5 ms 下，`test` 随机脉冲档的稳定 8 s NRMSE 从 0.27637 降至 0.19120，失稳可用区间 NRMSE 从 1.02829 降至 0.48950，确认召回率从 57.78% 升至 88.89%。对应割集覆盖率由 57.78% 升至 88.89%，在各自可评的样本中，精确割集匹配率由 84.14% 变为 75.00%，Jaccard 由 0.871 变为 0.826。盲测 20 dB 档的确认召回率由 82.50% 升至 91.88%，总储能 AUROC 由 0.621 升至 0.934。这些数值为五次噪声重复的平均。

端点脉冲分组呈现不同方向。`test` 首帧组的峰值正欠估中位数从 1.848 增至 3.629 rad/s，末帧组从 0.749 降至 0.159 rad/s。`blind_v2` 首帧组从 0.519 降至 0.457 rad/s，末帧组从 0.536 增至 0.655 rad/s。数值为 2.5 ms 下五次重复中位数的平均。

`blind_v2` 对 21 个故障组做 10,000 次配对重采样。每次在两模型、两步长及各噪声重复之间使用同一组抽样权重。下表为 2.5 ms 下 A 减原 ES-ROM 的差值及百分位 95% 区间，1.25 ms 的区间是否跨零结论一致。NRMSE 越小越好。

|---|---:|---:|
| 固定尺度 20 dB | −0.0352 [−0.0448, −0.0270] | −0.1160 [−0.1780, −0.0496] |
| 随机脉冲 | −0.0300 [−0.0396, −0.0224] | −0.1354 [−0.2056, −0.0650] |

九个带噪档中，稳定 NRMSE 有八档区间低于零，失稳可用区间 NRMSE 有三档。九档总储能 AUROC 的差值区间全部高于零，20 dB 档为 +0.314 [0.239, 0.401]。确认召回率在 20 dB 和 Student t₃ 档的区间高于零。九档精确割集匹配率和 Jaccard 的差值区间均跨零。稳态 PMU 档失稳 NRMSE 差值为 +0.0077 [−0.0708, 0.0755]。 [双步长 Bootstrap](../../../../results/noise_robustness_esrom_v4-blind-20261127T014602250965Z-620e133d-a8320676-sealed/blind_group_bootstrap.json)
