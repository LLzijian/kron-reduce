# ES-ROM V4 按物理量池化的噪声鲁棒性协议

V4 在 V3 的逐通道超额方差估计中，为功角和转速各设一个由因果观测计算的噪声下界。零失配试验定量核对起报峰值、完整轨迹误差和正失配方差计数。 [V1 噪声与评分协议](../protocol.md) · [V3 双轨结果](../v3/README.md)

## 输入、物理方程与统计估计

使用 100 ms 内 11 帧十机的惯量中心相对功角与转速、起报机械功率偏差和平衡点。起报后机械功率偏差保持常值，自由推演 8 s。保留冻结 V4 基线与 75 参数 ES-ROM 方程，以及原能量与耗散结构。正式试验采用 RTX 4060 Ti CUDA float64，使用 2.5 ms 和 1.25 ms 两档投影 RK4。

运动学 Tukey 净化、可见初态先验 0.0001、28 维 LM 和因果无噪分流沿用 V3。对每例，以功角十通道、转速十通道各自的较低中位数为组尺度。每通道取原有噪声尺度与本组尺度乘 0.7 的较大值。后四轮 LM 的失配方差和末帧融合都采用池化尺度。逆信噪比记忆先验继续使用原因果聚合噪声。末帧融合后投影至惯量中心。

候选 A–F 开启经验贝叶斯融合。B 与 C 仅在逆信噪比记忆先验的开关上不同。G 与 H 的 `c_var` 登记为 `off`，运行和 JSON 回执中记为 `null`。此时失配方差与融合增益均为零，直接使用联合 LM 的物理末帧。八组候选与共有参数绑定在登记配置中。

## 合成前置门

复用 V3 轨道 A 的匹配物理模型、初态、背景噪声和 40 个端点脉冲。每个步长覆盖十台机组、首末帧与两种相反的功角及转速脉冲符号。分别对首帧与末帧的 20 例计算受扰机组起报后 500 ms 绝对速度峰值误差。8 s NRMSE 使用起报后的 800 帧和固定的 0.476753 rad、1.003367 rad/s 尺度，汇总全部 40 例。按案例记录准确归零的 Tukey 权重和正失配方差通道数。

同一候选在两个步长的三项误差都须较原 GN 至少降低 80%，并且每项至多为 V1 候选 B 的 1.02 倍。前置工程核验覆盖 28 维切线有限差分、低于 10⁻¹⁰ 的无噪初态恢复误差、低于 10⁻¹² 的带噪推演能量残差和惯量中心约束，以及每步长 80/80 个目标脉冲元素权重精确归零。通过后进入完整 `val=107`。

## 验证、条件拟合与冻结

八组零重训候选都在 `val=107` 上执行十档和双步长的压力评估，共 78,752 条预测。确定性噪声引擎与 V1 的 46 项 `val` 哈希逐组对齐，只对量测输入注入噪声。沿用 V1 的标签、尺度、综合损失、未决和数值不合格规则。无噪档需确认 12/12 个失稳事件、稳定误报不增加、稳定 8 s NRMSE 增幅不超过 2%。动态高斯、固定尺度 30 dB、Laplace、Student t₃、随机脉冲和端点脉冲这六档，在两个步长的综合损失均须较原 ES-ROM 与因果平滑 GN 降低至少 1%。十档双步长数值不合格数须为零。合格候选按六档、两步长、两对照的平均相对改善排序，同分按登记顺序。

仅在八组均未过门时启动条件拟合。以平均相对改善排名最高的有限 `c_var` 候选为起点，从而在一次登记中优化四个连续标量。每次目标评估覆盖 `train=346`，两步长等权计算失稳事件前 500 ms 正欠估与稳定事件 3 s NRMSE。沿用 V3 对数空间的同时扰动对称差分与 Adam。扰动半径为 0.05，种子为 20261127，学习率为 0.08。范围为 `alpha` 1e-5 至 10，`c_var` 0.5 至 16，`kappa_term` 0.5 至 6，`huber_delta` 0.5 至 4。最多 15 次全量更新，每三次核验完整 `val`，首次过门时停止。训练覆盖失败时保留逐例证据。

只有通过完整验证门后才提交获胜配置、预测代码、冻结权重、预处理和验证证据的 SHA-256。一次性预算同时绑定 `test=76` 与 `blind_v2=94`，共六模型、十档、双步长 93,840 条预测。起报与推演延迟在同一 RTX 4060 Ti 以 `batch=1`、`batch=64` 对六模型计时。盲测按 21 个故障组进行 10,000 次配对 Bootstrap。留出评估后合并本地三组名单的噪声清单，并逐项核对对侧的 138 份 SHA-256。跨仓库表和图读取获准的四份对侧汇总文件。
