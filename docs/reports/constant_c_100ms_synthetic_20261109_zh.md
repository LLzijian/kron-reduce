# 常值 C、100 ms 已知真值研究结果

2026-11-09。**在本轮固定主参数下，100 ms 观测足以恢复隐藏初态并准确预测可见未来；这个结论取决于模型、采样与误差尺度，不能推广为所有常值 C 系统的统一保证。** 弱耦合、采样混叠和不可见隐藏方向三个对照分别说明：隐藏状态对误差的敏感性、真实采样映射是否唯一，以及可见未来是否受影响，需要分别判断。

将 C 缩小至原来的 `1e-4` 后，采样算子的最小奇异值降至 `5.190997e-7`，条件数仍约 `1.712`。绝对信息强度显著降低，条件数本身没有揭示这一变化。干净积分估计及含最弱方向噪声的估计未达到隐藏恢复阈值，但对应可见未来达到阈值；不能把隐藏状态误差直接等同于未来预测失败。

主模型和弱耦合模型的预设有限状态对，在 8 s 内的最大可见差分别为 `8.856e-4`、`2.583e-5`，均未超过 `2e-2`。这两个状态对没有构成协议规定的未来信息不足反例；这不是整个状态集合稳健可恢复的证明。

## 3. 窗口长度与模型失配

20/50/100/200 ms 使用同一主线性真值、同一预测起点和干净嵌套观测。

| 历史长度 | 完整采样算子最小奇异值 | 积分 LS 隐藏初态误差 | 积分 LS 8 s 最大可见误差 |
| --- | ---: | ---: | ---: |
| 20 ms | 1.374289e-3 | 6.577e-6 | 1.097e-6 |
| 50 ms | 2.841396e-3 | 6.837e-6 | 1.131e-6 |
| 100 ms | 5.190002e-3 | 7.300e-6 | 1.190e-6 |
| 200 ms | 9.546759e-3 | 8.338e-6 | 1.310e-6 |

四种长度的精确采样 LS 隐藏恢复误差均小于 `1e-15`。更长窗口提高了这里的绝对采样灵敏度，但没有让固定插值积分法的偏差单调下降。100 ms 不是这个干净系统的最小必要长度。

刚度失配对照只把候选模型的一条边刚度从 0.12 改为 0.18，观测仍来自主线性真值。

| 初态方法 | 隐藏初态误差 | 3 s 可见最大误差 | 8 s 可见最大误差 |
| --- | ---: | ---: | ---: |
| 精确采样 LS | 6.315e-2 | 9.571e-3 | 1.122e-2 |
| 积分 LS | 6.337e-2 | 9.557e-3 | 1.124e-2 |

三者的未来误差都未达到 `1e-3`。两种估计吸收部分模型误差，未来最大误差甚至小于提供真实隐藏初态的对照，但并未消除失配。此结果支持单独研究模型失配与初始化之间的作用，不支持把本轮现象认定为 A15/A17 的已证实失败根因。

## 5. 完成范围与后续问题

实际调用为 54 次矩阵指数、36 次 SVD、38 次初态 LS、762 次独立力求值、93 段传播、168 次登记诊断、312 次物理检查 RHS 和 389,760 次积分 RHS。两组正弦对照的四种“对照×方法”均可解，共 18 段正弦积分、97,440 次 RK4 更新。真实数据读取、参数拟合、优化更新均为零。

阶段一证明了主参数下的可恢复实例，也保留了不能从算子满秩、条件数或隐藏误差单独推出未来结论的反例。后续能量约束初始化器应作为独立候选，与无约束 LS 在同一有限合成条件下比较隐藏恢复和可见未来；它的半径来源、判据和预算需要先冻结并单独审查。C(q)、势能及时间目标保持分离。此次结果不证明真实数据 100 ms 充分，不新增失稳漏判率，不打开 train/val/test，也不改变已归档结论。
