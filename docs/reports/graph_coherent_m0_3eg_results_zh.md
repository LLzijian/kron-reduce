# 图论粗化能否提升基础 M0-3EG：F2/F3 单 seed 研究节点报告

## 摘要

本轮只研究基础 `TransientEmfM0Model`（M0-3EG），不引入 GMD、DF、M2A 残差、神经网络或额外的 (P_m) ODE。问题是：能否从同步图、慢相干与数据质量出发，找到比固定七节点聚类更可靠的粗化，使基础 M0-3EG 的条件重积分优于直接辨识原始十机。

答案是：**现有证据不支持任何降阶表示优于直接十机 M0-3EG。** F3 训练数据只对机组对 ((1,2)) 给出跨数据源、响应、机械输入和图结构的一致支持，因此严格共识算法自动选择九节点，而不是强制七节点。九节点相对匹配坐标的十机投影平均 RMSE 仍差 2.32%，故障线路聚类 bootstrap 的 95% CI 跨越零。训练轨迹七节点在同一折上差 28.13%，且置信区间完全大于零。F2 曾观察到训练发现七节点的 4.18% 点改善，但区间仍跨零；F2/F3 的不一致进一步否定了“七节点普遍更优”的表述。

这一负结果不是算法失效。它明确区分了两件事：聚类确实能减少参数和共线性，但更好的条件数不必然带来更准确的闭环动力学；固定删除缺乏跨源一致性的簇内差模，会以结构偏差换取统计稳定性。当前数据支撑将图聚类作为诊断和保守正则化工具，但不支撑把七聚类作为精度创新点或严格低通滤波器。

## 1. 科学问题与证据边界

本报告回答四个具体问题：

1. 少量只有 9–17 个点的短轨迹是否主导了此前的训练分区？
2. high-order 与 dense 数据是否支持同一套相干机组关系？
3. 图论约束能否避免不可靠合并，并提高基础 M0-3EG 的重积分精度？
4. 七节点为何显著改善弱式设计矩阵条件数，却没有稳定改善闭环误差？

证据仅限 F2/F3、seed 324、validation-only。test 未读取。observed (P_m(t)) 是条件重积分上界，不是因果部署结果。所有分区均在验证误差计算前由训练数据冻结；验证只在每个既定表示内部选择基础 M0-3EG 的 ridge、(alpha)、(	au) 和应力阈值。

## 2. 第一性原理

### 2.1 线性化同步图

基础摆动骨架在平衡点附近写成

\[
M\ddot\delta+D\dot\delta+L_s\delta=\Delta P_m,
\qquad
L_s=B\operatorname{diag}\!\left(K\cos(B^\top\delta_{\rm eq})\right)B^\top.
\]

其中 (L_s) 是运行点相关的同步刚度拉普拉斯。广义特征问题

\[
L_s\phi_k=\lambda_k M\phi_k
\]

给出惯量加权的机电模态；小非零 (lambda_k) 对应慢相干方向。该构造比在原始节点编号上做欧氏聚类更接近摆动动力学。

### 2.2 almost-equitable partition 条件

令 (P) 为质量加权的簇一致投影。若簇一致子空间对线性化动力学精确不变，则

\[
(I-P)M^{-1}L_sP=0.
\]

本轮使用相对缺陷

\[
\varepsilon_{\rm AEP}
=\frac{\left\|(I-P)M^{-1}L_sP\right\|_F}
{\left\|M^{-1}L_s\right\|_F}
\]

衡量粗化对同步图邻接关系的破坏。AEP 约束控制的是线性化簇一致子空间是否近似闭合，并不自动保证大扰动非线性重积分精度。

### 2.3 输入一致性不可省略

即使两个节点在无输入模态上接近，如果其加速功率

\[
a_i(t)=\frac{\Delta P_{m,i}(t)}{m_i}
\]

明显不同，合并仍会强迫一个簇坐标同时解释两个不同输入。被删除的差模会被持续激励，不能视为可忽略的高频分量。因此本轮同时检查：

- (delta,omega) 响应距离；
- (M^{-1}\Delta P_m) 输入距离；
- 同步图 AEP 缺陷；
- high-order 与 dense 两个训练数据源的一致性。

### 2.4 保守的自适应粗化

对十机系统枚举三条互不相交的候选合并边。每个训练数据源、每个视角分别求最小代价匹配，并以 1000 次 case bootstrap 估计每条边的选择概率。只有同时满足以下条件的边才能合并：

1. 属于同步图最小 AEP 缺陷匹配；
2. 属于每个数据源的响应最优匹配；
3. 属于每个数据源的输入最优匹配；
4. 每个数据源和视角的 Wilson 95% 选择概率下界均大于 0.5。

最终分区取这些集合的严格交集。若数据源分歧，算法减少合并数，而不是为了得到七节点强制选择第三对。

## 3. 数据质量与系统一致性审计

### 3.1 短轨迹没有改变训练分区

在 F3 训练集上，将最小 valid length 依次设为 9、101、501、1001，并将相干窗口设为 1、5、10 s，训练轨迹分区始终为

\[
((0,7),(1,2),(3,6),(4),(5),(8),(9)).
\]

因此，“少量短轨迹改变了此前分区”这一假设被否定。短轨迹仍被本轮预声明质量门排除，以避免它们对阈值统计产生不必要影响，但它们不是此前七节点结果不稳定的主因。

### 3.2 两个数据源的相干关系不同

仅使用 high-order 训练轨迹，最优三对为

\[
(0,7),\ (1,2),\ (5,6).
\]

仅使用 dense 训练轨迹，最优三对为

\[
(1,2),\ (3,6),\ (4,5).
\]

同步图的最小 AEP 缺陷三对与 high-order 一致。bootstrap 显示 high-order 三对的选择概率约为 0.993–1.000；dense 对 ((1,2)) 与 ((3,6)) 为 1.000，而第三对存在不同竞争。机械输入视角同样只有 ((1,2)) 在两个数据源都稳定入选。

这证明的是**有效相干结构随数据源/运行区域变化**，尚不能直接证明 canonical 数据混入了不同物理参数。dense 轨迹更接近临界大扰动区，M0-3EG 的运行点线性图和单个节点暂态电势状态可能不足以描述其状态依赖相干关系。要声称“系统参数不同”，还需要分源参数同质性检验、似然比或层次模型证据。

### 3.3 严格共识只支持一对合并

图 AEP、high-order 响应、dense 响应、high-order 输入和 dense 输入的严格交集只有

\[
(1,2).
\]

因此主候选为九节点分区

\[
((1,2),(0),(3),(4),(5),(6),(7),(8),(9)).
\]

这不是人工指定九节点，而是“证据不足时不删除差模”的结果。

表中“相对改善”为 ((\mathrm{RMSE}_{10\to r}-\mathrm{RMSE}_{r})/\mathrm{RMSE}_{10\to r})。九节点均值略差且区间跨零；七节点均值明显更差且区间完全大于零。所有重积分成功，COI 与物理审计通过，(dt,dt/2,dt/4) 收敛，因此差异不是数值爆炸或积分器失稳造成的。

### 4.2 分数据源结果

| 数据源 | 9 节点原生 | 10→9 投影 | 方向 |
|---|---:|---:|---|
| high-order | 0.019562 | 0.019755 | 9 节点轻微更好 |
| dense | 0.515993 | 0.503500 | 9 节点更差 |

九节点在 high-order 上的轻微收益没有延伸到 dense。该现象与训练审计一致：同步图由 high-order 弱式锚点构造，因而更忠实于 high-order 的近线性相干结构，而非 dense 的大扰动非线性结构。

### 4.3 与 F2 的关系

此前 F2 训练发现七节点相对匹配坐标十机投影的点改善为 4.18%，但 fault-line bootstrap 95% CI 为

\[
[-0.008398,\ 0.000331],
\]

上界仍大于零，所以当时已经是 NOT_SUPPORTED。F3 同类七节点则显著更差。两折方向不一致表明 F2 的点收益不能被解释为稳定的系统级规律。

## 5. 为什么条件数更好却精度更差

七节点将弱式参数从 55 个降到 28 个，条件数从 25.25 降到 5.70。它确实减少了共线列和估计方差，但同时无条件删除三个簇内差模。对基础 M0-3EG 而言，每个簇只有一个 (delta_i,omega_i,q_i)；一旦被合并机组的输入、暂态电势或大扰动响应不同，模型没有状态可以承载这些差异。

因此总误差存在典型的偏差—方差权衡：

\[
\text{闭环误差}
=\text{参数估计方差}
+\text{结构截断偏差}
+\text{非线性运行点失配}.
\]

七节点显著降低第一项，却放大后两项。九节点只合并一对，结构偏差较小，但参数数目只减少 18.2%，条件数只改善约 5.1%，不足以超过十机基线。

从图信号角度，将簇内差模删除可被解释为一种投影，但不能无条件称作“低通滤波”。只有当被删除子空间同时对应较高广义特征值、受到很弱输入激励，并在目标运行域内保持快衰减时，低通解释才成立。当前第三对合并不满足跨源输入和响应一致性，因此“严格低通滤波器”仍是锁定声明。

## 6. 工程指标与物理意义

本轮采用的工程/物理指标包括：

- 广义机电特征值与 COI 零模计数；
- AEP 不变性缺陷；
- 跨源 (delta,omega) 相干距离；
- 加速功率输入一致性；
- 弱式设计矩阵条件数、有效秩和参数数；
- 闭环频率与边角差综合 RMSE；
- mean、median、pooled、P90、CVaR10；
- failure rate、COI 漂移与步长收敛；
- fault-line 聚类 bootstrap；
- 每个数据源不退化门。

这些指标分别覆盖模态、图结构、输入可约性、参数可辨识性、闭环精度和证据不确定性。任何单一指标都不能独立决定聚类优劣。

## 7. 学术定位

慢相干方法把电力系统区域划分与惯量加权慢特征空间联系起来；加权 almost-equitable partition 则给出簇一致子空间保持网络动力学的结构条件。二阶网络降阶文献进一步强调，应按节点输入—输出动力学相似性而不是纯拓扑距离聚类。本轮算法把这些原则转化为训练专用的同步图、响应、输入和数据源共识门，并用“减少合并数”处理证据冲突。

## 8. 可接受结论与下一步

### 8.1 当前可接受结论

- 短轨迹不是此前 F3 七节点分区的决定因素。
- 两个数据源支持不同的有效相干结构；只有 ((1,2)) 跨所有物理与数据视角稳定。
- 自适应九节点显著减少了强制七节点的截断风险，但没有超过直接十机 M0-3EG。
- 七节点可以改善条件数和压缩参数，却不能被表述为当前数据上的精度创新点。
- 现阶段基础 M0-3EG 的精度主线应保留原始十机；九节点可作为保守诊断/压缩消融。

### 8.2 后续最有信息量的研究

1. **状态依赖相干图：** 用多个训练运行点的 (L_s(\delta)) 或非线性切线算子评估大扰动相干性，避免只依赖平衡点同步图。
2. **分源同质性检验：** 在不读取 test 的条件下比较共享 ((D,K,\alpha,\tau)) 与分源参数模型，检验差异是运行域还是系统参数造成。
3. **保结构多分辨率模型：** 保留十机状态，在参数层使用图拉普拉斯正则、谱子空间或层次共享，而不是硬删除节点差模。
4. **输入感知的 Petrov–Galerkin/Kron 粗化：** 直接最小化目标输入—输出误差，并保持摆动方程结构；这比质量平均硬聚类更符合网络降阶理论。

这些方向在进入 test 或多 seed 之前仍应先做 train/validation 单 seed 预注册验证。
