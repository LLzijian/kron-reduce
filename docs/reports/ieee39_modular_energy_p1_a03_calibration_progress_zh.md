# P1-A03：受限读取与公平损失校准实现

日期：2026-08-31。范围：模型单元门之前的实现片段，不是 IEEE39 性能实验。

本轮已把“完整样本上的公平损失比较”接到真实模型求解器，而不再只有评价合同。
它仍不是完整五组执行器，尚不能结束 P1 科学审查。

## 已实现

1. **受限读取。** 请求必须包含完整、已登记的 F1 角色；未知 ID、混入其他角色、漏事件或
   请求锁定角色，会在打开 HDF5 前失败。只读取固定观测窗的角度、速度、清除时刻 Pm
   和平衡先验，不沿用会读入未来 Pm、标签和事件信息的旧完整事件接口。
2. **完整平衡目标。** 所有 fit 事件均进入 1/5/10 s 的角度与速度误差；按来源、线路、事件、
   视界和输出逐层等权。最终保存每个误差单元的权重，较长窗口或更多角度坐标不会自动
   挤压速度权重。尺度仅来自 fit，selection 和 internal audit 不能进入该校准入口。
3. **真实模型对照校准。** 两种损失使用相同模型起点、事件、尺度、物理参数组和求解预算，
   只改变权重。记忆端口按保持互易连接的方式缩放。原始模型不被修改。
4. **明确回退。** 预测失败、覆盖不全、非有限尺度、误差平方和溢出、超出参数边界或求解器
   失败均拒绝候选。即使误差下降，求解失败仍不能接受；失败时保留原参数、尺度和诊断记录。
5. **可检查的梯度。** 保存各误差单元对实际优化变量的梯度，与完整残差算出的总梯度及
   总目标有限差分对照，不能用绝对值之和代替向量相加。

## 不能由本轮结果推出的结论

- 没有运行新的 IEEE39 五组科学对照，没有读取锁定数据来选择方法或门槛。
- 当前校准变量是每个物理参数组的正缩放，不是全部系数重新辨识。零模块不会由缩放变成
  非零，因此本轮不能证明新模块已被发现或独立支持。
- 校准入口只使用 fit，不代表调用者提供的起始模型历史上也只用 fit 训练。该项在返回记录中
  明确为未证明；正式执行器必须从头拟合，并核验训练来源，不能复用旧 fit+selection 模型冒充。
- 两组共同改用了完整事件和三个视界，因此它们不是旧少量事件脚本的逐步重放。
- IEEE39 准确度改善、已识别频率和稳定证书均没有新增主张。
