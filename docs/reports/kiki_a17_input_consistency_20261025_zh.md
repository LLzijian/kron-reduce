# A17 历史输入一致性比较：保留基线

原 train 的有界比较、两项独立复核和 Astra 正式审核均给出 **REJECT / KEEP_BASELINE**。在三个固定 A06 模型、两种计算步长下，候选 C 相对旧初始化方案 I、保留基线 E 的十二个配对比较全部未通过；每个比较的七项条件均未通过。物理、数值、来源和执行完整性检查通过，全部 10,356 个计算范围完整闭合。这是该候选的有效负结果。

候选 C 把已观察到的 100 ms、11 个时刻的历史功率同时用于初态估计和历史闭环回放，再从共同观察起点预测未来。三个模型参数始终固定，训练与优化更新均为 0。I 使用 A15 保存的旧初始化结果；E 使用 A09/A10 保存的基线结果，没有补算对照轨迹。本轮证据不支持采用 C 替换 E，也不支持把输入处理的修正直接转为新的联合训练。

复核期间修复了两处只读检查工具的格式错误：外部完成检查曾读取错字段层级，独立指标核验器曾把模型说明字段当成数组。原始 FAIL、修订审核及 250 项通过检查均保留；真实实验没有重跑，原结果没有改写。运行前 509 项统一工程检查和当时精确提交的仓库检查同样保留。

本轮只评价原 train 上最多 3 秒的轨迹，没有读取标签、internal val 或 source val/test，也没有评价新的 8 秒失稳结果。**零漏判目标尚未实现，本轮不产生新的漏判率。** 现有基线继续保留，默认初始化、模型晋升和预测交付均不由本轮开启。
