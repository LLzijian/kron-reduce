# R20/R21 完整 TASK3 配对结果

本轮用 `kiki_ieee39_v1` 十机数据和 TASK3 冻结名单比较 R20 与 R21。两组共享 A06 seed324 第 240 步动力学骨架、逐机参数初值、100 ms 输入合同、train 尺度和评分规则。train 346 例用于拟合，val 107 例用于选择检查点，test 76 例用于冻结后的比较。

R20 学习十个端口幅值和十个时间常数。R21 多学习一个共享刚度系数。训练前校核了对数刚度经三次历史初始化和未来预测的梯度，自动微分与中心差分的相对误差为 (3.87\times10^{-7})。

## 配对结果

R21 在完整 val 上的 1 秒／3 秒归一化 MSE 更低。按 TASK3 固定尺度，val 的 95 个八秒可评分事件上，事件平均归一化 RMSE 从 R20 的 0.244 升至 R21 的 0.291。val 的真实失稳样本中，R20 判出 11/12 例，R21 判出 8/12 例，其余未决。

两组均完成完整 test。67 个八秒可评分事件的事件平均归一化 RMSE 从 R20 的 3.103 降至 R21 的 2.796，合并所有评分点计算的归一化 RMSE 从 6.215 降至 5.176。8 秒稳定性在可判定样本上的准确率为 R20 的 58/73（79.45%）和 R21 的 55/72（76.39%）。稳定误报从 15 例增至 17 例，未决从 3 例增至 4 例。默认基线保留。
