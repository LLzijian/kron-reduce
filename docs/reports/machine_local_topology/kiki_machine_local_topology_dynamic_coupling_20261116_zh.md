# TASK3 完整 train 共同动态耦合诊断

固定共同动态耦合在两个阻尼对照中均降低了稳定组动量残差，同时提高了失稳组残差。完整 train 346 例通过工程门，全部样本与失稳样本的科学门未通过。按执行协议，本轮停在路径诊断。

## 比较条件

使用原 T0M1 和同参数的逐机功角阻尼。耦合恢复速率为 \(1\,\mathrm{s}^{-1}\)，共用实测功角驱动的 \(c\) 路径。各阻尼模型用自己的 100 ms 历史方程估计因果记忆起报，再配对比较加修正前后的动量残差。自由记忆投影使用同一列空间。保留 98,341 个实测区间，起报后参与评分的区间为 94,881 个。[执行协议](../../protocols/kiki_machine_local_topology_dynamic_coupling_v1_zh.md) · [合成结果](machine_local_topology_dynamic_coupling_20261116_zh.md)
