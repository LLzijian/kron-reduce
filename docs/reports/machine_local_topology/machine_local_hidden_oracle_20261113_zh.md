# 逐机隐状态：初始化与动力学误差的完整合成对照

日期：2026-11-13。64 个固定已知真值事件、四组对照、全部 train 32 / val 16 / test 16 已完成。真值、数值和匹配条件下的恢复门全部通过，运行耗时 288.2 秒，无数值失败、未决或未覆盖样本，保持原部署基线。

本轮区分了两个机制：在本次 64 例固定正弦 L10 事件中，动力学匹配时，100 ms 历史能恢复隐藏初态；可见刚度增加 10% 后，因果初始化会用偏离真值的隐藏状态吸收部分动力学误差。该补偿在三秒平均误差上增加偏差，对八秒误差的作用则随样本变化。因此，降低历史残差与恢复正确动力学需要分别评价。

## 固定对照与口径

真值模型为十机正弦骨架和每机一个隐状态。新相位生成全部 64 个事件，每个划分包含等量失稳和稳定样本。没有拟合参数或添加噪声，没有读取真实数据。所有事件都有相同的 100 ms 历史和完整八秒目标。四组共享可见预测起点；oracle 对照直接使用真值的隐藏预测起点，GN 对照使用三次历史求解后的隐藏末态。失配只把全部可见刚度乘以 1.10。

三秒平均误差在三个划分中都因失配下的 GN 初态进一步增大，但并非每个事件都如此。八秒时，失配 GN 对照在 train 和 val 上的合并归一化 RMSE 略小于失配 oracle，对 test 则更大。初态对错误动力学的补偿有利有弊，不能用未来误差的单向变化判定隐藏状态是否正确。

这组证据支持下一步先检验可见骨架的单因素校准，并保留相同的因果初始化器作为对照。它不把真实 TASK3 的误差直接归因为刚度失配，也不据已曝光 test 调参。后续真实训练继续使用完整 train 346 / val 107 / test 76。
