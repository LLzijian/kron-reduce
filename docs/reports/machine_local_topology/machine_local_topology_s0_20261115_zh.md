# 逐机耦合与记忆隐变量 S0 合成结果

在四组已知共享系数的系统上，从 100 ms 清洁历史估计事件的耦合修正与记忆初态，随后在 GPU 上自由预测 8 秒。四组各有 train 6、val 3、test 3，全部完成两档步长评估。T1 的边刚度按两个端点的隐变量乘积调整，每个事件内保持固定。M1 的十个逐机记忆状态随方程演化。

四组已知隐态对照通过。真值历史起点的瞬时能量恒等式最大归一化残差为 (2.64\times10^{-16})。静止 T1M0 的历史 Jacobian 秩为 0/9，等衰减率 T0M1 为 9/10，均符合解析预期。
