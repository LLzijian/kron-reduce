## 先验和半径各改变了什么

- **硬半径下，单独衰减先验维持了全部 453 例的原分类。** `val` 稳定误差只变动 −0.00007，`train` 见证和 `val` 峰值欠估分别增加 0.00808 和 0.01057 rad/s。在同为软 (2R\) 的对照中，衰减先验使两项速度残差分别下降 0.29112 和 0.21316 rad/s，同时使 `val` 稳定误差由 0.26284 增到 0.31095，误报由 1 个增到 2 个，未决由 0 个增到 1 个。这些是冻结模型的配对差异。硬球到软球同时改变半径、坐标映射及先验所作用的坐标。
- **固定先验软 (1.8R\) 和 (2R\) 已达到检出与误报门，见证分别改善 16.50% 和 16.12%。** (1.8R\) 的稳定 NRMSE 在新检出 12/12 的组内最低，距门槛仍差 0.02017。(2R\) 的 `val` 首摆欠估更小，为 1.01328 rad/s。两档步长均得到同样的验收结论。
- **P85 与 P90 减少了对低残差历史的改动，未通过连续指标。** 两个阈值分别为 0.220826 和 0.250502。`val` 后验历史 NRMSE 中位数分别为 0.06364 和 0.06818（旧自适应 GN 为 0.02146）。两组均重新检出 `expansion_0189`，原来检出的 `pilot_0366` 转为未决。峰值欠估下降 17.91% 和 17.55%，见证残差中位数分别升高 1.39% 和 2.50%。
- `train` 中 `pilot_0280` 与 `pilot_0300` 在保持硬 (R\) 的单独衰减方案中均仍漏判。固定先验软 (2R\) 已能检出 `pilot_0280`，固定先验软 (1.4R\) 已能检出 `pilot_0300`。本轮两次恢复发生在不同半径配置下。
