固定 M1 第 0 步方程时，自适应 GN 将完整 `val` 的失稳检出从 11/12 提到 12/12，将 33 个 `train` 见证的带符号分离速度残差中位数降低 27.53%。`val` 稳定样本的 8 秒归一化 RMSE 从 0.22020 升至 0.31095，超过原 0.25 门槛。这组证据支持把初始化作为直接作用于失稳预测的因素，并优先用固定方程的配对对照定位稳定精度的代价。[协议](../../protocols/unified_first_swing_probes_v2_zh.md) · [核验回执](../unified_first_swing_probes_v2_20261119_evidence.json)

## 下一轮的判读顺序

优先做冻结方程下的初始化拆分，加上固定先验配软半径、残差自适应先验配原半径两组。在可比参数化内分别估计先验衰减和半径的作用，继续用 `val` 稳定 8 秒误差 0.25 作为原门槛，同时记录 33 个见证和 `val` 的连续峰值差。损失重构以新的轨迹与首摆梯度重新定标。这一顺序同时承接了 B 的直接失稳增益和 A 的局部阻尼方向差异。
