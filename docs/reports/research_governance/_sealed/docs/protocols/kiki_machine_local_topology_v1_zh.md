# TASK3 逐机记忆与事件耦合修正对照

比较固定耦合的逐机记忆方程 T0M1 和随事件调整耦合的 T1M1。两组复用 A06 seed 324、第 240 步骨架的惯量、边刚度形状和可见阻尼，并以原端口 Frobenius 范数除以功率投影 Frobenius 范数初始化每机端口强度。十机时间常数在 0.06 到 1.6 秒之间按几何级数初始化。两组分别学习同样的 22 个共享系数，包含两个正值刚度与阻尼尺度、十个端口强度和十个时间常数。刚度、阻尼尺度均从 1 开始，约束在 [0.5, 2]。T1M1 的节点修正每个事件由历史估计，预测期间恒定。边刚度为基础刚度乘以两个节点修正和的指数。无源记忆端口和能量核算沿用合成验证方程。

以冻结的 11 点、100 ms 功角和转速历史，以及第 11 点的机械功率偏差初始化。每个模型使用五次 Gauss–Newton 后按球投影，两组共用记忆半径 \(R_z=3\sqrt{\sum_i M_i s_{v,i}^2}\)，其中 \(s_{v,i}\) 是完整 train 的 COI 历史速度 RMS，下限 \(10^{-5}\) rad/s。边耦合节点修正的零和坐标半径为 0.6。半径限制历史起点隐藏状态，随后按方程传播。增广最小二乘对每次提议的新隐态加权，令平均归一化历史残差平方和加上 \(10^{-6}(\|z/R_z\|^2+\|a/0.6\|^2)\)，避免弱激励时未定的求解方向。记录的最小奇异值来自增广方程。历史尺度、轨迹训练尺度和半径均从 train 一次确定。初始化只访问历史及机械输入，预测重置可见末点。

训练使用固定 TASK3 train 的 346 例，每次更新累积全部样本的梯度，批量至多 64。按已有实现等权计算预测起点后的 1 秒和 3 秒归一化 MSE，短记录使用实际可用点数。用 5 ms RK4，Adam 学习率 0.006，梯度裁剪范数 1。每组最多 72 次更新，初始、第 12、24、36、48、60、72 步完整评价 val 107 例。36 步之后，两组连续三次完整检查均无有效进步则提前结束。有效进步指跨到更优轨迹门层、覆盖或错判计数改善，或在相同计数下轨迹分数降低至少 0.1%。超出轨迹上限但分数有限时只按轨迹分数的相对改善触发续训。数值失败停止该组拟合，保留其已评价检查点。

val 采用完整 8 秒双步长推理。轨迹分数采用冻结 TASK3 六项口径，门槛为 0.50（R20 既存 val 分数为 0.4349）。门内检查点依次最小化无有效判定数、未判对事件数、轨迹分数和步数。门外的有限分数按轨迹分数、无有效判定数、未判对事件数和步数排序。分数无效的检查点排在最后。冻结的两个选中模型完整评分，不以轨迹门槛判决省略 test。

正式评分覆盖固定名单 train 346、val 107 和 test 76。两档 RK4 步长为 2.5 和 1.25 ms，GPU float64，评价批量至多 32。批次数值失败后逐例隔离一次。真实标签、稳定性阈值和评分尺度沿用 TASK3。test 仅在两个模型、权重数组、预处理、输入和评分代码全部冻结后单独读取一次。报告全部事件覆盖、稳定性准确率、TP/TN/FP/FN、失稳召回率、漏判率、稳定误报率、未决和数值失败，以及完整轨迹误差。达到准确率目标须在完整 test 判定 76/76，且至少判对 69 例。部署决定保持 `KEEP_BASELINE`。

前置验证以冻结的[混合激励合成证据](../reports/machine_local_topology_transfer_20261115_zh.md)、实单位合成接口测试及精确实现审查登记。接口测试涵盖静止历史、实单位梯度与有限差分、冻结重载和 64 例、3 秒目标的 GPU 反传显存检查。完整名单的读取顺序、缓存哈希、算子预算和单次运行约束由每阶段计划定义。
