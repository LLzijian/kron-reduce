# 聚类、主数据源与工程治理决策

日期：2026-10-23。范围：本项目工程设置及数据适用性审计；不启动新模型训练。

## 决策

后续真实数据研究统一使用 `kiki_ieee39_v1`，保留十机空间分辨率，暂停聚类
要求。动态阶数、历史隐状态、物理模块删除与能量结构仍是研究目标。合成真值
继续用于验证结构与稳定算法，旧 canonical 数据保留为显式历史复现来源。

## 聚类证据

当前 canonical IEEE39 聚类审计选择完整十机分辨率：AFSD v5 为
`FULL_RESOLUTION_REQUIRED`，v6 为 `CLUSTER_NOT_BETTER`，高阶聚类验证为
`VALIDATED_REFUSAL`、rank 10。较早的三机等值作为特定任务的历史基线保留。
这些结果支持暂停当前主线的空间聚类要求；它们没有证明所有系统或所有激励
都不能聚类，也没有构成对 kiki 数据的新聚类检验。

证据入口：`docs/structure_discovery_roadmap.md`、
`configs/workflows/m0_afsd_v6_full_model_subset_validation.json`、
`docs/research/ieee39_modular_energy_paper_master_plan_zh.md`。

## 数据比较

| 项目 | 原 canonical | 登记 kiki 数据 |
|---|---|---|
| 接受事件 | 315，稳定264、失稳51 | 591，稳定497、失稳94 |
| 数据生成 | 高阶100例与近临界215例的历史合并 | 可追溯 ANDES 生成，两个互补故障母线批次 |
| 动态状态 | 100例有扩展通道，其余共享基础通道 | 全部保留220维动态状态及代数量 |
| 系统一致性 | 保留来源、校准和排除记录 | 检查每例故障后恢复同一参数与开关签名 |
| 划分 | 已登记按线路分组的多组划分 | 原 train 369、val 117、test 105，跨批次母线/线路隔离 |
| 科学用途 | 历史结果复现和来源审计 | 统一系统动力学、历史初始化与因果闭包的主数据 |

kiki 对当前目标更合适，依据是可追溯生成、完整状态、恢复后的同一系统和
跨批次分组检查。两套数据上的模型分数不参与数据源选择，也不作为配对提升。
原 canonical 有38条故障线路并已去重，不能把不同采样计划概括为全面覆盖
优劣。kiki 目前仍是单运行点、恢复拓扑的数据，不能直接承担 Level 6 全部证据。

本次直接核对索引唯一性、全体事件ID、HDF5形状、物理扰动元数据唯一性、
跨来源母线/线路隔离、系统签名与源文件 SHA-256；有限性、控制器恢复与
物理/数值结局检查采用源数据已有QA，未重新计算模型或读取 test 轨迹数组。
机器摘要：`docs/reports/research_governance/data_source_audit_20261023.json`；可复查计算见同名 notebook。

## test 独立性

TASK3 的 `paper/campaign2_final/test_exposure_notice.md` 记录：2026-09-27
已使用其登记的76个可评估 test 事件，旧 Pilot test 也有使用记录。该次76例
来自 expansion 与额外 holdout 补充，不能等同为本次登记原 test 的105例。
保守执行方式是整个既有池不再提供新的独立确认资格，不凭旧状态文件认定新鲜。

kiki 的 `configs/test_release_v1.json` 另记录旧 canonical 315事件已被历史
分析使用，也不提供新的独立确认资格。本次将这两份来源记录存为只读副本。
以后正式 test 必须来自新登记的独立 kiki 数据，先冻结模型、规则与访问账本，
再通过原有权限执行。数据迁移本身不授权重开旧 test。

## 已实施的工程设置

- `configs/research_policy.json` 为新研究统一入口；旧 canonical 执行需要
  `--historical-reproduction`，并校验原配置和工作流哈希。
- 真实数据入口强制 kiki、十机分辨率、声明输入窗口，阻止旧 test 性能读取；
  开跑前校验源数据哈希。源 train 白名单按真实ID复核，不能伪造角色打开test。
- 每个工作流持有跨进程执行锁，尝试ID避免碰撞，失败保留异常与调用记录。
  有科学门槛失败时保留基线；不自动训练到达标，不自动修改门槛。
- GitHub CI 用合成样本检查政策、因果性、稳定算法和工程退化，保存环境版本。
  原始数据、完整结果目录、压缩包和本地环境留在本机，Git保存代码和来源清单。

自动检查与失败阻断已经接入；常驻自主科研调度和模型自动晋级不属于本次部署。
后续修改按 `codex/` 分支、检查、审查和集成推进，科学模型晋级仍遵守登记验收。
