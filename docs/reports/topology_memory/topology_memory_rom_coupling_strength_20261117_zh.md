# 耦合强度变化的辨识与初值估计

改用与支路耦合强度直接相关的坐标估计初值后，合成 val 正确选出了固定耦合、仅整体变化、仅各支路分别变化和两者并存四种结构。两种变化并存时，200 ms 动量误差已达标，支路耦合隐状态的最大相对误差仍为 38.2%，超出 20% 的验收线。这一项使修正对照未通过完整科学验收。

## 初值求解和方程误差

本轮把全部支路乘同一个倍率称为耦合强度整体变化，把不同支路使用不同倍率称为各支路耦合强度分别变化。两种变化在历史起点的对数倍率均方根均为 0.08。每种真值含 24 组配对激励，完整 train 24、val 12、test 12。首轮比较五种真值与四个候选。修正轮重算五种真值下含支路变化的两个候选，固定耦合和仅整体变化的候选引用首轮经过哈希核验的评分。两轮均采用干净的 100 ms 历史、已知方程系数和五次 Gauss–Newton 更新，拟合次数为零。

使用真实起报状态时，正确结构在仅支路变化、两种变化并存两组 val 的最大归一化动量误差分别为 \(1.84\times10^{-11}\) 和 \(2.44\times10^{-11}\)。表中比较两种因果初值方法。动量误差是起报后首 200 ms 的逐机动量增量归一化 RMSE，在 val 全部 12 例和两档积分步长中取最大值。隐状态误差也取两档步长、历史起点及起报点的 val 最大值。

| 合成真值 | 原方法动量误差 | 修正后动量误差 | 原方法支路耦合隐状态误差 | 修正后隐状态误差 |
| --- | ---: | ---: | ---: | ---: |
| 仅各支路耦合强度分别变化 | 4.15e−4 | 4.92e−5 | 22.9% | 0.905% |
| 整体和各支路均变化 | 4.02e−3 | 4.49e−5 | 232.5% | 38.2% |

修正方法按支路耦合对数倍率对应的坐标计算更新，再转换回原隐状态并施加联合半径约束。首轮在仅整体变化真值中，允许两种变化的对照有一例 val 的双步长轨迹差为 \(1.72\times10^{-5}\)，超出 \(10^{-5}\) 数值门。修正后同一例降至 \(1.19\times10^{-7}\)。

两种变化并存时，val 中支路隐状态误差最大的一例 `transfer-26`，100 ms 历史的归一化 RMSE 约为 \(2.01\times10^{-7}\)，历史起点的联合耦合隐状态范数约为 0.251，低于半径 0.6。该例的历史轨迹已拟合得很接近，支路隐状态仍有明显偏差。现有结果无法区分五次更新的收敛程度和该事件在 100 ms 内的可辨识程度。38.2% 是支路耦合隐状态的相对误差。
