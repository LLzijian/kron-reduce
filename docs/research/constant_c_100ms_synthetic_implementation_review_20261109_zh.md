## 审核结论

完整采样映射、积分卷积及缩放、W_c/T 与离散 Gram 比较、含噪首末点、历史闭环和可见重置均符合协议。alias 与 hidden_null 分别检验未来相关混叠和未来无关隐藏方向；人工积分右端不冒称 ODE 观测。有限噪声状态对使用两倍未来容差判定不可同时准确预测，正弦有限病例不作全局可辨声明。

运行前发现的 RK4 浮点时钟问题已关闭：固定传入 `nominal_step*(1+1e-10)`，调用前逐区间断言 8/16 子步；实际步长仍为区间宽度除以对应整数。日志区分历史、未来、truth、方法和步长；返回值先保存，再写 returned 记录。矩阵生成显式使用 P，模型失配的右端变化与观测噪声分开命名。

静态调用树对应全局上限：expm 54、SVD 36、LS 38、独立力求值 762、probe 168、rollout 93、physical_rhs 312、integration_rhs 389,760。probe 包含计划列明的包装操作，不是互斥底层数值原语总数。各 scope cap 独立，不转移预算。

正弦未决分支已明确：令 a 为两个病例中 resolved 的方法数，实际积分 RHS 必须等于 `78720+77760*a`，路径段数为 `2+4*a`，并与四倍时钟记录的 RK4 更新数一致。未决方法保留分解和状态，不传播替代初态。V 检验注册分支和数值有效性，恢复与 3/8 s 未来误差分别判定；不要求所有候选达到科学误差阈值。

专用入口核对政策、计划、审核、实现与实际加载模块路径/SHA及依赖版本，共享 Git common directory 排他消费一次授权。失败和中断保持已消费，返回数组和可用失败中间量保留；通用 runner 拒绝该执行模式。

本审查只读代码、协议、计划和已有工程记录，并计算文件哈希；没有构造模型、调用 expm/SVD/LS/RHS、生成轨迹或读取真实数组。先前 13 项测试日志已核对，SHA 为 `f27d5fad44e9dc3f21cdf11c5a28f018fae0ad15269a093bc791944733c4cd60`。最终 12 项门禁专测、此前 4 项 runner 测试、Ruff、harness audit 及只读运行环境预检通过由协调者和工程审查者报告，本审查没有重跑这些检查。

1. 本收据、计划、协议及全部绑定进入同一干净提交，该准确提交已推送且适用 CI 通过；运行环境守卫通过。
