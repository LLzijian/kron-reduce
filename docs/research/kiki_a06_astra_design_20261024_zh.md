# A06：从完整已存模型出发，检验固定预算的共同微调

日期：2026-10-24。核心设计与科学判断：Astra Ultra。用户已要求继续改进算法并执行新的研究，目标是降低失稳漏判至 0。本稿把该目标具体化为一个固定、有限的 A06 比较；不承诺必然达到 0，不重新启用 A04 或 A05，不允许依据 val 结果反复追加训练。

**A06 保留 A05 J 的全部结构与参数，用重新初始化的 Adam 共同微调。** 三个 seed 各运行一条 240 次新增更新的训练路径，共 3 次新拟合、720 次新更新；第 80 次更新保存诊断检查点，第 240 次更新是唯一主终点。全部训练完成并封存后才读取本轮 val 轨迹并评分，任何中途结果都不改变训练预算和主终点。

## 1. 已存预测指出需要改进的是动力学幅值和时序

本次设计依据 [A05 科学复核](kiki_a05_astra_result_review_20261024_zh.md)及不可变收尾 run `paper_kiki_a05_closeout-closeout-20261023T163350182759Z-26c29376-878bf661`。其工件清单 SHA256 为 `2c31bdff0f58691b65c2ad76d62a1771fa467224a4a06f12e4390a455da36280`。这里只读该 run 的评分 JSON、参数和 `stability_paths.npz`，没有补算模型预测或读取原始轨迹。

冻结的失稳判据要求：角度最大差超过 π、最大惯量中心相对转速超过 0.02 pu，且二者同时连续满足 5 个 10 ms 采样点。五个共同漏判事件在三个 J seed 中均未满足这一条件。已存 JSON 的拼接路径最大角差约为 7.00–7.52 rad，已经超过 π；直接从保存的未来状态数组复算，所有未来点的最大相对转速均低于 0.02 pu。

|---|---:|---:|
| expansion_0008，Line_12 | 0.013762–0.013762 | 0.0000494–0.0000583 |
| expansion_0118，Line_37 | 0.014828–0.015669 | 0.0000504–0.0000645 |

这里的“未来”是 100 ms 预测起点至其后 8 s，包含起点。计算使用保存的相对转速、质量与同步角频率：

\[
s_i(t)=\max_j\left|v_{ij}(t)-\frac{\sum_km_kv_{ik}(t)}{\sum_km_k}\right|/\omega_s.
\]

五个事件乘三个 seed 的未来超速点数均为 0。`expansion_0120` 在既有 JSON 中的全路径最大转速为 0.022634 pu，来自拼接的历史部分；它不能被当作未来预测已经达到转速条件。NPZ 没有保存完整历史与平衡角，因此本次不重建绝对角差的逐点时序，只引用已存分类 JSON 的角差峰值。五个事件的 `window_settled` 均为 false。

证据支持的描述是：**这些模型预测了大角位移，随后转速衰减，没有形成固定判据要求的持续高速分离。** 这没有证明是阻尼偏大、隐状态不足或机械功率闭包错误；这些机制需要进一步区分。降低转速阈值、改成只看角差或将“未收敛”直接判作失稳，会改变任务，本轮不采用。

A05 J 在预算末端的 train 损失仍下降，为先研究优化预算提供了具体依据，但不保证增加更新会改善 val。A06 因而先控制训练程序，不增加网络容量或更换损失。

## 2. 保留方程、数据和目标

保留十节点正弦恢复力与两维结构化记忆：

\[
\dot q=v,\qquad
M\dot v=P\{u-B[k\odot(\sin B^T(q+\bar\delta)-\sin B^T\bar\delta)]-Dv-Gz\},
\qquad \dot z=G^Tv+(J-R)z.
\]

参数化仍为 \(k=\operatorname{softplus}(a_k)\)、\(D=Q\operatorname{diag}(\operatorname{softplus}(a_d))Q^T\)、\(G=QW\)、\(J=(A-A^T)/2\)、\(R=\operatorname{diag}(\operatorname{softplus}(a_R)+10^{-5})\)。因此原储能关系 \(\dot H=v^Tu-v^TDv-z^TRz\) 保留；这仍是拟合方程的结构，不是实际系统的稳定域证书。

使用原 source train 的冻结内部 train／val 分配：258 个合格 train、88 个合格 val；原分配数 268／101 继续完整报告。输入保持 100 ms 的 11 个真实观测点，编码器使用第 0／5／10 点及原登记特征；预测中的机械功率保持 `Pm[10]`，不读取未来 Pm。标签、故障线路、来源和事件结果均不进入模型特征或训练权重。

损失不变：

\[
L=\sum_{i\in train}w_i\frac{m_{i,1s}+m_{i,3s}}2
 +10^{-4}\operatorname{mean}(E^2),\qquad
w_i=\frac1{S L_{s(i)}N_{s(i)\ell(i)}}.
\]

训练使用真实可用目标点、原 train 归一化尺度、相同事件权重、float64、全批量、学习率 0.01、完整梯度范数上限 10、10 ms RK4；历史附加损失权重为 0。原始 source val／test 继续关闭。所有数值、物理和失稳阈值均与 A05 相同。

## 3. 从完整检查点恢复，明确重新初始化优化器

三个起点分别绑定 A05 J 的最终模型，不再运行 NNLS，也不重新随机初始化记忆：

| seed | A05 J 的 model.npz SHA256 |
|---|---|
| 324 | `c81e4722a5bf6fb9514a6809f3fcd63fdfa5e651fa5ddeac64c329a043364e95` |
| 325 | `a54b74e6fef678d6b909848667c4907f9344506553073c7a5152ee5f272947a2` |
| 326 | `0a2df962d7842ab9cc71eed1ff6b87f354fa99ce7e3672aafebbe0822ca56f0c` |

入口 `full_start` 恰好接收九个数组：`mass、edge_stiffness、damping、coupling、latent_skew、latent_dissipation、encoder、feature_scale、target_scale`。它与 `paired_start`、`freeze_backbone=True` 互斥。恢复方法固定为：

\[
d=\operatorname{diag}(Q^TDQ),\quad W=Q^TG,\quad A=J,\quad
a_k=\operatorname{softplus}^{-1}(k),\quad
a_d=\operatorname{softplus}^{-1}(d),\quad
a_R=\operatorname{softplus}^{-1}(\operatorname{diag}(R)-10^{-5}).
\]

反函数采用稳定计算并匹配原 softplus 的线性分支。逐项检查形状、有限性、正值及可表示性；回代刚度的二范数误差、各矩阵的 Frobenius 范数误差和编码器误差均不超过 `1e-12`。质量须逐项完全相同；两种尺度由相同 train 口径重算核验，绝对误差不超过 `1e-12`、相对容差为 0，并实际复用存值。

A05 没有保存 Adam 末态，也没有保存原始 skew 参数中的全部冗余对称分量。A06 取反对称代表 \(A=J\)，将 Adam 一阶、二阶矩及步数全部重新置零。**本轮是从同一物理模型出发的 fresh-Adam 微调，不是旧优化器的精确续训。** 这一区分不改变零步模型方程，但影响随后的优化路径。80 与 240 的比较回答同一重启路径中的新增更新量；与已有 J 零新增更新的比较同时包含重启优化器后实施微调这一训练干预。

每次更新记录完整损失、分量、参数块梯度范数、裁剪及已更新步数，全部 238 个已存标量参数共同更新。新检查点同时保存原始参数与 Adam 状态，以便未来另行登记的实验准确恢复；当前授权不会因为保存了状态而自动延长。

## 4. 固定执行顺序与预算

1. 核验源 run、九数组、源训练配置、输入合同、分配与代码哈希，冻结既有 J 的评分为零新增更新参照。已有 val 摘要不进入优化器。只加载本轮 train 轨迹。
2. 每个 seed 预留 240 次更新，执行一条共同微调路径。第 80 与第 240 次更新完成后分别深拷贝并保存模型、实际步数、当时的完整日志及 Adam 状态。第 80 点不重新开启优化器，不是第二次拟合。
3. 三条路径全部结束后，封存全部已有检查点及训练记录。成功路径必须共 720 次新更新、6 个计划检查点；任何失败保留已完成步数及工件，失败槽不得重试或补 seed。
4. 此后才加载本轮 val，按固定计划评价两个检查点的 train／val 1／3 s 轨迹及 val 数值精化。冻结模型与轨迹证据后读取标签，完成分组贡献及 8 s 失稳诊断。80 点只解释路径，240 点是唯一科学接受终点。
5. 完整报告原分配未覆盖事件、评分失败、数值未决及拒绝；不做结果驱动的额外积分、重新评分或阈值修改。

训练积分预算为 `53,803,440` 个 RK4 事件步、`215,213,760` 次右端项事件求值；登记前由冻结 train 的真实目标点数复核。它对应 3×240 次新增更新，不包含保存快照的复制开销。历史 A04 的 960 次、A05 的 480 次优化更新继续披露，不混入本轮新增预算或当作独立重复实验。

## 5. 验收与停止规则

主比较以每个 seed 的 A05 J 已存结果为参照，固定使用 A06 第 240 次新增更新后的模型。所有 seed 都必须满足：

- val 主归一化 RMSE 不高于对应 J；完整 3 s 共同队列的归一化 RMSE 不超过对应 J 的 1.05 倍。
- FN 和 FP 均不增加，88 个合格 val 全部有有效判定，其中失稳 14 个、稳定 74 个；无数值未决或开发评价拒绝。
- 末端全部轨迹与 8 s 数值检查通过，精确检查点重放通过，批量／逐事件最大归一化差不超过 `1e-10`。其他门槛保持：轨迹精化 `1e-5`、8 s 精化 `1e-3`、LOS 决策一致且触发差不超过 20 ms、能量恒等式 `1e-8`、COI `1e-10`。
- 三次拟合和全部预算记录完整，三个主终点对应实际 240 次新增更新，源与产物哈希一致。仅有一个保存成功的 240 检查点不能抵消该拟合的其他完整性失败。

接受状态固定如下：全部上述条件通过且三个 seed 的 FN＝FP＝0，记 `ACCEPT`，名称必须是“合格内部 val 上的零漏判”。若尚未达到零，但三个 seed 的 FN 都严格减少且上述条件全部通过，记 `RETRY`，表示有继续研究的证据；它不触发重试、追加拟合或循环训练。其他情况记 `REJECT`。三种状态均为 `KEEP_BASELINE`，不晋升、不开放部署预测。

主归一化 RMSE、完整 3 s 归一化 RMSE、标签组的同总体分母平方误差贡献以及 8 s 分类分别报告。80 点的失败保留且不用于改选主终点；结构实现、输入越权或工件完整性错误须停止有关执行并保留证据。非有限训练失败消耗该拟合槽，不追加预算。不会因目标“降到 0”更改 `automatic_training_until_pass=false`。

原分配 val 中的 27 个失稳样本，仍只有 14 个满足本输入合同，覆盖率 `14/27=51.85%`。即使合格集合达到零漏判，也不能称为全部 27 个样本或未来数据上的零漏判。三 seed 使用同一事件集合，不构成独立风险确认。独立注册数据、既有 test 门槛及稳定域证书要求继续有效。

## 6. 实现接口与验证要求

`fit_nonlinear_model` 新增 `full_start=None、checkpoint_steps=()、checkpoint_callback=None`，原默认路径及 A05 的 `paired_start` 路径保持语义。回调签名为 `checkpoint_callback(step, model_snapshot, training_state)`，只在预定更新完成后调用。模型快照日志中的 `actual_optimizer_steps` 和 `final_checkpoint_optimizer_step` 为实际步数，`planned_optimizer_steps` 单独记录 240。

`training_state` 使用可直接保存为 NPZ 的独立数组：每个 `raw／port／skew／decay／encoder` 参数对应 `parameter__{name}`、`adam_exp_avg__{name}`、`adam_exp_avg_sq__{name}`、`adam_step__{name}`，另存优化器超参数及实际、计划步数。后续训练不能修改已交付快照，回调修改自己的副本也不能影响继续优化。

运行前用合成数据验证：全量起点和物理回代、互斥参数、尺度拒绝、无 NNLS／记忆随机重置、更新后保存顺序、80／240 实际步数、独立深拷贝、Adam 矩与步数、默认路径回归及失败保留。真实预检查只核验已存参数和授权；新的真实拟合由绑定 A06 授权、固定配置与不可变新 run 的工作流执行。
