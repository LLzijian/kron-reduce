## 2. 真实可用段已经提供规则证据

三个 seed、两个步长都对应同一批 21 个真实正触发事件，且没有历史已触发。首触发发生在预测起点之后 0.03–1.61 s，均在该事件的真实可用终点以内；真实正余量范围为约 0.00228383–0.06939505，并非浮点零附近的阈值翻转。

六组路径共同未保留同样的 17 个事件，涉及两个来源、12 条不同物理线路。三个 seed 在细步长上的 51 项代表窗口 `C−pM` 都严格大于 1e−12，范围约 0.00728446–0.27112793。这里的代表窗口仅由真值最大余量、最早平局规则确定，预测没有参与窗口选择。

按原来源→线路→事件权重，21 个观测触发事件的权重质量为 0.0874210165；共同未保留的 17 个事件为 0.0695524267。细步长下，这 17 个事件对总体主 MSE 的贡献分别为 0.0200494877／0.0200951817／0.0200491188。它们是共享总体分母的误差贡献，不是组内平均 RMSE。seed 不是独立事件样本。

从保存 NPZ 独立重算的 rho、逐时刻 e² 与 JSON 一致，C−pM 最大重算差为 5.55e−17；全部保存的 history／含未来／全窗口／真值代表窗口误差界均满足原代数关系。逐时刻角度、COI 速度和归一化误差可用于描述规则余量怎样被改变；它们不能单独证明是哪一项动力学或训练机制造成误差。

**这批事实不能一概解释为“没有 8 s 真值，所以无法诊断”。** 观测规则的正触发和模型未保持已经发生在真实可用的短段中；不需要虚构后续真值才能指出这个差异。不过，它们只是固定规则的观测证据，不是新读取的失稳标签，本审计不计算 FN／FP／FSR，也不由 rho≤0 宣称稳定。原 val 漏判是否具有同一机制尚未由本审计证明。

所有路径及物理检查通过，最大能量恒等式误差为 2.27373675e−13，最大质量加权 COI 残差为 2.66453526e−15。774 项粗细规则判定全部一致，触发末点差条件全部通过。

## 4. 下一项行动的科学理由与边界

A10 的问题是：**在同一固定模型、输入和全部 train 下，保存的 0.005 s 路径与新 0.0025 s 路径是否满足原数值门槛，时间局部现象是否仍成立？** 这是固定参数的数值问题，不是扩大模型搜索或延长训练。

新预算固定为 774 条路径、1548 次 rollout、896724 次 RK4、3586896 次积分 RHS，加 225729 次输出状态物理检查，共 3812625 次 RHS；0 拟合、0 更新。读取边界与 A09 相同，真值／质量／平衡角／尺度／offsets 须与 A09 已存数组逐位一致。旧 0.005 s 数组及 JSON 先作零 RHS、1e−12 评分与规则统计重建；新 0.0025 s 路径按原精化／物理条件判断，不要求与 0.01 s 评分逐位相等。

只有全体新比较通过，且从全部 train 重新确认至少两个事件、两条物理线路、三 seed 两步长均未保留严格真实正触发、预定新细步长代表窗口均有 C−pM>1e−12，A10 才能独立支持**提出**统一的时间聚合对照。它仍不能证明该目标有效，不能据事件名单重加权，也不自动授权训练。非线性记忆仍缺少本任务要求的独立幅度／残余力证据。

若 A10 仍有数值失败，则保留 REJECT，不自动继续减小步长或增加预算。若数值通过而现象条件不成立，也不启动新损失。A09 原结果、模型和授权消费记录永久保留；全部模型 KEEP_BASELINE，零漏判尚未实现。
