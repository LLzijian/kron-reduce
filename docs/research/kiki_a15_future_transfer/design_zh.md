## 1. 唯一问题与研究次序

A14 在固定 A06 三模型上，使闭环历史 MSE 降低约一半，同时提高了模型隐藏储能。下一项有信息的问题是：从同一真实可见末态出发，该隐藏状态能否改善不再接收真实观测的未来轨迹？这是历史收益能否迁移的检验，不再训练、重估初态或修改损失。

固定对照 E 为 A09/A10 已保存的原 encoder 未来路径；固定候选 I 为 A14 已保存的积分初始化闭环末态。先在全部原 258 个 train 事件、三个 seed 上检验最多 3 s 的真实可用未来。若迁移条件失败，保存负结果并停止，不打开 val，也不增加 epoch、求积点数、岭参数、隐藏状态缩放或新结构。若通过，只支持提出独立登记的 val 比较，不自动执行。

选择 train-only 的理由是 A14 目前证明历史重建，且较高隐藏储能可能改变未来行为。提前检验这个可证伪环节，可以避免用反复曝光的 val 代替机制验证。train 结果不能作为新独立确认，不能把真实可用段规则一致性称为 FSR。

## 4. 时钟、端点与精确新计算预算

N_i 为每事件非起点真实可用未来点数，1≤N_i≤300，ΣN_i=72,147。每条 future 有 N_i+1 行，包含共同起点，因此总行数为 72,405。起点不评分，但其 reset 后状态必须接受物理检查，不能用历史末点物理检查替代。

源码核查显示原 provider 先检查 raw 时钟接近 .01 s 网格，再用 `np.arange(end-origin)*.01` 构造 forecast_time；A15 逐位复用 A10 独立保存的 forecast_time，不宣称它是未重建的原始未来时钟。history_time 则保留原真实时间差，本轮不再次积分历史。

每事件必须在新 RHS 前核验：时钟首点恰为零，有限严格递增；各 offsets 逐数组一致、末值为 72,405；真实 future 首行与历史末点一致；原积分规则

\[
B_{i,h}=\sum_{j=1}^{N_i}\max\{1,\lceil(\tau_j-\tau_{j-1})/h-10^{-12}\rceil\}
\]

分别等于 2N_i 与 4N_i。保持原标量 `closure.rollout` 的 RK4 和每步 COI 投影，不引入新的批量积分器。

| 新计算项 | 固定次数 |
| --- | ---: |
| 从 A14 六参数构造固定 closure | 3 |
| 候选 future rollout | 3×258×2 = 1,548 |
| RK4 成功更新 | 3×(2+4)×72,147 = 1,298,646 |
| 积分 RHS | 5,194,584 |
| 每个新 future 输出状态的物理 RHS，含 t0 | 3×2×(72,147+258) = 434,430 |
| 总 RHS | **5,629,014** |
| 新历史路径 / 对照路径 / encoder / expm / SVD / LS / 独立力函数 | **全部 0** |

原 closure 构造和每次 rollout 都调用原结构校验器，不能绕过或漏报这部分。正常路径有 3+1,548 次结构校验，每次原样检查三个对称矩阵的特征值，合计 4,653 次 `eigvalsh`；它们作为固定结构校验子预算另列，不是隐藏初始化的 SVD、学习或新模型选择。正常执行应逐项精确完成；失败时保留实际耗用，不补满预算。

不添加“顺便检查”的直接/重载预测槽；保存路径的数组身份、有限性、首点、评分及预算用零 RHS 独立重放核对。如果实现认为必须新增预测性重放，应在冻结前改成明确独立槽并重新审核，不能从本预算借用。

## 5. 冻结评价与三层判定

### V：有效性

全部来源、成员、人口、权重、时钟、reset 对应、闭环隐藏状态来源及预算通过；全部 774 槽的两条新路径完成。新未来每输出点的原能量恒等式绝对残差≤1e−8、质量加权 q/v COI 绝对残差≤1e−10。两步长全未来可见路径最大绝对差除以原 target_scale≤1e−5；隐藏路径最大二范数差≤1e−5(1+细步长隐藏路径最大二范数)。不自动降至 .00125，不局部修复某事件。

旧对照继承已通过的 A10 .005/.0025 数值与物理证据，本轮仍用已授权对照数组复核全量有限性、起点身份及可见/隐藏步长差；不额外生成旧预测。候选和对照的全量比较若缺一槽，不能用可用子集宣布通过。

真实可用规则诊断完整复用 A10 的四类界：history、含未来点的窗口、full、真值固定代表五点窗口。coarse/fine 使用同一个真值代表窗口；索引、两路径 margin 与余量误差界须一致。数值界验证失败使 V=false，而不是隐藏该条诊断。规则阈值、连续五点、COI 和余量定义不改；history+future 拼接时去掉重复 t0。

### I：未来轨迹迁移

令 e_ij 为 20 通道、原尺度下每个非起点未来时刻的均方误差。每个事件的原主 MSE 为

\[
\ell_i=\tfrac12\left[\frac1{|J_{i,1}|}\sum_{j\in J_{i,1}}e_{ij}
+\frac1{|J_{i,3}|}\sum_{j\in J_{i,3}}e_{ij}\right],
\quad J_{i,H}=\{j\ge1:\tau_j\le H+10^{-12}\}.
\]

只使用真实可用点；两个集合非空。总体主 MSE 为 Σw_iℓ_i。保留原 RMSE 展示，但验收直接用 MSE。q/v 分项各按自身 10 通道取均值，二者平均等于可见主 MSE。

对每个 seed、每个步长都要求：候选主 MSE 严格下降；1 s 与 3 s 分时段 MSE、q/v 主分项和最差原权重 10% 的事件 ℓ_i CVaR 均不增；完整 3 s 事件的条件均方误差不增。最后一项统一使用完整 3 s 子集上的原 w_i 除以该子集原权重总和，候选与对照人口一致，不重算 source/line 权重。严格下降须超过 1e−12 的绝对数值比较容差；“不增”容差为 1e−12，不设置数据驱动相对容忍度。

另完整报告 <1 s、1–3 s、达到3 s 三个固定时长组的事件数、原权重质量和同总体分母的误差贡献，不因某组结果删除或改权重。三个 seed 不取最佳者，不按多数表决。

### D：真实可用段规则表现，独立于标签分类

对全 258 事件统一计算真值与预测的含未来五点窗口规则，不使用源标签。报告真值正触发未保留数、真值未触发但预测触发数、无可用窗口数、固定代表窗误差、首次逐点违规与五点确认时间。`rho≤0` 不表示系统稳定，真值未触发也不能当标签稳定。

D 的预定保护条件为：六组中，上述“正触发未保留数”和“真值未触发但预测触发数”都不得比同组 E 增加；任一未知/缺失诊断使 D 未完成。另单独报告各 seed 在两个步长上是否严格增加保留数。两类保护条件防止以普遍抬高预测幅度换取触发数，但不能替代未来 val 的 FP 守门。来源标签、事件ID或真值触发身份都不参与计算输入或方法选择。

## 6. 顺序、保存与失败处理

独立专用入口验证完整登记、文本/源 SHA、clean HEAD，原子占用一次性 shared ledger 后才进行许可 NPZ 校验或解码。登记全部 268 分配、774 槽和每槽两个步长。来源/读取/保存/日志/预算错误整轮停止；数值失败保留当前已输出和实际算子记录，余下独立预定槽可继续，任何失败使 V=false。禁止 retry/resume，未执行槽保持 not_attempted。

源读取允许按文件做持久预留：打开前先把该文件的确定成员、头部/payload/标量/字节额度和顺序 fsync；逐调用 attempted/returned 写入文件并 flush；文件结束核对配对与范围 SHA 后 fsync 关闭记录。预留或日志失败先停止，不调用后续源操作；崩溃时整文件范围 unknown/spent，不恢复、不重读。完整清单的收尾字节校验仍单独按预定第二次完整读取记账。此策略改变持久化粒度，不改变许可读取内容、硬额度或失败语义；不要求每个数组调用都 fsync，但最终记录必须能逐调用重放与核对。

先冻结全部候选 reset、对照首点对应、参数、输入与人口摘要，再解码许可真值未来并验证其对应；真值只供评价。按 seed→原事件顺序→.005/.0025 执行，不按任何误差或规则重排。各事件 scope 先持久预留硬额度，再写逐调用 attempted/returned，scope 结束校验实际配对及范围 SHA 后 durable close；崩溃 scope 标 unknown/spent，不能重试。

新路径先保存，再算物理和诊断；异常不能丢弃已生成路径。完整保存候选/对照/reset/真值时钟及数组指纹、各事件分通道/分时长误差、四类余量界和判断所用标量、全部层次权重、访问与预算日志。独立审计只从保存产物重建 V/I/D，不重新调用模型。失败输出也须满足严格 artifact/stage 合同。

## 8. 正式冻结时的实现消歧

本文件来源于先行草案 SHA256 `306dceade41e4c9bc9695b4f46a6b1131f12d81a285dd2789d21fb6228f31ff8`。该草案原样保留。以下条款在 A15 任何真实读取、积分或评分前固定，具体化指标和原 A10 数值条件，不增候选、超参数或科学预算。运行仍须独立授权及最终实施审核。

**I 的准确布尔条件。** 对每个 seed、每个步长，比较同人口的 I 与 E，且全部六组通过：

**V 的完整规则精化条件。** 每个 E/I 方案的粗细两路径，除可见与隐藏误差门外，必须有完全一致的 `future_rho.prediction.triggered`；两者都触发时，首次连续五点确认末点的索引差≤2。这沿用 A10 的条件；Lipschitz 余量界本身不能替代触发一致性。隐藏路径差是 A15 对许可数组的新核验，A10 已有证书没有证明该项。候选新路径任一能量/COI/状态或派生检查值非有限就失败，禁止用 `max` 吞掉 NaN。

`audit_event` 在 E/I 的两个步长都生成 history/future/full/真值代表五点窗四类诊断；`compare_on_truth_windows` 固定真实未来选定的代表窗生成粗细四类界。每个诊断都核查字段存在、有限、索引及同窗 margin 对应，并数值验证

\[
|\rho_p-\rho_t|\le E_{atom}+\epsilon,\quad
E_{atom}\le E_{vector}+\epsilon,\quad
\epsilon=10^{-12}\max(1,|\rho_t|,|\rho_p|,E_{vector}).
\]

所有界的 `bound_verified` 也必须为真。不得只信汇总布尔值或把缺失的固定代表窗当作通过。粗细代表窗应与两个真值诊断相同；其真实记录网格索引为 start≥0、end=start+4、end≥11、end<11+N_i。

**D 的准确整数计数。** 令 T_i 为 `future_rho.truth.triggered`，P_i^g 为方案 g 的 `future_rho.prediction.triggered`。对每个 seed/step，

\[
M_g=\sum_i1[T_i\text{ is True}\ \land\ P_i^g\text{ is not True}],\quad
F_g=\sum_i1[T_i\text{ is False}\ \land\ P_i^g\text{ is True}].
\]

要求 M_I≤M_E 且 F_I≤F_E，按整数事件数逐组六次检验，不能加权抵消或跨 seed 汇总。触发严格以 rho>0 为准；rho=0 为 False，并保留 arithmetic_boundary 标记；`1e-12` 是界的算术容差，不是触发阈值。None 表示没有可用窗口，不能转 False；任一未知/缺失使 D 未完成。正常人口 N_i≥1，真实 11 点 history 与未来拼接后应始终有含未来窗口。

规则路径固定为 `concat(real_history, future[1:])`，共同起点仅出现一次。history 有 7 个五点窗口；future 是末点索引≥11 的窗口，允许跨越起报点，共 N_i 个；full 有 N_i+7 个窗口。首次逐点联合违规另用原逐点余量严格大于零定位，分别报告 full 域 indices 0..10+N_i 和 future 域 indices 11..10+N_i；输出记录时间 i×.01 与起报时间 i×.01−.1。若 full 首点即违规，记录 `pre_record_onset_unknown=true`。这些时间只作诊断，不用于新 gate；不能把五点确认末点减四当成首次逐点违规。
