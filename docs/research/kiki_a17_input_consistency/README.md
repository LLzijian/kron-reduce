# A17 历史输入一致性比较

本方案直接检验：固定模型的初态估计与闭环历史回放共同使用已观测 Pm11 后，未来轨迹是否同时优于 A15 方案 I 和 A09/A10 基线 E。三个模型、两个步长和原 train 人口全部保留，0 fit、0 优化更新。

[Astra 科学协议](design_zh.md)冻结唯一候选、输入合同、数值检查、原权重和接受条件。预测先冻结，真实未来最后读取评分。每次失败都保留原样本与原分母。

当前为设计与工程准备。A17 尚无真实执行授权；最终读取清单、运算预算、专用入口、合成检查及 Astra Ultra 精确实施审核完成后，才能登记激活。当前模型和默认初始化保持不变。

有限读取清单和计算计划现已冻结。专用流程按 10,356 个范围执行，分别冻结全部历史起点与候选未来，再读取保存的对照和真值。实际输入计算、数值更新、物理检查、文件写入与失败记录均可追查；独立核验器只使用本轮保存的证据，不重算模型。

当前联调使用合成系统。509 项统一检查已通过，覆盖完整流程、有限读取、独立结果核验、原权重保留和保存故障；检查期间源文件哈希保持一致。精确实施审核及仓库检查仍待完成，这些工程检查不构成真实数据上的改善结果。完整检查曾发现文件接口恢复不完整，修复后的通过记录与原失败记录均保留。
