## 7. 唯一下一研究优先级

原盲写条件草案明确：V 通过而 G_I 失败时，默认不启动输入一致联合 LS 训练，更不能直接转入 C(q)。本轮正式执行这一 **NO_TRAIN** 分支；不启动草案中的六个 fit，也不从某 seed、某指标或某些事件另选支持证据。

有理由准备的唯一前置问题是：**在具有已知真值、同一常值耦合结构的合成系统中，去除隐藏坐标等价后，100 ms 因果历史是否足以稳定区分会导致不同闭环未来的状态和参数？** 目标是检查收益论证中尚未成立的信息条件，不是挽救 A17 或预先保证训练有效。

该准备应固定已知模型/初态的 oracle 对照，包含输入无失配时两流程一致的负对照，覆盖历史→可见 q/v 重置→各自 z_T→相同未来常值输入的完整链。需明确区分历史观测近似相同但未来不同的方向、弱激励、状态恢复误差、采样误差和未来输入闭包；L 满列秩、小 LS 残差或单独梯度公式通过均不能替代这些条件。可以先形成理论问题和固定合成验证计划，不增加模型容量、不运行优化器、不做候选搜索；任何实际合成预算另行明确，任何新真实比较或训练仍须独立登记和审核。

如果必要条件不成立，应允许停止该方向，而不是立即增加隐藏维度或 C(q)。纯反对称耦合在同 H、同完整初态、同输入和同耗散、共同有效域的前提下，不改变同一充分能量屏障的能量论证；容量增加没有达到零漏判的保证。本轮没有借此推断任何真实误判处于该认证区域内。
