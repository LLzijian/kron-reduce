## 1. 唯一问题、对象与结果判定

## 3. 唯一初态求解及数值检查

对每槽，B=Ltilde∈R^(100×2)，原四点加权右端 b₄=btilde4，d_w 是 A16 保存的 `weighted_impulse[:,point]`。该量已经是 vec(c_j S d_j)，其中 d_j 是物理动量冲量；不能把未缩放的原 d_j 直接加到 btilde4，也不能再给 d_w 加一次 cS。

\[
b_4^+=b_4+d_w,\qquad
z_0^+=V_h^\top\big[(U^\top b_4^+)/s\big].
\]

浮点顺序固定为先逐元素 b₄+d_w，再 `U.T @ rhs`，再逐元素除原 s，最后 `Vh.T @ coefficients`。一次登记的 LS 调用保存 rhs、projected_rhs、coefficients、z₀；不通过 `z_old+Δz` 代替，不使用 solve/lstsq/pinv，不新做 SVD/QR/eig/expm，不重算 g、B、w，不改变秩、加 ridge、截断奇异值、裁剪或缩放状态。

原 rank 必须为 2，s 降序、有限且正，原 threshold 逐位等于 `64*eps64*100*max(s[0],natural_norm)`，两奇异值都严格大于该阈值。保存分解必须与同一 B、seed、事件、模型和时钟绑定，不使用另一个槽的分解，即使数值看起来相同。

设 τ_num=64 eps64×100。以下是事前冻结的数值检查，不是分类阈值，也不是对真实状态的误差证书：

1. 用缓存数组检查 `||U.T U−I||F≤τ_num`、`||Vh Vh.T−I||F≤τ_num`、`||B−(U*s)@Vh||F≤τ_num max(1,||B||F)`，不另做分解。
2. 新解、全部中间值与 r=b₄⁺−Bz₀⁺、g=Bᵀr 必须有限。令 A_num=max(1,||B||F(||b₄⁺||₂+||B||F||z₀⁺||₂))，要求 `||g||₂≤τ_num A_num`。
3. 继承同槽 A16 正 Gram 界，λ_lo=`nextafter(det_lower/trace_upper,−inf)`，要求有限且 λ_lo>0。再要求条件敏感度检查量 `(||g||₂+τ_num A_num)/λ_lo ≤ 1e−6(1+||z₀⁺||₂)`。这防止只看小正规方程残差而忽略病态放大；它仍标为数值代理，不将常数保护项误称严格向外舍入前向误差证书。

原两个求积右端加入相同 d_w 后，在精确固定线性 LS 映射下有 z₂⁺−z₄⁺=z₂−z₄。保留原缓存绝对差 δ_z=||zh2−zh4||₂ 和 δ_T=||zTobs2−zTobs4||₂；只作一次新观测驱动映射 z_T,obs⁺=PhiT z₀⁺+wT，检查

\[
\delta_z\le10^{-6}(1+\|z_0^+\|_2),\qquad
\delta_T\le10^{-6}(1+\|z_{T,obs}^+\|_2).
\]

字段名称用 `inherited_quadrature_proxy`。有限缓存差含旧舍入误差，本轮没有重新解二点右端，也没有新的严格求积误差上界；V 不得写成连续系统或真实隐态的证书。新的 z_T,obs⁺只作这个检查，绝不进入未来起点。若代理门不通过，保留数值失败并停止该槽后续路径，不能追加求积或重解第二候选。

新 LS 残差只是这个离散方程的求解检查，不进入收益判定。A16 的 `dynamic_after` 保持旧状态，不能作为 A17 已重求解残差或未来指标。

## 4. 历史 PL、完整状态和未来接口

历史数学时钟严格沿用 τ_j=history_time[j]−history_time[0]，h_j=τ_(j+1)−τ_j，保留原两次减法顺序。原 A14 的每事件两步长计数应为 20/40，在新 LS/RHS 前核验；不能为了凑预算改成理想间隔。T 是原记录的第 11 个观察点，不称物理清除时刻。

历史起态为 `[q_obs(0),v_obs(0),z₀⁺]`，可见部分逐位保留，不再 COI 投影或重新初始化。其 COI 约束必须已经满足。两步长共用同一个新 z₀，分别闭环生成各自历史。

每段的子步数 n=max(1,ceil(h_j/h_max−1e−12))，dt=h_j/n。第 k=0..n−1 子步的四个 RK4 输入分数固定为 k/n、(k+.5)/n、(k+.5)/n、(k+1)/n。分数为 0 或 1 时直接返回保存的 u_j 或 u_(j+1)；内部使用 `left+fraction*(right−left)`。不累加绝对时间定位端点，不跨原历史结点，不以左端常值代替四阶段输入。k2/k3 各记一次 input_eval，不缓存成一次。

所有阶段 q/v/z 都由模型和之前的阶段生成；已观测 q/v 仅用于初态方程、历史首点和 T 的可见重置。PL 使用区间右端历史帧，它相对于 forecast origin T 因果可用，不声称相对于每个过去时刻在线因果。实际 input_eval 日志保留原区间、子步、阶段及分数；输入原节点与程序绑定，使独立审计能够核对实际调度，没有隐蔽插值或结点越界。不重复运行 A16 冲量/Gram 诊断来增加候选证据。

RK4 的状态更新、每完整子步的两次 COI 投影、`max(abs(state))>1e12` 发散拒绝及原算术顺序保持源实现。历史用专用 PL 模式；未来 constant 模式直接传原 constant_power，不经过 PL 算术。必须在合成数据上证明 constant 模式与原 rollout 逐点逐位一致，包括非均匀时钟和边界计数。当前输入仅允许这两个固定模式，不新增插值候选。

历史闭环末态 x_T⁻ 与未来起态分别为

\[
x_T^+(h)=[q_{obs}(T),v_{obs}(T),z_T^{-,closed}(h)].
\]

两个步长各自保留自己的闭环 z_T，不共享细步长末态；未来 t=0 必须逐位等于 x_T⁺。新 z_T 不得替换为 z_T,obs⁺。未来只用原 p_old=Pm10 衍生常值输入，不读取未来功率、不在未来重置。

A16 仅规定 u11[10] 与 p_old 的绝对差≤1e−12，并另存逐位一致性。A17 必须保存实际 δu=p_old−u11[10]，按原门检查，不能静默 snap。历史末段终点使用原 u11[10]，未来首点使用原 p_old。若二者不同，这是有限输入跳变，不产生状态冲量或能量跳变；可见重置才产生观测注入的能量变化。

每个历史末态和对应重置态分别调用原 energy，保存 H⁻、H⁺、H⁺−H⁻，三者均须有限；检查隐藏两通道逐位不变。能量差可正可负，既不是优化目标，也不是被动性失败。不能要求受迫历史 H 单调下降，不能把重置前后拼接成无跳变的物理轨迹。

## 7. G_I 与 G_E：完全相同的未来轨迹指标

每事件 i 的未来非起点 q/v 状态按原 20 通道尺度 s 计算 e_ij=||([q,v]_pred−[q,v]_truth)/s||²/20。只用真实可用时刻，J_(i,H)={j≥1:clock_j≤H+1e−12}，H∈{1,3}；两集合必须非空。事件主 MSE

\[
\ell_i=\tfrac12\left[|J_{i,1}|^{-1}\sum_{j\in J_{i,1}}e_{ij}
+|J_{i,3}|^{-1}\sum_{j\in J_{i,3}}e_{ij}\right],
\qquad L=\sum_i w_i\ell_i.
\]

q/v 主分项各自按十通道和相同时间规则计算，二者平均为可见主 MSE。任何 RMSE 展示必须明确是该 MSE 的平方根，不能把 A16 的平方范数当作同一指标。

对 R∈{I,E}，G_R 要求三个 seed、两个步长的全部六组同时满足：

1. C 的主 MSE `< R − 1e−12`。
2. horizon1 和 horizon3 的 20 通道总体 MSE，各 `C <= R + 1e−12`。
3. q 主分项、v 主分项，各 `C <= R + 1e−12`。
4. 原权重最差 10% 的事件主损失 fractional CVaR，各 `C <= R + 1e−12`。
5. N_i=300 的完整 3 s 子集纯 3 s、20 通道事件 MSE，按该子集原权重总质量归一，`C <= R + 1e−12`。

沿用 A15 的数值比较容差，不增加事后相对容忍度或“差不多”判断；不跨 seed 平均抵消、不多数表决。该容差区分数值比较，不构成实际工程效益阈值。没有预先定义的工程收益尺度，就只报告实际差值，不宣称实用显著。

CVaR 各方法按自己的事件 ℓ 降序、同值按原缓存行号；取原质量 0.1，边界事件只取所需分数质量，除以 0.1。不按标签筛选。时长组固定 N_i<100、100≤N_i<300、N_i=300，报告事件数、原权重质量及同总体分母贡献，不把三组重新等权。完整 3 s 子集的条件归一只用于预定第 5 项，不替代总体。

G_I/G_E 分别保存每组每项、差值、布尔量和缺失原因。若 V=false，可保存有效槽的原权重部分贡献与缺失质量，但总体门为未完成/false，不生成删样本后的“新总体”。不计算 LOS/误触发来转移本轮判定；达到零漏判仍需未来独立研究与适当数据，不能靠本协议承诺。

## 9. 实施前证据与最终交付

最低合成验证覆盖：完整固定 SVD 求解与已知答案、无新分解/求解器路径、rank/阈值或绑定损坏在 LS 前停止；全零输入修正退化为原估计/流程；constant 模式跨两个步长、非均匀时钟和不同状态尺度与原 rollout 逐位一致；PL 的四阶段输入和原结点端点；无 teacher forcing；非均匀质量的 COI/能量；显式可见重置能量；两条历史分别产生各自未来末态；日志与保存故障注入永久停止、所有失败入口的部分记录和已消费预算；评分在真假收益/缺失/尾部/完整3s子集的已知数组上与独立计算一致。合成测试不作为真实收益证据。
