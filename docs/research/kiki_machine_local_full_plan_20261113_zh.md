# TASK3 完整名单的逐机隐状态学习计划

日期：2026-11-13。科学设计：Astra Ultra。用户要求本轮直接完成 `train=346`、`val=107`、`test=76` 的完整评价，并以完整名单作为后续默认范围。本计划据此登记一次 L10 学习，不安排两个真实事件的先行试验。准确源码、来源清单、协议和操作上限通过实施审核后执行；已有 consumed 授权保持关闭。

## 1. 本轮回答的问题

在固定真实可见动力学骨架上，用与正弦方程一致的 100 ms 历史初始化，训练十个局部端口幅度和十个时间常数，能否形成可执行、可核查的完整 TASK3 轨迹与稳定性预测。

[clean 线性学习](machine_local_clean_learning_result_review_20261113_zh.md)已验证匹配系统中的二十参数学习；[非线性历史 S0](machine_local_nonlinear_history_result_review_20261113_zh.md)已验证三次 Gauss–Newton、同阶段 RK4 切线和端到端梯度。两项证据足以支持本次另行登记的有界真实试验，不要求再追加一轮非线性合成训练。本轮首次检验这一组合的真实学习表现，固定四十次更新不预先承诺收敛。

本轮不执行 G2/G10/L10 多模型搜索、encoder 联合训练、模块发现、噪声扫描或参数筛选，不把结果计作原九次 T0 比较已经完成。默认部署模型保持原状。

## 2. 一个模型与一条完整因果链

固定 A06 seed 324 的一个已保存模型，提取其质量、正弦势能刚度和阻尼；准确文件和允许成员由新来源清单绑定。保留十台机器，使用

\[
P=I-m\mathbf1^T/(\mathbf1^Tm),\qquad C=P\operatorname{diag}(g),
\]

\[
\dot q=v,\quad M\dot v=P\{u-\nabla U_0(q)-D_0v-Cz\},\quad
\dot z=C^Tv-\operatorname{diag}(1/\tau)z.
\]

十个幅度的共同初值为 `g_i=||C_A06||_F/||P||_F`，时间常数为 `geomspace(0.06, 1.6, 10)` s。该幅度使初始局部端口与来源端口具有相同 Frobenius 范数，不要求两模型动力学等价。尺度须为有限正数，来源不满足时记录失败，不换尺度。沿现有正值参数化学习 g 和 `0.02<τ<5` s；encoder 为零且绕过，质量、刚度、阻尼、单位和坐标规则不训练。

每个事件只输入 0–100 ms 的十一帧 q/v、`Pm[10]−Pm_equilibrium` 的恒定功率，以及静态平衡点。遵循 `measured_history_100ms_zoh_v1`，未来功率、Pe、电压、标签、事件时间、有效长度、来源和故障信息不进入模型。可用目标长度只控制损失和报告范围。

历史求解完全复用已通过 S0 的接口：隐藏初态从零开始，固定三次 Gauss–Newton，用同一 RK4 阶段推进状态和切线，通过薄 QR 与三角解更新隐藏初态，再完整重算最终历史。预测起点重置为观测末点 q/v，保留模型的隐藏末态。三次迭代、切线、QR、重算历史和未来均保留参数梯度；不加 ridge、伪逆、line search 或额外迭代。秩须为十，条件数不超过 `1e8`；非有限或隐藏幅度超过 `1e12` 为数值失败。

## 3. 完整 train 的四十次更新

名单严格按[固定来源限定 ID](../../configs/proposals/kiki_task3_split_reference_v1.json)核对。train 中不再划分新 val，不删样、不补样。来源适配、质量一致性、时间网格、单位、平衡量和输入特征在读取边界验证。

历史标准化尺度只从 346 个 train 的十一帧可见历史估计；训练目标尺度只从 train 预测起点后的实际可用目标、最多三秒估计。两者分别对各事件逐通道平方值先作时间平均，再作事件等权平均并开方，下限 `1e−5`，保存准确数组和计算点数。目标不含预测起点，未来不参与历史尺度或初始化。TASK3 比较尺度另行固定，不与训练尺度混用。

训练目标为逐事件等权的 1 s/3 s 归一化平方误差，各时窗按该事件实际可用点数归一，再对两个时窗等权平均。全部 346 个事件的权重均为 `1/346`，无额外正则或历史损失。缺少合法目标的分配事件使完整 train 目标不可用，不能把其权重分配给其他事件。

使用 CPU float64、单线程、确定性；一次 fresh Adam，固定 `lr=0.01`、`betas=(0.9,0.999)`、`eps=1e−8`、`weight_decay=0`、`amsgrad=False`、`foreach=False`、`fused=False`、`maximize=False`。按来源限定 ID 排序，固定大小为 64 的连续批次：五批 64、末批 26。每次参数更新前，六批全部在同一参数上前向并累积梯度；各批的损失使用全名单权重，不按批大小重新平均。仅在六批全部完成后，对二十个参数的合并梯度裁剪至范数 10，再更新一次。

历史与三秒预测均使用 0.005 s RK4 最大子步，输出间隔 0.01 s；梯度不截断、不重计算。固定四十次更新后的参数为终点，训练 trace 记录更新前 loss、梯度及更新后的参数，不按最低 loss 选模型。首轮完整 train 前向产生无额外噪声的初步结果；不额外启动真实子样本试训。

任何批次、梯度或优化器状态数值失败即停止拟合。丢弃本次尚未提交的累积梯度，保存失败证据并冻结上一个已完成更新的有限参数；第一个更新前失败则冻结初始参数。该记录明确属于失败轮，不称为四十步完成；仍完成可执行的全部 train/val/test 评价。不得删除失败批次后继续、改变批大小、缩步、调学习率或重试拟合。

## 4. 模型冻结与独立 test 阶段

训练结束或上述失败冻结后，先封存参数、train 尺度、因果合同、代码哈希、名单哈希和评价规则，再评价完整 train 与 val。val 本轮用于描述性报告，无 checkpoint、阈值或参数选择。无论 RMSE 是否达到任何晋升门，都进入既定 test 评价。

test 使用独立登记的零拟合阶段，绑定上述冻结物和本轮来源清单。仅在冻结完成后读取 test 载荷；一个参数模型覆盖全部来源及所有角色。test 读取不开放训练入口，不因 test 结果修改参数、阈值、尺度或代码。该 test 名单已有历史暴露，结果属于固定比较基准，独立确认需要独立数据。

静态与 train/val 来源读取、test 来源读取分别记账。准确最小文件/成员、来源 SHA-256、允许的反序列化类型、数组尺寸和解码次数须在来源清单与实施审核中绑定。优先使用已保存 TASK3 缓存；缺少成员或身份不一致时记录明确失败，不临时回退到另一份数据或调用原 provider。标签只进入冻结后的评分链，原 TASK3 真值标签不重标。

## 5. 全名单预测与失败保留

每个模型预测从 100 ms 起点完整推进八秒，保存 801 个未来点，分别使用 0.0025 s 与 0.00125 s 子步，两个档位均独立求解历史。评价按固定顺序以每批最多 16 个事件运行，train/val/test 分别为 22/7/5 批。批间无模型参数更新、跨事件归一化或状态混合。

若某个步长的批量求解抛出数值异常，对该批每个事件分别执行该步长预测各一次，以分辨具体失败事件；另一档仍按其独立批次正常执行。这个预登记的逐事件隔离不改变输入、模型、初值、三次 GN 或步长；原批次失败记录保留。正常返回但数值门或分类门未通过的事件不触发追加计算。逐事件隔离仍失败时，该事件保留为失败且继续下个事件；不递归重试、不只保留较好档位。

轨迹误差按 TASK3 固定 1/2/5/8 s 时窗计算：每个时窗使用完整覆盖该时窗的真实目标，失稳样本另按全部实际可用目标单列评分，不补齐目标。记录每个时窗的事件数和点数；报告事件平均、pooled、CVaR10、最差误差及物理 RMSE。delta/omega 固定比较尺度分别为 `0.47675314588683515`、`1.0033667249602924`，外部 TASK3 评分实现须随源码冻结。内部 1/3 s 训练损失单列。模型输出相对运动，共同频率采用明确的零偏差输出约定并报告对应 RMSE，不将其称为已学习通道。

预测稳定性严格使用固定 TASK3 八秒窗口和阈值：观测历史与不重复起点的未来轨迹拼接，角范围大于 π 且最大 COI 相对速度大于 0.02 pu 连续五点为失步；没有失步且最后一秒角范围小于 π、速度小于 0.005 pu 才记窗口内安定，其余未决。真值保留官方标签。两档均须完整有限，TASK3 固定尺度下的相对状态 RMS 精化差及共同频率 RMS 精化差均不超过 `0.001`，其检查范围与被冻结 TASK3 评分代码一致：轨迹分数检查其对应完整时窗；分类检查八秒，两档均失步时检查至较晚触发点。失步触发时间相差不得超过 0.02 s。本轮稳定性汇总另外要求两档的失步、窗口内安定或未决三类一致，不把“两个都没失步”视为安定一致。模型保持原质量 COI 投影；本轮不额外套用合成 S0 的 `1e−5` 最大误差验收线。这些是数值与窗口规则检查，不构成稳定性证书。

每个角色列出分配数、可用数、数值失败、未覆盖、未决、可判定数和覆盖率，并给出 TP/TN/FP/FN。存在任一未决、未覆盖或数值失败时总体准确率为 null；另给可判定准确率及其上的失稳召回 `TP/(TP+FN)`、漏判率 `FN/(TP+FN)`、稳定误报率 `FP/(TN+FP)`，分母为零则为 null。任何缺失或无效轨迹指标保持 null 与明确失败原因，不以零填补或隐藏分母变化。

## 7. 接受与后续
