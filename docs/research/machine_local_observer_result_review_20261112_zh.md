## 结果及意义

三个真值动力学 clean 病例的主/3 s NRMSE 和两个起点隐状态 RMSE 均通过冻结门槛，两个新种子也通过。该结果支持以模型历史响应替代自由编码器进行 clean 状态初始化。

下表为固定真值动力学、1% 历史噪声下的 **3 s 可见状态归一化 RMSE**，使用 clean train 未来通道尺度；冻结上限为 0.02。

两组的主 NRMSE 也全部未达标。local 历史起点隐状态 RMSE 为 0.1616/0.1422/0.1394，nonlocal 为 5.4400/5.4706/2.9366，均按 train/val/test 顺序列出。相应观测矩阵条件数为 24.54 和 778.92，数值秩均为十。这说明本次满秩与数值条件数门不能保证抗噪状态恢复；隐状态误差与可见预测误差也不能直接互相替代。

原 S1 学得 L10 配合本次 clean 历史求解器的 val 3 s NRMSE 为 0.006465，明显低于条件最优自由编码器下的 0.161977，仍高于 clean 上限 0.001。真值动力学的同样初始化通过，而学得动力学未通过，支持后续继续处理动力学参数及其诱导的状态估计误差。本次尚未确认学得模型。

## 下一项可证伪修正

现有方法把第一帧含噪 q/v 当作精确初态。下一项修正只解除这一等式约束：在质量 COI 子空间内联合估计 18 个可见初态坐标和十个隐状态，使用相同 100 ms、十一帧加权历史损失，保留预测起点可见重置，不增加 ridge 或改变噪声权重。

这是待检验的机制，不是已确定的唯一根因。联合估计增加未知量，也可能放大弱方向噪声。历史拟合残差下降是解除约束后最小二乘的固有性质，不能单独作为成功证据；判据仍是预先冻结的未来误差和独立新种子确认。两组旧含噪样本只提供 train/val 配对机制比较，旧 test 不参与选择。
