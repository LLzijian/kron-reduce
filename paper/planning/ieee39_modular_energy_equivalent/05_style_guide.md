# Style guide

- Language: Chinese for plans/reports; concise IEEE-style English for manuscript.
- Target reader: power-system engineers and dynamics/model-identification researchers.
- Tone: scientific-question-driven and engineering-feasibility; conservative about evidence.
- Terminology: use “统一模块模型”“激励视图”“闭环重积分”“储能证书”“认证包络”“条件上界”. Define abbreviations once.
- Forbidden expressions: “完美”“彻底解决”“证明真实参数”“保证安全”“普适”“显著” without a registered statistical test; avoid describing a failed scientific hypothesis as a failed workflow.
- Supervisor preferences: lead with the outcome; explain the physical reason before naming an algorithm; use tables for gates; keep negative results and rollback decisions explicit.
- Citation style: IEEE numbered references in the final manuscript; planning files may use run IDs and direct project paths.
- Number rule: every quantitative statement must link to an immutable run or evidence artifact. Rounded headline values must be generated, not copied by hand.
- Naming rule: use `stability-certified equivalent` only after the machine-readable Level 6 acceptance artifact passes every required gate.
